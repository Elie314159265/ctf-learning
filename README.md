# ctf-learning

CTF 学習用リポジトリ。

## daily-vul/

クラウドの scheduled routine「Daily vulnerability summary」が毎日 06:00 (Asia/Tokyo) に
直近24時間の CVE・脆弱性情報をまとめて出力します。

- `daily-vul/en/YYYY-MM-DD.md` — English
- `daily-vul/ja/YYYY-MM-DD.md` — 日本語（内容は英語版と同一）

このリポジトリは Public のため、PoC（実証コード）や具体的な攻撃手順は含めず、
脆弱性の概念的な説明と対策のみを記載する方針です。
