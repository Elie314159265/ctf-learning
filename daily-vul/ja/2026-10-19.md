## 最新 / 悪用確認済み（直近24〜72時間）

### 1. BeyondTrust Remote Support — 認証バイパス (CVE-2026-102764)
- **公開日:** 2026-10-16 に CISA がアラートを出し、KEV に追加。
- **原理・根本原因:** リモートの未認証の攻撃者が初期アクセスを得られる認証バイパス。CISA は、その後の永続化、権限昇格、横展開を報告しています。
- **影響範囲:** BeyondTrust Remote Support 26.2.3 以前。
- **対策:** ベンダーのパッチを適用（サポート対象バージョンでは 24.3.1 以降が修正版と報告）。管理画面のインターネット公開を制限し、不審なアカウントやセッションがないか確認し、CISA KEV のガイダンスに従ってください。

### 2. Nextcloud Collabora アプリ — 未認証の OS コマンド実行 (CVE-2026-110447)
- **公開日:** 2026-10-16〜17 頃（概算）。
- **原理・根本原因:** 入力の不適切な処理により、未認証の攻撃者がサーバー上で OS コマンドを実行できる（CVSS 9.2）。報道によると Web シェル設置に悪用されています。CISA KEV での掲載は未確認です。
- **影響範囲:** Collabora 連携を有効にした Nextcloud サーバー。正確なバージョンは未確認。
- **対策:** 修正版の Nextcloud / Collabora アプリへ更新するか、パッチ適用までアプリを無効化。Web ルート配下に不審なファイルがないか確認し、ログを精査してください。

## Microsoft 月例パッチ — 2026-10-13

CVE の総数は情報源により異なります（約1,100〜1,800件）。正確な数は Microsoft Security Update Guide で確認してください。

- **CVE-2026-96951 — Windows Shell の Mark-of-the-Web バイパス（悪用確認済み）。** Shell の処理におけるコマンドインジェクションにより、ファイルが「インターネットから取得」の保護や警告を回避します。CISA が KEV に追加し、連邦機関の期限は 2026-10-16。深刻度は情報源により CVSS 8.8〜9.5 と分かれています。影響はサポート対象の Windows。**対策:** 2026年10月の累積更新プログラムを適用。
- **CVE-2026-10839 — .NET の信頼できない検索パス（公開済み）。** 認証済みの攻撃者が Windows Defender Application Control の適用を回避できます。**対策:** .NET / Windows の更新を適用。
- **CVE-2026-92707 — MessagePack-CSharp のサービス拒否（公開済み）。** **対策:** MessagePack-CSharp パッケージや影響を受けるコンポーネントを更新。
- **CVE-2026-21413 — Raw Image Extension のヒープバッファオーバーフロー（CVSS 9.8）。** 悪意ある RAW 画像のサムネイル生成時にリモートコード実行が起こり得ます。**対策:** Microsoft Store / Windows Update で拡張機能を更新。（この CVE 番号は古い番号帯のため、要確認です。）
