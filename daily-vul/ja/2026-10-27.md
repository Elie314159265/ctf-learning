## 最新・最優先(直近24〜48時間)

### 1. PHP「PHP2Shell」— CVE-2026-109618 / CVE-2026-109619(Critical、悪用確認済み)
- **公開日:** 2026-10-21 に修正版リリース(予定より少し前に詳細が漏えいしたとの報道あり)。2026-10-26 に CISA KEV へ追加(連邦機関の対応期限は 2026-10-29)。
- **深刻度:** CVSS v4.0 9.2(9.8 とする情報源もあり)。
- **原理・根本原因:** いずれも、PHP エンジンが内部状態の更新途中でリクエスト処理から抜け出し、その中途半端な状態を後で信頼してしまうことが原因です。CVE-2026-109618 は multipart ボディ解析中のメモリ不足処理におけるメモリ破壊、CVE-2026-109619 は同一ワーカー上で前のリクエストの状態が次のリクエストに残ることによる use-after-free です。組み合わせにより認証不要のリモートコード実行につながり得ます。
- **影響範囲:** 修正前の PHP 全般(PHP 5.4 〜 8.5.x に遡るとの報告)。インターネット上の露出が非常に大きい(Censys: 影響の可能性があるバージョンを示すサービスが約 3,670 万件)。
- **対策:** PHP 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 へアップグレード、または旧系統はディストリビューションのバックポートを適用。CMS やプラグインの更新だけではエンジンの脆弱性は解消されません。暫定対策として、セッションのアップロード進捗機能の無効化(`session.upload_progress.enabled=Off`)、リクエストボディサイズの制限、ワーカーの異常終了の監視が報告されています。
- **注記:** 一部の第三者トラッカーは、確認時点で MITRE/NVD に CVE レコードが見えないなどレコードの一部に異議を唱えています。ベンダーと主要メディアは実在の脆弱性として扱っています。php.net で確認してください。

### 2. Node.js / Google Brotli デコーダの境界外書き込み — CVE-2026-111497(High〜Critical)
- **公開日:** Node.js セキュリティリリースは 2026-10-21(計 10 件の CVE、うち High 4 件)。Brotli エコシステム全体の告知は 2026-10-23/24。
- **原理・根本原因:** Google の Brotli 解凍ライブラリが、細工された信頼できない圧縮データを復号する際に境界外メモリ書き込みを起こします。攻撃者が与えたコンテンツを復号するサーバー/クライアントでリモートコード実行の可能性があります。CVSS v4.0 9.2(Google 評価)、Node.js は High と評価。
- **影響範囲:** 修正前の Node.js 22.x / 24.x / 26.x。EOL 系統(20.x 以前)は影響を受け、パッチも提供されません。Google Brotli 1.0.3〜1.2.0、Python の `Brotli` / `brotlicffi`、Perl の `IO::Compress::Brotli`(0.004001 以上 0.023 未満)。Brotli を同梱する他製品(後述の .NET を含む)も影響する可能性があります。
- **対策:** Node.js を 22.23.4 / 24.22.1 / 26.12.1 へ更新。Node.js バイナリは Brotli を内包しているため、OS の libbrotli や npm パッケージの更新では解消しません。Brotli を 1.0.10 / 1.1.1 / 1.2.1 以降、Python `Brotli` 1.2.1 / `brotlicffi` 1.2.1.0、Perl モジュール 0.023 以降へ更新。EOL の Node.js から移行。修正適用までは信頼できない送信元の Brotli コンテンツの復号を避けてください。

### 3. Microsoft .NET 緊急セキュリティ更新 — CVE-2026-111497(Brotli)および CVE-2026-114148
- **公開日:** 2026-10-25 に .NET 8、9、10、11 RC3 向けの緊急パッチが報じられました(単一情報源。記事間で CVE 番号が異なるため Microsoft の公式アドバイザリで確認してください)。
- **原理:** Brotli 解凍時のバッファ/境界の欠陥(上記と同じ上流ライブラリの問題)と、tar アーカイブ展開時の所有者メタデータの安全でない扱いによるローカル権限昇格(CVE-2026-114148)。
- **対策:** 最新の .NET ランタイム/SDK のサービス更新を適用し、自己完結型アプリは再ビルド・再デプロイ。信頼できない tar アーカイブを高い権限で展開しないこと。

### 4. Nextcloud 向け Collabora CODE Server(richdocumentscode)— CVE-2026-110447(Critical、悪用確認済み)
- **公開日:** 2026-10-23/24 頃に CISA KEV へ追加。悪用は正式な告知の約 1 か月前の 9 月中旬から始まっていたと報じられています。
- **原理:** 内蔵 CODE サーバーアプリの `proxy.php` エンドポイントにおける OS コマンドインジェクションで、認証不要のリモートコード実行につながります。悪用には内蔵 CODE サーバーが停止状態(再起動・アップグレード・クラッシュ後など)である必要があります。Nextcloud サーバーに Web シェルが設置された事例が報告されています。
- **影響範囲:** `richdocumentscode` 26.4.303 より前。スタンドアロンの Collabora Online、Docker、RPM/DEB、Nextcloud All-in-One は影響なしと報告されています。
- **対策:** 26.4.303 以降へ更新、またはアプリを削除(無効化だけでは不十分)。Nextcloud の Web ルート配下の不審なファイルや Web シェルを調査し、Web サーバーログを確認、侵害の疑いがあれば認証情報を更新してください。

### 5. Arista VeloCloud Orchestrator(オンプレミス)— CVE-2026-114625(悪用確認済み)
- **公開日:** 2026 年 10 月に修正。2026-10-24 頃に CISA KEV へ追加(The Hacker News による。CISA 自身のアラートは未確認)。
- **原理:** SQL インジェクションにより、リモートの攻撃者が特権的な内部機能にアクセスできる可能性があります。
- **影響範囲:** 修正版より前のオンプレミス版 VeloCloud Orchestrator(影響範囲の詳細は入手した情報源では未確認)。
- **対策:** 各系統の 5.2.3.18 / 6.1.3.10 / 6.4.2.12 へ更新。管理インターフェースの公開を信頼できるネットワークに限定。
