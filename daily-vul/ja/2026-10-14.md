## 最新項目(直近24〜48時間)

### 1. CVE-2026-104935 — Ivanti Connect Secure:認証不要のリモートコマンド実行(ゼロデイ)
- **開示日:** Ivanti が限定的な悪用を認め、CISA が 2026-10-13 に KEV へ追加(期限 2026-10-16)。
- **原理・根本原因:** VPNアプライアンスのネットワーク公開サービスの欠陥により、リモートの認証なし攻撃者が任意のコマンドを実行できる。具体的な欠陥の種類は入手可能な情報では未確認。
- **影響範囲:** Ivanti Connect Secure 22.x および 25.x 系(正確な影響ビルドは未検証)。
- **緩和策:** Ivanti のアドバイザリにある修正版(22.x / 25.x)を適用。Integrity Checker Tool の実行、ログ確認、侵害が疑われる場合は初期化と認証情報のローテーション。管理インターフェースの公開を制限。

### 2. CVE-2026-96951 — Windows Shell セキュリティ機能バイパス(Mark of the Web)
- **開示日:** 2026-10-13(Microsoft 10月月例パッチ);実環境で悪用;CISA KEV、期限 2026-10-16。
- **原理・根本原因:** Windows Shell のロジック欠陥により、信頼できない発信元のコンテンツが Mark-of-the-Web タグを失う/回避し、SmartScreen や保護ビューの警告が表示されない。ユーザーが配信されたファイルを開く必要があり、通常はフィッシング攻撃チェーンの一段階として使われる。
- **影響範囲:** サポート対象の Windows クライアント/サーバー(正確な一覧は未検証。MSRC を参照)。
- **緩和策:** 2026年10月の累積更新プログラムを適用。メールゲートウェイで危険な添付形式をブロックし、ユーザー教育を継続。
- **補足:** 月例パッチの修正CVE数は過去最多(報告値は 1,407〜1,415)。公開済みの他の項目:CVE-2026-108398(.NET Framework)、CVE-2026-92707(MessagePack-CSharp、DoS)。後者の悪用有無は報告が食い違う。Windows 11 24H2 Home/Pro はサービス終了。

### 3. CVE-2026-0322(PAN-OS)および CVE-2026-76519(Cisco Secure Email Gateway)— 2026-10-14 CISA KEV 追加
- CISA の 2026-10-14 付アラートは、PAN-OS のコードインジェクションと Cisco Secure Email Gateway のパストラバーサルを悪用確認済みとして掲載。いずれのIDもベンダー詳細を確認できず、Cisco 製品の検索では別のCVE番号も表示されたため、ID を確認すること。
- **緩和策:** Palo Alto Networks と Cisco PSIRT のアドバイザリを確認し、修正版を適用、管理インターフェースの公開を制限。パストラバーサルは一般にユーザー指定パスの正規化不足、コードインジェクションは未検証の入力がインタプリタに到達することで発生する。

### 4. CVE-2026-105133 & CVE-2026-105134 — AhsayCBS 認証バイパス+コード実行
- **開示日:** 悪用の初観測は 2026-10-07(Huntress);KEV は 2026-10-14。
- **原理:** 一方の欠陥はバックアップ管理コンソールの認証をバイパスし、もう一方はコード実行(SYSTEM 権限と報告)を許す。連鎖により認証不要のRCEとなる。観測された事後活動:Webシェル設置と暗号資産マイナー。
- **影響範囲:** AhsayCBS 10.3.2 以前;10.3.4 については報告が食い違う。Ahsay は 2026-10-10 に v10.3.4.0 では完全に修正されていないと表明。
- **緩和策:** ホットフィックス v10.3.4.45 を適用して再起動。管理インターフェースを信頼できるネットワークに限定し、不審なJSPファイルやマイニングプロセスを調査。

## 今週のその他の注目項目

### 5. CVE-2026-104286 — Fortinet FortiMail パストラバーサル/認証不要のファイル書き込み(CVSS 9.8)
- **開示日:** KEV 2026-10-01;ゼロデイとして悪用(Fortinet FG-IR-26-175)。
- **根本原因:** ファイルパスの検証不足により、認証なしのリクエストで本来のディレクトリ外にファイルを書き込める。
- **影響範囲:** FortiMail 8.0.0–8.0.1、7.6.0–7.6.6、7.4.0–7.4.8、7.2.0–7.2.9(上限は情報源により異なる)。
- **緩和策:** 公開され次第 8.0.2、7.6.7、7.4.9 へアップグレード。7.2 向け修正は報告されておらず、移行を計画。回避策:IBE の無効化、管理アクセスの制限。

### 7. CVE-2026-102255 — SonicWall SMA1000 認証前SSRF(CVSS 10.0)
