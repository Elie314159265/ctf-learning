## 1. CVE-2026-114938 — 「Java4Shell」：OpenJDK HotSpot Base64 デコーダのヒープオーバーフロー

**原理・根本原因：** HotSpot JVM のハードウェアアクセラレーション（イントリンシック）Base64 デコーダにおけるヒープバッファオーバーフロー。AVX-512 VBMI 命令セット拡張に対応した x86-64 CPU 上では、JIT が生成するベクトル化デコード処理が特定の入力に対してバッファ境界を正しく扱えず、攻撃者が与えた Base64 データのデコード時に出力先バッファの範囲外へ書き込みが発生し得ます。信頼できない入力の Base64 デコードは非常に一般的（HTTP 認証ヘッダ、JWT、SAML、API ペイロードなど）なため、Jira、Jenkins、Keycloak などを含む多くの Java サーバアプリケーションで認証前に脆弱なコードパスへ到達でき、認証前リモートコード実行のリスクがあります。上流の修正は小規模です（JDK-8393212 として追跡）。

**緩和策：**
- JDK/JRE を修正済みビルドに更新：上流 OpenJDK **17.0.21.1、21.0.13.1、25.0.5.1、27.0.1.1**（以降）、または CVE-2026-114938 を明記したベンダービルド（例：Amazon Corretto 17.0.21.1.2 / 21.0.13.1.2 / 25.0.5.1.2 / 27.0.1.1.4、Azul Zulu 2026年11月アップデート、Oracle Java SE 8 Enterprise Performance Pack 8u513-perf）。
- 独自の JRE を同梱するコンテナイメージやアプリケーションを再ビルド・再デプロイすること。ホストの JDK を更新するだけでは同梱ランタイムは修正されません。
- ディストリビューションのパッケージ状況を追跡：執筆時点で Red Hat（RHSB-2026-018）および Debian 安定版の修正は未提供、Eclipse Temurin のビルドは順次提供中です。ベンダービルドが提供されるまで、AVX-512 対応ハードウェア上のインターネット公開 Java サービスを優先してください。
- CISA（2026-11-17 アラート）は即時のパッチ適用を強く求めています。

**影響範囲：** AVX-512 VBMI 対応の x86-64 Intel/AMD CPU 上で動作する、修正ビルドより前の OpenJDK 系ランタイム **17.0.6 以降、21、25、27**。影響なしと報告：Java 8（標準版）、Java 11、17.0.0〜17.0.5、ARM64。2026-11-17 公開・修正。2026-11-18 時点で実際の悪用は未確認。

## 2. CVE-2026-129448 — Apache Roller の認証不要 XML-RPC デシリアライゼーション RCE

**原理・根本原因：** Roller の XML-RPC エンドポイント（`/roller-services/xmlrpc`）がベンダー「拡張」型を受け入れる設定になっており、リクエスト送信者の認証確認**より前に**それらを Java オブジェクトへデシリアライズしていました（CWE-502、信頼できないデータのデシリアライゼーション）。そのため、認証されていないリモート攻撃者がサーバ上で攻撃者の影響下にあるオブジェクトを生成させ、コード実行に至る可能性があります。脆弱なバージョンでは、デシリアライズがその設定の参照より前に行われるため、管理画面で XML-RPC を無効化するだけでは不十分です。

**緩和策：**
- **Apache Roller 6.1.6 以降**へアップグレード（現行リリースは 6.1.7）。
- 直ちに更新できない場合：`WEB-INF/web.xml` で `enabledForExtensions` を `false` に設定するか、XML-RPC サーブレットのマッピングを削除し、Roller を再起動。
- 悪用が確認されているため、侵害の兆候（不審なプロセス、Web シェル、外向き通信）がないかサーバを確認。

**影響範囲：** Apache Roller 4.0.0〜6.1.4（6.1.5 における同様の問題は CVE-2026-82384 として別途追跡）。2026-11-18 に Apache が実際の悪用を確認。

## 3. CVE-2026-115731 — Puppet Server レポート処理におけるデシリアライゼーション RCE

**原理・根本原因：** Puppet Server のレポート処理コンポーネントにおける、信頼できないデータの不適切なデシリアライゼーション。エージェントは「リッチデータ」型を含み得る実行レポートを送信しますが、サーバは許可する型を十分に制限せずに再構築していました。CA 署名済みのエージェント証明書を持つクライアントであれば、細工したレポートを送信して Puppet Server 上で Puppet サービスアカウント権限でのコード実行を引き起こせます。これは構成管理のコントロールプレーン、ひいては管理対象のフリート全体の侵害に等しいものです。証明書の自動署名（autosign）を緩く設定している環境では署名済み証明書の入手が容易になるため、リスクが高まります。

**緩和策：**
- **Puppet Enterprise 2023.8.13（LTS）、2025.12.1、2026.0.1**、オープンソース版 **Puppet Core 8.22.2 / 9.1.3**、OpenVox Server **8.18.0 / 9.2.0** 以降へアップグレード。修正を読み込ませるため、更新後に Puppet Server を再起動。
- 証明書の自動署名設定を監査・厳格化し、署名済みエージェント証明書の一覧を確認して想定外のものを失効。
- Puppet サービスアカウントによる異常な活動を調査。CISA の連邦機関向け期限：2026-12-01。

**影響範囲：** Puppet Enterprise 2023.8.0〜2023.8.12、2025.0.0〜2025.12.0、2026.0.0。Puppet Core 8.22.1 以前、9.1.2 以前。Perforce が 2026-11-03 に修正、悪用確認を受けて 2026-11-17 に CISA KEV に追加。

## 4. CVE-2026-123039 — Check Point DynamicCLI のローカル権限昇格

**原理・根本原因：** Check Point Security Gateway および Security Management サーバの DynamicCLI デーモンにおける、重要リソースへの不適切な権限割り当て（CWE-732）。低権限のローカルプロセスが本来アクセスできないはずの特権リソースを操作でき、root へ権限昇格できます。観測された攻撃では攻撃チェーンの第2段階として使われており、まず「PHP2Shell」と呼ばれる Mobile Access ポータルの脆弱性（CVE-2026-109618 / CVE-2026-109619）で初期侵入し、その後本脆弱性でアプライアンスの root 権限を取得しています。

**緩和策：**
- CVE-2026-123039 に対応した Check Point のホットフィックス／Jumbo Hotfix Accumulator を適用し、PHP2Shell の修正も適用済みであることを確認。
- Mobile Access が不要であれば無効化し、必要な場合はポータルの公開範囲を制限。
- 10月下旬以降に未修正のまま公開されていたアプライアンスは侵害の可能性があるものとして調査。

**影響範囲：** Check Point Security Gateway および Security Management 製品（正確なバージョンはベンダーアドバイザリを参照）。2026-10-30 から悪用を観測、2026-11-13 CISA KEV に追加。

## 5. CVE-2026-114713 — UnrealIRCd labeled-response モジュールのコマンドインジェクション

**原理・根本原因：** labeled-response モジュールにおける区切り文字の不適切な無効化（CWE-140）。リンクされたサーバ間で中継されるメッセージデータが正しく区切られておらず、一般の非特権ユーザーに由来する内容が、相手側サーバでサーバレベルのプロトコルコマンドとして解釈され得ます。2台以上のサーバがリンクされたネットワークでは、一般ユーザーがサーバ権限で操作できてしまいます。

**緩和策：**
- **UnrealIRCd 6.2.7.1 以降**へアップグレード。
- 直ちに更新できない場合は labeled-response モジュールの無効化を検討し、サーバが他サーバとリンクしているかを確認。

**影響範囲：** UnrealIRCd 6.0.0 から 6.2.7.1 未満。2026-11-13 CISA KEV に追加。

## 6. VSA-2026-062 — Vates Xen Orchestra の認証バイパス

**原理・根本原因：** セッション Cookie 処理の欠陥。認証 Cookie の値はオブジェクトとして解析されますが、不正な値によって空のオブジェクトが生成され、それがトークンプロバイダに渡されると、フェイルオープンして特権（管理者）トークンが返されます。その結果、認証なしで Xen Orchestra の管理者権限を取得でき、管理対象プールの制御や XCP-ng ホストの root 取得につながります。別のアドバイザリ VSA-2026-063（VM インポート処理における権限の問題）が攻撃で組み合わせて使われたと報告されています。

**緩和策：**
- **Xen Orchestra 6.9.2（stable）または 6.10.1（latest）** 以降へアップグレード（Xen Orchestra Appliance（XOA）を含む）。
- Xen Orchestra をインターネットに公開せず、専用の管理ネットワークに配置。Vates が公開した IOC（IP／ドメイン）をブロック。
- 監査ログおよびハイパーバイザーホストに不正な管理操作がないか確認。

**影響範囲：** Xen Orchestra 6.9.2 未満（stable チャネル）および 6.10.1 未満（latest チャネル）。2026-11-10/11 に悪用中として公開。執筆時点で CVE は未採番。

## 7. CVE-2026-125350 — Google Chrome XML の Use-After-Free（ゼロデイ）

**原理・根本原因：** Chrome の XML 処理コンポーネントにおける use-after-free。XML 関連オブジェクトのメモリが参照が残ったまま解放され、その後アクセスされます。細工された Web ページによってメモリ破壊を引き起こし、レンダラー内でのコード実行につながる可能性があります。Google は実環境でのエクスプロイトの存在を確認しています（2026年に悪用された Chrome ゼロデイとして8件目）。

**緩和策：**
- **Chrome 157.0.8103.50/.51**（Windows/macOS）、**157.0.8103.50**（Linux/Android）、または Extended Stable **156.0.8078.96** へ更新し、ブラウザを再起動。
- その他の Chromium ベースのブラウザ（Edge、Brave、Opera、Vivaldi）も各ベンダーの修正提供に合わせて更新。CISA の連邦機関向け期限：2026-11-24。

**影響範囲：** 上記バージョンより前の Chrome デスクトップ版および Android 版。2026-11-09 パッチ公開。

## 8. CVE-2026-124194 — Microsoft Outlook のスプーフィング／NTLM ハッシュ漏えい（ゼロデイ）

**原理・根本原因：** Outlook のスプーフィング脆弱性。被害者が細工されたメッセージファイルを開くと、Outlook が攻撃者の管理するリソースへの認証を開始するよう誘導され、ユーザーの NTLM(v2) 認証ハッシュが漏えいする可能性があります。漏えいしたハッシュはオフラインでの解析や他サービスへのリレーに悪用され得ます。

**緩和策：**
- 2026年11月の Office/Outlook セキュリティ更新プログラム（Patch Tuesday、2026-11-10）を適用。
- インターネット向けの外向き SMB（TCP 445）をブロック。重要ユーザーの Protected Users グループへの追加や、SMB/LDAP 署名・EPA の強制によりリレーの効果を低減することを検討。

**影響範囲：** Microsoft 365 Apps for Enterprise、Office LTSC 2021 および 2024（ビルドは Microsoft セキュリティ更新プログラムガイドを参照）。実環境で悪用済み。過去最多規模（1,200件超の CVE）の Patch Tuesday の一部。

## 9. CVE-2026-116606 & CVE-2026-111560 — Barracuda ESG の認証前バイパス＋コマンドインジェクション

**原理・根本原因：** CVE-2026-116606 は Barracuda Email Security Gateway における代替パスによる認証バイパス（CWE-288）で、構成バックアップのインポート機能にログインなしで到達できます。CVE-2026-111560 は複数の Barracuda 製品に共通する OS コマンドインジェクションです。両者を組み合わせると、認証されていない攻撃者がアプライアンスの root 権限を取得できます。

**緩和策：**
- ESG：**9.4.0.030 以降**へアップグレード（両 CVE を修正）。
- ADC、Backup/Message Archiver（BMA）、WCC、WAF、Web Security Gateway：Barracuda のアドバイザリに記載のパッチを適用。
- 管理インターフェースを信頼できるネットワークに限定し、侵害の兆候を確認。

**影響範囲：** ESG 9.4.0.030 未満。CVE-2026-111560 は ADC 6.4.0 以前、BMA 5.5.4.0 以前、WCC 2.2.1 以前、WAF 11.0.1 以前、WSG 16.1.100.100 以前も対象。2026-11-10 CISA KEV に追加。

## 10. CVE-2026-20320 — Cisco BroadWorks OCI の XXE／CVE-2026-111793 — Openwave Webtop

**原理・根本原因：** CVE-2026-20320 は BroadWorks Open Client Interface（OCI）の XML パーサにおける XML 外部実体（XXE）の脆弱性で、外部実体の解決が無効化されていないため、認証なしの XML 入力によってサーバが機密の構成情報を開示し得ます。CVE-2026-111793 は Openwave Messaging Webtop Media Transcoder において管理者が定義したファイル種別制限が強制されておらず、認証済みユーザーが想定外のファイル種別を変換できる問題です。

**緩和策：**
- BroadWorks：**RI.2026.07 以降**へアップグレード（回避策なし）。OCI の公開範囲を信頼できるネットワークに限定。
- Openwave Webtop Media Transcoder：**1.1.22.0 以降**へアップグレード。
- CISA の連邦機関向け期限：2026-11-24。

**影響範囲：** RI.2026.07 より前の Cisco BroadWorks、1.1.22.0 より前の Openwave Webtop Media Transcoder。2026-11-10 CISA KEV に追加（通信事業者を狙った攻撃との関連が報じられています）。

## 11. （継続）CVE-2026-111357 & CVE-2026-118527 — Ivanti Connect Secure の連鎖ゼロデイ

**原理・根本原因：** CVE-2026-111357 は重要な機能に対する認証の欠如で、権限昇格を可能にします。CVE-2026-118527 は予測可能な識別子の生成により、認証済みユーザーが既知の場所へファイルをアップロードできる問題です。以前の認証バイパス CVE-2026-104935 と組み合わせて、攻撃者（UTA0576 として追跡）が認証なしで root 権限のコード実行を達成しており、少なくとも 2026-10-01 から攻撃が続いていました。

**緩和策：** **Ivanti Connect Secure 25.1.1.3 または 22.8R2.6** へアップグレード（回避策なし）。Ivanti の整合性チェックツールを実行し、公開されていたアプライアンスを調査。

**影響範囲：** Connect Secure 25.1.1.2 以前、22.8R2.5 以前。2026-11-02 パッチ公開。

## 12. （継続）CVE-2026-107441 — Zyxel GS1900 の認証前境界外書き込み

**原理・根本原因：** スイッチファームウェアの Web CGI プログラムにおける、ログイン前に到達可能な認証不要の境界外書き込み。以前の CVE-2026-7273 と同じコード内に存在するため、6月の修正を適用したスイッチも引き続き悪用可能でした。約1,000台のデバイスが侵害されたと報告されています。

**緩和策：** すべての GS1900 モデルを対応する **V2.90 Patch 3（「.3C0」）ファームウェア**へ更新（例：GS1900-8 → 2.90(AAHH.3)C0）。スイッチの管理画面を信頼できないネットワークに公開しないこと。

**影響範囲：** Patch 3 より前のファームウェアを搭載した Zyxel GS1900 シリーズ10機種。2026-11-03 公開。
