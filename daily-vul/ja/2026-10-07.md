## 1. CVE-2026-104286 — Fortinet FortiMail パストラバーサル / 任意ファイル書き込み(ゼロデイ)

**原理・根本原因:** パス名の制限不備(CWE-22)とNULLバイト処理の不備(CWE-158)の組み合わせ。細工したHTTP/HTTPSリクエストにより、認証なしで本来のディレクトリ外にファイルを書き込める。メールゲートウェイ上の任意ファイル書き込みはコード実行や永続化につながり得る。

**対策:**
- Fortinetは修正版として 7.4.9、7.6.7、8.0.2 を「近日公開」と記載。開示時点では未提供。アドバイザリ FG-IR-26-175 を確認し、公開次第アップグレード。
- 暫定策: IBE(Identity-Based Encryption)機能の無効化、管理インターフェースのインターネット公開の遮断。
- 公開されていたアプライアンスは侵害有無(不審なファイル、設定変更)を調査。
- 7.0はサポート終了、7.2は修正予定なしとの報告あり — 移行を計画。

**影響範囲:** FortiMail 8.0.0–8.0.1、7.6.0–7.6.6、7.4.0–7.4.8、7.2.0–7.2.9(情報源により上限が異なる。7.0も影響の可能性)。**開示日:** 約2026-10-01。CISA KEV登録 2026-10-01(連邦機関の期限 2026-10-04)。

## 2. CVE-2026-102489 / CVE-2026-102490 — Zammad セッション固定 + ローカル権限昇格

**原理・根本原因:** CVE-2026-102489 はセッション固定の欠陥で、セッション乗っ取りから `zammad` サービスユーザーとしてのコード実行に至る。CVE-2026-102490 は権限管理の不備で、そのローカルユーザーがrootへ昇格できる。連鎖するとホスト全体が侵害される。オランダのDIVD(Dutch Institute for Vulnerability Disclosure)への攻撃で悪用された。

**対策:**
- Zammad 7.2.0 へアップグレード(推奨。関連コードも強化)。DIVDはZammad 7への移行、または影響インスタンスの停止を推奨。
- アップグレード前にアプリ/ネットワークログを保全し、侵害の兆候を確認。
- 注意: Zammad GmbHはDIVDの指摘の一部に異論を唱えており、2026-10-05時点で正式なベンダーアドバイザリやCVE-2026-102490の修正確認は見つからなかった。再確認すること。

**影響範囲:** CVE-2026-102489: Zammad 6.3.0–6.5.4(7.0.0–7.1.3は該当コードを含むが悪用不可と報告)。CVE-2026-102490: 1.5.0〜7.1.0-alphaと報告(情報源により不一致)。**開示日:** KEV登録 2026-10-02(連邦機関の期限は 2026-10-05 と報告)。

## 3. CVE-2026-88779 — Citrix NetScaler ADC / Gateway SAMLメモリ処理の欠陥(DoS)**[未確認]**

**原理・根本原因:** SAML処理経路のメモリバッファ処理の欠陥により、サービスがクラッシュし認証・リモートアクセスがDoS状態になる。過去のCitrixの脆弱性のように、より深刻な影響へ発展し得ると研究者は警告。このCVE IDは独立したデータベースでは確認できなかった。

**対策:** Citrixの最新ブレティンを確認し、修正済みビルドを適用。最低限、項目6の修正ビルド(14.1-73.37以降 / 13.1-64.23以降)を適用し、新ブレティンで確認。SAML設定の仮想サーバーの公開範囲を制限。

**影響範囲:** SAML構成のNetScaler ADCおよびGateway。**開示日:** 約2026-10-04(KEV登録、期限2026-10-07との情報)— 未確認。

## 4. CVE-2026-21589 — Atlassian Jira / Confluence / Bitbucket の重大な欠陥 **[未確認]**

**原理・根本原因:** 認証不要のファイル開示の欠陥と報告されている。正確なパスが分かれば、Webルート内のファイルを読み取れる。詳細な技術解説の公開から数時間でハニーポットで悪用が観測された。このCVE IDや修正版は独立には確認できなかった。

**対策:** Atlassianのセキュリティ情報を確認し、最新のData Center/Server版を適用。インターネット公開を制限し、不審なファイル要求をログで監視。

**影響範囲:** Jira、Confluence、Bitbucket(正確なバージョンは未確認)。**開示日:** 2026年10月第1週ごろ。CISA KEVでは未確認。

## 5. CVE-2026-76504 — Cisco Catalyst SD-WAN Manager APIの認証バイパス

**原理・根本原因:** Manager APIにおける認証不要の認証バイパス。有効な資格情報なしでリクエストが認可され、設定に関係なくSD-WANコントロールプレーンの管理者権限が得られる。

**対策:**
- 回避策なし。各系統(20.9、20.12、20.15、20.18、26.1、26.2)の修正版へアップグレード。20.9より前は修正版へ移行が必要。
- 2026年9月に信頼できないネットワークから到達可能だったManagerは侵害された可能性があるとみなし、ログ確認と、パッチ適用後の資格情報・鍵のローテーションを実施。

**影響範囲:** Cisco Catalyst SD-WAN Manager 26.2、26.1、20.18、20.15、20.12、20.9およびそれ以前。**開示日:** Ciscoは2026年9月に悪用を認知。CISA KEV 2026-09-30(期限 2026-10-03)。

## 6. CVE-2026-88771 / CVE-2026-88772 — Citrix NetScaler ADC / Gateway 重大ゼロデイ(参考)

**原理・根本原因:** CVE-2026-88771 は入力検証の不備により、認証なしでコマンド実行が可能(既定構成でも該当)。CVE-2026-88772 はDTLS有効時(VPN vServerで既定)のメモリオーバーフローで、コード実行またはDoSにつながる。根本原因の分析が公開され、大規模な悪用が広がっている。

**対策:**
- 14.1-73.37以降 または 13.1-64.23以降へアップグレード(FIPS: 14.1-73.37 FIPS以降、13.1-37.279以降)。ブレティン CTX697096。
- DTLS無効化はCVE-2026-88772のみ緩和。
- パッチ適用は過去に侵害されていないことを意味しない — 侵害の兆候を確認。

**影響範囲:** NetScaler ADCおよびGateway(FIPS/NDcPP含む)、NetScalerを使うSecure Private Access Hybrid。**開示日:** 2026-09-27(ブレティンおよびCISA KEV)。
