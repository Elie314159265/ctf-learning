## 1. CVE-2026-88771 / CVE-2026-88772 — Citrix NetScaler ADC / Gateway のリモートコード実行(ゼロデイ)

**原理・根本原因:** CVE-2026-88771 は不適切な入力検証の欠陥で、特別な機能を有効にしていないデフォルト構成も影響を受けます。CVE-2026-88772 はメモリオーバーフロー(メモリ安全性)の欠陥で、DTLS 有効時(VPN 仮想サーバーではデフォルトで有効)に到達可能です。いずれも認証なしでアプライアンス上のリモートコード実行につながり得ます。開示前に Web シェルの設置や永続化に悪用されたと報じられています。

**緩和策:**
- NetScaler ADC/Gateway 14.1-73.37 以降、13.1-64.23 以降(13.1系)、14.1-FIPS 14.1-73.37 以降、13.1-FIPS / 13.1-NDcPP 13.1-37.279 以降へアップグレード。
- パッチ前から悪用されていたため、インターネット公開アプライアンスで Web シェルや不審な永続化を調査し、アプライアンスが保持する認証情報・セッションを更新。

**影響範囲:** 上記修正版より前の NetScaler ADC および NetScaler Gateway。修正は 2026-09-27 公開、同日 CISA KEV 追加。

## 2. CVE-2026-76504 — Cisco Catalyst SD-WAN Manager の認証バイパス

**原理・根本原因:** 認証バイパスにより、未認証のリモート攻撃者が管理プレーンの管理者権限を取得できます。(注: 以前にも CVE-2026-20127 など関連する Cisco SD-WAN 認証バイパスが存在します。本 CVE 番号自体は他情報源で確認できていません。)

**緩和策:** Cisco のアドバイザリに従い修正版 SD-WAN Manager を適用。管理プレーンの公開を制限し、不正な管理者アカウントや設定変更を確認。

**影響範囲:** Cisco Catalyst SD-WAN Manager(詳細バージョンは Cisco アドバイザリ参照)。2026-09-30 に CISA KEV 追加。

---

## 3. CVE-2026-67279 / CVE-2026-86060 — MikroTik RouterOS の連鎖的な認証バイパス

**原理・根本原因:** CVE-2026-67279 は、SSH 系セッション処理におけるワークフロー(状態)の強制が不適切で、認証完了前に未認証クライアントがチャネル上でコマンド実行要求を行える欠陥です。CVE-2026-86060 と連鎖させることで、パスワードなしに管理コンソールへ完全アクセスされます。

**緩和策:** MikroTik RouterOS の修正版を適用。管理サービス(SSH/WinBox/WebFig)をインターネットに公開せず、送信元 IP で制限。不審なユーザー、スクリプト、スケジューラ項目を監査。

**影響範囲:** インターネットに公開された MikroTik RouterOS 機器(バージョンは MikroTik アドバイザリ参照)。少なくとも 2026-09-02 から攻撃を観測(CERT Polska)。9月下旬に CISA KEV 追加。

## 4. CVE-2026-65660 — Microsoft SharePoint のコードインジェクション

**原理・根本原因:** 攻撃者が影響し得る入力の検証不足によるコードインジェクションで、ネットワーク経由の認可済み攻撃者が SharePoint サーバー上でコードを実行できます。

**緩和策:** Microsoft の SharePoint セキュリティ更新を適用。外部アクセスを制限し、サーバーログやファイルの不審な変更を確認。

**影響範囲:** Microsoft SharePoint Server(バージョンは Microsoft アドバイザリ参照)。2026-09-25 時点で悪用確認、CISA KEV 追加。

---

## 5. CVE-2026-5430(WSO2)および CVE-2026-71362(Adobe Commerce)

**原理・根本原因:** CVE-2026-5430 は、偽造または検証不十分な JWT トークンが WSO2 ゲートウェイコンポーネントで受理される認証バイパスです。CVE-2026-71362 は、既存アカウントや管理者権限なしで Adobe Commerce への不正アクセスを許します。

**緩和策:** ベンダーのパッチ/ホットフィックスを適用。侵害が疑われる場合は署名鍵と API 認証情報をローテーションし、アクセスログで異常なトークン使用や管理操作を確認。

**影響範囲:** WSO2 Universal Gateway および Adobe Commerce(バージョンはベンダー情報参照)。過去1週間に悪用が報告されています。
