## 1. CVE-2026-102489 / CVE-2026-102490 — Zammad のセッション固定および不適切な権限管理

**原理・根本原因:** CVE-2026-102489 はセッション管理の不備(セッション固定/ハイジャック)で、Zammad サービスユーザーとしてのコード実行につながり得ます(報告 CVSS 9.4)。CVE-2026-102490 は不適切な権限管理の欠陥で、Zammad のローカルアカウントが基盤OS上の管理者権限を取得できます。両者を連鎖させると、Web セッションの乗っ取りからコード実行、さらにホスト全体の掌握に至ります。2026-09-21 にオランダの Vulnerability Disclosure Institute(DIVD)への実際の侵害で悪用されました。

**緩和策:**
- ベンダーのアドバイザリーに従い、Zammad を最新の修正版へ更新する。
- 不審なセッション、新規の管理者/特権アカウント、異常な外向きデータ転送がないか確認し、侵害の疑いがある場合はシークレットとセッションを更新する。
- Zammad のネットワーク露出を制限し、最小権限で稼働させる。

**影響を受けるもの:** CVE-2026-102489:Zammad 6.3.0〜6.5.4。CVE-2026-102490:Zammad 1.5.0 〜 プレリリース 7.1.0-alpha 未満。**開示日:** 技術詳細と CVE は 2026-09-30 に公開、2026-10-02 に CISA KEV 登録。

## 2. CVE-2026-104286 — Fortinet FortiMail のパストラバーサル/任意ファイル書き込み(ゼロデイ)

**原理・根本原因:** HTTP/HTTPS リクエスト内のパストラバーサル文字列とヌルバイトの不適切な処理により、認証不要のリモート攻撃者が基盤システム上に任意のファイルを書き込め、コード実行につながり得ます。CVSS 9.8。

**緩和策:**
- 修正版 8.0.2、7.6.7、7.4.9 が予告されていますが、報道時点では未リリースです。Fortinet PSIRT を確認し、公開され次第直ちに適用してください。
- 7.2 の利用者は 7.4 以降へアップグレードしてください。
- それまでは管理/Web インターフェースを信頼できるネットワークに限定し、アプライアンス上の不審なファイル書き込みや新規ファイルを監視してください。
- CISA は連邦機関の対応期限を 2026-10-04 に設定しています。

**影響を受けるもの:** FortiMail メールセキュリティゲートウェイ(7.2、7.4、7.6、8.0 系で修正版待ち)。**開示日:** 悪用報告は 2026-10-01 頃、同日 CISA KEV 登録。

## 3. CVE-2026-88771 / CVE-2026-88772 — Citrix NetScaler ADC / Gateway のゼロデイ

**原理・根本原因:** CVE-2026-88771 は入力検証不備により、認証不要でリモートからコマンド実行が可能になる欠陥で、デフォルト構成でも影響を受けます。CVE-2026-88772 はメモリオーバーフローで、DTLS が有効な場合(VPN 仮想サーバーでは既定で有効)にリモートコード実行またはサービス拒否を引き起こし得ます。いずれも単独でリモートコード実行に至り得ます。両方とも CVSS v4.0 で 9.5。

**緩和策:**
- NetScaler 14.1-73.37 以降、または 13.1-64.23 以降へ更新する。FIPS 版は 14.1-73.37 FIPS 以降、13.1 FIPS/NDcPP は 13.1-37.279 以降。
- パッチ未適用でインターネットに公開されていたアプライアンスは侵害されたものとみなし、Web シェルや永続化の痕跡を調査し、認証情報とシークレットを更新する。

**影響を受けるもの:** 上記の修正版より前の NetScaler ADC および NetScaler Gateway。**開示日:** 2026-09-27 にパッチ公開および悪用確認、CISA KEV 登録。

## 4. CVE-2026-86950 — Apple Core Graphics の境界外書き込み(ゼロデイ)

**原理・根本原因:** 細工されたファイルの処理時に Core Graphics で境界外書き込みが発生し、任意コード実行につながり得ます。Apple は、特定の標的に対する「極めて高度な攻撃」で悪用された可能性があると発表しています。Meta Product Security による報告です。

**緩和策:**
- iOS 26.7.1、iPadOS 26.7.1、macOS Tahoe 26.7.1、または macOS Sequoia 15.8.1 へ更新する。
- ハイリスクなユーザーはロックダウンモードの利用を検討する。

**影響を受けるもの:** 上記修正版より前の iOS/iPadOS および macOS(iOS 27 / macOS 27 系は影響なしとみられる)。**開示日:** 2026-09-28。
