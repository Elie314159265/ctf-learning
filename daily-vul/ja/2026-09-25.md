## 1. CVE-2026-86708 — ManageEngine Applications Manager のハードコードされたクラウド認証情報の露出

**原理・根本原因:** Applications Manager のインストーラーパッケージに Google Cloud サービスアカウントの秘密鍵が埋め込まれた状態で同梱されている(CWE-321、ハードコードされた暗号鍵の使用)。このインストーラーを入手できた者は誰でも鍵を抽出し、対象環境に一切触れることなく、そのサービスアカウントとして直接 Google Cloud API に対して認証できてしまう。

**対策:**
- Zoho が該当ブランチ向けに公開する 182200 より新しい修正済みビルドへアップグレードする。
- 埋め込まれた鍵はすでに漏えいしたものとして扱い、関連する Google Cloud サービスアカウントの認証情報をローテーション/失効させ、そのアカウントに紐づく Cloud IAM 監査ログで不審な活動がないか確認する。

**影響範囲:** ManageEngine Applications Manager バージョン 182200 以下。2026-09-24頃開示。執筆時点で実際の悪用は確認されていないが、被害者側インフラへの一切の接触を必要としない性質のため、リスクは高いものとして扱う。

## 2. CVE-2026-59167 — SunEditor のサニタイザバイパス(格納型XSS)

**原理・根本原因:** SunEditor の HTML サニタイザ(`src/lib/core.js` 内)は、名前空間付きまたはカスタムの HTML 要素名を一貫して拒否しない。そのため、非標準の要素タグに細工して付与されたイベントハンドラ属性(例: `onclick`)がサニタイズ処理を通過して残存する場合がある。攻撃者が投入したエディタコンテンツをアプリケーションが描画し、被害者がそのページを操作すると、残存したハンドラがアプリケーションのオリジン上で被害者のブラウザセッション内にてJavaScriptを実行してしまう(CWE-79、格納型クロスサイトスクリプティング)。

**対策:**
- `suneditor` を 2.47.11 以降にアップグレードする。
- SunEditor が生成した HTML を保存し、後で他のユーザーに再描画するアプリケーションは、影響が格納型(永続的)XSSであるため、優先度の高いパッチとして扱うべきである。

**影響範囲:** `suneditor` npmパッケージ、2.47.11より前のバージョン。2026-09-23公開。現時点で悪用の報告はない。

## 3. CVE-2026-86248 — Apache Tomcat の CLIENT_CERT 認証バイパス

**原理・根本原因:** OCSP の「ソフトフェイル」が無効化されている場合、Tomcat の `CLIENT_CERT` 認証は、特定の失効確認エラーシナリオにおいて期待通りにフェイルクローズ(拒否側に倒れる)しない。結果として、本来拒否されるべきクライアント証明書(失効状態を確認できなかったもの)が受理されてしまう可能性があり、CLIENT_CERT で保護されたリソースには有効かつ失効していない証明書が必要という前提が崩れる。

**対策:**
- Tomcat 11.0.26、10.1.60、または 9.0.122 にアップグレードする。
- OCSP失効確認を伴う相互TLSクライアント証明書認証に依存している環境では、本更新を優先的に適用し、CLIENT_CERT保護リソースへの最近のアクセスを監査すること。

**影響範囲:** Apache Tomcat 11.0.0-M14〜11.0.25、10.1.22〜10.1.59、9.0.92〜9.0.121。2026-09-23公開。執筆時点で実際の悪用の報告はない。

## 4. CVE-2026-12227 — Visual Composer Website Builder の未認証ローカルファイルインクルージョン

**原理・根本原因:** 本プラグインのフロントエンドテンプレート読み込みロジック(WordPressの `template_include` フィルタにフックされた `PageTemplatesController`)は、攻撃者が制御可能なリクエストパラメータ `vcv-template`(および `vcv-template-type`)を、解決可能なファイルの範囲を十分に制限しないまま尊重してしまう。これにより、未認証の訪問者がサーバーに任意のファイルをインクルードさせることが可能となり、攻撃者がPHPコードを含むファイル(例: PHPが埋め込まれたアップロード済みの「画像」)を配置または再利用できる場合には、リモートコード実行にまで発展する。

**対策:**
- 修正済みの Visual Composer Website Builder リリースが公開され次第アップデートする。プラグインの変更履歴で本問題を解消したバージョンを確認すること。
- 暫定対策として、Webサーバーまたは WAF レイヤーで `vcv-template`/`vcv-template-type` パラメータを含むリクエストを制限・監視し、予期しないファイルアップロードを監査する。

**影響範囲:** Visual Composer Website Builder(WordPressプラグイン)45.16.0以下。今週開示。公開された技術解説とPoCが存在するため、短期的な悪用リスクが高まっている — 速やかなパッチ適用が必要。

## 5. CVE-2026-19804 — s2Member の未認証リモートコード実行

**原理・根本原因:** 本プラグインの「サインアップ追跡コード」機能は、ユーザーが入力した `first_name` フィールドを組み込んだテンプレートを評価(`eval`)する。既存の入力サニタイズは正規表現の後方参照を除去するのみでPHPタグは除去しないため、細工された `first_name` 値により、評価対象のテンプレートに実行可能なPHPコードを注入できる。さらに、サイト共通のプロキシ検証鍵が漏えいしていることで、攻撃者は正規の取引なしにPayPalのポストバックリクエストを偽造し、脆弱なコードパスを発火させることが可能となっている。

**対策:**
- s2Member をビルド260814より新しいベンダー提供の修正版にアップデートする。
- アップデート後、サイトのプロキシ/ポストバック検証鍵をローテーションする。過去に漏えいした鍵は漏えい済みとして扱うべきである。

**影響範囲:** s2Member(WordPressメンバーシップ/ペイウォールプラグイン)、ビルド260814以下。今週開示。関連する権限昇格の問題(CVE-2026-1994、パスワードリセットの悪用)は2026年の早い時期に修正済み — 両方の修正が適用されているか確認すること。

## 6. CVE-2026-90898 — Bifrost AIゲートウェイの未認証リモートコード実行

**原理・根本原因:** Bifrost の管理APIはデフォルトで認証が無効化された状態で出荷されており、MCP(Model Context Protocol)クライアントを登録するためのエンドポイント(`/api/mcp/client`)を公開している。「stdio」タイプのクライアントを登録すると、プロトコルハンドシェイクや認証情報の確認が一切行われる前に、Bifrostがゲートウェイ自身のプロセスユーザー権限で攻撃者指定のコマンドを直ちに起動してしまう。ゲートウェイは接続中のすべてのAIプロバイダのAPIキーも保持しているため、ゲートウェイ上でのコード実行はそれらの認証情報の漏えいにもつながる。

**対策:**
- Bifrost の HTTP トランスポートを 2.1.0 以降にアップグレードする。
- 管理API認証を明示的に有効化し、パッチ適用後もlocalhost/信頼されたネットワークの外に管理ポートを公開しないこと。
- 同根本原因を共有する関連の脆弱性(CVE-2026-86242、2026-09-06開示、攻撃者制御下のURLから未認証でプラグインを登録可能)も併せて修正すべきである。

**影響範囲:** Bifrost HTTPトランスポート、管理認証がデフォルト(無効)設定のままの2.1.0より前の全バージョン。2026-09-22開示。AIインフラ関連ツールに対する実際の標的型攻撃事例として注目される(拡大しつつある標的カテゴリ)。

## 7. CVE-2026-7273 — Zyxel GS1900シリーズスイッチのスタックベースバッファオーバーフロー(継続: 実際に悪用中)

**原理・根本原因:** スイッチファームウェアのCGI Web管理プログラムに存在するスタックベースバッファオーバーフローにより、LAN隣接かつ未認証の攻撃者が細工したHTTPリクエストを送信することで、固定サイズのバッファをオーバーフローさせ、隣接するスタックメモリを破壊し、デバイス上で任意のOSコマンド実行を可能にする。

**対策:**
- GS1900シリーズ向けのZyxelファームウェア更新を適用する。
- 管理インターフェースへのアクセスを、信頼された管理VLAN/ネットワークのみに制限する。信頼できないLANセグメントやインターネットにスイッチのWeb管理機能を公開しないこと。

**影響範囲:** 脆弱なファームウェアを実行するZyxel GS1900シリーズスイッチ。中国系とみられる攻撃者が2026-08-17以降本脆弱性を悪用しており、難読化されたPythonベースの収集ツールをTFTP経由で配布し、数十か国にわたる約1,000台のスイッチから設定情報・認証情報を窃取・持ち出している。2026-09-21にCISA KEVへ追加され、連邦機関向けの修復期限は短期間に設定された。

## 8. CVE-2026-32996 — Veeam Agent for Microsoft Windows のローカル権限昇格

**原理・根本原因:** Veeam Endpoint Backup サービスはローカルの名前付きパイプ経由で通信を行い、「昇格された管理者」セッションのマーカーを、要求元の特定ユーザーや接続に暗号学的に紐づけられていないセッションUIDをキーとしてキャッシュする。このUIDは標準(非管理者)ユーザーが読み取り可能なサービスログファイルに書き込まれるため、ローカルの低権限ユーザーが有効なUIDを取得し、それを再利用することで、サービスに自らのセッションをすでに昇格済みとして扱わせ、SYSTEM権限でのコマンド実行に至る。

**対策:**
- Veeam Backup & Replication 13.0.2.29 / Windowsエージェントビルド 13.0.3.1220 以降にアップデートする。
- パッチ適用までの間、該当エージェントを実行しているホストへの対話的/ローカルアクセスを制限し、サービスのログディレクトリの権限を強化する。

**影響範囲:** Veeam Agent for Microsoft Windows 13.0.1.2067以下、およびそれ以前のv13ビルド。技術詳細とPoCが2026-09-14に公開され、研究者により2026-09-22頃から実際の悪用試行が報告されている。

## 9. CVE-2026-76460 — Cisco ISE の認証バイパス(継続: 実際に悪用中)

**原理・根本原因:** Cisco Identity Services Engine (ISE) のWeb管理インターフェース内にある特定のAPIエンドポイントが、リクエストを処理する前に認証を強制していない(CWE-648、権限付きAPIの誤用)。当該エンドポイントに到達できるリモートかつ未認証の攻撃者は、権限付きの管理機能を直接呼び出すことができ、認証済みのISE管理者と同等のアクセス権を取得できる。これには、企業全体のネットワークアクセスポリシーを操作する能力も含まれる。

**対策:**
- 修正済みリリース(3.1 Patch 12、3.2 Patch 11、3.3 Patch 12、3.4 Patch 7、3.5 Patch 4、またはそれ以降)を適用する。ISE 3.0はソフトウェアメンテナンス終了に達しているため、移行が必須。
- ISE管理インターフェースへのネットワーク到達性を、信頼された管理ネットワークのみに制限する。

**影響範囲:** 上記修正版より前のCisco ISEおよびISE Passive Identity Connector。2026-09-16にCISA KEVへ追加。今週も継続した悪用と分析が報告されている。

## 10. CVE-2026-76461 — Cisco Secure Email Gateway のSQLインジェクションによるroot権限RCE(継続: 実際に悪用中)

**原理・根本原因:** AsyncOSのメール解析ロジックは、受信メッセージから抽出した特定のデータをバックエンドのSQLクエリで使用する前に十分な検証を行っていない(CWE-89、SQLインジェクション)。脆弱な解析処理はすべての受信メールに対して自動的に実行されるため、未認証の攻撃者は脆弱なゲートウェイに細工したメールを送信するだけでこれを発火させることができ、管理アクセスや対話操作は一切不要である。成功したSQLインジェクションはさらに悪用され、root権限でのOSコマンド実行に至る。

**対策:**
- Ciscoの修正済みAsyncOSリリース(該当ブランチの15.5.5-014、16.0.4-302、16.5.0-780、またはそれ以降)を適用する。
- root権限での侵害により攻撃者が証跡を消去できる可能性があるため、ゲートウェイおよびメールログを確認し、異常な処理や設定変更の痕跡がないか調査する。

**影響範囲:** 脆弱なAsyncOSリリースを実行するCisco Secure Email Gatewayアプライアンス。Ciscoのアドバイザリはサポートケース対応中に発見され2026-09-14に公開され、ほぼ同時期に実際の悪用が確認された。悪用活動と対策ガイダンスに関する議論は今週も続いている。

## 11. CVE-2026-87886 — Acronis Backup プラグインの安全でないデフォルト権限(継続: 実際に悪用中)

**原理・根本原因:** cPanel/WHM、Plesk、DirectAdmin向けのAcronis Backupプラグインは、特定のファイルまたはディレクトリを過度に緩いアクセス制御で設置してしまう(CWE-276、不適切なデフォルト権限)。すでに共有ホスティングサーバー上で低権限の認証済みアクセスを保持している攻撃者は、この脆弱な権限設定を悪用して、より高い権限を持つLinuxアカウントへ昇格できる。

**対策:**
- 修正済みビルド(cPanel/WHM プラグイン 1.9.3.1021以降、Plesk 拡張 1.8.11.638以降、DirectAdmin プラグイン 1.2.3.238以降)にアップグレードする。
- 悪用が確認されて以降、共有ホスティング環境においてAcronisプラグインに関連する権限昇格活動の痕跡がないか監査する。

**影響範囲:** 修正済みビルドより前のcPanel & WHM、Plesk、DirectAdmin(Linux)向けAcronis Backupプラグイン/拡張機能。Acronisが特にcPanel/WHM環境における実際の悪用を確認した後、2026-09-16にCISA KEVへ追加された。

## 12. CVE-2026-69399 — Microsoft Azure Arc の権限昇格(継続)

**原理・根本原因:** ハイブリッド/オンプレミスおよびエッジリソースへAzure管理機能を拡張するために使用されるAzure Arcに、ネットワーク経由の攻撃者がサービスを意図しないプロキシとして動作させ、認証や対話操作なしに権限昇格を引き起こせる欠陥(CWE-441、意図しないプロキシまたは仲介者)が存在した。

**対策:** クラウドサービス側の修正であるため、通常のAzure Arcエージェント更新以上に顧客側で必要な対応は基本的にない。接続済みマシンエージェントが最新のサポート対象バージョンであることを確認し、ベストプラクティスとしてAzure Arc のRBAC割り当てを見直すこと。

**影響範囲:** Microsoft Azure Arcサービス。今週の対象期間の境界にあたる2026-09-17に一般公開された。CVSS最高値であることに加え、ハイブリッドクラウド管理プレーンが高価値な標的であることから掲載する。クラウドホスト型サービスコンポーネントの修復はMicrosoftが管理する。
