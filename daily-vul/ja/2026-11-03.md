## 1. Fortinet の協調セキュリティ更新と開示の延期 (2026-10-22 公開、詳細は 2026-11-10 予定)

**原理・根本原因:** 非公開です。Fortinet は緊急としてアップデートを公開しましたが、CVE ID、CVSS、技術的詳細は 2026-11-10 まで伏せています。専門家は、攻撃者がパッチ適用前後のビルドを比較 (パッチ差分解析) して脆弱性を再発見し、正式開示前に悪用する可能性があると警告しています。

**緩和策:**
- 2026-11-10 を待たず、FortiOS、FortiManager、FortiAnalyzer の最新版 (および最近の FortiMail、FortiAuthenticator の更新) を直ちに適用する。
- 管理インターフェースを信頼できるネットワークに限定し、管理者の異常な操作を監視する。

**影響範囲:** FortiOS、FortiManager、FortiAnalyzer。先行して FortiMail、FortiAuthenticator にも関連更新。具体的なバージョンは未公開です。5つの製品ラインとする情報もありましたが、確認できたのは上記の製品のみです。

## 2. CVE-2026-101767 — Oracle E-Business Suite の SQL インジェクション

**原理・根本原因:** E-Business Suite のコンポーネントにおける SQL インジェクション (データベースクエリへの入力の不適切な無害化)。リモートの攻撃者がバックエンドのクエリを操作できる可能性があります。

**緩和策:** 2026年10月の Oracle Critical Patch Update (約 1,209 件の CVE を修正、うち 6 件が CVSS 10.0) を適用する。EBS のインターネット公開を制限し、異常なクエリパターンを監視する。

**影響範囲:** Oracle E-Business Suite (正確なバージョンは Oracle CPU アドバイザリを参照)。修正の約1週間後にあたる 2026-10-27 以降、ハニーポットでプロービングを観測。Oracle は悪用を報告していません。

## 3. CVE-2026-109619 — 悪用が報告されている (製品不明)

**詳細:** まとめ記事によると、この CVE は悪用が確認され、2026-10-26 から CISA KEV に掲載されています。情報源には製品、根本原因、修正の記載がありませんでした。**対応:** CISA KEV カタログで対象製品と対応期限を確認してください。

## 4. CVE-2026-28336 — SolarWinds Dameware のコマンドインジェクション (*未検証*)

**原理・根本原因:** あるアグリゲータが、OS コマンドインジェクション (CVSS 9.9)、2026-11-03 公開、悪用は未確認として掲載しています。追加検索では SolarWinds などでこの ID の記録を確認できなかったため、情報が不完全または不正確な可能性があります。

**緩和策:** SolarWinds Trust Center のアドバイザリを確認し、更新が公開され次第 Dameware に適用する。Dameware サービスの公開範囲を制限する。
