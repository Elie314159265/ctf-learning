## 最新 / 最優先

### 1. PHP2Shell — CVE-2026-109618 および CVE-2026-109619(PHP本体)
- **公開日:** 2026-10-21 にパッチ公開、2026-10-26 に CISA KEV 追加(連邦機関の期限は 2026-10-29)。パッチ公開前から悪用の試行があったと報告されています。
- **深刻度:** CVSS 9.2(Critical)。認証不要のリモートコード実行。
- **原理・根本原因(概念):** PHP が信頼できないWebリクエスト/アップロードを処理する際の2件の欠陥により、認証されていない遠隔の攻撃者がサーバー側でコードを実行できる可能性があります。公開されている詳細は限定的で、具体的にはPHPのアドバイザリを参照してください。
- **影響範囲:** PHP 5.4 以降の広範なバージョン(8.1 以前は公式修正なし)、および修正版より前の 8.2〜8.5。PHPを使うWebサーバー、CMS、ホスティング基盤が対象。
- **対策:** PHP 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 へ更新。サポート終了ブランチ(8.1以前)はサポート対象ブランチへ移行、またはディストリビューションのバックポートを適用。Webサーバーログで異常なアップロード/リクエストを確認し、Webルート配下の不審なファイルを点検。アップロード処理の制限やWAFルールの適用も検討。

### 2. Brotli「Node2Shell」— CVE-2026-111497(Google Brotli デコーダ)
- **公開日:** 2026-10-21(Node.js が公表)、2026-10-27 に CISA KEV 追加。修正は 2026年2月に助言なしで upstream にコミット済み。
- **深刻度:** Zscaler による CVSS 4.0 評価 9.2(Critical)、CWE-787。
- **原理・根本原因:** Brotli 展開ライブラリが細工された圧縮データを処理する際の境界外書き込みにより、メモリ破壊およびリモートコード実行につながる可能性があります。信頼できない入力(HTTPリクエスト/レスポンス等)を展開するアプリが対象。実環境での悪用と公開PoCが報告されています。
- **影響範囲:** Brotli 1.0.10 / 1.1.1 / 1.2.1 より前。Node.js、.NET、PowerShell、Bun、Envoy、Istio、Python Brotli パッケージなど、Brotliを組み込む下流製品。
- **対策:** Brotli を修正版へ更新。Node.js は 22.23.4 / 24.22.1 / 26.12.1(以降)で修正。コンテナのベースイメージや同梱依存関係を更新・再ビルドし、Brotliを静的に同梱するソフトウェアを棚卸し。パッチ適用まで、信頼できない経路でのBrotli content-encoding の無効化を検討。
