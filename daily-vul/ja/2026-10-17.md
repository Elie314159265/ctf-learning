## 1. CVE-2026-104935 — Ivanti Connect Secure のゼロデイ

**原理・根本原因:** Connect Secure VPNアプライアンスの脆弱性で、攻撃者は権限昇格を含む他の2件と連鎖させて侵害に利用しています。報道によれば、2026年7月の25.1.3.0で部分的に修正され、他の対応ブランチへバックポートされている間に悪用が発生しました。

**緩和策:**
- 修正版へアップグレード(報道: 22.8R2.5、25.1.1.2、25.1.3.0、25.1.3.1 以降)。
- IvantiのIntegrity Checker Toolを実行し、侵害の痕跡を調査(Volexityによれば悪用は2026-10-03頃から)。
- 連鎖内の別の権限昇格の脆弱性は未修正と報じられています。Ivantiの案内に従い、修正リリース後に適用してください。

**影響範囲:** Ivanti Connect Secure。バージョン一覧は情報源で食い違います(CVEレコード: 25.1.3.0より前。他の報道: 22.8R2.4以前、25.1.2.2以前、25.1.1.1以前)。Ivantiのアドバイザリで確認してください。
**公開日:** 2026-10-13(同日CISA KEV追加)。

## 2. CVE-2026-96951 — Windows Shell のセキュリティ機能バイパス(Mark of the Web)

**原理・根本原因:** Windows Shellが細工されたファイルを適切に処理せず、Mark of the Webによる保護(ダウンロード警告、保護ビュー、SmartScreen等によるブロック)が適用されなくなります。メール、チャット、コラボレーションツール、ダウンロード経由の悪意あるファイルを開くと保護が働きません。今年3件目の悪用されたWindows Shellの脆弱性で、過去の修正が不完全だった可能性も指摘されています。

**緩和策:**
- 2026年10月のMicrosoftセキュリティ更新プログラムを全Windows端末・サーバーに適用。
- 不審なファイルへの注意喚起、メール/Webゲートウェイでの危険な添付ファイルの制限。
- CISAの連邦機関向け対応期限は2026-10-16。

**影響範囲:** サポート対象のWindows(詳細なビルドはMicrosoft Security Update Guideを参照)。
**公開日:** 2026-10-13(パッチチューズデー。1,400件超のCVEと異例の規模と報じられています)。

## 3. CVE-2026-110447 — Nextcloud「Collabora Online – Built-in CODE Server」のコマンドインジェクション

**原理・根本原因:** このアプリのプロキシ用スクリプトは、ローカルのドキュメントサーバーが待ち受けていない場合にそれを起動します。この経路でのリクエスト入力の不適切な処理により、認証なしでコマンドインジェクションが可能です。ただしローカルサーバー停止中(再起動、アップグレード、クラッシュ時)に限られます。攻撃者はPHPのWebシェル設置に悪用しています。

**緩和策:**
- アプリ(richdocumentscode)を 26.4.303 以降に更新、または削除。アプリを無効化するだけでは脆弱性は解消されません。
- 予期しないPHPファイルの有無を確認し、Nextcloudの整合性チェックを実行。侵害が疑われる場合は認証情報をローテーション。

**影響範囲:** Collabora Online – Built-in CODE Server アプリの 26.4.303 より前の全バージョン。
**公開日:** アドバイザリ/CVEは2026-10-14。修正は2026-09-11にリリース済み。最初の攻撃は2026-09-10と報告。
