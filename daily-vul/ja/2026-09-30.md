## 1. CVE-2026-76504 — Cisco Catalyst SD-WAN Manager APIの認証バイパス

**原理・根本原因：** 管理APIにおける認証バイパス。特定のAPIリクエストで認証チェックが適用されず、未認証のリモートの攻撃者が本来管理者向けの機能に到達できます。具体的なコードパスは詳細確認中。

**緩和策：**
- Ciscoアドバイザリに記載された、自環境のソフトウェア系列向け修正リリースへアップグレード。
- 管理プレーンへのアクセスを信頼できるネットワークに限定し、インターネットに公開しない。
- APIアクセスログ、不明な管理者アカウントや設定変更を確認。未パッチで公開されていたインスタンスは侵害された可能性を前提に扱う。

**影響範囲：** Cisco Catalyst SD-WAN Manager（具体的バージョンはCiscoアドバイザリ参照）。**公開日：** 2026-09-30；CISA KEV掲載、実環境で悪用中。

## 2. CVE-2026-88771 & CVE-2026-88772 — Citrix NetScaler ADC / Gatewayのゼロデイ

**原理・根本原因：** CISAの説明では、CVE-2026-88771は不適切な入力検証、CVE-2026-88772はメモリバッファ内操作の不適切な制限（メモリ安全性の不具合）です。いずれも単独でアプライアンス上のリモートコード実行につながり得ます。CISAは世界的に悪用されていると述べています。

**緩和策：**
- NetScalerのブランチごとのCitrix修正ビルドを直ちに適用（連邦機関期限 2026-09-30）。
- 侵害の兆候（不審なファイル／プロセス、新規アカウント、外向き通信）を調査。パッチ適用だけでは既存の侵入は除去されない。適用後、アプライアンス上の認証情報・シークレットを更新し、アクティブセッションを終了する。

**影響範囲：** NetScaler ADC および NetScaler Gateway（正確なビルドはCitrixブレティン参照）。**公開日：** CISA KEV追加 2026-09-27。

## 3. CVE-2026-65660 — Microsoft SharePoint Serverのコードインジェクション（RCE）

**原理・根本原因：** 当初スプーフィングと評価されたコードインジェクションの欠陥。その後の分析で、認証済み攻撃者によるリモートコード実行が可能と判明。

**緩和策：** Microsoftのセキュリティ更新プログラムを適用。SharePointへのアクセスを制限・監視し、サイト作成／編集権限を持つアカウントを見直す。

**影響範囲：** SharePoint Server Subscription Edition、2019、2016。**日付：** 週次ブリーフィングによりCISA KEV 2026-09-25（連邦機関期限 2026-09-28）。悪用は報告されていないとする情報もあり要確認。

## 4. MCP Python SDK — トークン素通しの弱点

**原理：** SDKのHTTPリソース処理にトークン分離がなく、悪意あるMCPサーバーがアプリケーションを誘導してOAuth認証情報を意図しない相手へ転送させ得ます。MCP仕様（受け取ったトークンを上流APIへ渡してはならない）に反する、confused deputy／認証情報漏えいの問題です。

**緩和策：** アドバイザリの修正版SDKへ更新。信頼できるMCPサーバーにのみ接続。OAuthトークンのスコープ最小化とローテーション。**影響範囲：** 公式MCP Python SDK（バージョンはアドバイザリ参照）。**日付：** 2026-09-29。
