## 最新項目（直近24〜48時間）

### 1. CVE-2026-123039 — Check Point Gaia OS DynamicCLI のローカル権限昇格（PHP2Shell との連鎖）

**原理 / 根本原因：** Gaia OS の DynamicCLI サービスは、コマンド要求を受け付けるローカルソケットを公開しています。どのローカル呼び出し元が要求を送れるかを適切に制限していないため、低権限のローカルプロセスでも root としてコマンドを実行させられます。攻撃者はこれを Mobile Access Web ポータルの「PHP2Shell」脆弱性（CVE-2026-109618 / CVE-2026-109619、CVSS 9.2）と連鎖させました。PHP2Shell でポータルのサービスアカウントとしての初期コード実行を得て、CVE-2026-123039 でゲートウェイ上の root に昇格します。

**観測された活動：** Check Point Research によると、2026-10-30 からスキャンと悪用が始まりました。当初はイスラエルの組織が標的で、2026-11-02 以降は複数の国の組織に広がっています。侵害後には Web シェル、「TSGA」と報じられたバックドア、場合によっては VMware ESXi ホストを狙うワイパーが展開されました。Check Point によると被害顧客は数十件です。

**緩和策：**
- すべての Management Server と Security Gateway に 2026年11月の Jumbo Hotfix Accumulator を適用してください。報告されている修正 Take は R82.20 Take 14、R82.10 Take 52、R82 Take 132、R81.20 Take 174（以降）です。インターネットに公開された Mobile Access ポータルを持つゲートウェイから着手してください。
- すぐにパッチを適用できない場合、Check Point は `dynamic_server` プロセスを停止し、再起動しないようにすることを推奨しています。
- 単体の PHP2Shell 修正は 2026-10-23 から提供されています。Mobile Access を公開したまま未修正だったゲートウェイは侵害済みの可能性があるものとして扱い、Web シェルや不明な永続化の痕跡を調査し、接続先の ESXi 基盤も確認してください。

**影響範囲：** Check Point Quantum Security Gateway / Gaia OS。PHP2Shell は R80〜R82.20 に影響します。2026年11月上旬に公開・修正され、2026-11-13 に CISA KEV に追加されました。

### 2. CVE-2026-114713 — UnrealIRCd labeled-response のインジェクション

**原理 / 根本原因：** `labeled-response` モジュールは、クライアントが指定した IRCv3 の `label` メッセージタグをエスケープせずにサーバー応答へ埋め戻します。そのため2台以上のサーバーがリンクされたネットワークでは、一般ユーザーでも、リンク先サーバーにサーバー間プロトコルのコマンドとして解釈される内容を注入できます。注入されたコマンドはサーバー権限で実行されるため、そのユーザーは IRCOp／サーバー権限で操作できます（例：他ユーザーの切断）。

**緩和策：**
- UnrealIRCd 6.2.7.1 にアップグレードするか、再起動不要のホットパッチを適用してください。同じリリースで他に8件のセキュリティ問題も修正されています。
- UnrealIRCd 5（2023年に EOL）も影響を受けると報告されています。`labeled-response` モジュールをブラックリストに登録して再起動し、バージョン 6 へ移行してください。

**影響範囲：** UnrealIRCd 6.0.0〜6.2.7。ベンダー評価は Critical で、スコアは 7.3 と 8.6 の両方が流通しています。プロジェクトが実際の悪用を確認しており、2026-11-13 に CISA KEV に追加されました。

### 3. CVE-2026-119618 — Apache HTTP Server mod_http2 の競合状態（RCE の可能性）

**原理 / 根本原因：** HTTP/2 実装（mod_http2）に競合状態があり、1本の接続上でストリームを並行処理するとヒープメモリが破損します。ネットワークに公開されたサーバーでのヒープ破損は、認証されていないクライアントによるリモートコード実行につながる可能性があります。影響を受けるのは HTTP/2 が有効（`Protocols` ディレクティブに `h2` がある）なサーバーだけです。この脆弱性は Anthropic の OSS スキャンで発見され、Google Cloud の脆弱性調査チームが確認しました。

**緩和策：**
- Apache HTTP Server 2.4.71（2026-11-11 リリース）またはディストリビューションの修正済みパッケージにアップグレードしてください。一部のディストリビューション（Debian の安定版ブランチや Amazon Linux など）では、執筆時点で修正の提供が進行中です。
- パッチを適用するまでは、`Protocols` から `h2`/`h2c` を外して HTTP/2 を無効化してください。Apache のアドバイザリには他の回避策は記載されていません。
- 単体の `mod_h2` GitHub モジュール（2.0.8〜2.0.42）には修正版がなく、リポジトリもアーカイブ済みです。httpd 2.4.71 に同梱のモジュールへ移行してください。

**影響範囲：** mod_http2 が有効な Apache httpd 2.4.55〜2.4.70、および単体の mod_h2 2.0.8〜2.0.42。実環境での悪用は確認されていません。公開された研究がメモリ破損の実証にとどまるかどうかについては報道が食い違っています。

### 4. CVE-2026-126325 — PTC Windchill / FlexPLM の逆シリアル化による RCE

**原理 / 根本原因：** アプリケーションが、リモートクライアントから渡された信頼できないデータを十分に検証せずに逆シリアル化します（CWE-502 / CWE-20）。安全でない逆シリアル化では、攻撃者が選んだオブジェクト構造が復元処理中に任意のコードパスを起動でき、PLM サーバー上でのリモートコード実行につながる可能性があります。

**緩和策：**
- PTC のアドバイザリに記載された修正を適用してください（ナレッジベース記事 CS473270 / CS483249 が引用されています）。
- Windchill/FlexPLM サーバーへのネットワークアクセスを信頼できるユーザーとネットワークに限定し、インターネットに公開しないでください。

**影響範囲：** Windchill 11.0 M030、11.1 M020、11.2.1.0、12.0.2.0、12.1.2.0、13.0.2.0、13.1.0.0〜13.1.4.0。FlexPLM は同系列の 13.1.3.0 まで。上限バージョンは情報源によって異なります。2026-11-12 公開。悪用は確認されておらず、CISA KEV にも未登録です。以前に別途悪用された Windchill/FlexPLM の逆シリアル化ゼロデイとは別の脆弱性なので、混同しないでください。

### 5. CVE-2026-116606 & CVE-2026-111560 — Barracuda アプライアンスの認証バイパス＋コマンドインジェクション

**原理 / 根本原因：** CVE-2026-116606 は Barracuda Email Security Gateway（ESG）の認証前の認可バイパスで、認証されていないリモートの要求が、認証済み管理者向けの機能に到達できます。CVE-2026-111560 は OS コマンドインジェクションで、特権機能に届いた入力が適切に無害化されないままシステムシェルに渡されます。2つを連鎖させると、認証のない攻撃者がアプライアンス上で root を取得できます。

**緩和策：**
- ESG を 9.4.0.030 以降に更新してください。ADC、BMA、WAF、WSG、WCC の CVE-2026-111560 については、Barracuda のアドバイザリに記載された修正を適用してください。二次情報源にはこれらの修正バージョンが記載されていませんでした。
- Barracuda は少数の組織で悪用が確認されたと報告しています（アドバイザリは 2026-11-09 に更新）。公開しているアプライアンスに侵害の痕跡がないか確認してください。

**影響範囲：** 9.4.0.030 より前の Barracuda ESG（両 CVE）。CVE-2026-111560 は Barracuda ADC、Message Archiver（BMA）、WAF、Web Security Gateway（WSG）、WCC にも影響します。2026-11-10 に CISA KEV に追加され、連邦機関の期限は 2026-11-13（本日）です。

### 6. CVE-2026-124194 — Microsoft Outlook のなりすまし / NTLM ハッシュ漏えい（ゼロデイ）

**原理 / 根本原因：** 細工されたメッセージファイルを開くと、Outlook は通常の外部コンテンツ警告を表示しないまま、攻撃者が管理するリモートの場所に接続します。この接続の際に Windows がユーザーの NTLMv2 認証ハッシュを送信するため、攻撃者はそれを取得してオフラインでのクラッキングやリレーに使えます。被害者がファイルを開く必要があり、プレビューウィンドウは攻撃経路になりません。

**緩和策：**
- 2026年11月（2026-11-10）の Outlook/Office セキュリティ更新プログラムを適用してください。
- 多層防御として、インターネット向けの SMB（TCP 445）と NTLM の外向き通信を遮断し、SMB 署名と NTLM リレー対策を強制し、重要なユーザーを Protected Users グループに追加することも検討してください。

**影響範囲：** MSRC でこの CVE の対象とされている、サポート中の Microsoft Outlook / Microsoft 365 Apps / Office。悪用中で、CISA KEV の期限は 2026-11-24 です。

### 7. CVE-2026-125350 — Google Chrome XML の解放後使用（ゼロデイ）

**原理 / 根本原因：** Chrome の XML 処理における解放後使用（use-after-free）で、解放済みのメモリが引き続き参照されます。そのため細工された Web ページがメモリを破損させ、レンダラーのサンドボックス内でコードを実行できます。

**影響範囲：** 157.0.8103.50 より前の Chrome。2026-11-06 に報告され、2026-11-09 に修正、2026-11-10 に CISA KEV に追加されました。2026年に悪用された Chrome ゼロデイの8件目です。

### 11. CVE-2026-123158 — OpenSSH "SSHole" パスワード認証バイパス（musl / Alpine）

**原理 / 根本原因：** musl libc を使い、PAM なしで OpenSSH をビルドした Linux システム（主に Alpine Linux）では、パスワード検証処理が一部の特殊なパスワード入力を正しく扱えません。報告によると、musl のパスワードハッシュ関数のエラー処理の仕方により、sshd が照合の失敗を成功として扱うことがあり、リモート攻撃者が正しいパスワードなしで一部のアカウントにログインできます。glibc ベースのディストリビューション（Debian、Ubuntu、RHEL、Fedora）は影響を受けるとはされていません。

**緩和策：**
- OpenSSH 10.6p2（2026-11-05 リリース）、または Alpine のバックポート済みパッケージにアップグレードしてください：edge 10.6_p2-r0、3.24 10.3_p1-r2、3.23 10.2_p1-r1、3.22 10.0_p1-r11、3.21 9.9_p2-r1、3.20 9.7_p1-r6。バックポート後も SSH のバージョンバナーは変わらないため、バナーではなくパッケージのリビジョンを確認してください。
- 暫定策：`PasswordAuthentication no` を設定し（keyboard-interactive 認証の無効化も検討）、sshd を再起動してください。
- Alpine/musl ベースのコンテナイメージや組み込み機器も確認してください。

**影響範囲：** PAM を使わない musl ベースのシステム上の、10.6p2 より前の OpenSSH。CVSS 8.1。2026-11-09 に CISA KEV に追加されました（連邦機関の期限 2026-11-12）。

### 15. CVE-2026-19868 — SonicWall SonicOS SSLVPN の SAML / MFA バイパス

**原理 / 根本原因：** SSLVPN が SAML（MFA を強制する場合がある）を必須とするよう設定されていても、別の認証方式の有効な認証情報を持つ者はログインでき、SAML/MFA の手順を飛ばせます（CWE-308：単一要素認証）。
**緩和策：** SonicOS 7.3.4-7013（Gen7）または 8.2.3-8015（Gen8）にアップグレードしてください。SonicWall は回避策を示していません。VPN の認証情報を更新し、VPN のログイン記録を確認してください。
**影響範囲：** SSLVPN ログインで SAML が有効な場合の、Gen7 7.3.3-7015 以前および Gen8 8.2.2-8015 以前の SonicOS。2026-11-06 に CISA KEV に追加されました（期限 2026-11-20）。
