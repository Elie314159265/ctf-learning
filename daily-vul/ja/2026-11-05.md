## 1. CVE-2026-119977 — WordPress コアの更新処理における競合状態（TOCTOU）

**原理・根本原因:** WordPressコアの更新（アップグレード／ステージング）処理におけるTOCTOU（チェック時点と使用時点の差）競合状態。ある時点で検証された状態が使用前に変化し、タイミング窓を突いた攻撃者が更新処理の内容に影響を与え得ます。攻撃の複雑性は高とされています。

**対策:**
- WordPress 7.1.4（7.1系）または 7.0.8（7.0系）以降へ更新。
- コアの自動更新が有効か確認し、更新時間帯前後の不審なファイル変更を確認。

**影響範囲:** WordPressコア 7.1.0〜7.1.3 および 7.0.0〜7.0.7（第三者報告）。
**開示日:** 2026-11-03 CISA KEV追加。連邦機関の期限は 2026-11-06。
**注記:** CNAはWordfence。SecurityWeekは同じ競合状態をCVE-2026-97229と関連付けていますが、他の情報源ではこれはGitLab（項目3）のIDです。ID対応は未確定です。

## 2. CVE-2026-111357 / CVE-2026-118527 — Ivanti Connect Secure 攻撃連鎖

**原理・根本原因:** 認証バイパスCVE-2026-104935を含む3つの脆弱性の連鎖の一部。攻撃者は認証バイパスで侵入し、CVE-2026-118527（認証済みユーザーによるファイルアップロードの欠陥で、予測可能な場所に悪意ある内容を配置）、続いてCVE-2026-111357（権限昇格）を悪用して、VPNアプライアンスのroot権限を完全に掌握します。

**対策:**
- Ivanti Connect Secure 25.1.1.3（25.1.x）または 22.8R2.6（22.8R2.x）へ更新。
- IvantiのIntegrity Checker Toolを実行し、侵害の兆候を確認。侵害が疑われる場合は、該当機器上または到達可能な認証情報・シークレットをローテーション。

**影響範囲:** Ivanti Connect Secure（修正版より前の 25.1.x および 22.8R2.x）。
**開示日:** Ivanti が 2026-10-29 にパッチ公開、10-30 に両CVEがCISA KEV追加。連邦機関の期限は CVE-2026-111357 が 2026-11-02、CVE-2026-118527 が 2026-11-13。
**注記:** CVE-2026-111357 のCVSSは情報源により異なります（Ivanti 8.8、MITRE/NVD 7.0）。

## 3. CVE-2026-97229 — GitLab の整数オーバーフロー／ラップアラウンド

**原理・根本原因:** GitLab Community / Enterprise Edition における整数オーバーフロー（ラップアラウンド）の欠陥。攻撃者が影響を与え得る値の演算が型の範囲を超え、意図しないメモリ／ロジック動作を招きます。リモートコード実行につながり得るとされ、CVSS 10.0。

**対策:**
- GitLabのセキュリティリリースノートに従い、最新のパッチ版へ更新。
- パッチ適用までセルフマネージド環境のアクセスを信頼できるネットワークに制限し、ログの異常を確認。

**影響範囲:** セルフマネージド GitLab CE/EE（正確なバージョンはGitLabのアドバイザリ参照。本レポートでは未確認）。
**開示日:** 2026-10-29 CISA KEV追加。連邦機関の期限 2026-11-01（経過済み）。

## 4. CVE-2026-76418 — Cisco ASA / FTD SSL VPN のサービス拒否

**原理・根本原因:** 認証不要のリモート攻撃者が、SSL VPNサービスの不適切な処理を誘発するトラフィックを送ることで、Cisco Secure Firewall ASAおよびThreat Defense（FTD）をクラッシュ／再起動させることができます。

**対策:**
- Ciscoのアドバイザリに記載された修正版のASA/FTDを適用。
- パッチ適用が遅れる場合はSSL VPNの公開範囲を制限し、予期せぬ再起動を監視。

**影響範囲:** SSL VPNを有効にしたCisco ASAおよびFTD（バージョンはCiscoアドバイザリ参照）。
**開示日:** 2026-10-29 CISA KEV追加。連邦機関の期限 2026-11-01（経過済み）。KEVの告知に訂正通知あり。

## 5. CVE-2026-98432 — Linux カーネル IPv4 TCP のUse-After-Free（リモート）

**原理・根本原因:** 受信TCP接続要求に付随するIPv4オプションの解放時の競合状態。リクエストソケットの移行が行われる場合（net.ipv4.tcp_migrate_req=1、またはBPF reuseport移行プログラム）、参照中にオプションが解放されUse-After-Freeとなります。上流の修正はRCU猶予期間後に解放する方式。Linux 4.4 から存在する欠陥です。

**対策:**
- ディストリビューションの修正カーネルを適用して再起動。
- 暫定策: 不要なMPTCPを無効化（net.mptcp.enabled=0）し、net.ipv4.tcp_migrate_req=0 に設定。現在知られているリモート経路は塞がりますが、脆弱性自体は修正されません。

**影響範囲:** 修正前のLinuxカーネル（4.4以降）。2026-10-30時点で、Debian、SUSE、Oracle Linux、Amazon Linux 2023（一部リリース）で修正カーネルが提供され、UbuntuとRHELは未提供と報告。最新のディストリビューション情報を確認してください。
**開示日:** CVE公開 2026-10-15（修正コミット 2026-10-05）。MPTCPリスナーに対するリモートroot取得エクスプロイトが 2026-10-27 に公開。実環境での悪用状況は情報源により異なります。

## 6. CVE-2026-41709 — VMware ESX/ESXi の低深刻度脆弱性（隠蔽目的で悪用）

**原理・根本原因:** ESXホストにおける低深刻度（CVSS 2.7）の欠陥。報告によれば、侵害後に脅威アクターがハイパーバイザー上の悪意ある活動を隠蔽するために悪用しています。

**対策:**
- Broadcomの修正済みESXiビルド（8.0 / 9.0）を適用。
- ハイパーバイザーのログと整合性を監視し、管理プレーンへのアクセスを制限。

**影響範囲:** VMware ESX/ESXi 8.0 および 9.0（ビルドはBroadcomアドバイザリ参照）。
**開示日:** 2026-10-28 CISA KEV追加。ある情報源では連邦機関の期限は 2026-11-11。
