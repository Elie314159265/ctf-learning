## 1. CVE-2026-81963・CVE-2026-85880 — Microsoft Windows ゼロデイ(2026年9月定例パッチ)

**原理・根本原因:** Microsoftの2026年9月定例パッチ(966〜974件のCVEを含み、過去最大級の単発リリース)には、パッチ提供前から実悪用されていた権限昇格の欠陥が2件含まれていました。CVE-2026-85880は、Windowsの Advanced Local Procedure Call(ALPC)サブシステムにおけるヒープベースのバッファオーバーフローです。低権限のコード(AppContainerサンドボックス内からも含む)を実行できる攻撃者が、ALPCサービスのヒープメモリを破壊し、ユーザー操作なしにSYSTEM権限へ昇格できます。CVE-2026-81963は、Windows Updateスタックにおける「ファイルアクセス前のリンク解決不備」(リンクフォロー、CWE-59/61系統)の欠陥です。ローカルの攻撃者がシンボリックリンク/ジャンクションを仕込むことで、Updateスタックが昇格権限で実行するファイル操作を攻撃者の意図した場所にリダイレクトさせ、これもまたSYSTEM権限相当のアクセスにつながります。

**対策:**
- 2026年9月の累積更新プログラムを直ちに適用してください。両脆弱性ともパッチ提供前から悪用されていたため、緊急展開として扱うべきです。特に信頼できないローカルコードにさらされる端末(共有ワークステーション、サンドボックス/AppContainerをホストする端末、RDS/VDIなど)を優先してください。
- 低権限コード実行がすでに可能な端末(ブラウザ、サンドボックス化アプリなど)を優先対応してください。両脆弱性とも、初期侵入後に連鎖利用されるローカル権限昇格の手段として典型的です。

**影響範囲:** 現行のサポート対象Windowsクライアント/サーバー全般における、Windows Updateスタック(CVE-2026-81963)およびALPCコンポーネント(CVE-2026-85880)。2026-09-08に開示・パッチ提供。両方とも同日CISA KEVに追加。

## 2. CVE-2026-75650 — Adobe Commerce / Magento「StyleSmuggler」ゼロデイRCE

**原理・根本原因:** CVSS最大値の10.0と評価されるこの脆弱性は、Magentoのサーバーサイドテンプレートレンダリング機能における特殊要素の不適切な無害化(CWE-1336、「テンプレートエンジン内の特殊要素」)です。本来は無害なスタイル/テンプレートデータとして扱われるはずの攻撃者制御下の入力が、テンプレートエンジンによって解析・実行されてしまい、未認証のリモート攻撃者がログインもユーザー操作も不要でWebアプリケーションのコンテキスト内で任意のPHPコードを実行できます。研究者は、悪意あるペイロードがエンジンに予期せず評価されるスタイル/テンプレートフィールドを介して「密輸」されることから、この手法を「StyleSmuggler」と命名しました。

**対策:**
- Adobeのセキュリティ情報APSB26-146に基づく緊急ホットフィックスを直ちに適用してください。本脆弱性は実悪用中です。
- パッチが存在する前から攻撃が数日間続いていたため、影響を受けるインターネット公開ストアはすでに侵害されている可能性があるものとして扱ってください。想定外のcronジョブ、書き込み可能なディレクトリ内の見慣れないPHPファイル/Webシェル、バックドアと矛盾しない未知の送信先通信を確認してください。
- 侵害の兆候が見つかった場合は、パッチ適用後に管理者認証情報やAPIキーをローテーションしてください。

**影響範囲:** Adobe Commerce、Adobe Commerce B2B、Magento Open Sourceの、2.4.9-2026-aug、2.4.8-2026-aug、2.4.7-2026-aug、2.4.6-2026-aug以下の各バージョン。実悪用は2026-09-04から確認され、Adobeのホットフィックスは2026-09-07に提供、CISA KEVには2026-09-08に追加されました。攻撃者はこの脆弱性を用いてRustベースのLinuxバックドアとPHP Webシェルの両方を展開しています。

## 3. CVE-2026-86218 — N-able N-central 認証前静的コードインジェクション/RCE

**原理・根本原因:** CVSS 10.0で、CWE-96(「静的コードインジェクション」)に分類されます。N-centralのサーバーサイドコードは、攻撃者が指定したディレクティブを静的に評価されるコードパスへ保存する前に適切に無害化しておらず、未認証のネットワーククライアントがコードを注入し、それをN-centralサービス自体の権限で後から実行させることができます。N-centralのようなリモート監視管理(RMM)プラットフォームは、多数の管理対象顧客ネットワークに特権を持つエージェントを配備しているため、中央サーバーの侵害はそれが管理するすべてのエンドポイントへ連鎖的に波及し得ます。

**対策:**
- 直ちにN-central 2026.3.1.14(「2026.3 Hotfix 4」として提供)以降にアップグレードしてください。
- これは6週間で3件目となるN-centralの単独ゼロデイです。即時パッチが困難な場合は、N-centralの管理インターフェースへのネットワークアクセスを信頼できる送信元・VPN経由のみに制限し、これまでの攻撃波による事前侵害の兆候がないかエージェント/サーバーのログを確認してください。

**影響範囲:** 2026.3.1.14より前のすべてのN-able N-centralビルド。ホットフィックスは2026-09-06(UTC)にリリースされ、CISA KEVには2026-09-08に追加されました。Huntressをはじめとする対応チームは、本年のこの製品における3回すべての攻撃波にわたって実悪用の試みを確認していると報告しています。

## 4. SAP 2026年9月セキュリティパッチデー — 複数のCritical脆弱性

**原理・根本原因:** SAPの月次パッチデーでは、19件の新規セキュリティノートと1件の更新が提供されました。最も深刻な**CVE-2026-44756**(CVSS 10.0)は、SAP Extended Passport Processingにおけるメモリ破損の脆弱性で、複数のSAPカーネル/Web Dispatcherバージョンに影響します。悪用に成功するとプロセスメモリが破損し、任意のコード実行につながる可能性があります。**CVE-2026-58240**(CVSS 9.8)は、SAP NetWeaver Message Serverにおける認証チェック欠落の欠陥で、有効な認証情報を持たない攻撃者が、本来認証を要求すべきサービスと対話できてしまいます。**CVE-2026-76969**(CVSS 9.4)は、SAP Cloud Application Programming Modelを基盤としたマルチテナントアプリケーションで使用されるライブラリ `sap/cds-mtxs` における認証情報漏えいの不具合で、テナント分離ロジックの欠陥により、あるテナントの認証情報/シークレットが別のテナントに露出する可能性があります。

**対策:**
- 該当するSAPノートを適用してください:3747649(CVE-2026-44756)、3759472(CVE-2026-58240)、およびCVE-2026-76969に対応するCAP `cds-mtxs` の更新。インターネットまたはWANから到達可能なNetWeaver Message ServerおよびWeb Dispatcherを優先してください。
- CVE-2026-76969については、中央のSAPインフラだけでなく、影響を受けるバージョン(1.18.3 / 2.7.6 / 3.9.6 / 4.0.2)を組み込んでいるすべてのマルチテナントアプリケーションで `sap/cds-mtxs` をアップグレードしてください。

**影響範囲:** CVE-2026-44756についてはSAPカーネル/Web Dispatcher(KERNEL 7.22、7.53、7.54、7.77、7.89、7.93、8.04、9.16〜9.20)、CVE-2026-58240についてはNetWeaver Message Server(KERNEL 9.16、9.18、9.19、9.20)、CVE-2026-76969については `sap/cds-mtxs` の1.18.3/2.7.6/3.9.6/4.0.2以下の各バージョン。2026-09-08にパッチ提供。確認済みの実悪用は現時点でありませんが、深刻度の高さと、SAPではパッチ差分から攻撃者が迅速にリバースエンジニアリングを行ってきた過去の経緯を踏まえ、速やかな適用を推奨します。

## 5. CVE-2026-67276・CVE-2026-86060 — MikroTik RouterOS「MikroTrick」SSHバイパス連鎖

**原理・根本原因:** 2つの脆弱性を連鎖させることで、リモートの攻撃者が有効な認証情報なしにインターネット公開されたRouterOSデバイスをSSH経由で完全に乗っ取ることができます。CVE-2026-67276(CVSS 9.2)は、RouterOSがSSH公開鍵認証時にRSA公開鍵全体ではなく一部のみを検証していたことが原因で、特別に細工された別の鍵を、正規の既存ユーザーに属する鍵であるかのように受け入れてしまいます。この認証前の状態に到達した後、CVE-2026-86060(CVSS 9.2)により、攻撃者はRouterOSのSSHログインヘルパーがユーザー識別ではなくコマンドライン引数として誤解釈するよう細工したユーザー名を与えることで、完全な管理者権限へ昇格できます。これは典型的な引数インジェクションのパターンです。CERT Polskaはこの2段階の連鎖を「MikroTrick」と命名しました。

**対策:**
- MikroTikが2026-09-03にリリースしたRouterOSビルドへできる限り速やかに更新してください。
- パッチ適用までの間は、RouterOSデバイスのWAN/インターネットからのSSHアクセスを無効化するか、管理用VPN経由に制限してください。
- 事前侵害の兆候を確認してください。報告によれば、この連鎖を悪用した実際の攻撃キャンペーンでは、文字通り「-2」という名前の不審なSSHユーザーが既知の痕跡として確認されています。

**影響範囲:** 2026-09-03の修正版ビルド以前で、SSHを公衆ネットワークに公開しているMikroTik RouterOSデバイス。実悪用は2026-09-02(パッチ提供の前日)から始まり、CERT Polskaのアドバイザリは2026-09-05に公開されました。

## 6. CVE-2026-85046 — Google Chrome/Chromium V8タイプコンフュージョン ゼロデイ

**原理・根本原因:** Chromeおよびその他のChromiumベースブラウザで使用されるJavaScript/WebAssemblyエンジンV8におけるタイプコンフュージョン(型混同)の欠陥です(CVSS 8.8)。V8内の特定のコンパイラ階層が、汎用(「packed」)要素として宣言された配列を、小さな整数のみを保持するものとして誤って扱うことがあり、エンジンの内部的な型の想定とオブジェクトの実際のレイアウトとの間に不一致が生じます。細工されたWebページはこの不一致を引き起こしてJavaScriptヒープ内の範囲外読み書きのプリミティブを取得でき、これをブラウザのレンダリングサンドボックス内での任意コード実行にまでエスカレートさせることができます。

**対策:**
- Chrome(および Edge、Brave、Opera などChromiumベースの各種ブラウザ)を152.0.7977.82以降に更新してください。ブラウザの「バージョン情報」画面で、更新が実際に適用され、ブラウザが再起動されたことを確認してください。
- 実悪用が確認されていることを踏まえ、企業は管理下の更新ポリシーによって本バージョンが速やかに配布されたことを確認してください。

**影響範囲:** 152.0.7977.82より前のChrome/Chromium。外部研究者により2026-08-04に報告され、2026-09-03〜04にパッチが提供され、CISA KEVには2026-09-04に追加されました。

## 7. CVE-2026-32475 — Elementor Pro(WordPress)任意ファイルアップロード — 大規模実悪用が継続中

**原理・根本原因:** Elementor ProのFormsモジュールにおけるファイルアップロード機能では、拡張子の検証とアップロードファイルの最終配置への移動処理が2つの別々のコードループで行われており、「空」のファイルエントリの扱いが両ループで一貫していません。同一フォームフィールドに対して2つのファイルパートを送信することで、未認証の攻撃者は一方のパートで拡張子チェックを通過させつつ、もう一方のパートを介して公開アクセス可能なディレクトリにPHPファイルを書き込むことができ、拡張子ブロックリストを完全に回避してWebシェルの設置に至ります。

**対策:**
- 未対応の場合は直ちにElementor Pro 4.2.2以降に更新してください(修正版は2026-08-19から提供されています)。
- 大規模なスキャン・実悪用が確認されていることから(Wordfenceは2026-09-02時点で19万件超の攻撃試行をブロックしたと報告)、パッチ適用後もアップロードディレクトリ内に想定外のPHPファイルがないか対象サイトをスキャンしてください。

**影響範囲:** 4.2.1以下のElementor Pro。推定約600万件のWordPressサイトに影響。公開は2026-08-19に開始され、本レポートの対象期間中も大規模な実悪用が継続して報告されています。
