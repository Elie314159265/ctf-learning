## 1. CVE-2026-109618 / CVE-2026-109619 — PHP「PHP2Shell」リクエスト状態の破壊(認証不要 RCE)

**原理・根本原因:** 両 CVE は同一の根本的弱点に起因します。PHP が内部状態の更新途中でリクエスト処理を中断(bailout)し、状態が不整合のまま残ることがあるというものです。CVE-2026-109618 は、multipart リクエストボディの解析中にメモリが枯渇した際、後続のリクエストクリーンアップで使われるデータが破壊されるメモリ破壊の問題です。CVE-2026-109619 は、同一ワーカー上で前のリクエストの古い状態が次のリクエストに残存する問題です。これらを組み合わせることで、Web に公開された PHP で認証不要のリモートコード実行が可能になります。上流の修正(「Avoid state corruption via bailout」)は、このような中断を防ぎ、リクエスト間で残存状態をクリアします。

**緩和策:**
- 直ちに PHP 8.5.12、8.4.27、8.3.36、8.2.35(またはそれ以降)へアップグレード。
- 公式修正のないブランチ(8.1 以前。7.4/8.0/8.1 は最小限のバックポートのみ、5.4〜7.3 は無し)は、サポート対象ブランチへ移行するか、ディストリビューションのパッチを適用。
- 可能な限り PHP アプリのインターネット直接公開を制限し、暫定措置としてリクエスト単位のメモリ制限や、大きい/不正な multipart ボディに対する WAF 制御を適用。また、侵害の兆候(不審な Web シェル、Web ルート内の新規ファイル)がないか確認。

**影響範囲:** 修正版より古い、HTTP を処理するすべての PHP(PHP-FPM、mod_php、php-cgi、FrankenPHP、LiteSpeed)。研究者は影響を受けるコードを PHP 5.4 まで遡ると報告。
**日付:** パッチ公開前の 2026-10-17 から悪用試行が観測されたとの報告あり。修正 2026-10-21(CISA 注意喚起 2026-10-21)。CISA KEV 追加 2026-10-26。

## 2. CVE-2026-111497 — Brotli デコーダの境界外書き込み(「Node2Shell」)

**原理・根本原因:** Google の Brotli 展開ライブラリにおける境界外書き込み(CWE-787)で、戻り値の未チェック(CWE-252)が根本原因です。デコーダが完了できないブロック切り替えに遭遇した際、脆弱なバージョンは「不正なストリーム」と「追加入力が必要」を区別できず、デコードを続行します。細工された圧縮ストリームにより、小さな作業バッファを超えて書き込み、隣接メモリが破壊される可能性があります。攻撃者が制御する Brotli データ(HTTP リクエスト/レスポンスボディなど)を展開するアプリケーションが露出の条件です。

**緩和策:**
- Brotli ライブラリ: 1.0.10、1.1.1、または 1.2.1 へ更新。
- Node.js(独自のコピーを同梱しており、OS の libbrotli を更新しても効果なし): 26.12.1、24.22.1、22.23.4。EOL ライン(20.x 以前)には上流の修正がないため移行が必要。
- .NET: 2026-10-25 の Microsoft 臨時更新(8.0.33、9.0.22、10.0.14、11.0 RC3)。Python: Brotli 1.2.1 / brotlicffi 1.2.1.0。Bun: 1.4.4。
- 暫定措置: 可能であれば信頼できない Brotli の Content-Encoding を拒否または展開しない。コンテナや同梱アプリ内のベンダリングされた Brotli コピーを棚卸し。

**影響範囲:** Brotli 1.0.3〜1.2.0(正確な範囲は情報源により若干異なる)、およびそれを組み込むソフトウェア(上記の Node.js、.NET、Python、Bun ランタイムを含む)。
**日付:** 修正と公開はおおよそ 2026-10-21〜10-25。公開 PoC の報告あり。KEV 登録とする報告がある一方、2026-10-23 時点で確認した他の情報源では未登録。最新の KEV 状況を確認してください。

## 3. CVE-2026-110447 — Collabora Online Built-in CODE Server(Nextcloud)の OS コマンドインジェクション

**原理・根本原因:** Nextcloud の「richdocumentscode」アプリのプロキシ部分における OS コマンドインジェクション(CWE-78)。信頼できない入力が十分な無害化なしにシェルコマンドへ渡されます。認証不要で到達可能ですが、組み込み CODE サーバープロセスが停止中(再起動、アップグレード、クラッシュ後など)の場合に限られます。

**緩和策:**
- Built-in CODE Server アプリを 26.4.303 以降へ更新、またはアプリを完全に削除(無効化のみでは不十分との報告)。
- Nextcloud ホストで Web シェルや不審なファイルを調査。侵害の疑いがある場合は認証情報をローテーション。

**影響範囲:** richdocumentscode の 26.4.303 より前のバージョン(26.4.302 が最後の影響バージョン)。スタンドアロンの Collabora Online サーバー(Docker、RPM/DEB)、Nextcloud Office と併用する別個の Collabora サーバー、Nextcloud All-in-One は影響なし。
**日付:** 2026年9月から悪用が報告されている。CISA KEV 追加 2026-10-23。

## 4. CVE-2026-114625 — Arista VeloCloud Orchestrator の SQL インジェクション

**原理・根本原因:** SQL インジェクション — ユーザー制御の入力がパラメータ化されずにデータベースクエリへ組み込まれ、管理オーケストレーター上でクエリを操作される可能性があります。

**緩和策:** ベンダーのアドバイザリに従い Arista の修正版 Orchestrator を適用。管理プレーンへのアクセスを信頼できるネットワークに制限。異常なクエリや管理変更がないかログを確認。修正版のバージョン番号は、参照できた情報源では確認できませんでした。

**影響範囲:** Arista VeloCloud Orchestrator(具体的なバージョンはベンダーのアドバイザリを参照)。
**日付:** CISA KEV 追加 2026-10-23。
