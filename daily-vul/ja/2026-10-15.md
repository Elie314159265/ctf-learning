## 最新の項目(直近24〜48時間)

### 1. CVE-2026-104935 — Ivanti Connect Secure 認証バイパス(ゼロデイ)

**原理・根本原因:** なりすましによる認証バイパス(CWE-290)。認証されていないリモートの攻撃者が信頼されたIDを偽装し、アプライアンス上でコマンドを実行できます。報道によると、脅威アクターUTA0576が、未修正の権限昇格の脆弱性を含む他の2件と連鎖させ、パッチ適用済みの機器でもroot権限でのコード実行を達成しています。

**緩和策:**
- 下記の修正版へ直ちにアップグレードする。
- アプライアンスのログや整合性チェックで侵害の兆候を確認し、兆候がある機器は再構築を検討する。
- 未修正の連鎖する権限昇格の脆弱性に対するIvantiの修正に注意する。

**影響範囲:** Ivanti Connect Secure 25.1.2.2 以前、25.1.1.1 以前、22.8R2.4 以前。修正版は 25.1.3.0、25.1.3.1、22.8R2.5。22.7R2.14 以前は影響を受けないとみられます。

**公開日:** 2026-10-13(Ivantiアドバイザリ。Volexityが発見)。悪用は約 2026-10-01〜10-03 から確認。CISA KEV 2026-10-13、連邦機関の期限は 2026-10-16 と報じられています。

### 2. CVE-2026-96951 — Windows Shell セキュリティ機能のバイパス(悪用ゼロデイ)

**原理・根本原因:** Windows Shell のコマンドインジェクション(特殊要素の不適切な無害化)により、細工されたファイルやリンクが Mark-of-the-Web を除去します。その結果、ダウンロードしたコンテンツに対して SmartScreen や保護ビューの警告が表示されません。ユーザーがファイルを開く操作は依然として必要です。

**緩和策:**
- 2026年10月の累積更新プログラムを適用する。
- メール・チャット・Webリンク経由のファイルに関するユーザー教育を強化し、添付ファイルやマクロのブロック機能を有効に保つ。
- 本来あるはずの Mark-of-the-Web が付いていないダウンロードファイルを探索する。

**影響範囲:** サポート対象の Windows(正確な一覧は MSRC を参照)。

**公開日:** 2026-10-13(パッチ Tuesday)。実環境で悪用確認、CISA KEV 2026-10-13。今回のリリースは過去最大規模(約1,410件以上のCVE、Critical 75件、ゼロデイ3件、Office プレビューウィンドウの脆弱性23件)と報じられていますが、件数は情報源により異なります。

### 3. Cisco Secure Email Gateway — 重大なパス トラバーサル(悪用確認)

**原理・根本原因:** 相対パストラバーサル(CWE-23)。ファイルパスの検証が不十分なため、リモートの攻撃者が想定ディレクトリ外のファイルを読み取り・操作できます。Cisco は 2026-10-14 に、重大(CVSS 9.8)な脆弱性が悪用されていると警告しました。CISA は CVE-2026-76519 として掲載していますが、関連する9月のアドバイザリではパストラバーサルに CVE-2026-76440 が挙げられており、悪用されている脆弱性のCVE対応は情報源で食い違います。Ciscoのアドバイザリで確認してください。

**緩和策:**
- Cisco のアドバイザリにある修正版へアップグレードする。以前のアドバイザリの報道によれば、Secure Email Gateway は 15.5.5-014(正確なビルドは要確認)および 16.5.0-780、Secure Email and Web Manager は 15.5.5-006 および 16.5.0-429。16.0 には修正版がなく、サポート対象ブランチへの移行が必要です。
- 回避策は報告されていません。管理インターフェースの公開を制限し、ログを確認する。

**影響範囲:** 上記ブランチの Cisco Secure Email Gateway(および関連する Secure Email and Web Manager)。

**公開日:** 2026-10-14、CISA KEV 2026-10-14。

CISA の 2026-10-14 付アラートに、Palo Alto Networks PAN-OS のコードインジェクションの脆弱性 CVE-2026-0322 が掲載されたと報じられています。この識別子と詳細は二次情報では裏付けを取れませんでした。CISA KEV 掲載のとおり悪用されているものとして扱い、影響を受ける PAN-OS バージョンと修正は Palo Alto Networks のセキュリティアドバイザリで確認し、パッチ適用と管理インターフェースの公開制限を行ってください。

### 5. CVE-2026-105133 / CVE-2026-105134 — AhsayCBS 認証バイパス+コード実行

**原理・根本原因:** バックアップ管理コンソール AhsayCBS の2つの脆弱性が連鎖します。CVE-2026-105133 は認証を回避し、CVE-2026-105134 は SYSTEM 権限でのリモートコード実行を可能にします。攻撃者はWebシェルや暗号資産マイナーを設置し、永続化のために偽のサービスを作成しています(Huntress)。

**緩和策:**
- Ahsay は 2026-10-10 に、10.3.4.0 では完全には修正されていないと認めました。ホットフィックス 10.3.4.45 を適用し、サーバーを再起動する。
- コンソールをインターネットに公開しない。予期しない JSP ファイル、不審なサービス(「Edge 更新」を装うもの等)、マイナーを探索する。

**影響範囲:** AhsayCBS 10.3.2 以前、およびその後の調査では 10.3.4.0 も。

**公開日:** 悪用は 2026-10-07 に初確認。CISA KEV 2026-10-14(以前の報道では未掲載)。

### 6. CVE-2026-102489 / CVE-2026-102490 — Zammad ヘルプデスク

**原理・根本原因:** セッションハイジャックによりアプリケーションユーザー権限でのコード実行に至る脆弱性(CVE-2026-102489)と、rootへのローカル権限昇格(CVE-2026-102490)が連鎖します。DIVD が採番し、両者を連鎖させたAI支援型の侵入を報告しています。Zammad GmbH は影響バージョンと悪用可能性に異議を唱えており、2026-10-05 時点でベンダーのアドバイザリや CVE-2026-102490 の確認済み修正は見つかっていません。

**緩和策:** Zammad を最新版へ更新し、公開範囲を制限し、ホストの侵害有無を確認する。ベンダー/DIVD の最新情報に従う。

**影響範囲:** Zammad 6.3.0〜6.5.4(7.0.0〜7.1.3 でも報告あり)。**公開日:** CISA KEV 2026-10-02。

### 7. CVE-2026-88779 — Citrix NetScaler ADC / Gateway

**原理・根本原因:** SAML サービスプロバイダ/IdP として構成されたアプライアンスで、認証なしに到達できるメモリオーバーフロー(CWE-119)。観測された攻撃ではアプライアンスがクラッシュし、関連する脆弱性(CVE-2026-88771)の悪用を助ける可能性があります。

**緩和策:** セキュリティ情報に従い Citrix の修正ビルドを適用する。Citrix 管理のクラウドサービスは影響を受けません。

**影響範囲:** SAML SP/IdP 構成の NetScaler ADC および Gateway。**公開日:** CISA KEV 2026-10-04(連邦機関の期限 2026-10-07)。

### 8. CVE-2026-70229 — Active Directory Domain Services RCE

PDQ によれば AD DS の重大なリモートコード実行(CVSS 8.1)で、特定のネットワーク条件下で認証なしに悪用可能とされ、2026-10-13 の更新で修正されました。悪用の報告はありません。深刻度の表記は情報源により異なるため MSRC で確認してください。まずドメインコントローラーに10月の更新を適用してください。
