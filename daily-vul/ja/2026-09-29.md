## 1. CVE-2026-88771 / CVE-2026-88772 — Citrix NetScaler ADC / Gateway ゼロデイ RCE

**原理・根本原因:** CVE-2026-88771 は不適切な入力検証の欠陥で、認証なしのリモート攻撃者が任意のコマンドを実行できます。CVE-2026-88772 はメモリオーバーフロー(メモリ安全性の欠陥)で、DTLS が有効な場合(VPN 仮想サーバーではデフォルト)に到達可能で、RCE またはサービス拒否につながります。Citrix によれば、影響を受けるバージョンのすべての展開(デフォルト構成を含む)が前提条件を満たします。

**緩和策:**
- Citrix セキュリティ情報 CTX697096 の修正ビルドへ直ちにアップグレードする。
- 13.1 系で `show ns variable` が設定済み変数を返す場合は、既知の再起動ループを避けるため 13.1-64.24 へアップグレードする。
- インターネットに公開された機器は侵害されている可能性を前提に、侵害の痕跡を調査し、パッチ適用後に認証情報・セッション秘密情報をローテーションする。

**影響範囲:** NetScaler ADC / Gateway 14.1(14.1-73.37 未満)、13.1(13.1-64.23 未満)、14.1-FIPS(14.1-73.37 FIPS 未満)、13.1-FIPS/NDcPP(13.1-37.279 未満)。
**開示日:** 2026-09-26 に悪用が公に警告(watchTowr)、2026-09-27 にパッチ公開および CISA アラート。修正前からゼロデイとして悪用。

## 2. CVE-2026-86950 — Apple CoreGraphics ゼロデイ(iOS / iPadOS)

**原理・根本原因:** グラフィックス・画像・文書をシステム全体で描画する CoreGraphics フレームワークの欠陥。Apple は、特定の標的に対する極めて高度な攻撃で悪用された可能性があると報告しています。根本原因の詳細は非公開です。

**緩和策:**
- iOS 26.7.1 / iPadOS 26.7.1 以降へ更新する。自動アップデートを有効化する。
- 高リスクのユーザーはロックダウンモードの利用を検討する。

**影響範囲:** iOS/iPadOS 26.7.1 未満の iPhone / iPad(他の Apple 製品は Apple のアドバイザリを確認)。
**開示日:** 2026-09-28。

## 3. CVE-2026-93616 — Check Point Security Management Server 認証前パストラバーサル

**原理・根本原因:** 管理サーバーのパストラバーサル(パス検証不備)により、認証なしのリモート攻撃者が意図されたディレクトリ外にファイルを書き込み、スクリプトのアップロードと実行が可能となり、管理基盤でコード実行に至ります。

**緩和策:**
- 緊急の R82.20 Security Hotfix、または Jumbo Hotfix Accumulator を適用する(R82.10 Take 45、R82 Take 127、R81.20 Take 170、R81.10 Take 192)。
- 通常の LivePatch(CVE-2026-91843 向けの Take 28/29 を含む)ではこの問題は**修正されない**。
- 管理インターフェースを信頼できるネットワークに限定し、サーバー上の不審なファイル/スクリプトを調査する。サポート終了版(R81 以前)には修正がないため移行する。

**影響範囲:** Security Management Server、Multi-Domain Security Management、Log Server、Multi-Domain Log Server、SmartEvent — R82.20(ホットフィックス未適用)、R82.10 Take 44 以下、R82 Take 126 以下、R81.20 Take 166 以下、R81.10 Take 190 以下、R81 以前(サポート終了)。
**開示日:** 2026-09-22。標的型攻撃で悪用。

## 4. CVE-2026-65660 — Microsoft SharePoint Server RCE(悪用確認)

**原理・根本原因:** 型チェックのバイパスにより、認証済みの低権限ユーザーがコード実行を得られます。認証なしの RCE には、別の認証バイパス脆弱性との連鎖が必要です。

**緩和策:**
- 2026年8月の月例パッチ(Patch Tuesday)の SharePoint 更新を適用する(修正はその時点で提供済み)。CISA の連邦機関向け期限は 2026-09-28。
- SharePoint のインターネット公開を制限し、ハードニングガイダンスを適用し、異常なアクティビティを確認する。

**影響範囲:** 2026年8月の更新が未適用のサポート対象オンプレミス SharePoint Server(正確なバージョンは MSRC のエントリで確認)。
**開示日:** 2026年8月にパッチ公開。悪用が確認され 2026-09-25 に CISA KEV へ追加。

## 5. CVE-2026-67279 / CVE-2026-86060 — MikroTik RouterOS 認証バイパスの連鎖

**原理・根本原因:** CVE-2026-67279 は動作ワークフローの不適切な強制で、認証なしのクライアントが想定外の順序でセッションチャネルを開き実行要求を送れます。CVE-2026-86060 はログイン処理における引数インジェクションの欠陥です。両者を連鎖させると、インターネットに公開されたルーターの管理者権限をパスワードなしで完全に奪取できます。

**緩和策:**
- MikroTik のアドバイザリに従い RouterOS を最新のパッチ版へ更新する。
- SSH/管理サービスをインターネットに公開せず、送信元 IP で制限する。認証情報をローテーションし、不正な設定変更がないか確認する。

**影響範囲:** 脆弱なバージョンでインターネットに公開された MikroTik RouterOS 機器(MikroTik のアドバイザリ参照)。
**開示日:** CISA KEV への追加は CVE-2026-67279 が 2026-09-25、CVE-2026-86060 は 2026-09-10。
