## 1. CVE-2026-109618 / CVE-2026-109619 —「PHP2Shell」PHP本体のメモリ安全性の欠陥

**原理・根本原因:** 認証不要で到達可能なPHP本体の2つのメモリ安全性バグ。CVE-2026-109618:メモリ不足(OOM)処理により、内部のリクエストデータが部分的にしか初期化されていない状態で処理が中断され、リクエスト終了時のクリーンアップが不正なデータを有効とみなしてメモリ破壊に至ります。CVE-2026-109619:リクエスト所有の内部状態が、裏付けメモリの解放後も残存し、同じワーカーが処理する後続リクエストが通常の初期化前にその古い状態を使用してしまいます(use-after-free型)。いずれもWeb公開されたPHPでのリモートコード実行につながり得ます。

**緩和策:**
- PHP 8.5.12、8.4.27、8.3.36、8.2.35(2026-10-21公開)へ更新。
- PHP 8.1以前は上流でサポート終了。移行するか、ディストリビューション/LTSベンダーのバックポート修正を適用。
- すべてのSAPI(PHP-FPM、mod_php、php-cgi、FrankenPHP、LiteSpeed)およびコンテナ/ベースイメージを対象にし、パッチ後はワーカーを再起動。研究者が影響を示したCMS(WordPress、Drupal、Joomla)のホストを棚卸し。

**影響範囲:** 修正版より前のPHP 8.2〜8.5。旧ブランチも影響の可能性があるがサポート外(「PHP 5以降すべて」との事前報告は未確認)。**開示日:** 2026-10-21(リリース前に詳細が流出)。CISA KEV:10/22時点で未掲載。

**影響範囲:** GitLab CE/EE 7.0から上記修正版未満。**開示日:** 2026-10-21。悪用:未確認、公開PoCの報告なし。

## 3. Plex2Shell — Plex Media Server 脆弱性チェーン(CVE-2026-96652、-96654、-96655、-96656)

**原理・根本原因:** エンコードされたURIスキームの不適切な無害化、ファイル名/パスの外部制御などの弱点が連鎖し、メディアサーバー上でのリモートコード実行を可能にします。技術詳細の公開直後から悪用が始まったと報告されており、暗号資産マイナーやプロキシソフトが設置されています。

**緩和策:** Plex Media Server を 1.43.3.10861 以降へ更新(自動更新されないDocker/NAS/Linux環境を含む)。サーバーを直接インターネットに公開しない。未知のマイナー/プロキシプロセスがないか確認。

**影響範囲:** 1.43.3.10861 未満の Plex Media Server。**日付:** 約2026-10-17から悪用報告、2026-10-20 CISA KEV追加(期限 2026-10-23 / 2026-11-03)。広範な悪用の証拠は一部単一のハニーポットに基づく(要確認)。
