## 1. CVE-2026-57967 — Apache ActiveMQ Artemis CORE プロトコルによるセッション乗っ取り

**原理・根本原因:** ActiveMQ ArtemisブローカーのCOREワイヤープロトコルは、ネットワーク断絶後にクライアントが既存セッションを再開するための`SESSION_REATTACH`操作をサポートしています。ブローカーは、再接続を要求しているクライアントがそのセッションの正当な認証済み所有者であるかを十分に検証していません(CWE-306、重要機能に対する認証の欠如)。そのため、未認証の攻撃者が細工した`SESSION_REATTACH`パケットを送ることで受け入れられてしまい、そのセッションに紐づく全ての操作への継続的なアクセス権が付与されます。これにより、リモートの未認証攻撃者が事実上、既に認証済みのセッションに成り代わり、その権限で操作できるようになります。

**対応(緩和策):**
- Apache Artemis / ActiveMQ Artemisをバージョン2.57.0以降へアップグレードする。
- パッチ適用までの多層防御として、ブローカーのCOREプロトコルポートへのネットワークアクセスを信頼できるホストに制限する。

**対象:** Apache Artemis 2.50.0〜2.56.0、およびApache ActiveMQ Artemis 1.0.0〜2.44.0。2026-09-11に開示。現時点で実悪用の確認報告はないが、複雑度が低く認証不要であるため速やかな悪用が予想され、予防的なパッチ適用が推奨される。

## 2. CVE-2026-67277・CVE-2026-86060 — MikroTik RouterOS「MikroTrick」連鎖型攻撃

**原理・根本原因:** CVE-2026-67277は、RouterOSの帯域幅テスト(`btest`)サービスにおける認証欠如の欠陥です。未認証のネットワーク入力が本来ログイン済みユーザー向けのコードパスに到達可能であり、これに関連する未初期化メモリの漏えいとサイズ検証における整数アンダーフローが組み合わさることで、カーネルメモリの露出やデバイスのクラッシュを引き起こす可能性があります。CVE-2026-86060は、SSHログイン経路における別の引数インジェクションの欠陥で、特定の禁止文字で始まるユーザー名によってトリガーされ、未認証のSSHセッションからRouterOS内部の信頼・ポリシーマスクを変更し、権限昇格につなげることができます。研究者(CERT Polska)は、この2つの脆弱性を連鎖させることで、完全に未認証のままデバイスを乗っ取れることを示しました。

**対応(緩和策):**
- RouterOSを6.49.21(Long-term)、7.23.4(Long-term)、7.24.2(Stable)、またはそれ以降へアップグレードする。
- 帯域幅テストサービスを無効化またはファイアウォールで保護し、SSH管理アクセスを信頼できるネットワークに限定する。

**対象:** 上記修正版より前のMikroTik RouterOSバージョン。2026-09-07にCERT Polskaが「MikroTrick」と名付けて詳細を公開。ルーターの乗っ取りを目的とした実悪用が確認されており、2026-09-10にCISA KEVへ追加。

## 3. CVE-2025-25249 — Fortinet FortiOS/FortiSwitchManager/FortiSASE ヒープバッファオーバーフロー

**原理・根本原因:** FortiOSおよび関連製品にヒープベースのバッファオーバーフロー(CWE-122)が存在します。細工されたネットワークパケットにより、ヒープバッファに本来のサイズを超えるデータが書き込まれ、隣接するメモリが破壊されます。その時点でのメモリ配置次第では、デバイスをクラッシュさせるだけでなく、攻撃者がプログラムの実行フローを操作し任意コードを実行するために悪用される可能性があります。

**対応(緩和策):**
- FortiOS、FortiSwitchManager、FortiSASEをFortinetのアドバイザリに記載された修正バージョン(FortiOSの6.4〜7.6系および対応するFortiSwitchManager/FortiSASEのリリース)へアップグレードする。
- 対象デバイスの管理プレーンの露出を制限し、リモートアクセス型トロイの木馬の展開に一致する予期しないプロセスを監視する。

**対象:** FortiOS 7.6.0〜7.6.3、7.4.0〜7.4.8、7.2.0〜7.2.11、7.0.0〜7.0.17、6.4.0〜6.4.16、FortiSASE 25.2.bおよび25.1.a.2、FortiSwitchManager 7.2.0〜7.2.6および7.0.0〜7.0.5。元々は2025年付のCVEだが、リモートアクセス型トロイの木馬「PivotC2」を展開する実悪用が確認され、2026-09-09にCISA KEVへ追加(連邦機関の対応期限は2026-09-12)。

## 4. CVE-2026-19490 — Citrix NetScaler ADC/Gateway 認証バイパス

**原理・根本原因:** NetScalerアプライアンスがGatewayまたはAAA(認証・認可・監査)仮想サーバーとして構成されている場合(SSL VPN、ICA Proxy、CVPN、RDP Proxy用途を含む)に、代替経路による認証バイパス(CWE-288)が存在します。特定のファームウェアおよびSAML設定条件下では、リクエストがプライマリの認証フローと同じログインチェックを強制しない代替コードパスに到達してしまい、リモートの未認証攻撃者がログインを完全に回避し、本来VPN/ゲートウェイの背後に保護されているサービスに到達できます。

**対応(緩和策):**
- Citrixが提供する修正済みNetScalerファームウェアを直ちに適用する。
- NetScaler Gateway/AAAアプライアンスは通常ネットワークの境界に配置されるため、未パッチのインスタンスは優先度の高いインシデントとして扱う。対応するログインイベントを伴わない異常なセッション生成がないか認証ログを確認する。

**対象:** GatewayまたはAAA仮想サーバーとして構成されたCitrix NetScaler ADCおよびNetScaler Gatewayアプライアンス。2026-08-21に詳細が公開。実際の実悪用が確認されており、2026-09-09にCISA KEVへ追加。

## 5. CVE-2026-20079・CVE-2026-20316 — Cisco Secure Firewall Management Center(FMC)連鎖型侵害

**原理・根本原因:** CVE-2026-20079(CVSS 10.0)は、FMC起動時に作成される不適切に処理されたシステムプロセスに起因します。基盤となるデータベースに部分的な管理セッションレコードが残され、起動後に正規ユーザーが認証しなかった場合、未認証のリモート攻撃者が細工したHTTPリクエストをWebインターフェースに送信することで、その残留セッションをroot権限でのコマンド実行が可能なものへと昇格させることができます。CVE-2026-20316(CVSS 8.9)は、これとは別の静的認証情報の問題です。FMCに組み込まれたハードコードされた低権限アカウントにより、未認証の攻撃者がWebインターフェースにログインし、機密データを直接読み取ることができます。Ciscoおよび外部研究者は、この2つの脆弱性が侵入行為者によって組み合わせて使われ、初期アクセスの獲得からroot権限への昇格に用いられていると報告しています。

**対応(緩和策):**
- 未適用の場合、Ciscoの修正(2026-07-29から提供済み)を直ちに適用する。
- インターネットに到達可能で未パッチのFMCインスタンスは、侵害されているものとして扱う。Webシェル、JARベースのコマンド実行ツール、Netcatリバースシェル、プロキシツールなどの痕跡を調査し、認証情報のローテーションと不正な管理者アカウントの有無を確認する。

**対象:** 2026年7月の修正版より前のCisco Secure Firewall Management Centerソフトウェア。両CVEとも国家支援型・ランサムウェア関連の攻撃者による実悪用が確認されている。CVE-2026-20316は2026-07-29にCISA KEVへ追加され、CVE-2026-20079は(Ciscoによる新たな確認と合わせ)2026-09-09〜10頃に追加されたと報じられている。実悪用の連鎖に関するCiscoの新たな確認により、今週特に注目される項目。

## 6. CVE-2026-86218(CVE-2026-86206/86207を含む)— N-able N-central 認証前リモートコード実行

**原理・根本原因:** CVE-2026-86218は、N-central(マネージドサービスプロバイダーが利用するRMMプラットフォーム)における静的・未サニタイズのコードインジェクションの欠陥で、未認証の攻撃者が実行可能コードとしてサーバーに評価される入力を送信でき、資格情報を一切必要とせずにリモートコード実行につながります。別途、CVE-2026-86206とCVE-2026-86207は連鎖させることで認証を完全にバイパスし、攻撃者が制御する新規のシステム管理者アカウントを作成できます。N-centralは通常、多数の下流顧客エンドポイントを管理するために利用されるため、アプライアンス自体の侵害はサプライチェーン型の足がかりとなり、管理下の全環境への波及点となります。

**対応(緩和策):**
- オンプレミス版N-centralを直ちに2026.3.1.14(または2026.3 Hotfix 4のベースライン)へアップグレードする。
- N-centralサーバーのインターネット露出を監査し、予期しない管理者アカウント作成を含め、2026年9月上旬まで遡って侵害の兆候がないかログを確認する。

**対象:** 2026年9月のホットフィック以前のN-able N-centralオンプレミス導入環境。過去5週間で4回目のN-centralホットフィックとなる。2026-09-05にパッチ提供。「完全にパッチ適用済み」とされていた環境が侵害された事例(根本原因は調査中)を含め、実悪用が確認されている。CISA KEVに追加され、連邦機関の対応期限は本日2026-09-11。

## 7. CVE-2026-87491・CVE-2026-85046 — Google Chrome V8ゼロデイ(サンドボックス脱出への連鎖)

**原理・根本原因:** いずれもChromeのJavaScript/WebAssemblyエンジンであるV8におけるメモリ安全性の不具合です。CVE-2026-85046は型混同(type confusion)の欠陥で、エンジンがメモリ上のオブジェクトの型を誤って解釈し、細工したスクリプトによって意図しない挙動を引き起こすことができます。CVE-2026-87491は境界外書き込み(out-of-bounds write)で、細工された入力によってエンジンが割り当てられたバッファの境界を超えて書き込みを行います。いずれも被害者が悪意あるWebページを閲覧するだけでトリガー可能であり、Chromeのレンダラーサンドボックス内での任意コード実行に悪用され得ます。これは通常、サンドボックスを完全に脱出することを狙ったより長い攻撃連鎖の第一段階となります。

**対応(緩和策):** Chromeを153.0.8010.36/.37(またはそれ以降)へ更新する。これには、まだ適用していない場合は前回の152.0.7977.82/.83リリースで提供されたCVE-2026-85046の修正も含まれる。Edge、Brave、Operaなど他のChromiumベースブラウザについても、各ベンダーが提供する同等の更新を適用する。

**対象:** 152.0.7977.82より前のChromeバージョン(CVE-2026-85046、2026-09-03にパッチ)、および153.0.8010.36より前のバージョン(CVE-2026-87491、2026-09-08にパッチ)。いずれもゼロデイとして実悪用が確認されている。Googleはいずれについても攻撃者の帰属や標的の詳細を公表していない。これは2026年にパッチされた実悪用ゼロデイとしては7件目にあたる。

## 8. CVE-2026-81963・CVE-2026-85880 — Microsoft Windows ゼロデイ(9月Patch Tuesday)

**原理・根本原因:** CVE-2026-81963は、Windows Update Stackにおける不適切なリンク解決(「リンク追従」)の欠陥です。ローカル攻撃者は、更新プロセスが操作されたファイルシステムリンクを追従するよう仕向けることができ、Update Stackの昇格された権限で攻撃者が選択したファイルに対して操作を行わせることができます。CVE-2026-85880は、ローカルプロセス間通信に使用されるOS機能であるWindows Advanced Local Procedure Call(ALPC)におけるヒープベースのバッファオーバーフローで、不正な形式の入力によってヒープメモリが破壊され、権限昇格に悪用され得ます。いずれも、既に低権限のコード実行を有するローカル攻撃者がSYSTEM権限まで昇格することを可能にします。

**対応(緩和策):** 過去最大規模となった2026年9月のPatch Tuesday(修正されたCVEは約973〜974件、うち105〜113件がCriticalと評価)の一部として提供された、Microsoftの2026年9月累積更新プログラムを適用する。

**対象:** CVE-2026-81963は現行のWindows 11リリースおよびWindows Server 2025に影響。CVE-2026-85880は古いWindows 10およびWindows Serverの系列に影響。いずれもパッチ提供前から実悪用が確認されていたゼロデイ。2026-09-08にパッチ提供、同日中にCISA KEVへ追加(連邦機関の対応期限は2026-09-22)。(別件として、Windows Defenderに対する「ShieldCrash」と名付けられたPoC手法も今回開示されており、SYSTEM権限でのファイル読み取りに至る経路が説明されているが、本稿執筆時点でベンダー修正は未提供。)

## 9. CVE-2026-75650 — Adobe Commerce / Magento Open Source テンプレートインジェクションのゼロデイ

**原理・根本原因:** この脆弱性は、Magentoのメールテンプレートシステムを悪用します。通常の取引メール(「決済取引失敗リマインダー」通知)を生成する際に使用されるデータに細工した値を注入することで、テンプレートエンジンが攻撃者制御のコンテンツを無害なテキストではなく実行可能なPHPコードとして評価してしまいます。このテンプレートは通常の注文・決済処理の一環として自動的にレンダリングされるため、認証もユーザー操作も不要であり、攻撃者は脆弱なメール経路をトリガーするだけで済みます。

**対応(緩和策):** Adobeが提供するAPSB26-146の更新を直ちに適用する。CVSS 10.0の評価と実悪用が確認されていることから、有効な回避策は存在しない。

**対象:** Adobe CommerceおよびB2Bエディションの2.4.4〜2.4.9、ならびにMagento Open Sourceの2.4.6〜2.4.9。ゼロデイとしての実悪用は2026-09-04から開始(Sansecが特定)、Adobeは2026-09-07にパッチを提供。攻撃者は既にステルス性の高いRustベースのバックドアと従来型のPHP Webシェルの両方を展開していることが確認されており、未パッチのインターネット公開ストアはパッチ適用後であっても既に侵害されている可能性があるものとして扱い、永続化の痕跡を確認すべきである。

## 10. SAP 2026年9月セキュリティパッチデー — 4件のCritical脆弱性

**原理・根本原因:** SAPの9月パッチデーでは19件のセキュリティノートが提供され、うち4件がCriticalに分類されました。CVE-2026-44756(CVSS 10.0)は、Kernel/Web Dispatcher内のSAP「Extended Passport」処理におけるメモリ破損の問題で、認証なしに到達可能です。CVE-2026-58240(「S4GET」、CVSS 9.8)は、SAP GUIのログオン要求をルーティングする内部ブローカーであるNetWeaver Message Serverにおけるロジックの欠陥で、未認証のリモートコード実行を可能にし、現行のS/4HANAリリースで使用されるカーネル系列に影響します。CVE-2026-76969(CVSS 9.4)は、SAP Cloud Application Programming Modelのマルチテナンシーライブラリを用いて構築されたマルチテナントアプリケーションにおいて、認証情報の露出につながる可能性があります。CVE-2026-66768(CVSS 9.0)は、SAP GUI for Javaにおける不適切なアクセス制御の問題です。

**対応(緩和策):** 影響を受けるKernel、Web Dispatcher、NetWeaver、CAP(`@sap/cds-mtxs`)、SAP GUI for Javaの各コンポーネント向けに、2026年9月のSAPセキュリティノートを遅滞なく適用する。未認証のリモートコード実行に直結するCVE-2026-44756およびCVE-2026-58240を優先すること。

**対象:** SAP Kernel 7.22/7.53/7.54/7.77/7.89/7.93/8.04およびWeb Dispatcher 9.16〜9.20(CVE-2026-44756)。カーネル9.16/9.18/9.19/9.20上のNetWeaver Message Server(CVE-2026-58240、現行の全S/4HANA 2025システムに影響)。`@sap/cds-mtxs`を使用するCAPマルチテナントアプリケーション(CVE-2026-76969)。SAP GUI for Java(CVE-2026-66768)。2026-09-08にパッチ提供。現時点で実悪用の確認報告はないが、未認証のRCEという性質とSAPシステムの一般的な業務重要性を踏まえ、緊急のパッチ適用が推奨される。

## 11. CVE-2026-1357 — WPvivid Backup & Migration(WordPressプラグイン)未認証RCE

**原理・根本原因:** プラグインのRSAベース復号処理における暗号的な「フェイルオープン(検証失敗時に処理を許可してしまう)」欠陥と、アップロードファイル保存時のパス検証不足という2つの欠陥が連鎖することで、未認証の攻撃者がプラグインの`send_to_site`アクションを介して任意のファイル(実行可能なPHPファイルを含む)をアップロード・配置でき、完全なリモートコード実行に至ります。悪用には、サイトでデフォルト無効の「他サイトからのバックアップ受信」機能が有効になっている必要があり、攻撃者は関連する暗号鍵の有効期限であるおよそ24時間の時間枠内に行動する必要があります。

**対応(緩和策):** WPvivid Backup & Migrationをバージョン0.9.124以降へ更新する。「他サイトからのバックアップ受信」機能を積極的に利用していないサイトでは無効化する。

**対象:** WPvivid Backup & Migrationのバージョン0.9.123以前(有効インストール数90万以上)。今週広く報じられたが、二次情報源間で当初の開示時期の記載に一貫性がなく(2026年の早い時期を初出とする情報もある)、正確な開示日は未確認として扱い、露出評価にあたっては日付よりもバージョン確認を優先すべきである。

## 13. CVE-2026-32475 — Elementor Pro(WordPressプラグイン)任意ファイルアップロード(継続情報)

**原理・根本原因:** Elementor ProのFormsモジュールは、アップロードされたファイルの検証・処理を、「ファイル未送信」状態を異なる方法で扱う2つの別々のコードループで行っています。細工したマルチパートフォーム送信によってこの不整合を悪用すると、本来拒否されるべきファイルアップロードが受け入れられ、実行可能な拡張子を持つWebアクセス可能なパスに書き込まれてしまい、未認証の攻撃者にリモートコード実行を許してしまいます。

**対応(緩和策):** Elementor Proをバージョン4.2.2以降へ更新する。

**対象:** Elementor ProのFormsモジュール、バージョン4.2.1まで(インストール数約1,000万)。2026-07-16に確認され、2026-08-19に詳細公開・パッチ提供。既にサイト侵害への悪用が確認されており、9月上旬時点でもインストールの約2/3が未パッチのままでした。開示時期は今週の対象期間より前ですが、現在も高蔓延度の実際のリスクであるため、ここに含めています。
