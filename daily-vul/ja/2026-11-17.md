## 1. CVE-2026-90436 — Apache Axis 1.x の安全でないリフレクション（Confluence Data Center、N-able N-central）

**原理／根本原因：** レガシー SOAP ライブラリである Apache Axis 1.x は、例外クラス名を指定できる SOAP フォルトメッセージを処理します。Axis は指定されたクラスを読み込み、それが正当なフォルト型であることを検証する**前に**インスタンス化する場合があります（CWE-470：外部から制御される入力によるクラス／コードの選択）。クラスを読み込むだけで static 初期化子が実行されうるため、クラス名を制御できる攻撃者は本来到達できないコードパスを起動できます。さらに、このフォルトは Axis が呼び出し先サービスを解決している段階、すなわちサービスごとの認証ハンドラが動作する前に解析されるため、サービス単位の認証では防げず、Axis エンドポイントを公開する製品では実質的に認証前の RCE となります。

**緩和策：**
- **Confluence Data Center：** 9.2.28 以降（または Remote API 機能自体が削除された 10.x）へアップグレード。すぐにアップグレードできない場合は **Remote API（XML-RPC & SOAP）機能を無効化**してください（有効時のみ脆弱）。
- **N-able N-central：** N-able のアドバイザリに従い修正ビルドを適用。パッチ適用までコンソールへのネットワークアクセスを制限。
- **Axis 1.x を同梱するその他のソフトウェア：** Axis 1.x は EOL で、Apache は 1.x の新リリースを予定していません。上流のパッチコミットを適用するか Axis2/Java へ移行してください。
- Java アプリケーションプロセスがシェルやダウンロードツール（`bash`、`curl` など）を起動していないか、SOAP エンドポイントで不審な HTTP 500 応答がないかを調査。

**影響：** Apache Axis 1.x（1.4 まで）およびこれを組み込む製品。Atlassian Confluence Data Center 9.2.28 未満（Remote API 有効時）、および影響を受ける N-able N-central バージョンを含む。2026-11-06 公開。Rapid7 が 2026-11-13 に Confluence に対する実際の悪用を観測し、2026-11-17 にも Confluence および N-central に対する悪用報告が続いています。公開エクスプロイトコードの存在が報告されています。

## 2. CVE-2026-125160 & CVE-2026-125163 — TYPO3 CMS Form Framework（アップロードパス漏えい＋無制限アップロード）

**原理／根本原因：**
- **CVE-2026-125160（情報漏えい、CVSS 6.3）：** フォームのファイルアップロードが失敗した際のエラーメッセージに、アップロードフォルダのサーバー側保存パスが含まれていました。通常このパスは推測困難として扱われるため、漏えいにより攻撃者はフォーム経由でアップロードされたファイルの公開 URL を特定できます。
- **CVE-2026-125163（無制限ファイルアップロード）：** FileUpload／ImageUpload フォーム要素に設定された MIME タイプ許可リストが実際には適用されておらず、未認証の訪問者がブラウザで実行可能なファイル形式（HTML、SVG など）をアップロードできました。
- 両者を組み合わせると、攻撃者はアクティブコンテンツを公開ストレージに配置しその URL を把握できるため、該当フォルダに厳格な Content-Security-Policy を適用していないサイトで格納型クロスサイトスクリプティングが成立します。

**緩和策：**
- TYPO3 14.3.12 LTS、13.4.40 LTS、12.4.52 ELTS、11.5.57 ELTS、または 10.4.63 ELTS へ更新。
- フォームのアップロード先フォルダに厳格な Content-Security-Policy を適用（TYPO3 同梱の `fileadmin/.htaccess` は Apache 上のデフォルトストレージで適用します。nginx 等では設定を確認してください）。
- すべてのフォームアップロードフィールドで許可 MIME タイプを明示的に設定し、アップロードフォルダに想定外の HTML／SVG ファイルがないか確認。

**影響：** Form Framework（`ext:form`）を使用する TYPO3 CMS の上記修正版未満。2026-11-17 公開（TYPO3-CORE-SA-2026-029 および -032、約10件の修正の一部）。TYPO3 は CVE-2026-125160 が悪用されていると報告しています（一部アグリゲーターは異なる見解）。同じバッチのインストーラー関連の別の脆弱性は CVSS 9.4 と報じられています。詳細は TYPO3 のアドバイザリ一覧を確認してください。

## 3. N-able N-central "4EverAble2Shell" / "Agent2Shell" ゼロデイ（CVE 未採番）

**原理／根本原因：** あるセキュリティ研究者が、リモート監視・管理（RMM）プラットフォーム N-able N-central に対する2つのエクスプロイトチェーンを公開しました。1つは N-central アプライアンス上での root 権限、もう1つは管理対象 Windows エージェント上での SYSTEM 権限を取得するものです。ベンダーは詳細な根本原因を公表していません。同研究者は今年すでに一連の N-central 脆弱性を公開しています。

**緩和策：**
- N-able の最新のセキュリティ更新とガイダンスに従う。N-able はホスト型 N-central 環境をオフラインにし、オンプレミス顧客に修正準備中はサーバーを停止するよう呼びかけたと報じられています。
- N-central コンソールをインターネットに公開しない。VPN／信頼済み IP 範囲にアクセスを限定。
- N-central サーバー上の暗号資産マイナー、新規サービス、想定外の外向き通信を調査。RMM の侵害はすべての管理対象端末に波及するため、エージェント経由で発行されたタスクやスクリプトも確認。
- これは Apache Axis 経由の N-central に対する CVE-2026-90436 の悪用（項目1）とは別件ですが、時期が重なっています。

**影響：** N-able N-central オンプレミスアプライアンスおよび管理対象 Windows エージェント。当時の最新セキュリティ更新を適用済みのシステムも含まれると報じられています。PoC 公開から数時間以内に悪用が始まり（2026-11-12 報道）、少なくとも21台のサーバーが侵害され暗号資産マイナーが展開されました。CVE および CISA KEV 登録はまだありません。

## 4. CVE-2026-123039 — Check Point Gaia OS のローカル権限昇格（PHP2Shell との連鎖）

**原理／根本原因：** Check Point Gaia OS のローカル権限昇格の脆弱性で、`dynamic_server` コンポーネントに存在すると報じられています。低権限プロセスが root を取得できます。観測された攻撃では、Mobile Access ポータル上の PHP2Shell 脆弱性（CVE-2026-109618 / CVE-2026-109619 — 中断されたリクエストが PHP ランタイムの内部状態を中途半端に更新したまま残し、後でそれを信頼してしまうことによる認証不要の RCE）で初期侵入し、CVE-2026-123039 で root へ昇格していました。攻撃者は破壊型ワイパーマルウェアを展開し、VMware ESXi ホストも被害を受けました。

**緩和策：**
- 11月の Jumbo Hotfix を適用（報道されているテイク：R82.20 Take 14 以降、R82.10 Take 52 以降、R82 Take 132 以降、R81.20 Take 174 以降 — Check Point sk1000362 で確認）。
- PHP2Shell の修正（sk1000302）が適用済みであることを確認。インターネットに面した Mobile Access ゲートウェイを優先。
- すぐに適用できない場合：`dynamic_server` プロセスを停止し、再起動しないようにする（ベンダーの暫定緩和策）。R81.10（サポート終了）には該当 Jumbo テイクがないため、アップグレードまたはベンダーの緩和策を適用。
- 環境内のその他の PHP：PHP 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 以降へ更新。

**影響：** 11月の Hotfix 未適用の Gaia OS を実行する Check Point Security Gateway、Firewall、Security Management Server、Multi-Domain Security Management Server、Scalable Platforms。「数十」の顧客に対して悪用。2026-11-13 に CISA KEV へ追加、連邦機関期限 2026-11-16（経過済み）。

## 5. CVE-2026-114713 — UnrealIRCd のメッセージタグ未エスケープによるコマンドインジェクション

**原理／根本原因：** IRCv3 の `labeled-response` モジュールが、クライアントから送られた `label` メッセージタグを適切にエスケープせずに応答へ反映します。IRC プロトコルは行区切りであるため、このタグに改行を挿入できるユーザーは追加のプロトコル行 — リンクされたネットワークではサーバー間コマンドを含む — を紛れ込ませることができます（CRLF インジェクション系のコマンド／プロトコルインジェクション）。メンテナーは「15年間で最悪の UnrealIRCd の問題」と述べています。

**緩和策：**
- UnrealIRCd 6.2.7.1（2026-11-07 公開、9件の問題を修正）へアップグレード、または 6.0.0〜6.2.7 ではメンテナーのホットパッチ（bundle-20261107）をネットワーク内の**全サーバー**に適用。
- UnrealIRCd 5（2023年から EOL）も影響を受けます：`labeled-response` モジュールを無効化（ブラックリスト化）して再起動し、アップグレードを計画。

**影響：** UnrealIRCd 6.0.0〜6.2.7（および EOL のバージョン 5）。2026-11-07 修正。悪用確認済み。2026-11-13 に CISA KEV へ追加、連邦機関期限 2026-11-16（経過済み）。

## 6. CVE-2026-119618 — Apache HTTP Server mod_http2 の競合状態（RCE）

**原理／根本原因：** mod_http2 のヘッダー処理（`assign_headers()` 関数と報じられている）における競合状態により、並行する HTTP/2 ストリーム処理がヒープメモリを破壊する可能性があります。リモートの未認証クライアントから到達可能なヒープ破壊は、httpd ワーカープロセスでのリモートコード実行に悪用されうるものです。Anthropic の OSS スキャナーと Google Cloud Vulnerability Research が発見者としてクレジットされています。

**緩和策：**
- Apache HTTP Server 2.4.71（2026-11-11 公開）へアップグレード。同リリースでは低深刻度の CVE-2026-106023（mod_md）と CVE-2026-109163（mod_vhost_alias）も修正。
- ディストリビューションのパッケージは遅れる場合があります。RHEL 系では修正が AppStream にある場合があるため、CVE フィルタ付きの更新コマンドに頼らず、インストール済みパッケージのバージョンを確認。
- パッチ適用できない場合は、暫定策として HTTP/2 を無効化（`Protocols` から `h2`／`h2c` を削除、または mod_http2 をアンロード）。
- スタンドアロンの `mod_h2` GitHub プロジェクトはアーカイブ済みで公式修正版がないため、2.4.71 同梱のモジュールへ移行。

**影響：** HTTP/2 を有効にした Apache HTTP Server 2.4.55〜2.4.70。2026-11-11 修正。**悪用状況は情報が食い違っています：** 今週、悪用と PoC 公開を主張する報告がある一方、他の情報源（および執筆時点の CISA KEV カタログ）では確認されていません。深刻度と露出度を考慮し、いずれにせよ高優先度で対応してください。

## 8. CVE-2026-125350 — Google Chrome XML の Use-After-Free（ゼロデイ）

**原理／根本原因：** Chrome の XML 処理における use-after-free：オブジェクトが解放された後も参照が残り、その後使用されるため、細工された Web コンテンツがメモリを破壊し、レンダラーサンドボックス内でコードを実行できます。Google は実際の悪用を確認しており、2026年に悪用された Chrome ゼロデイとして8件目です。同じリリースで別の XML use-after-free（CVE-2026-125346、悪用報告なし）も修正されました。

**緩和策：** Chrome を 157.0.8103.50/.51 以降に更新して再起動。Microsoft Edge およびその他の Chromium ベースのブラウザも対応ビルドへ更新。

**影響：** 157.0.8103.50 未満のデスクトップ版 Google Chrome、Chromium ベースのブラウザ。2026-11-09 修正。CISA KEV 2026-11-10（期限 2026-11-24）。

## 9. CVE-2026-124194 — Microsoft Outlook の NTLM ハッシュ漏えい（ゼロデイ）

**原理／根本原因：** なりすまし／潜在的に危険な操作に対するユーザー確認の欠如（CWE-356）に分類。細工されたメッセージファイルを開くと、Outlook は通常の外部コンテンツ警告を表示せずに攻撃者が管理するサーバーへ接続し、ユーザーの NTLMv2 認証情報を漏えいさせます。これはオフラインで解析されたり、他のサービスへリレー（NTLM リレー）されたりする可能性があります。

**緩和策：**
- 2026年11月の Office／Microsoft 365 セキュリティ更新（2026-11-10 公開）を適用。
- インターネットへの外向き SMB（TCP 445）をブロック。重要ユーザーを Protected Users グループに追加。SMB／LDAP 署名と Extended Protection for Authentication を強制してリレーを抑止。

**影響：** Microsoft 365 Apps for Enterprise、Office LTSC 2021、Office LTSC 2024（32/64ビット）。ゼロデイとして悪用。CISA KEV 2026-11-10、期限 2026-11-24。非常に大規模な11月の Patch Tuesday（情報源により約1,090〜1,200件超の CVE、Critical 約63件）における唯一の悪用済みゼロデイです。

## 10. CVE-2026-20320 — Cisco BroadWorks の XXE、CVE-2026-111793 — Openwave Webtop

**原理／根本原因：** CVE-2026-20320 は BroadWorks の Open Client Interface XML パーサーにおける XML 外部実体参照（XXE）の脆弱性です。パーサーが攻撃者の送る XML 内の外部実体を解決するため、未認証のリモート攻撃者がサーバー上の機密ファイルを読み取れます。Openwave Webtop の CVE-2026-111793 も同日に KEV へ追加されました（詳細は限定的）。

**緩和策：** 影響を受ける BroadWorks 製品を RI.2026.07 以降へアップグレード（Cisco は回避策なしとしています）。OCI の公開範囲を信頼済みネットワークに限定。Openwave はベンダーの修正を適用。

**影響：** RI.2026.07 未満の Cisco BroadWorks（4製品）、Openwave Webtop。いずれも 2026-11-10 に CISA KEV へ追加、期限 2026-11-24。BroadWorks の悪用は通信事業者を狙う攻撃者によるものとされています（未確認）。

## 11. CVE-2026-123158（"SSHole"）— OpenSSH のパスワード認証バイパス

**原理／根本原因：** portable 版 OpenSSH の sshd を **musl libc** 環境（Alpine Linux など）で **PAM なし**でビルドした場合、sshd は自身でパスワードを検証しますが、その処理の欠陥により過大な長さのパスワード入力で検証を回避でき、本来パスワードログインが無効なアカウントへのログインが可能になります。

**緩和策：** OpenSSH 10.6p2 以降へアップグレード（Alpine ではパッケージ更新後に sshd を再起動）。可能な限りパスワード認証を無効化し鍵認証を使用。

**影響：** musl libc かつ非 PAM のパスワード認証を使用する Linux 上の 10.6p2 未満の portable OpenSSH。2026-11-05 修正、2026-11-07 から悪用、CISA KEV 2026-11-09（期限 2026-11-12）。
