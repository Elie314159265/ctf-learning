## 1. CVE-2026-94127 — F5 BIG-IP APM ヒープバッファオーバーフロー（未認証RCE）

**原理・根本原因:** APM（Access Policy Manager）のアクセスポリシーと OAuth プロファイルを同時に設定した BIG-IP 仮想サーバーにおいて、OAuth 処理コードが攻撃者の影響を受けるデータをサイズ検証なしにヒープバッファへ書き込みます（CWE-122）。この過大な書き込みにより、Traffic Management Microkernel (TMM) データプレーン内の隣接ヒープメモリが破壊されます。攻撃者は破壊される領域に流れ込む内容を操作できるため、このメモリ破壊を任意コード実行へと発展させることが可能であり、しかも認証は一切不要です。

**対策:**
- F5 のアドバイザリ K000162872 に従い、該当バージョンに対する修正を速やかに適用する。
- パッチ適用前は、影響を受ける仮想サーバーについて F5 サポートから iRule ベースの暫定緩和策を入手する。
- APM アクセスポリシーと OAuth プロファイルを併用している仮想サーバーを洗い出す（この組み合わせのみが影響を受ける）。

**影響範囲:** BIG-IP APM 17.1.0〜17.1.3、17.5.0〜17.5.1、21.1.0（APM アクセスポリシーと OAuth プロファイルの両方を設定した仮想サーバーのみ）。2026-09-02 に F5 が社内発見として公表。カナダサイバーセキュリティセンターも悪用を裏付けており、2026-09-22 に CISA KEV へ追加。

## 2. CVE-2026-85102 & CVE-2026-93616 — Check Point Security Gateway / Management Server のゼロデイ

**原理・根本原因:** CVE-2026-85102 は Check Point Security Gateway（特に Spark ファイアウォール）の VPN 証明書処理における未認証の欠陥で、認証バイパスからリモートコード実行に至ります。CVE-2026-93616 は Check Point Management のWebサービスにおける未認証のパストラバーサル脆弱性で、細工したパスにより未認証の攻撃者が任意の場所からスクリプトを実行させ、任意の Java クラスをロードさせることができ、実質的に管理プレーン上でのコード実行を実現します。

**対策:**
- 両CVEに対するCheck Pointの緊急ホットフィックスを直ちに適用する（CVE-2026-85102 は2026年9月上旬から、CVE-2026-93616 は2026年7月の限定攻撃公表後から提供済み）。
- Security Gateway の VPN ポータルおよび Management Server の Web インターフェースのインターネット露出を制限し、特に VPN・プロキシ等の匿名化インフラからの通信を含む不審な認証・スクリプト実行活動をログで確認する。

**影響範囲:** Check Point Security Gateway / Spark ファイアウォール（CVE-2026-85102）、Security Management Server、Multi-Domain Security Management Server、Log Server、Multi-Domain Log Server、SmartEvent（CVE-2026-93616）。Spark を狙った悪用の波が2026-09-12から観測されており、両CVEとも2026-09-22にCISA KEVへ追加。

## 3. CVE-2026-93952 — Arista VeloCloud Orchestrator 未認証の特権アクセス

**原理・根本原因:** VeloCloud Orchestrator (VCO) の Web インターフェースにおける不適切な入力検証により、リモートの未認証攻撃者が、本来オペレーター／テナントの資格情報を必要とする内部の特権機能に到達できます。この露出は、管理対象の Edge デバイスを証明書で認証するよう設定されたオーケストレーターに特に影響し、攻撃が成功するとオーケストレーター自体、さらには管理下の Edge デバイスまでもが侵害される可能性があります。

**対策:**
- 5.2系および6.4系の修正リリースを直ちに適用する。6.1系および7.0系向けの修正についてはAristaのアドバイザリを注視し、公開され次第適用する。
- 暫定策として、VCO Webインターフェースへのネットワークアクセスを信頼できる管理ネットワークに制限する。

**影響範囲:** Edge の認証に証明書を使用している（自己ホスト型の）VeloCloud Orchestrator。Arista がホストする版および専用版 VCO インスタンスは Arista によって既にパッチ適用済み。外部報告により発見され、悪用が確認されており、2026-09-22 に CISA KEV へ追加。CVSS 10.0。

## 4. CVE-2026-7273 — Zyxel GS1900 シリーズスイッチのスタックバッファオーバーフロー

**原理・根本原因:** Zyxel GS1900 スイッチの CGI プログラムは、ユーザー入力の長さを検証しないまま固定長のスタックバッファへコピーします（CWE-121）。同一ローカルネットワーク上の攻撃者が、細工した過大な HTTP リクエストを送信することで隣接するスタックメモリを上書きでき、CGI プロセスの実行フローを制御下に置き、最終的に認証なしで任意の OS コマンドを実行できます。

**対策:**
- GS1900-48HPv2（および他の影響を受けるモデル）のファームウェアを 2.90(ABTQ.2)C0 以降にアップグレードする。
- 管理インターフェースへのアクセスを信頼できる管理VLAN・ネットワークに制限し、2026年8月中旬以降の不正な設定変更や認証情報流出の兆候がないかスイッチを確認する。

**影響範囲:** Zyxel GS1900 シリーズスイッチ、ファームウェア 2.90(ABTQ.1)C0 以前。中国語話者とみられる脅威アクターが2026-08-17からこの脆弱性を悪用しており、48カ国で推定996台のスイッチから設定情報とハッシュ化されたrootクレデンシャルが窃取されたとみられる。2026-09-21にCISA KEVへ追加され、連邦機関の対応期限は2026-09-24。

## 5. CVE-2026-89422 — Erlang/OTP TLS 1.3 要求外PSKによる認証バイパス

**原理・根本原因:** Erlang/OTP の `ssl` クライアントが TLS 1.3 をネゴシエートする際、自身が提示していない `pre_shared_key` 拡張を ServerHello 内に受け取っても、それを受け入れてしまう場合があります。これによりクライアントの状態遷移が直接セッション再開経路（`maybe_resumption/1` → `wait_finished`）に進み、証明書関連の処理――証明書チェーン検証、`verify_fun`、ホスト名検証、`partial_chain`、CRL確認、OCSPステープリング――がすべて省略されます。結果として、有効な証明書も秘密鍵も持たない通信相手が「成功した」ハンドシェイクを完了でき、信頼されたサーバーとして扱われるため、中間者攻撃によるなりすましが可能になります（CWE-322: エンティティ認証を伴わない鍵交換）。

**対策:**
- OTP 27.3.4.18、28.5.0.7、29.1.1、またはそれ以降（対応する `ssl` アプリのバージョン 11.2.12.13、11.6.0.6、11.7.7）へアップグレードする。
- この脆弱性はTLS 1.3のセッション再開経路に固有であるため、暫定策として、パッチ適用まで対象のTLSクライアントをTLS 1.2に制限する。

**影響範囲:** OTP 22.2 以降、上記修正版より前の Erlang/OTP `ssl`（デフォルトのクライアント設定が対象）。2026-09-22 に公開。本稿執筆時点で実際の悪用は報告されていないが、深刻度（CVSS 9.3）とメッセージング・通信インフラにおける Erlang/OTP の普及度を考えると速やかなパッチ適用が望ましい。

## 6. CVE-2026-94301 — Apache MINA `resolveProxyClass` 許可リストバイパス（修正不備）

**原理・根本原因:** これは修正不備に起因する問題です。以前の Apache MINA の脆弱性（CVE-2026-47065）で、デシリアライズ／プロキシ可能なクラスを制限する `acceptMatchers` 許可リストが追加されましたが、`resolveProxyClass()` における `java.lang.reflect.Proxy` オブジェクトの取り扱いに関する修正は MINA 2.2.x ブランチにのみコミットされていました。2.0.x および 2.1.x のメンテナンスブランチ――元の問題を修正済みとされていたリリースを含む――は依然としてバイパス可能であり、攻撃者はプロキシオブジェクトを介して許可リストを回避し、許可されていないデシリアライズ・コードパスに到達でき、任意コード実行につながる可能性があります。

**対策:**
- 完全な修正を含む Apache MINA 2.2.x ブランチ（2.2.8 以降など）へ移行する。
- 直ちに移行できない場合は、可能な限り厳格なデシリアライズ許可リストを適用し、MINAベースのサービスを信頼できないネットワークに公開しないようにする。

**影響範囲:** Apache MINA 2.0.x および 2.1.x ブランチ、2.0.30 および 2.1.14 までのバージョンを含む（すなわちCVE-2026-47065を修正済みとしていたが、このバイパスは未修正のリリース）。2026-09-22頃公開。本稿執筆時点で実際の悪用は確認されていない。CVSS 9.8。

## 7. CVE-2026-94545 (GHSA-vcvr-r3jv-pc5j) — Next.js `next/og` ImageResponse のリモートコード実行

**原理・根本原因:** `next/og` の `ImageResponse` の Node.js 実装は、動的な画像（例：Open Graph画像）を生成するために SVG 風のマークアップをレンダリングします。アプリケーションコードが十分なサニタイズを行わずに攻撃者が制御可能なデータを SVG の要素・属性・スタイルに渡した場合、レンダリングパイプラインを操作されてリモートコード実行に至る可能性があり、認証もユーザー操作も不要です。

**対策:**
- Next.js 16.3.6 以降（または、RCE自体の影響は受けないもののNext.js 15.x向けの関連する強化策が含まれる15.5.26）へアップグレードする。
- `next/og` の `ImageResponse` の利用箇所を監査し、攻撃者の影響を受ける入力が SVG コンテンツに流れ込んでいないか確認し、アップグレードまではそうした入力を信頼できないものとして扱う。

**影響範囲:** Next.js バージョン 16.2.0 以上 16.3.6 未満。2026-09-22 の緊急（out-of-band）セキュリティリリースで修正済み。本稿執筆時点で実際の悪用は報告されていないが、認証・ユーザー操作が不要である点とCritical（CVSS v4）評価を踏まえ、特にユーザー入力から動的にOG画像を生成する公開アプリケーションでは速やかなパッチ適用が重要。

## 8. CVE-2026-86473 — Apache Airflow ログアウト時のセッション失効不備

**原理・根本原因:** Airflow の Core API のログアウトエンドポイントは、セッショントークンが `_token` クッキーとして提示された場合にのみそれを失効させます。クライアントが同じトークンを `Authorization` ベアラーヘッダーとして認証に使用していた場合、ログアウトエンドポイントは通常の成功レスポンスを返すものの、実際にはトークンを失効させません（CWE-613: 不十分なセッション有効期限）。ベアラートークンのコピーを入手した攻撃者は、正規ユーザーがログアウトしたと認識した後もトークンの有効期間（デフォルト24時間、設定変更可能）が尽きるまで有効なアクセスを維持できます。

**対策:**
- Apache Airflow 3.3.2 以降へアップグレードする。
- 可能であればデフォルトのトークン有効期間を短縮し、アップグレード後も、それ以前に発行済みのベアラートークンは設定された有効期限まで有効である可能性がある点に留意する。

**影響範囲:** 3.3.2 より前の Apache Airflow デプロイメント。2026-09-21 公開。本稿執筆時点で実際の悪用は報告されていない。CVSS 9.1。

## 9. CVE-2026-32996 — Veeam Agent for Microsoft Windows のローカル権限昇格

**原理・根本原因:** Veeam Endpoint Backup サービスは、ローカルの gRPC 名前付きパイプ経由でクライアントと通信します。昇格されたクライアントセッションを処理する際、このサービスは、リクエスト元の特定ユーザーや接続に適切に紐づけられていないクライアント提供のセッションUIDに対して、昇格された「管理者」プリンシパルをキャッシュしてしまいます（CWE-284系のアクセス制御不備）。ローカルの低権限ユーザーはこれを悪用し、自身のセッションをキャッシュされた昇格プリンシパルとして扱わせることで、`NT AUTHORITY\SYSTEM` へと昇格できます。

**対策:**
- Veeam Backup & Replication を 13.0.2.29 以降へアップグレードする（これにより Veeam Agent for Windows もビルド 13.0.3.1220 に更新され、修正が適用される）。
- 公開PoCコードが既に出回っているため、ローカル・低権限アクセスが可能なホスト（共有ワークステーション、マルチテナントのビルドホスト等）では緊急対応として扱う。

**影響範囲:** Veeam Agent for Microsoft Windows 13.0.1.2067 以前のバージョン13系ビルド。2026-09-14 に公開PoCが公開。2026-09-22の週の報告によれば、実際の悪用が確認されており、侵害後の権限昇格活動に組み込まれている。

## 10. CVE-2026-76460 — Cisco Identity Services Engine の認証バイパス（継続項目）

**原理・根本原因:** ISE/ISE-PICのAPIエンドポイントが、認証を適切に強制しないまま特権的な内部APIを誤って信頼しています（CWE-648: 特権APIの不適切な使用）。露出したAPIへの細工された未認証リクエストにより、Webベースの管理画面の認証が完全にバイパスされ、Ciscoによれば悪用が成功するとアプライアンス上でroot権限でのコマンド実行に至る可能性があります。

**対策:** Cisco ISE の修正済みリリースへ直ちにアップグレードする――有効な回避策は存在せず、管理プレーンへのアクセスを制限するインフラストラクチャACLは部分的・暫定的な露出低減にしかならない。

**影響範囲:** Cisco Identity Services Engine (ISE) および ISE-PIC の、未パッチのサポート対象リリース全て。CVSS 10.0。悪用が確認されており、2026-09-16 に CISA KEV へ追加。連邦機関の対応期限は異例に短い3日間（2026-09-19）に設定された。

## 11. CVE-2026-87886 — Acronis Backup プラグインのデフォルト権限不備（継続項目）

**原理・根本原因:** cPanel & WHM、Plesk、DirectAdmin（Linux）向けの Acronis Backup 連携機能は、安全でないデフォルトのファイル権限で提供されています（CWE-276）。Linuxホストに対して既に認証済みの低権限アクセスを持つ攻撃者は、ユーザー操作を必要とせず、この過度に緩い権限を悪用して権限昇格できます。

**対策:** cPanel & WHM 向け Acronis Backup プラグインをビルド 1.9.3.1021 以降、Plesk 拡張機能をビルド 1.8.11.638 以降、DirectAdmin プラグインをビルド 1.2.3.238 以降へアップグレードする。

**影響範囲:** 上記ビルドより前の、Linux上のcPanel & WHM、Plesk、DirectAdmin向けAcronis Backup連携機能。CVSS 7.8。cPanel & WHM環境に対する実際の悪用が観測されており、2026-09-16にCISA KEVへ追加。

## 12. CVE-2026-76461 — Cisco Secure Email Gateway のSQLインジェクションからrootでのRCE（継続項目）

**原理・根本原因:** Cisco Secure Email Gateway の未認証かつネットワーク到達可能なコンポーネントに SQL インジェクションの脆弱性があります。注入された SQL を悪用することで、資格情報なしにアプライアンス上で root 権限でのコマンド実行が可能になります。

**対策:** まだ適用していない場合はCiscoの修正済みソフトウェアリリースを直ちに適用する。連邦機関はCISAのKEV期限に基づき2026-09-17までの対応が義務付けられていた。

**影響範囲:** Cisco Secure Email Gateway の未パッチリリース。CVSS 9.8。2026-09-14に公開・悪用確認され、同日CISA KEVへ追加。厳密な7日間の対象期間からはわずかに外れるが、連邦機関の対応期限および悪用継続が今週も引き続き重要であるため、参考として掲載。
