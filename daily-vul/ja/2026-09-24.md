## 1. CVE-2026-85102 & CVE-2026-93616 — Check Point Security Gateway / Management Server

**原理・根本原因:** CVE-2026-85102 は、Security Gateway および Spark Firewall 製品において VPN ネゴシエーション時に証明書の検証が不適切に行われる脆弱性です。Site-to-Site または Remote Access VPN が有効な場合、証明書処理ロジックが攻撃者提供のデータを受け入れてしまい、未認証のリモートコード実行につながります。CVE-2026-93616 は別の脆弱性で、Management Web サービスにおける未認証で悪用可能なディレクトリトラバーサル兼任意ファイルアップロードの欠陥です。攻撃者は意図したディレクトリ外にファイルを書き込み、任意のスクリプトまたは Java クラスの実行をトリガーできます。

**対策:**
- CVE-2026-85102 に対して Check Point が2026-09-09に公開したホットフィックスを直ちに適用する。
- CVE-2026-93616 に対して Management Web サービスにパッチを適用する。インターネットに公開されている Management インターフェースは最優先で対応する。
- CISA の連邦機関向け対応期限は両方とも2026-09-25。セクターを問わず今すぐパッチを適用すべき。

**影響を受ける製品:** Site-to-Site/Remote Access VPN を利用している、または Management Web サービスが公開されている Check Point Security Gateway、Spark Firewall、Management Server 製品。Check Point は CVE-2026-93616 が2026-07-23からゼロデイとして悪用されていたことを確認しており、CVE-2026-85102 についても Spark 顧客に対する悪用の波が2026-09-12から始まっている。両方とも2026-09-22にCISA KEVへ追加。

## 2. CVE-2026-93952 — Arista VeloCloud Orchestrator 未認証特権アクセス

**原理・根本原因:** オンプレミス版 VeloCloud Orchestrator（VCO）における不適切な入力検証の欠陥（CWE-20）により、リモート攻撃者が有効な認証情報なしに内部の特権機能へアクセスできます。悪用には、VeloCloud Edge デバイスと Orchestrator 間で証明書ベースの認証が構成されている必要があります。VCO の Web UI へのネットワークアクセスと、正規 Edge 認証証明書の公開部分を持つ攻撃者は、信頼された Edge-Orchestrator 間通信になりすまし、本来完全な認証を要求すべき機能へ到達できます。これにより Orchestrator および管理下の全 Edge の機密性・完全性・可用性に影響が及ぶ可能性があります。

**対策:**
- Arista のセキュリティアドバイザリ 0183 に記載されたパッチ済み VCO リリースを直ちに適用する。
- VCO Web UI のネットワーク露出を制限し、証明書ベースの Edge 認証設定に異常がないか監査する。

**影響を受ける製品:** 証明書ベースの Edge 認証を使用しているオンプレミス版 Arista VeloCloud Orchestrator。ゼロデイとして開示・悪用が確認されており、2026-09-22にCISA KEVへ追加。

## 3. CVE-2026-94127 — F5 BIG-IP APM OAuth ヒープバッファオーバーフロー

**原理・根本原因:** BIG-IP Access Policy Manager（APM）の OAuth UserInfo ハンドラは固定サイズ（0x4100バイト）のヒープバッファを確保しますが、攻撃者が制御可能な `Authorization` ヘッダーをそのサイズ制限を検証せずにコピーします。典型的な境界チェック漏れによるヒープオーバーフローであり、隣接するヒープメモリ（関数ポインタに類するデータ構造を含む）を破壊できます。これにより未認証の攻撃者がプログラムの制御フローに介入し、リモートコード実行を達成できる可能性があります。

**対策:**
- F5 の技術情報 K000162605 に記載された修正を直ちに適用する。
- 影響範囲は APM アクセスポリシーと OAuth プロファイルを持ち、APM が OAuth 認可サーバーとして動作している仮想サーバーに限定される。APM をクライアント/リソースサーバーとしてのみ使用する構成は影響を受けないが、念のため構成を確認すること。

**影響を受ける製品:** OAuth 認可サーバーとして構成された F5 BIG-IP APM の、修正版より前のバージョン。ゼロデイとして悪用され、2026-09-22にCISA KEVへ追加。

## 4. CVE-2026-7273 — Zyxel GS1900 シリーズスイッチ スタックバッファオーバーフロー

**原理・根本原因:** GS1900 スイッチの CGI 管理プログラムに、特別に細工した HTTP リクエストで到達可能なスタックベースのバッファオーバーフロー（CWE-121）が存在します。認証は一切不要です。この方法でスタックメモリを上書きすることで、攻撃者はスイッチ自体で OS コマンドを実行できます。

**対策:**
- Zyxel が2026年6月にリリースしたファームウェア（バージョン 2.90(XXXX.1)C0 以降の修正版）にアップグレードする。
- 管理インターフェースへのアクセスを信頼できるネットワークに制限し、スイッチの設定や認証情報に改ざんの兆候がないか確認する。

**影響を受ける製品:** ファームウェア 2.90(XXXX.1)C0 以前を実行している Zyxel GS1900 シリーズスイッチ。中国語話者とみられる脅威アクターが2026-08-17から本脆弱性を悪用しており、48カ国で約1,000台のデバイスから設定情報とハッシュ化された認証情報を侵害・窃取している。2026-09-21にCISA KEVへ追加され、連邦機関の対応期限は本日2026-09-24。

## 5. CVE-2026-61674 — Fluent Bit `out_forward` Secure-Forward スタックバッファオーバーフロー

**原理・根本原因:** Fluent Bit の `out_forward` 出力プラグインは、Secure-Forward と共有キーを構成している場合、サーバー側が制御する「PONG」ハンドシェイクメッセージを、MessagePack の型やフィールド長を検証せずに固定サイズ（32バイト）のスタックバッファへコピーします。悪意のある、またはなりすました転送先は、初回ハンドシェイク中に過大な reason 値を送信することで隣接するスタックデータを上書きできます。スタックカナリア保護のないビルドでは Fluent Bit プロセスのユーザー権限でリモートコード実行につながる可能性があり、保護されたビルドでも最低限クラッシュ（サービス拒否）が発生します。

**対策:**
- Fluent Bit をバージョン 5.0.8 以降にアップグレードする。
- 多層防御として、`out_forward` の転送先が信頼できるものであり、認証済みかつネットワーク制限された経路でのみ到達可能であることを確認する。

**影響を受ける製品:** `out_forward` プラグインを Secure-Forward と `Shared_Key`/`Empty_Shared_Key` で使用している Fluent Bit バージョン 0.11.0〜5.0.8未満。技術的な解説とPoCが2026-09-23に公開された。実際の悪用は現時点で未確認だが、Fluent Bit がクラウドのログ収集パイプラインで広く使われていることから、PoC公開により近い将来のリスクが高まっている。

## 6. CVE-2026-89422 — Erlang/OTP TLS 1.3 サーバーなりすまし

**原理・根本原因:** Erlang/OTP の `ssl` アプリケーションは、クライアントが提示していないにもかかわらず TLS 1.3 の `ServerHello` に含まれる意図しない `pre_shared_key` 拡張を誤って処理します。これによりハンドシェイクの状態機械が誤って再開（resumption）用の「wait_finished」パスへ直接進んでしまい、ホスト名検証・CRLチェック・OCSPステープリングを含む証明書ベースのパス検証が完全にスキップされます。結果として、クライアントは有効な証明書もセッションも提示しない相手であっても、信頼できるサーバーと通信していると誤認したままハンドシェイクを完了してしまいます（エンティティ認証を伴わない鍵交換、CWE-322）。これにより中間者攻撃によるなりすましが可能になります。

**対策:**
- OTP 27.3.4.18、28.5.0.7、29.1.1、またはそれ以降（`ssl` 11.2.12.13 / 11.6.0.6 / 11.7.7 以降）にアップグレードする。
- TLS 1.3 クライアント動作を固定しているアプリケーションは、独立した証明書検証を伴わないセッション再開への依存がないか監査する。

**影響を受ける製品:** OTP 22.2 から上記修正版までの Erlang/OTP を使用し、`ssl:connect` 経由で TLS 1.3 クライアント接続を行うすべてのアプリケーション。2026-09-22開示。CISA KEVには未登録。

## 7. CVE-2026-94301 — Apache MINA 許可リストバイパス（過去の修正が不完全だった事例）

**原理・根本原因:** MINA の以前の修正（CVE-2026-47065対応）では `acceptMatchers` 許可リストフィルタが追加されましたが、これはデシリアライズされるオブジェクトの宣言クラス名に対してのみチェックされていました。`java.lang.reflect.Proxy` オブジェクトを処理する `resolveProxyClass()` は同じチェックを強制するよう更新されておらず、攻撃者は許可されていないクラスを動的プロキシでラップすることで、Java オブジェクトのデシリアライズ時にこの許可リストを回避できます。ホストアプリケーションがデシリアライズされたオブジェクトをどう扱うかによっては、任意コード実行や不正なリソースアクセスにつながる可能性があります。

**対策:**
- 修正（`resolveProxyClass()` のオーバーライド）は 2.2.x ブランチ（例: 2.2.8）にのみコミットされている。2.0.x/2.1.x 系のメンテナンスブランチを使用しているアプリケーションは、現時点でバックポートが存在しないため 2.2.x への移行が必要。
- 直ちに移行できない場合は、信頼できない MINA プロトコルオブジェクトのデシリアライズを避けるか、プロキシを考慮した独立の許可リストチェックでデシリアライズをラップする。

**影響を受ける製品:** Java オブジェクトのシリアライズ/デシリアライズに依存する Apache MINA 2.0.x（2.0.30まで）および 2.1.x（2.1.14まで）ブランチ。2026-09-22開示。現時点で実際の悪用は未確認。

## 8. CVE-2026-86473 — Apache Airflow のログアウトがベアラートークンを失効させない

**原理・根本原因:** Airflow の Core API ログアウトエンドポイントは、セッション認証情報が `_token` クッキーとして提示された場合にのみ失効処理を行います。代わりに同じトークンを `Authorization: Bearer` ヘッダーとして認証に使用しているクライアントは、正常に見えるログアウト成功レスポンスを受け取りますが、実際にはトークンは無効化されず、自然な有効期限（デフォルト24時間、設定変更可能）まで使用可能なままとなります（不完全なセッション終了の欠陥、CWE-613）。

**対策:** Apache Airflow を 3.3.2 以降にアップグレードする。これによりトークンの提示方法にかかわらず失効処理が正しく行われるようになる。

**影響を受ける製品:** クッキーではなくベアラートークン経由で認証するクライアントや連携（CI/CD やAPI連携で一般的）を持つ、3.3.2より前のApache Airflowデプロイ。2026-09-21公開。実際の悪用は未確認。

## 9. CVE-2026-91710 & CVE-2026-93372 — Google Chrome の解放後使用(UAF)とWebGLバッファオーバーフロー

**原理・根本原因:** CVE-2026-91710 は Chrome の WebAppInstalls コンポーネントにおける解放後使用（use-after-free）の脆弱性で、細工されたHTMLページ経由で到達可能であり、ブラウザのサンドボックス外でのコード実行を許す可能性があります。CVE-2026-93372 は Chrome の WebGL 実装（当初 Android で確認）におけるバッファオーバーフローで、特定のWebGL操作処理時の境界チェック不足に起因します。こちらも悪意のあるWebページを通じて到達可能で、同様にサンドボックスを脱出したコード実行につながり得ます。

**対策:**
- Chrome 153.0.8010.47以降（Linux）/ 153.0.8010.52-53以降（Windows, macOS, Android）にアップデートする。ほとんどの環境ではブラウザの自動更新機構により適用される。更新を完了するにはブラウザの再起動が必要。
- 応急処置としてのみ、ブラウザの設定/フラグでWebGLを無効化できるが、WebGLに依存するサイトが動作しなくなる。

**影響を受ける製品:** 上記バージョンより前の Google Chrome および Chromium ベースのブラウザ。2026-09-22にリリースされた安定版更新で修正済み。両CVEは現時点でCISA KEVには未登録だが、Chromeでは今年すでに複数のゼロデイが実悪用された実績があるため、速やかな対応が望ましい。

## 10. CVE-2026-58491 — Warpgate SSOエンドポイントのXSSとオープンリダイレクト

**原理・根本原因:** Warpgate（バックエンドインフラへのアクセスをゲートするSSH/HTTPS/MySQL踏み台ホスト）は、SSOコールバックエンドポイント（`/warpgate/api/sso/providers/:name/start` および関連ルート）が受け付ける `next` パラメータを適切にサニタイズしません。このパラメータに攻撃者が制御する値を入れると、適切なエスケープなしに反映され、認証済みのWarpgateオリジン内で実行される反射型クロスサイトスクリプティングが可能になります。これによりセッションデータや管理APIへのアクセスが可能になる恐れがあります。また同じ未サニタイズのパラメータはオープンリダイレクトの悪用にも利用できます。

**対策:** Warpgate をバージョン 0.25.5 以降にアップグレードする。

**影響を受ける製品:** 0.25.5より前のWarpgateデプロイ、特にエンドユーザーにSSOログインを公開しているもの。実際の悪用は未確認だが、踏み台ホストという役割上、認証情報・セッション窃取の標的として価値が高い。

## 11. CVE-2026-32996 — Veeam Agent for Microsoft Windows のローカル権限昇格

**原理・根本原因:** Veeam Endpoint Backup サービスは、ローカルの gRPC 名前付きパイプ経由でクライアントが指定したセッションUIDに対して昇格した管理者権限のセキュリティプリンシパルをキャッシュしますが、そのUIDを要求元のユーザーや接続に紐付けていません。昇格したセッションUIDは標準ユーザーが読み取り可能なログファイルに書き込まれるため、低権限のローカルユーザーはログから有効なUIDを読み取り、それを再利用してサービスに NT AUTHORITY\SYSTEM 権限でコマンドを実行させることができます。

**対策:** Veeam Backup & Replication を 13.0.2.29 以降にアップグレードする（Windows エージェントがビルド 13.0.3.1220 に更新される）。

**影響を受ける製品:** Veeam Agent for Microsoft Windows 13.0.1.2067 以前の 13.x ビルド。PoCと技術詳細は2026-09-14に公開され、その後Arctic Wolfが侵害後の権限昇格チェーンの一環として実悪用を報告した。

## 12. CVE-2026-76460 — Cisco ISE 特権API認証バイパス（継続項目）

**原理・根本原因:** Cisco Identity Services Engine（ISE）および ISE-PIC のAPIエンドポイントにおける認証制御の不備により、未認証のリモート攻撃者がWebベースの管理インターフェースを完全に迂回し、特権的な内部APIへ到達できます。これによりroot権限でのコマンド実行や、デバイス上のフォレンジック証跡の削除・隠蔽が可能になる恐れがあります。有効な回避策は存在せず、管理/制御プレーントラフィックへのインフラACLはあくまで一時的な緩和策にすぎません。

**対策:** Cisco の修正を遅滞なく適用する。有効な回避策は存在しない。

**影響を受ける製品:** 修正版より前のバージョンの Cisco ISE および ISE-PIC。2026-09-16にCISA KEVへ追加（連邦機関の期限2026-09-19はすでに経過）。実悪用が確認されており、CVSS 10.0という深刻度の高さから、今週まだ未パッチの組織にとって引き続き重要であるため本レポートに含めている。

## 13. CVE-2026-87886 — Acronis Backup プラグインのデフォルト権限不備（継続項目）

**原理・根本原因:** cPanel & WHM、Plesk、DirectAdmin（いずれもLinux版）向けの Acronis Backup プラグイン/拡張機能には、不適切なデフォルトファイル権限（CWE-276）が設定された状態で出荷されています。すでにホスティングサーバーへの認証済み低権限アクセスを持つ攻撃者は、この権限設定の不備を利用して権限境界を越え、ホスト上でより大きな制御権を獲得できます。

**対策:** Acronis Backup プラグイン for cPanel & WHM をビルド 1.9.3.1021 以降、Plesk拡張をビルド 1.8.11.638 以降、DirectAdminプラグインをビルド 1.2.3.238 以降に更新する。

**影響を受ける製品:** 修正済みビルドより前の該当Acronis Backup連携を実行している共有ホスティングサーバー。Acronisはcatalog & WHMデプロイに対する実際の悪用を特に確認している。2026-09-16にCISA KEVへ追加（連邦機関の期限2026-09-19はすでに経過）。
