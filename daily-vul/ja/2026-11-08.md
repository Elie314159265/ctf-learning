## 1. CVE-2026-58115 — Siemens SIMATIC IoT2050 上の Node-RED における認証欠如

**原理・根本原因:** 対象の産業用ゲートウェイ上のNode-RED HTTPインターフェースが認証を要求しません(重要機能に対する認証欠如)。そのため認証されていないネットワーク攻撃者が、OSコマンドを実行できるプログラミングノードに到達でき、リモートコード実行につながります。

**緩和策:**
- Industrial OS / Node-RED を V4.3.4.1 以降に更新(Siemensアドバイザリ SSA-834709)、またはソフトウェアを削除。
- Node-REDをインターネットに公開せず、認証を強制し、信頼できるネットワークに限定。
- 配備済みフローに不審なものがないか確認し、再起動後も残る永続化の有無を点検。

**影響範囲:** Node-REDを搭載した SIMATIC IoT2050 Advanced のうち V4.3.4.1 未満。本製品以外の一般的なNode-RED環境への影響範囲は未確認。**開示・悪用:** VulnCheckが2026-10-30から悪用を観測(悪意あるフローによるLinuxボット、バックドア、Webシェルの設置)。2026-11-03/04に公表。VulnCheck KEVには掲載、2026-11-03時点でCISA KEV未掲載。

## 2. CVE-2026-119977 — WordPress Core アップグレード時の競合状態

**原理・根本原因:** WordPressコアの更新機構におけるTOCTOU競合状態(CWE-367)により、フルパッケージ更新中にリモートコード実行が可能になり得ます。深刻度評価は割れており、Wordfenceの記録はCVSS 8.1(High)、WordPressプロジェクトはLowと評価しています。

**緩和策:**
- WordPress 7.1.4(2026-10-28公開)へ更新。旧ブランチの修正版はリリースノートで確認。
- CISAはフォレンジック調査を推奨:パッチ適用だけでなく侵害の兆候も確認。個別の回避策は公表されていません。

**影響範囲:** WordPress Core 4.7〜7.1.3。**開示:** 悪用の証拠に基づき2026-11-03にCISA KEVへ追加。連邦機関の期限は2026-11-06。7月以降4件目のWordPressコアKEV掲載とされています。

## 3. CVE-2024-27834 — Apple WebKit(Safari、iOSほかAppleプラットフォーム)

**原理・根本原因:** 細工されたWebコンテンツによりメモリ安全性に関わる侵害が起こり得る、2024年のWebKit脆弱性。古いOSバージョンの端末を狙うAPT29関連の活動(SekoiaによるPoisoned Sourceキャンペーン)との関連が報告されています。

**緩和策:** iOS、iPadOS、macOS、Safariを最新版に更新。更新を受けられない端末は交換。

**影響範囲:** 未更新のApple端末・ブラウザ(古いOS)。**開示:** 2026-11-04にCISA KEV追加。連邦機関の期限は2026-11-18。

## 4. Barracuda Email Security Gateway — CVE-2026-116606 & CVE-2026-111560

**原理・根本原因:** CVE-2026-116606(CVSS 9.3、ESGのみ)は、バックアップ復元のインポート機能における認可バイパスで、装置のコア設定を変更できます。CVE-2026-111560(CVSS 8.6)は複数のBarracuda製品に影響するコマンドインジェクションです。連鎖するとroot権限でのコマンド実行に至ります。認証の要否は情報源で異なり、MandiantはESGの脆弱性は認証なしで悪用可能としています。

**緩和策:**
- Barracudaのパッチ BNSF-40425(ファームウェア9.4.017以降)または BNSF-40430(それ以前)を適用。Load Balancer ADC、Message Archiver、WAF Control Centerも修正対象。
- 管理インターフェースを信頼できる内部ネットワークに限定。

**影響範囲:** Barracuda ESG、Load Balancer ADC、Message Archiver、WAF Control Center(正確なバージョン閾値は情報源により異なるためベンダーのアドバイザリで確認)。**開示:** 2026-11-02にパッチ公開(11-03とする報道もあり)。2026-11-05時点で悪用の確認なし。

## 5. Ivanti Connect Secure — CVE-2026-111357、CVE-2026-118527(CVE-2026-104935 と併せて)

**原理・根本原因:** 10月上旬にVolexity(攻撃者 UTA0576)が観測したゼロデイ連鎖で、認証バイパス(CVE-2026-104935)、権限昇格/認証欠如(CVE-2026-111357)、認証後のファイルアップロード不備(CVE-2026-118527)を組み合わせroot権限の制御を獲得。攻撃者は連鎖自体のHTTPSリクエストでコマンドと結果をやり取りし、別個のバックドアを残さなかったと報告されています。

**緩和策:**
- 25.1.1.3 または 22.8R2.6 以降へアップグレード。2026-10-13の修正(25.1.1.2 / 22.8R2.5)では新しい2件は**修正されません**。
- Ivantiのアドバイザリと整合性チェックツールに従い、Web管理画面への異常なリクエストを調査。

**影響範囲:** 修正ビルド未満のIvanti Connect Secure。**開示:** Ivantiは2026-10-29にパッチ公開、2026-10-30にCISA KEV追加(期限 2026-11-02 と 2026-11-13)。KEV期限が本期間内にあるため参考として記載。
