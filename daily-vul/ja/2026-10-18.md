## 1. CVE-2026-0322 — PAN-OS 管理インターフェースのコードインジェクション

**原理・根本原因:** PAN-OS 管理インターフェースにおける、生成コードの不適切な制御(CWE-94)。管理インターフェースへネットワーク到達性があり、高権限で認証済みのユーザーが、攻撃者の影響下のコードを root 権限で実行させることができます。

**緩和策:**
- Palo Alto Networks のアドバイザリ(2026-10-14 公開)に記載された修正版 PAN-OS へアップグレードする。
- 管理インターフェースは信頼できる内部ネットワークに限定し、インターネットへ公開しない。
- 既知の回避策はありません。管理者アカウントと認証情報を見直してください。

**影響範囲:** PA-Series、VM-Series、Panorama 上の複数のサポート対象 PAN-OS ブランチ。Cloud NGFW と Prisma Access は影響なしと報告されています。正確なバージョンはベンダーのアドバイザリを参照してください。開示日: 2026-10-14。

## 2. CVE-2026-76519 — Cisco Secure Email Gateway のパストラバーサル(悪用あり)

**原理・根本原因:** Advanced Malware Protection 機能における相対パストラバーサル。細工されたメール添付ファイルを処理すると、認証不要のリモート攻撃者が意図されたディレクトリ外へファイルを書き込め、root 権限でのコマンド実行につながります。

**緩和策:**
- Cisco のアドバイザリに従い、Content Scanner Tools を 25.3.0.5525 以降へ更新する。
- File Reputation が有効でメールポリシーに割り当てられている場合に該当します。外部メールを処理するアプライアンスは侵害の兆候を確認してください。
- 同じ Cisco アドバイザリ群に関連する SQL インジェクション CVE-2026-76461 も報告されているため、あわせて確認してください。

**影響範囲:** Content Scanner Tools が 25.3.0.5525 より前で File Reputation が有効な Cisco Secure Email Gateway。アドバイザリ 2026-10-14、CISA KEV 期限 2026-10-17(経過済み)。

## 4. CVE-2026-104935 — Ivanti Connect Secure の認証バイパス(ゼロデイ)

**原理・根本原因:** Connect Secure ゲートウェイの認証バイパス。Web 層がクライアントから送られたリクエストヘッダーを信頼してルーティングと認証を判断するため、認証不要のリモート攻撃者がログインが必要なはずの機能に到達できます。認証情報の窃取やデータ持ち出しに悪用されています。Volexity は、攻撃者が別の未修正の権限昇格の脆弱性も使用したと報告しています。

**緩和策:**
- ブランチに応じて 22.8R2.5、25.1.1.2、25.1.3.0、25.1.3.1 のいずれかへアップグレードする。25.1.3.0 は新ハードウェア(ISA4500/6500/8500)または再構築した仮想アプライアンスでのみ動作します。
- Ivanti の整合性チェックツールを実行し、侵害の兆候を調査する。悪用は 2026-10-01〜10-03 頃から始まったと報じられています。
- アプライアンスを経由したアカウントの認証情報とセッションをローテーションする。

**影響範囲:** Ivanti Connect Secure 22.8R2.4 以前、25.1.2.2 以前、25.1.1.1 以前(22.7.x 以下は影響なしと報告)。開示日 2026-10-13、CISA KEV 期限 2026-10-16。

## 5. CVE-2026-96951 — Windows Shell の Mark of the Web バイパス(ゼロデイ)

**原理・根本原因:** Windows Shell のコマンドインジェクションの弱点により、細工されたファイルが Mark of the Web のチェック(SmartScreen や保護ビューの警告・ブロック)を回避します。ユーザーがメール、チャット、ダウンロードで届いたファイルを開く必要があります。過去の修正が不完全だった可能性も指摘されています。攻撃者の特定はまだありません。

**緩和策:**
- 2026年10月の Windows 累積更新プログラムを適用する。
- 不審なファイルを開かないようユーザーに周知し、メールと Web のフィルタリングを有効に保つ。

**影響範囲:** 2026年10月の更新プログラムが対象とするサポート対象の Windows クライアントおよびサーバー。修正 2026-10-13、CISA KEV、連邦機関の期限 2026-10-16。

## 7. CVE-2026-104286 — FortiMail のパストラバーサル/ヌルバイト処理(ゼロデイ)

**原理・根本原因:** 管理インターフェースにおけるパストラバーサル(CWE-22)とヌルバイトの不適切な無害化(CWE-158)の組み合わせ(アドバイザリ FG-IR-26-175)。Fortinet は 2026-10-01 の開示時に実環境での悪用を確認しました。

**緩和策:**
- 公開され次第、8.0.2、7.6.7、7.4.9 へアップグレードする(7.6.7 と 7.4.9 のリリースノートは存在すると報じられています。アドバイザリで確認してください)。7.2 の利用者は 7.4 以降へ移行する。
- 回避策: CLI で IBE(ID ベース暗号化)を無効化する。管理インターフェースへのインターネットからのアクセスを遮断するか、信頼できるネットワークに限定する。

**影響範囲:** FortiMail 8.0.0〜8.0.1、7.6.0〜7.6.6、7.4.0〜7.4.8、7.2.0〜7.2.9。開示 2026-10-01、CISA KEV 2026-10-01(期限 2026-10-04)。
