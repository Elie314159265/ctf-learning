## 1. CVE-2026-96951 — Windows Shell の Mark of the Web 回避（悪用ゼロデイ）

**原理・根本原因：** Windows Shell のファイル処理の欠陥（CWE-77）により、細工されたファイルが Mark of the Web（MotW）属性の付与、または適用を回避できます。MotW は信頼できない出所のファイルに対する SmartScreen や保護ビューの警告を発動させる仕組みで、これを回避されるとユーザー向けの重要な警告が表示されず、悪意あるファイルが実行されやすくなります。ユーザー操作（メール、チャット、コラボレーションツール、悪意あるサイト経由のファイルを開く／ダウンロードする）が必要です。

**緩和策：**
- 2026年10月のMicrosoftセキュリティ更新プログラム（2026-10-13公開）を全てのWindows端末・サーバーに適用する。
- メール／Web添付ファイルのフィルタリングとエンドポイント保護を有効に保ち、信頼できないファイルに関するユーザー教育を徹底する。

**影響：** サポート対象のWindows（正確な一覧はMicrosoftのアドバイザリを参照）。CVSS 3.1: 8.8。CISA KEV登録済み。今年3件目の悪用されたWindows Shell脆弱性と報じられています。10月の更新は非常に大規模（約1,400件超のCVE。件数は情報源により異なる）で、ゼロデイは合計3件と報告されています。

## 2. CVE-2026-104935 — Ivanti Connect Secure 認証バイパス（ゼロデイ）

**原理・根本原因：** アプライアンスのWeb層における、なりすまし型の認証バイパス（CWE-290）です。本来サーバー側のみが制御すべきクライアント送信のリクエストヘッダーを製品が信頼してしまうため、未認証のリモートリクエストが認証済みとして扱われます。権限昇格の脆弱性と連鎖させることで、パッチ適用済みの機器でも root 権限でのコマンド実行が可能になったと研究者が報告しており、悪用は 2026-10-03 頃から観測されています。

**緩和策：**
- 修正版へアップグレードする：22.8R2.5、25.1.1.2、25.1.3.0、25.1.3.1（製品ブランチにより異なる）。
- Ivanti は信頼できる侵害指標（IoC）がまだないとしています。Integrity Checker Tool の実行、ログ確認を行い、侵害の疑いがある場合は工場出荷状態へのリセット／再構築を検討する。管理系の公開を制限する。

**影響：** Ivanti Connect Secure 25.1.1.1以前、25.1.2.2以前、22.8R2.4以前（22.7.x以下は影響なしと報告。情報源により境界の表現が異なる）。CVSS 8.6。2026-10-13 公開、CISA KEV追加（連邦機関の期限 2026-10-16）。

## 3. CVE-2026-76519 — Cisco Secure Email Gateway パストラバーサル（ゼロデイ）

**原理・根本原因：** 電子メールの添付ファイルを処理する Advanced Malware Protection（AMP）機能における相対パストラバーサル（パスの不適切な処理）です。未認証のリモート送信者が細工した添付ファイルを送ることで、意図したディレクトリ外への任意ファイル書き込みが発生し、root 権限でのコマンド実行につながります。

**緩和策：**
- Content Scanner Tools 25.3.0.5525 以降の更新を適用する（ソフトウェア全体のアップグレードや再起動は不要）。
- Cisco が公開した侵害指標を確認する。Cisco は侵害の兆候があった Secure Email Cloud の顧客に通知済み。

**影響：** File Reputation が有効でメールポリシーに割り当てられており、Content Scanner Tools が 25.3.0.5525 より前の Cisco Secure Email Gateway。CVSS 9.8。実環境で悪用され、2026-10-14 に CISA KEV追加。直近数週間で2件目の悪用されたSEGゼロデイです（先行する CVE-2026-76461 はメール解析のSQLインジェクションで、2026-09-14 に公開）。

## 4. CVE-2026-0322 — Palo Alto Networks PAN-OS 管理インターフェースのRCE

**原理・根本原因：** PAN-OS の管理インターフェースにおけるリモートコード実行の欠陥（CVSS v4.0 で 8.6）。管理プレーンが信頼できないネットワークに公開されていることが主なリスク要因です。

**緩和策：**
- 管理インターフェースへのアクセスを信頼できる内部IPアドレスのみに制限し、インターネットに公開しない。
- ベンダーのアドバイザリに従い、修正版が提供され次第適用する。

**影響：** PA-Series および VM-Series ファイアウォールと Panorama 上の PAN-OS。Cloud NGFW と Prisma Access は影響を受けないと報告されています。2026-10-14 に CISA KEV追加。悪用が確認されているかは情報源により異なります（ある報道では「ごく限定的」）。KEV登録に従い、悪用されているものとして扱ってください。

## 5. CVE-2026-105133 / CVE-2026-105134 — AhsayCBS 認証の欠陥＋コマンドインジェクション

**原理・根本原因：** CVE-2026-105133 はシステムパスワード確認関数における不適切な認証、CVE-2026-105134 はレプリケーション受信コンポーネントにおけるOSコマンドインジェクションです。連鎖させると未認証でコードを実行でき（SYSTEM権限と報告）、確認された事後活動には Web シェル設置、暗号資産マイナーの展開、偽の Windows サービスによる永続化があります。攻撃は 2026-10-07 に初観測され、少なくとも5組織が標的となりました。

**緩和策：**
- ベンダーのリリース 10.3.4.0 はどちらの問題も十分に修正していません。ホットフィックス 10.3.4.45（Ahsay パートナーポータル経由）を適用し、再起動する。
- 管理インターフェースへのアクセスを制限し、Web シェルや不審なサービスを調査する。

**影響：** ホットフィックス適用前の Ahsay AhsayCBS バックアップサーバー。CVSS 5.5（CVE-2026-105133、VulDB）／9.3（CVE-2026-105134）。2026-10-14 に CISA KEV追加。

## 週前半・参考情報（7日より前だが対応が必要）

### CVE-2026-21589 — Atlassian Data Center 任意ファイルアクセス（2026-10-05）
アクセス制御の欠如により、攻撃者が正確なファイル名とパスを知っていれば未認証でファイルを読み取れます（ディレクトリ一覧は不可）。CVSS 9.3。Bitbucket、Confluence、Jira Service Management、Jira Software、Bamboo、Crowd、Crucible、Fisheye の Data Center 全バージョンが対象で、Cloud は修正済みです。技術解説の公開から数時間以内に悪用の試行が始まりました。緩和策：修正版を適用（例：Confluence 9.2.26 / 10.2.19、Jira Software 9.12.40 / 10.3.26 / 11.3.12）。

### CVE-2026-88779 — Citrix NetScaler ADC/Gateway SAML のメモリオーバーフロー（2026-10-04 CISA KEV）
SAML SP または IdP として構成されたアプライアンスでのメモリオーバーフロー（CWE-119）によりサービス拒否が発生します。コード実行（Webシェル設置）を狙う試みも報告されていますが未確認です。CVSS v4.0 8.7。緩和策：14.1-73.41 または 13.1-64.28 以降へアップグレードし、Citrix の拒否リストを適用。

### CVE-2026-102489 / CVE-2026-102490 — Zammad（2026-10-02 CISA KEV）
アプリケーションユーザー権限でのコード実行につながるセッションハイジャック（6.3.0〜6.5.4。7.xは実際には悪用不可と報告）と、root への権限昇格の連鎖です。影響バージョンと悪用可能性について DIVD とベンダーの間で開示内容に争いがあります。緩和策：ベンダーの案内に従い最新の Zammad 7.x へアップグレード、または修正までオフラインにする。

### CVE-2026-104286 — Fortinet FortiMail パストラバーサル（2026-10-01 CISA KEV）
任意ファイル書き込みを可能にする未認証のパストラバーサルで、悪用が確認されています。CVSS 9.8。緩和策：ベンダーのアドバイザリに従い、Fortinet の修正版 FortiMail を適用。
