### 1. PHP — CVE-2026-109618 / CVE-2026-109619(認証不要の RCE、悪用確認済み)
- **開示日:** セキュリティリリース 2026-10-21。悪用の証拠により CISA KEV に 2026-10-26 追加。
- **深刻度:** CVSS v4.0 9.2(情報源により 9.8 の記載もあり)。
- **原理・根本原因(概念):**
  - CVE-2026-109618: メモリ不足(OOM)時の処理でリクエスト処理が中断され、内部のリクエストデータが一部しか初期化されていない状態になる。後続のクリーンアップがその不正なデータを信頼してしまう(メモリ安全性の欠陥)。
  - CVE-2026-109619: PHP の致命的エラー時の処理(非局所ジャンプ)が一部のコンテキストで安全に扱われず、リクエスト終了時に解放されたメモリをグローバル状態が指し続ける。後続リクエストが解放済みメモリを利用する(Use-After-Free 系)。
  - これらにより、認証なしでのリモートコード実行につながり得る。
- **影響範囲:** PHP 5.x(5.4 とする情報あり)〜 8.5.11。Apache mod_php が対象で、PHP-FPM も前提条件は異なるが影響を受ける。8.1 以前のブランチには上流の公式修正なし。
- **緩和策:**
  - 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 以降へ更新。
  - 8.1 以前は OS・ディストリビューションのバックポートを適用するか、サポート対象ブランチへ移行。
  - PHP を同梱するコンテナのベースイメージやホスティング基盤を確認し、更新後は PHP ワーカー / Apache を再起動。
  - インターネット公開の PHP アプリを優先して対応し、ワーカーの異常終了や OOM の発生ログを確認。

### 2. Arista VeloCloud Orchestrator(VCO)— CVE-2026-114625(SQL インジェクションによる権限昇格、悪用確認済み)
- **開示日:** 2026-10-22。
- **深刻度:** CVSS 9.9(v3.1)/ 9.4(v4.0)(二次情報による)。
- **原理・根本原因:** データベースクエリ処理における入力の無害化が不十分で、低権限の認証済みユーザー(「Enterprise Read Only」相当とされる)がクエリを操作して権限を昇格できる。ユーザー操作は不要。
- **影響範囲:** オンプレミス版 VeloCloud Orchestrator。リリース系列ごとの修正版は情報源から確認できず、Arista Security Advisory 0199 を参照。
- **緩和策:** 該当系列の修正版 VCO を適用。管理プレーンへのアクセスを信頼できるネットワークに限定。Arista が公表した攻撃元 IP をブロック。アカウント・ロールを棚卸しし、不審な権限変更をログで確認。

### 関連: Arista VCO — CVE-2026-93952(CVSS 10.0、悪用確認済み、CISA KEV 掲載、開示 2026-09-22)
- 認証なしで内部の特権機能にアクセス可能。証明書ベースの Edge 認証を構成した Orchestrator のみが対象。9 月時点の報道では 5.2 / 6.4 系列に修正があり、6.1 / 7.0 系列は未提供だったため、最新状況を確認すること。

## その他の注目事項(7 日よりやや前、参考情報)

### 3. Cisco Secure Email Gateway — CVE-2026-76519(重大、悪用確認済み)
- **開示日:** 2026 年 10 月に悪用を確認。CISA KEV に 2026-10-14 追加。
- **深刻度:** CVSS 9.8。
- **原理:** ファイルレピュテーション / コンテンツスキャン機能が細工されたメール添付ファイルを処理する際に、任意ファイル書き込みや root 権限でのコマンド実行につながり得る。
- **影響範囲:** File Reputation が有効でメールポリシーに割り当てられ、Content Scanner Tools が 25.3.0.5525 未満の物理・仮想 Secure Email Gateway。クラウド版は Cisco が修正済み。
- **緩和策:** Content Scanner Tools を 25.3.0.5525 以降に更新(再起動不要)、または AsyncOS を修正版へアップグレード(15.5.5-014 / 16.5.0-780 との報道あり。アドバイザリ cisco-sa-esa-afw-zqYJkjxp で要確認)。回避策なし。侵害の疑いがある場合は、インプレースのアップグレードではなく(証拠保全のため)修正版で新規 VM を構築し、旧設定はインポートしない。クラスタ内に侵害機器がある場合は全メンバーを復旧。

- **開示日:** 2026-10-13。同日 KEV 追加。悪用は 2026-10-03 頃から報告。
- **深刻度:** CVSS 8.6。
- **影響範囲:** Connect Secure 25.1.2.2 以前、22.8R2.4 以前。

### 5. Microsoft Windows Shell — CVE-2026-96951(セキュリティ機能のバイパス、悪用確認済み)
- **開示日:** 2026 年 10 月のパッチ Tuesday(2026-10-13)。CVSS 8.8。
- **原理:** ユーザーが開く特定のコンテンツの処理時に Windows Shell が保護機能を適用せず、警告・信頼確認の仕組みを回避され得る。
- **緩和策:** サポート対象の全 Windows に 2026 年 10 月の累積更新を適用。信頼できないファイルを開かないよう周知。同月は約 1,400 件の CVE が修正されたと報じられている。
