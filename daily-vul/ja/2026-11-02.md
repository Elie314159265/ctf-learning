## 優先事項(最新・悪用確認済み)

### 1. PHP「php2shell」— CVE-2026-109618, CVE-2026-109619(RCE、2026-10-26 CISA KEV追加)
- **開示日:** 修正版は2026-10-21公開。CISA KEV追加は2026-10-26。
- **原理・根本原因:** PHPランタイムのメモリ安全性/状態管理の欠陥。CVE-2026-109618: リクエスト終了処理中のメモリ不足に起因する破壊(セッションのアップロード進捗ハンドラ経由)。CVE-2026-109619: 同一ワーカー上で後続リクエストが前のリクエスト所有のグローバル状態を再利用(multipart/form-dataパーサ経由)。いずれも認証なしのリモートコード実行につながり得る。
- **影響範囲:** PHP 8.5 < 8.5.12、8.4 < 8.4.27、8.3 < 8.3.36、8.2 < 8.2.35。7.4、8.0、8.1などのEOL系列も影響を受けるとの報告があり、公式修正なし(情報源により範囲が異なる)。
- **対策:** 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35、またはディストリビューションのバックポート版へ更新。EOL系列からの移行、またはベンダー提供のパッチ版を使用。`session.upload_progress.enabled=0` はCVE-2026-109618のみ緩和し、109619は緩和しない。関連するCVE-2026-115560(2026-10-23開示)は到達可能性が低いとされ、修正は次回の通常リリース予定。暫定策は同じ設定。

### 2. Brotli「HTTP2Shell」— CVE-2026-111497(CVSS 9.2、スキャン活動を確認)
- **開示日:** Node.jsの修正は2026-10-21、緊急パッチの報道は2026-10-26。
- **原理・根本原因:** Brotliデコーダライブラリで、細工されたデータの展開時に範囲外書き込みが発生。アプリやミドルウェアが実際にBrotli入力をデコードする場合に影響する。Brotliを組み込むソフトウェア(Node.js、Pythonバインディング、プロキシ等)が対象。
- **影響範囲:** Brotli 1.0.3〜1.2.0。Node.js 26.x < 26.12.1、24.x < 24.22.1、22.x < 22.23.4(EOLの25.x/23.x/20.x以前は修正なし)。
- **対策:** Node.jsを22.23.4 / 24.22.1 / 26.12.1へ、Brotliを1.0.10 / 1.1.1 / 1.2.1へ、Python Brotli 1.2.1 / brotlicffi 1.2.1.0へ更新。プロキシや同梱コピーも更新。修正版でも `process.versions.brotli` が古い値を示す場合があるため、Nodeのバージョンで確認する。パッチ適用が遅れる場合は信頼できないBrotliコンテンツのデコードを避ける。

### 3. Linux カーネル IPv4 TCP の use-after-free — CVE-2026-98432(CVSS 9.8(カーネルCNA)/ 8.1(Red Hat))
- **開示日:** 2026-10-27に公開分析(ディストリビューションの修正は2026-10-16頃から)。
- **原理・根本原因:** あるCPU経路がIPオプションオブジェクトを解放する一方、RCUリーダーとしてのみ保護された別経路がまだ使用している(解放前にRCU猶予期間がない)。TCPのリクエスト/子ソケット処理におけるuse-after-free。MPTCPリスナを持つサーバで認証なしのリモートroot取得が可能と報告されたが、より広い影響は確認されていない。
- **影響範囲:** 修正前のLinuxカーネル 4.4以降。
- **対策:** 修正済み安定版カーネル(5.10.272、5.15.223、6.1.190、6.6.159、6.12.113、6.18.56、7.2.10、7.3)またはディストリビューションのバックポート版へ更新(Oracle Linux・Debian trixieは10-16、Amazon Linux 2023 kernel6.18は10-24、kernel6.12は10-29に修正。Amazon Linux 2は執筆時点で未対応。RHEL 7は影響なし)。更新後に再起動。MPTCP無効化によるリスク低減は確認されていない。

### 4. Ivanti Connect Secure — CVE-2026-104935(認証バイパスからのRCE、KEV)
- **開示日:** 情報源が食い違う。修正/KEVは2026-10-13との報告があり、別の報告では連鎖悪用の一式が2026-10-30にKEV追加(連邦機関の期限は11-02と11-13)。
- **原理・根本原因:** 認証バイパスにより、リモートの未認証者がVPNアプライアンス上でコマンドを実行可能。他の脆弱性と連鎖してroot権限を取得され、一部パッチ済みの機器でも成功した事例が報告されている。
- **影響範囲:** Connect Secure 25.1.1.1以前、25.1.2.2以前、22.8R2.4以前(22.7.x以前は影響なしとの報告。情報源により差異あり)。
- **対策:** Ivantiの最新ビルドへ更新(報告されている修正版: 22.8R2.5、25.1.1.2、25.1.3.0、25.1.3.1。Ivantiのアドバイザリで要確認)。Ivantiの整合性チェックツールの実行、侵害調査、認証情報・セッションのローテーション、管理インターフェースの公開制限。

### 5. Drupal Commerce Core — CVE-2026-118539(認可欠如、CWE-862、悪用報告あり)
- **開示日:** アドバイザリ SA-CONTRIB-2026-254、2026年10月下旬(正確な日付は未確認)。Highly Critical(21/25)。悪用の確認状況は情報源により食い違い、ある情報源ではKEV未掲載。
- **原理・根本原因:** 認可チェックの欠如により、オンラインストアのアクセス制御を回避可能。
- **影響範囲:** Commerce Core 2.x(2.41まで)、3.x(3.3.12まで。3.3.13を含むとする報道もあるが、3.3.13が修正版)。
- **対策:** 3.xは3.3.13、2.xは8.x-2.41へ更新。回避策の記載なし。注文データに不整合がないか確認する。
