### 2. BeyondTrust Remote Support — CVE-2026-102764
- **開示日:** ベンダーアドバイザリ BT26-05。SaaSは2026-10-09までに修正済み。2026-10-16にCISA KEVへ追加。
- **深刻度:** 重大な認証バイパス（Rapid7・カナダ サイバーセキュリティセンターではCWE-290）。実環境で悪用されており、8月頃から中国系の攻撃者によるものと報告されています。
- **原理:** リクエストの送信元や身元の検証が不十分なため、攻撃者が認証済みとして扱われます。
- **影響範囲:** セルフホスト版 Remote Support 24.3.1〜26.2.3。24.3.1より古い版は先にアップグレードが必要です。
- **緩和策:** パッチ BT26-05-RS を適用（情報源によっては26.2.4以降へ更新）。アプライアンスは侵害されている可能性があるものとして扱い、保存されている認証情報・シークレットのローテーション、下流システムへの横展開の調査、ログ削除の有無の確認を行ってください。

### 3. Nextcloud Built-in CODE Server (richdocumentscode) — CVE-2026-110447
- **開示日:** 2026年10月公開。修正版26.4.303は2026-09-11にリリースされたと報告。セルフホスト環境でWebシェルが設置される悪用が報告されています。
- **深刻度:** CVSS v4.0 9.2。認証不要のOSコマンドインジェクション。
- **原理:** 同梱のCollaboraサーバーを起動するプロキシ部分が、サーバー停止時にサニタイズされていない入力をOSへ渡してしまいます。
- **影響範囲:** 「Built-in CODE Server」アプリ 26.4.303未満。スタンドアロンCollabora、Docker、RPM/DEB、Nextcloud AIOは影響なしと報告されています。
- **緩和策:** アプリを26.4.303以降へ更新、または削除（無効化だけでは不十分との情報あり）。アプリディレクトリに不審なファイルがないか確認し、見つかった場合はシークレットを更新してください。

### Palo Alto Networks PAN-OS GlobalProtect — CVE-2026-0257
- **開示日:** 当初の開示とKEV追加は2026-05-29頃。Unit 42が2026-10-20に脅威ブリーフを更新し、ランサムウェア運用者（Qilin、Inc）による悪用を報告。古い脆弱性ですが悪用は継続中です。
- **原理:** 認証オーバーライドCookieが有効で特定の証明書構成の場合に、GlobalProtectで認証をバイパスできます。CVSSは4.7から7.8へ引き上げられました。
- **影響範囲:** GlobalProtectポータル／ゲートウェイと上記Cookie構成を持つPAN-OS。PanoramaとCloud NGFWは影響なし。
- **緩和策:** ブランチごとの修正版へ更新（対応表はPalo Altoのアドバイザリ参照）。オーバーライドCookie専用の証明書を使用するか、機能を無効化。
