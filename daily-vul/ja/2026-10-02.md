# 日次脆弱性サマリー — 2026-10-02

対象期間: 2026-09-25 〜 2026-10-02。情報源: 公開ニュース・集約サイトの報告(今回の実行ではベンダー/CISAの一次ページを取得できませんでした)。**[未確認]** と記した項目は単一の二次情報に基づくか、内容に不整合があります。対応前にベンダーのアドバイザリで確認してください。エクスプロイトコードや攻撃手順は含みません。

## 最新・最優先(直近24〜72時間、悪用確認済み)

### 1. Citrix NetScaler ADC / Gateway — CVE-2026-88771 および CVE-2026-88772(悪用確認済み)
- **公開日:** 2026-09-27(同日CISA KEV追加。世界的な悪用が報告)
- **原理・根本原因:** CVE-2026-88771 は入力検証不備により、認証なしのリモート攻撃者がアプライアンス上でコマンドを実行できる(デフォルト構成でも影響と報告)。CVE-2026-88772 はDTLS処理におけるメモリオーバーフローで、リモートコード実行またはDoSにつながる。DTLSはVPN仮想サーバーでデフォルト有効。
- **影響範囲:** NetScaler ADC / Gateway 14.1(14.1-73.37 より前)、13.1(13.1-64.23 より前)、FIPS/NDcPPビルドの13.1(13.1-37.279 より前)および14.1 FIPS(14.1-73.37 FIPSビルドより前)。
- **対策:** 14.1-73.37 / 13.1-64.23 以降(FIPS/NDcPPは上記ビルド)へアップグレード。管理・ゲートウェイの公開範囲を制限し、パッチ前から悪用されていたため侵害の痕跡(不審なプロセス、新規アカウント、Webシェル様ファイル)を確認する。

### 2. Cisco Catalyst SD-WAN Manager — 認証バイパス(悪用確認済み)**[CVE番号は未確認]**
- **公開日:** 約2026-09-30(Ciscoのパッチ公開。CISA KEV追加と報告)
- **原理・根本原因:** URIエンコードの不適切な処理により、認証なしのリモート攻撃者が認証を回避して管理者権限を取得できる(CVSS 9.8と報告)。CVE-2026-76504 とする情報があるが確認できなかった。2026年の他のSD-WAN脆弱性(CVE-2026-20127、CVE-2026-20182など)は別件。
- **影響・修正バージョン:** 今回確認できず。Cisco Security Advisoryで確認のこと。
- **対策:** 修正版を直ちに適用し、管理プレーンへのアクセスを信頼できるネットワークに限定、不正な管理セッションや設定変更を監査する。

### 3. SolarWinds Observability Self-Hosted — CVE-2026-28324 および CVE-2026-28325
- **公開日:** 今週(正確な日付は未確認)。悪用の報告なし
- **原理・根本原因:** CVE-2026-28324(CVSS 9.8)は整合性チェック不足により、非デフォルトの非安全な構成で認証なしRCEが可能。CVE-2026-28325(CVSS 8.8)は特定の通信モードを使う環境における信頼できないデータのデシリアライズ。
- **影響範囲:** Observability Self-Hosted 2026.2.2 以前。
- **対策:** 2026.2.3 へアップグレード。非デフォルトの非安全な構成を避け、ネットワーク公開を制限する。

### 6. Adobe Commerce / Magento — CVE-2026-71362(悪用確認済み、KEV)
- **公開:** 2026年8月。9月にCISA KEV追加(連邦機関の対応期限は2026-09-27)。悪用の報告が継続。
- **根本原因:** 不適切な認可(CWE-863)。呼び出し元の権限が要求リソースに対して検証されず、認証なしでセッション切替・アカウント乗っ取りが可能。
- **影響範囲:** Adobe Commerce、Commerce B2B、Magento Open Source の2026年7月パッチレベルまで。
- **対策:** Adobeの最新セキュリティアップデートを適用し、不審な顧客セッション活動を監視する。
