## 1. CVE-2026-85046 & CVE-2026-85880 — 「GRIMWEDGE」Chrome–Windows ゼロデイ連鎖（今週最新の開示）

**原理・根本原因:** 中国系とされる攻撃者は、NGO を標的としたスピアフィッシングキャンペーンにおいて、米国の大学の正規ウェブサイトに存在する反射型クロスサイトスクリプティング（XSS）を悪用し、被害者を攻撃者インフラへリダイレクトさせました。そこから展開される多段階のエクスプロイトチェーンは、まず CVE-2026-85046（Chrome の JavaScript/WebAssembly エンジンである V8 のメモリ破損バグ）を用いてブラウザのサンドボックス内で任意の読み書き能力を獲得し、続いて CVE-2026-85880 ――今月の Patch Tuesday で修正された Windows ALPC（Advanced Local Procedure Call）のヒープオーバーフローと同一の脆弱性――を用いてサンドボックスを脱出し、SYSTEM 権限でブラウザプロセスにコードを注入します。生成される「GRIMWEDGE」バックドアは常駐型のインメモリ JavaScript インプラントで、コマンド&コントロールサーバーに定期的に問い合わせて追加命令を受け取ります。

**対策:**
- Chrome/Chromium と Windows を最新状態に更新する（Chrome 153.0.8010.x 以降、Windows は2026年9月の累積更新プログラム）。
- 両脆弱性はすでに標的型攻撃で武器化されていることを前提に、インターネット公開サーバーだけでなく、ユーザー向けブラウザ・エンドポイント全体のパッチ適用を優先する。
- NGO など標的にされやすい業界では、メール／Webゲートウェイのログでサードパーティ（.edu など）ドメイン経由の不審なリダイレクトを確認する。

**影響を受ける対象:** CVE-2026-85046 の修正前の Google Chrome/Chromium ビルド、および ALPC の脆弱性の影響を受ける Windows バージョン（項目4を参照）。キャンペーンは 2026-09-15 に初めて報告されましたが、両 CVE ともキャンペーン公表前に各ベンダーによって修正済みであり、悪用自体は一般公開より前から行われていました。

## 2. CVE-2026-76461 — Cisco Secure Email Gateway における未認証の root 権限 RCE（連邦機関の対応期限は明日）

**原理・根本原因:** Cisco の Secure Email Gateway 向け AsyncOS ソフトウェアは、メール解析時に攻撃者が制御可能なコンテンツの検証が不十分であり、特別に細工されたメールによってゲートウェイのバックエンドに SQL 文を注入できます（CWE-89、SQL インジェクション）。解析処理とデータベース処理が高い権限で動作しているため、注入された SQL 文を悪用して任意の OS コマンドを root 権限で実行できます。認証情報も、ゲートウェイが悪意あるメールを受信すること以外のユーザー操作も不要です。

**対策:**
- AsyncOS を 15.5.5-014（15.5系以前）、16.0.4-302（16.0系）、または Cisco が推奨する 16.5.0-780（16.5系）へアップグレードする。回避策は存在しません。
- インターネットに公開された Secure Email Gateway は最優先で対応する。CISA の連邦機関向け対応期限は 2026-09-17。

**影響を受ける対象:** 物理・仮想を問わず、すべての構成の Cisco Secure Email Gateway アプライアンス。Cisco Secure Email and Web Manager および Cisco Secure Web Appliance は対象外。実際に悪用されており、2026-09-16 の数日前に CISA KEV に追加されました。

## 3〜5. Microsoft 2026年9月 Patch Tuesday（2026-09-08）— 過去最大規模、悪用済みゼロデイ2件、ワーム化可能な DNS バグ1件

Microsoft の過去最大規模の Patch Tuesday では、約966〜995件の CVE（うち Critical 評価は105件以上）が修正されました。特に注目すべきは以下の3件です。

**CVE-2026-81963（Windows Update Stack、悪用済みゼロデイ）:** Windows の更新をインストールするコンポーネントにおいて、リンク解決とアクセス制御チェックが不適切であるため、ローカルの低権限攻撃者が更新プロセスによるファイル操作を操作し、SYSTEM 権限を取得できます。2022年以降に修正された Windows Update Stack の複数の権限昇格バグの中で、パッチ提供前に悪用が確認された初めての事例です。

**CVE-2026-85880（Windows ALPC、悪用済みゼロデイ）:** Advanced Local Procedure Call の処理におけるヒープベースのバッファオーバーフローにより、低権限のサンドボックス内（例: AppContainer、または上記 GRIMWEDGE のように侵害されたブラウザレンダラー）で既に動作しているコードが、ユーザー操作なしにサンドボックスを脱出して SYSTEM 権限に到達できます。

**CVE-2026-69730（「SigRed の後継」、Windows DNS Server、CVSS 9.8）:** Windows DNS Server の use-after-free バグにより、未認証のリモート攻撃者が特別に細工したネットワークパケットを送信するだけで、認証情報も操作も不要でサーバー上でコードを実行できます。セキュリティ研究者は、DNS インフラ全体に自己増殖（ワーム化）する可能性がある点で、2020年の SigRed（CVE-2020-1350）と本質的に類似していると指摘しています。悪用は未確認ですが、Microsoft および研究者は悪用の試みを予想しています。

**対策:** 2026-09-08 の累積更新プログラムを直ちに適用する。特に CVE-2026-81963 と CVE-2026-85880（すでに悪用済み）、および CVE-2026-69730（ワーム化の可能性があり、特にインターネット／境界に面した DNS サーバー）を優先する。

**影響を受ける対象:** CVE-2026-81963 — Windows 11（各バージョン）および Windows Server 2025。CVE-2026-85880 — Windows 10 および Windows Server 2012/2016/2019/2022。CVE-2026-69730 — サポート対象の広範なバージョンにわたる Windows Server の DNS ロール。両ゼロデイとも 2026-09-08 に CISA KEV に追加され、連邦機関の対応期限は 2026-09-22。

## 6〜7. CVE-2026-20079 & CVE-2026-20316 — Cisco Secure Firewall Management Center、連鎖利用で完全侵害へ

**原理・根本原因:** CVE-2026-20079（CVSS 10.0）は、起動時に生成されるシステムプロセスが、FMC 内部データベースに未認証・部分的な管理ツールセッションを残してしまうことに起因します。再起動後に管理者がログインしなければこのセッションが残り続け、リモートの未認証攻撃者がこれを悪用可能な権限へエスカレートさせ、細工した HTTP リクエストを通じて任意スクリプトの実行と基盤 OS への root アクセスを最終的に取得できます。CVE-2026-20316 は別の問題で、低権限アカウントに固定的で変更不能な認証情報が組み込まれているため、リモート攻撃者が直接ログインし、そのアカウントが利用可能なデータへアクセスできます。Cisco Talos は、ロシアの国家支援型グループや Qilin ランサムウェアを展開する攻撃者を含む複数の攻撃クラスタが、これらを連鎖利用して偵察、認証情報窃取、永続化を行っていることを確認しています。

**対策:**
- 両 CVE についてベンダー提供の修正版ソフトウェアまたは該当する Cisco ホットフィックスを適用する。CVE-2026-20079 には回避策がありません。
- FMC デバイスのログを監査し、管理者ログインを伴わずに作成された不審なセッションを確認する。また、組み込みの低権限アカウントに紐づく認証情報をローテーションする。

**影響を受ける対象:** オンプレミスの Cisco Secure Firewall Management Center 環境。両方とも実際に悪用されています。CVE-2026-20316 は2026年7月下旬に、CVE-2026-20079 は2026年8月〜9月に CISA KEV に追加され、今週も攻撃報告が続いています。

## 8. CVE-2026-67276 & CVE-2026-86060 — 「MikroTrick」MikroTik RouterOS SSH 認証バイパス連鎖

**原理・根本原因:** CVE-2026-67276 は、RouterOS が SSH 公開鍵認証を検証する方法に起因する脆弱性です。承認済み RSA 鍵の検証において、鍵全体（指数を含む）ではなく一部（法（モジュラス）のみ）しか確認していません。これがクライアントの署名検証方法と組み合わさることで、承認済みユーザーの公開鍵の法を知っている攻撃者は、実際の秘密鍵を保持していなくても RouterOS がそのユーザーとして受理してしまう別の鍵ペアを作成できます。CVE-2026-86060 は SSH ログイン処理における別の引数処理の不具合で、上記により確立されたセッションを完全な管理者権限へさらにエスカレートするために利用され得ます。

**対策:**
- RouterOS 6.49.21（Long-term）、7.23.4（Long-term）、または 7.24.2（Stable）以降へ直ちに更新する。
- SSH による管理アクセスを信頼できるネットワーク／VPN に制限する。攻撃者によって作成されたとみられる不審な SSH ユーザーアカウントがないか監査する。

**影響を受ける対象:** インターネットから SSH に到達可能な MikroTik RouterOS デバイス（上記修正版より前のバージョン）。実際の悪用は 2026-09-05 の一般公開に先立ち、2026-09-02 頃から始まっていました。Shadowserver は 2026-09-05 時点でインターネットに露出し SSH 到達可能なデバイスを約122,500台観測しています（露出台数であり、侵害確認済み台数ではありません）。

## 9. CVE-2026-19490 — Citrix NetScaler ADC/Gateway 認証バイパス（継続項目、現在大規模悪用中）

**原理・根本原因:** Gateway または AAA 仮想サーバーとして構成された NetScaler インスタンスには、代替認証経路（CWE-288）が存在し、リモートの未認証攻撃者が通常のログインチェックを経ずに保護された機能へ到達できます。

**対策:** NetScaler ADC/Gateway を 14.1-73.32、13.1-63.21、またはそれ以降へアップグレードする。

**影響を受ける対象:** 14.1-73.32 より前の NetScaler ADC/Gateway 14.1系、および 13.1-63.21 より前の 13.1系。アドバイザリは 2026-08-19 に公開され、2026-09-03 頃に信頼性の高い公開 PoC を契機として悪用が始まりました。2026-09-09 に CISA KEV へ追加され、連邦機関の対応期限は 2026-09-12。

## 10. CVE-2025-25249 — Fortinet FortiOS / FortiSwitchManager ヒープベースバッファオーバーフロー（継続項目）

**原理・根本原因:** `cw_acd` デーモンにおけるヒープベースのバッファオーバーフローにより、リモートの未認証攻撃者が特別に細工したネットワークパケットを送信してヒープメモリを破損させ、任意のコードまたはコマンドを実行できます。

**対策:** Fortinet のアドバイザリに従い、FortiOS と FortiSwitchManager を修正版へ更新する。管理プレーンのインターネットへの露出を制限する。

**影響を受ける対象:** FortiOS 6.4（全バージョン）、7.0.0〜7.0.17、7.2.0〜7.2.11、7.4.0〜7.4.8、7.6.0〜7.6.3。FortiSwitchManager 7.0.0〜7.0.5、7.2.0〜7.2.6。「PivotC2」リモートアクセス型トロイの木馬の展開のために実際に悪用されています。2026-09-09 に CISA KEV へ追加され、連邦機関の対応期限は 2026-09-12。

## 11. CVE-2026-87491 — Google Chrome V8 境界外書き込みゼロデイ（継続項目）

**原理・根本原因:** V8 における境界外書き込み（out-of-bounds write）により、特別に細工された HTML ページがメモリを破損させ、ブラウザのサンドボックス内で任意コード実行を可能にします。

**対策:** Chrome を 153.0.8010.36/.37（Windows/macOS）または 153.0.8010.36（Linux）以降へ更新する。Chromium ベースのブラウザを利用している場合は、同等の修正が適用されているか確認する。

**影響を受ける対象:** 修正版ビルドより前の Chrome/Chromium。2026年に修正された Chrome の7件目のゼロデイであり、2026-09-08 に230件の修正を含む Stable Channel リリースの一部として修正されました。2026-09-09 に CISA KEV へ追加され、連邦機関の対応期限は 2026-09-23。（上記 GRIMWEDGE 連鎖で使用された別の V8 脆弱性 CVE-2026-85046 とは異なるものです。）
