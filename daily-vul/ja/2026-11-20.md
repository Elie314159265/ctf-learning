## 1. CVE-2026-90436 — Apache Axis 1.x の安全でないリフレクション → 認証不要のRCE（実際に悪用）

**原理・根本原因:** Apache Axis 1.x（サポート終了のSOAPエンジン）には、安全でないリフレクションの不具合（CWE-470、「外部から制御される入力によるクラス／コードの選択」）が存在する。SOAPフォルトの処理時、Axisは呼び出し元が指定した `exceptionName` 要素を読み取り、その名前のクラスをロードする。付随する `String` 要素が存在すると、Axisはそのオブジェクトが本当に `AxisFault` であるかを検証する*前に*、単一の `String` コンストラクタを通じてそのクラスをインスタンス化してしまう。これにより、認証されていない攻撃者がサーバーに攻撃者指定の入力で任意のクラスを構築させ、リモートコード実行（RCE）に至る。

**緩和策:**
- Axis 1.x はサポート終了であり、Apache Software Foundation は 1.x の修正版をリリースする予定がない。保守されているSOAPエンジン（例: Apache Axis2）へ移行するか、パッチを適用した Axis 1.x ビルドを用いる。
- **Atlassian Confluence Data Center:** 1.x〜9.x のバージョンは「Remote API（XML-RPC & SOAP）」が有効な場合にのみ影響を受ける。未使用なら無効化するか、9.2.28（または該当ブランチの修正版）へ更新する。
- **N-able N-central:** 緊急措置として 2026.4 HF3 へアップグレードする。
- Axis 1.x ライブラリを同梱するすべての製品を棚卸しする — 影響は確認済みの2経路に限られない。

**影響範囲:** Apache Axis 1.x の全バージョン（1.4まで）、およびそれらを組み込むすべての製品（確認済み: 特定の Atlassian Confluence Data Center および N-able N-central ビルド）。ASF が 2026-11-06 に公開。CISA は CVSS 9.8 を付与。Confluence Data Center と N-central に対する悪用は 2026-11-13 から報告（Rapid7による）。2026-11-18 にCISA KEV追加、連邦機関の是正期限は 2026-11-21。

## 2. CVE-2026-129448 — Apache Roller XML-RPCデシリアライゼーション → 認証不要のRCE（実際に悪用）

**原理・根本原因:** Apache Roller（Java製ブログプラットフォーム）は、ベンダー「拡張」値型を扱うXML-RPCエンドポイントを公開しており、認証／認可チェックを行う*前に*提供データをデシリアライズする。認証されていない攻撃者が細工したリクエストを送ると、それが攻撃者の影響下にあるオブジェクトへデシリアライズされ、サーバー上でのリモートコード実行に至る。これは以前 CVE-2026-82384（2026年9月）として追跡されていたものと同一の根本的欠陥であり、CVE-2026-129448 は確認済みの影響バージョン範囲を拡大したものである。

**緩和策:**
- Apache Roller 6.1.6 以降へアップグレードする（少なくとも1つのトラッカーは 6.1.7 を推奨）。
- 即時アップグレードが不可能な場合、ネットワーク／プロキシ層で XML-RPC エンドポイントへの外部アクセスを制限または無効化する。

**影響範囲:** 一部の報告では Apache Roller 4.0.0 から 6.1.4 まで（6.1.4を含む）。Apache の勧告では範囲を「4.0.0 から 6.1.5 未満」と表現している。Apache Software Foundation は勧告（約2026-11-17）で実環境での悪用を確認した。9月に公開された変種向けの公開PoCが9月下旬から出回っており、攻撃のハードルを下げている。（本稿執筆時点でCISA KEV未確認 — それでも緊急扱いとすること。）

## 3. CVE-2026-115731 — Perforce Puppet Server レポートのデシリアライゼーション → RCE（実際に悪用）

**原理・根本原因:** Puppet Server のレポート処理経路は、エージェントから受信したデータをデシリアライズする。Puppet 認証局（CA）が署名した証明書を提示するクライアントは、細工したレポートオブジェクトを送信でき、それがデシリアライズされるとサーバーが攻撃者制御のコードを実行する。コードは Puppet サービスユーザー（必ずしも root ではない）として実行される。構成管理マスターはCAを保持し、フリート全体に変更を配布できるため、ここでの侵害は横展開およびCA鍵窃取の高いリスクを伴う。

**緩和策:**
- 修正版（2026-11-03 提供）へパッチ適用する: Puppet Enterprise 2026.0.1、2025.12.1、または 2023.8.13。Puppet Core 9.1.3 または 8.22.2。
- 悪用されたマスターはCA侵害として扱う: 発行済み証明書を確認し、必要に応じてCA／鍵をローテーションし、異常なエージェント登録やレポート送信を監査する。
- OpenVox 構成管理プラットフォームも同じ不具合の影響を受ける。パッチ直後に OpenVox を標的とした公開PoCが出現した。

**影響範囲:** Perforce Puppet Enterprise および Puppet Server（バージョン 2026.0.0 およびそれ以前の影響ブランチを含む）の、修正版より前のもの。CVSS 4.0 で 9.4 評価。悪用の最初の兆候は 2026-11-04 頃に表面化。2026-11-17 にCISA KEV追加、連邦機関の是正期限は 2026-12-01。

## 4. CVE-2026-125350 — Google Chrome XMLコンポーネントの解放後利用（ゼロデイ、実際に悪用）

**原理・根本原因:** Chrome の XML 処理における解放後利用（use-after-free）。細工したWebページにより、すでに解放されたメモリが再利用され、プログラム状態が破壊されて、レンダラー／ブラウザのサンドボックス内での任意コード実行へ誘導され得る。これは2026年に悪用された Chrome ゼロデイのうち、XMLコードを特に標的とした初のものであり、同年8件目の悪用済み Chrome ゼロデイである。

**緩和策:**
- Chrome を 157.0.8103.50/.51（Windows/macOS）または 157.0.8103.50（Linux）へ更新し、ブラウザを完全に再起動して修正を適用する。
- Chromium ベースのブラウザ（Edge、Brave など）は、上流同期ビルドが提供され次第更新する。

**影響範囲:** 上記ビルドより前の Google Chrome。High 評価（一部ソースでは CVSS 8.8）。Google は実環境での攻撃コードの存在を確認したが、標的や帰属の詳細は非公開とした。修正は 2026-11-09 にリリース。2026-11-10 にCISA KEV追加、連邦機関の是正期限は 2026-11-24。

## 5. CVE-2026-124194 — Microsoft Outlook のなりすまし → NTLMハッシュ窃取（ゼロデイ、実際に悪用）

**原理・根本原因:** Microsoft Outlook のなりすまし（spoofing）の不具合。細工したメッセージ／メッセージファイルを開くと、Outlook が通常の外部コンテンツ警告を出さずに攻撃者制御のサーバーへ外向き接続を開始する。この接続によりユーザーの NTLMv2 チャレンジ／レスポンス情報が漏洩し、攻撃者はオフラインクラッキングや、他サービスへの NTLM リレーに利用できる。CVSS は 6.5（Moderate）に過ぎないが、最小限のユーザー操作で資格情報素材が露出するため、実際の影響はより大きいと広く指摘されている。

**緩和策:**
- 影響ビルド向けの 2026年11月 Office セキュリティ更新を適用する。
- 多層防御: 境界で外向きの SMB/NTLM をインターネットへ遮断し、SMB署名を強制し、可能なら NTLM を無効化または制限する。
- Outlook に関連する、外部ホストへの予期しない外向き SMB/NTLM 認証を監視する。

**影響範囲:** Microsoft 365 Apps for Enterprise、Microsoft Office LTSC 2021、Microsoft Office LTSC 2024。Microsoft は実環境での悪用を確認。2026-11-10 にパッチ提供。2026-11-10 にCISA KEV追加、連邦機関の是正期限は 2026-11-24。

## 6. CVE-2026-114713 — UnrealIRCd のサーバー間コマンドインジェクション（実際に悪用）

**原理・根本原因:** オープンソースの UnrealIRCd IRC サーバーにおける、区切り文字の不適切な無害化の不具合（コマンドインジェクション）。2台以上のサーバーがリンクされたネットワークでは、ユーザーが細工した入力を送ることで追加のサーバー間（S2S）コマンドを注入でき、それがサーバー権限で処理される — 実質的に、本来発行できないはずの特権コマンドを実行する。

**緩和策:**
- UnrealIRCd 6.2.7.1 へアップグレードするか、プロジェクトのホットパッチ一式（2026-11-07 リリース）を適用する。
- 単一サーバーのネットワーク（リンクサーバーなし）はこのS2S経路では露出しないが、それでもパッチを適用すべき。

**影響範囲:** UnrealIRCd 6.0.0 から 6.2.7。深刻度は High と報告（CVE レコードは CVSS 3.1 で 8.6 を記載。Red Hat は High 評価）。2026-11-13 にCISA KEV追加、連邦機関の是正期限は 2026-11-16（本レポート時点で既に経過）— KEV エントリはシステムが既に侵害されていないかの法的調査（フォレンジックトリアージ）も要請している。

## 7. CVE-2026-123039 — Check Point Security Gateway/Management のローカル権限昇格（実際に悪用、連鎖）

**原理・根本原因:** Check Point Security Gateways および Security Management 製品におけるローカル権限昇格の不具合（CVSS 7.8）。単体ではデバイス上の既存アクセスを要するが、観測された攻撃ではチェーンの第2段階として使われた。攻撃者はまず「PHP2Shell」の不具合（CVE-2026-109618 / CVE-2026-109619）を悪用して Mobile Access ポータル経由で足場を得て、次に CVE-2026-123039 で root へ昇格した — イスラエルの組織に対する破壊的攻撃で、Webシェル、バックドア、場合によってはワイパーを展開したと報告されている。

**緩和策:**
- 影響する Security Gateway / Security Management バージョン向けの 11月 Jumbo Hotfix を適用する。
- 未対応であれば、Mobile Access の「PHP2Shell」初期アクセスの不具合（CVE-2026-109618 / CVE-2026-109619）も是正する。
- 侵害調査を実施する: 予期しないWebシェル、新規の root レベルプロセス、異常な Mobile Access ポータル活動を確認する。

**影響範囲:** Check Point Security Gateways および Security Management 製品（ベンダー勧告による）。2026-11-13 にCISA KEV追加、連邦機関の是正期限は 2026-11-16（本レポート時点で既に経過）。

## 8. SAP 11月パッチデー — ICM2SHELL（CVE-2026-76964 / CVE-2026-89126）および PROXYGATE（CVE-2026-89103）

**原理・根本原因:** SAP の 2026年11月 セキュリティパッチデーには CVSS 10.0 の不具合が4件含まれた。ICM2SHELL は2つのメモリ破壊バグから成る: SAP NetWeaver AS ABAP の Internet Communication Manager（ICM）における CVE-2026-76964 と、SAP Web Dispatcher における CVE-2026-89126。認証されていない攻撃者は、無効な長さフィールドを持つ細工したネットワークリクエストを送ってヒープの境界外書き込みを引き起こし、メモリを破壊してリモートコード実行に至り得る。WebSocket サポート（露出の前提条件）は既定で有効である。CVE-2026-89103（「PROXYGATE」）と CVE-2026-120017 が同じ速報の他の最大深刻度項目である。

**緩和策:**
- 2026年11月速報の SAP Security Note 3778530（ICM、CVE-2026-76964）および 3778556（Web Dispatcher、CVE-2026-89126）に加え、CVE-2026-89103 と CVE-2026-120017 のノートを適用する。
- パッチ適用を段階的に行う必要がある場合、ICM/Web Dispatcher エンドポイントの非信頼ネットワークへの露出を見直して適切に制限する。顧客側の設定手順については SAP のガイダンスに従う。

**影響範囲:** 2026年11月ノートによる SAP NetWeaver AS ABAP（ICM）および SAP Web Dispatcher。すべて CVSS 10.0、認証不要。2026-11-10 にパッチ提供。本稿執筆時点で独立に確認された実環境での悪用はなし。あるソースは公開PoCコードの主張を受けた予防的なシャットダウンに言及している — これらインターネットに面するコンポーネントは高優先度として扱うこと。

- Microsoft、Ivanti、Fortinet、SAP の各項目は 2026-11-10 の月例パッチ／ベンダーパッチデーの波（この7日間の直前）に由来するが、連邦機関のKEV期限および／または継続中の悪用活動がこの期間内に収まるため記載した。
- **未確認の項目:** 二次的なまとめで出回っている「2026-11-18 KEV バッチ」は、BerriAI LiteLLM（CVE-2026-40217）、Synology NAS（CVE-2024-10441）、REDCap（CVE-2026-90817）を挙げている。特に CVE-2026-40217 については、一次のエンリッチメントデータ（CISA ADP Vulnrichment）が依然としてPoCのみのステータスを示し、KEV登録とはマークしていなかった。確認済みの LiteLLM の KEV エントリは別のCVE（CVE-2026-42271、2026-06-08 追加）である。これらは一次のCISA KEVカタログでの確認が取れるまで本編リストから除外した。
- 上記の CVSS スコアと正確な日付は、CISA のアラートページに加え、二次報道（SecurityWeek、The Hacker News、Security Affairs、Rapid7、BleepingComputer、ベンダー関連ブログ）で裏付けを取っている。正確さが重要な場合は、行動前に各ベンダー自身の勧告および CISA KEV カタログで、正確なベクトル・影響ビルド・期限を確認すること。
- 本稿執筆時点で、この特定の期間内に新規公開された Apple iOS/macOS のセキュリティリリースは確認されなかった。
