## 1. CVE-2026-76418 — Cisco Secure Firewall ASA / FTD SSL VPN のサービス拒否

- **開示日:** 2026-10-28(Ciscoは10月中に悪用を把握)。
- **原理・根本原因:** SSL VPNサービスにおけるリクエスト処理の不備により、未認証のリモートの攻撃者がデバイスを予期せず再起動させ、VPN/ファイアウォールをサービス拒否状態にできる。
- **影響範囲:** Cisco ASA 9.16〜9.24、FTD 7.0〜10.1(SSL VPNのセカンダリ認証を設定している場合とされる)。
- **緩和策:** Ciscoの修正版またはホットフィックスを適用(報告されている修正版:ASA 9.16.4.104、9.18.4.96、9.20.4.50、9.22.3.200、9.23.1.48、9.24.1.27、FTD 7.0.11、7.2.13、7.4.9、7.6.7、7.7.14、10.0.3、10.1.1 — 未検証)。回避策は報告されていない。SSL VPNエンドポイントの公開状況を確認すること。
- **注意:** 同じSSL VPNのDoSをCVE-2026-20349として報じ、バージョン一覧が異なる情報源もある。Ciscoのアドバイザリで正式なCVE IDと修正版を確認すること。

## 2. CVE-2026-46300「Fragnesia」— Linux カーネル XFRM ESP-in-TCP のローカル権限昇格

- **開示/KEV日:** 2026-10-28にCISA KEV追加、連邦機関の期限は2026-10-31。カーネルの修正は2026年5月から提供されているとされる。
- **原理・根本原因:** カーネルのXFRM/IPsec ESP over TCP処理の欠陥により、ローカルの一般ユーザーがrootへ権限昇格できる。攻撃ではPHPの脆弱性(項目5)と連鎖(Webワーカーでのコード実行→ローカルroot化)して使われたと報告されている。
- **影響範囲:** XFRM ESP-in-TCP機能を持つ、修正済みstableリリースより前のLinuxカーネル(ディストリビューションにより異なる)。
- **緩和策:** ディストリビューションのカーネル更新を適用して再起動。パッチ適用が遅れる場合は、信頼できないローカル/コンテナのアクセスを制限する。

## 3. CVE-2026-97229 — GitLab CI/CD 正規表現エンジンの整数オーバーフロー(未認証RCE)

- **開示日:** 2026年10月下旬(CISAが2026-10-29に注意喚起したとの報道があるが、悪用確認やKEV掲載の有無は情報源間で食い違う)。
- **原理・根本原因:** CI/CD設定の処理で使われる正規表現コンパイラの整数オーバーフローにより、メモリ破壊と認証なしのコード実行につながる。
- **影響範囲:** セルフマネージドGitLab CE/EEの19.2(19.2.8未満)、19.3(19.3.5未満)、19.4(19.4.2未満)。GitLab.comは修正済み、Dedicatedも対応済み。
- **緩和策:** 19.2.8 / 19.3.5 / 19.4.2へアップグレード(19.3.4はマージリクエスト画面の別不具合があるため19.3.5を使用)。GitLabのインターネット公開を制限し、不審なCI設定がないか確認する。

## 4. CVE-2026-118539 — Drupal Commerce Core のアクセス制御バイパス

- **開示日:** 2026年10月下旬。
- **原理・根本原因:** Commerce Coreの認可/アクセス制御チェックの欠落または不備により、本来アクセスできないリソース(注文など)にアクセス可能。Drupalは「highly critical」と評価し、悪用が報告されている。
- **影響範囲:** 情報源によれば、Commerce Core 8.x-2.x(8.x-2.41の修正版より前)および3.0.0〜3.3.12(3.3.13で修正)。
- **緩和策:** 3.3.13 / 8.x-2.41以降へ更新し、注文やアクセスログに異常がないか監査する。2026-10-30時点でKEV未掲載とする情報源がある。

## 5. CVE-2026-109618 / CVE-2026-109619 — PHPのメモリ安全性の脆弱性(「PHP2Shell」)

- **開示日:** 2026-10-21(同日パッチ公開)、2026-10-26にCISA KEV追加。
- **原理・根本原因:** いずれもUse-After-Free(CWE-416)系。109618:リクエスト(マルチパート)解析中のメモリ不足により内部データが部分的にしか初期化されず、後処理がそれを有効として扱う。109619:リクエスト所有の状態がその裏付けメモリより長く残り、同一ワーカーの後続リクエストで再利用される。CVSS 4.0で9.2。PHP-FPMに対するコード実行が検証されたと報告されている。
- **影響範囲:** PHP 8.5.12、8.4.27、8.3.36、8.2.35より前。8.1以前(サポート終了、情報源により5.4まで遡る)はベンダーのバックポートがない限り影響を受ける。
- **緩和策:** 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35へ更新、またはベンダーのバックポート(Red Hat、CloudLinux、cPanel、Ubuntu等)を適用。暫定策:該当ワーカーのみを終了させるコンテナ/cgroupのメモリ制限を使用し、RLIMIT_AS/RLIMIT_DATAは避ける。EOLのPHPからは移行する。
