## 1. CVE-2026-0257 — PAN-OS GlobalProtect 認証バイパス

**原理・根本原因:** GlobalProtect ポータル/ゲートウェイにおける認証バイパスで、認証情報やユーザー操作なしにネットワーク越しに到達可能です。認証オーバーライドCookie機能が有効で、特定の証明書構成がある場合に該当し、Cookieベースの信頼チェックが認証されていない者によって満たされてしまいます。

**緩和策:**
- 各ブランチの修正済みホットフィックスを適用(例: 12.1系は 12.1.4-h6 / 12.1.7。他ブランチはPalo Alto Networksのアドバイザリを参照)。
- 暫定策: 認証オーバーライドCookieを無効化、またはその機能専用の証明書を使用。
- パッチ適用後、GlobalProtect ユーザーは一度再認証が必要。

**影響範囲:** PAN-OS 10.2〜12.1 および Prisma Access(情報源の一つによる。正確な範囲は情報源間で不一致)。Panorama と Cloud NGFW は影響なし。**開示日:** 2026年5月に初出(CISA KEV期限 2026-06-01)、2026-05-29の公開解析後に深刻度が引き上げ。Unit 42 が 2026-10-19 に脅威ブリーフを更新し、ランサムウェアグループ(Qilin、Inc 関連、公開報道ではSettra)による悪用試行を報告したため、現在の優先事項として掲載。

## 2. CVE-2026-104935 — Ivanti Connect Secure 認証バイパス(ゼロデイ)

**原理・根本原因:** リモートの未認証攻撃者がアプライアンス上で任意のコマンド実行につながる機能に到達できる認証バイパス。Volexity は、脅威アクター(UTA0576)が少なくとも 2026-10-03 から他の2件の脆弱性と連鎖させて悪用していると報告。同じ連鎖で使われた権限昇格の脆弱性については Ivanti が修正を準備中です。

**緩和策:**
- 22.8R2.5、または該当する 25.1.3.0 / 25.1.3.1 / 25.1.1.2 へアップグレード。
- パッチ前から悪用されているため、Integrity Checker Tool の実行と侵害調査、疑わしい機器の初期化、認証情報のローテーションを検討。

**影響範囲:** Connect Secure 22.8R2.4 以前、25.1.2.2 以前、25.1.1.1 以前。**開示日:** 2026-10-13。CISA KEV に追加、連邦機関の期限は 2026-10-16。

## 3. CVE-2026-96951 — Windows Shell の Mark of the Web バイパス(ゼロデイ)

**原理・根本原因:** Windows Shell におけるコマンド内の特殊要素の不適切な無害化(CWE-77)により、細工されたファイルが Mark of the Web の付与を回避し、ダウンロードコンテンツに通常表示される SmartScreen / 保護ビュー等の警告が抑止されます。ユーザー操作(配布されたファイルを開く)が必要で、メール、チャット/コラボレーションツール、悪意あるダウンロード経由で届けられるのが一般的です。

**緩和策:**
- 全Windows端末に2026年10月の累積更新(2026-10-13)を適用。
- 不審な添付ファイルに関するユーザー教育を強化し、メール/Webフィルタリングと EDR を維持。

**影響範囲:** 2026年10月の更新対象のWindowsバージョン(正確なビルド一覧は取得できず。Microsoft Security Update Guide で確認)。Tenable によれば、今年悪用が確認された3件目の Windows Shell 脆弱性。**開示日:** 2026-10-13。CISA KEV 追加は 2026-10-13/14。

## 4. CVE-2026-0322 — PAN-OS 管理インターフェースのコードインジェクション

**原理・根本原因:** 管理インターフェースにおけるコードインジェクションにより、認証済みユーザーが root 権限でコードを実行可能。

**緩和策:** Palo Alto Networks の修正版を適用。管理インターフェースへのアクセスを信頼できる内部ネットワークに限定(報道ではワークアラウンドなし)。

**影響範囲:** PAN-OS(バージョン一覧は未取得。ベンダーのアドバイザリ参照)。**開示日:** CISA KEV 追加 2026-10-14(連邦期限 2026-10-17)。

## 5. CVE-2026-76519 — Cisco Secure Email Gateway パストラバーサル

**原理・根本原因:** 相対パストラバーサルの欠陥で、未認証のリモート攻撃者がファイル書き込みおよびコマンド実行に至る可能性があると報じられています。

**緩和策:** Cisco のアドバイザリに従い修正版を適用。アプライアンスの管理/Webインターフェースの公開を制限。

**影響範囲:** Cisco Secure Email Gateway(バージョンは未取得)。**開示日:** CISA KEV 2026-10-14。

## 6. CVE-2026-105133 / CVE-2026-105134 — AhsayCBS の不適切な認証とコマンドインジェクション

**原理・根本原因:** AhsayCBS バックアップサーバーの管理サービスにおける不適切な認証とOSコマンドインジェクション。組み合わせることで、リモート攻撃者がアクセスを得てコマンドを実行できます。

**緩和策:** ベンダーの修正版 AhsayCBS へアップグレード。管理コンソールをインターネットに公開しない。

**影響範囲:** AhsayCBS(バージョンは未取得)。**開示日:** CISA KEV 2026-10-14。

## 7. CVE-2026-21589 — Atlassian: 外部からファイル/ディレクトリにアクセス可能

**原理・根本原因:** アクセス制御の不備により、ファイルやディレクトリが外部の第三者から到達可能となり(CWE-552 系)、意図しない情報漏えいが起こり得ます。

**緩和策:** ベンダーのアドバイザリにある修正版へ更新。可能であれば外部からのアクセスを制限。

**影響範囲:** Atlassian 複数製品(バージョンは未取得)。**開示日:** CISA KEV 2026-10-15。

## 8. Plex Media Server — CVE-2026-96651, -96652, -96654, -96655, -96656

**原理・根本原因:** パストラバーサル(ファイル読み取り。アカウントのオンライントークンが露出し得る)、完全なURLを受け付けるエンドポイントによるSSRF、プラグイン関数呼び出しを可能にするURLインジェクションなど。未認証のリモートコード実行に連鎖するかは報道により見解が分かれます。ある報道は攻撃者による悪用と 2026-10-16 公開のPoCに言及し、別の報道は実際の悪用を確認できなかったとしています。悪用されている可能性ありとして扱ってください。インターネット公開の約36,000台が未パッチと報告されています。

**緩和策:** Plex Media Server 1.43.3.10861 以降へ更新(1.43.3 には複数ビルドがあるため完全なビルド番号を確認)。サーバーを直接インターネットに公開しない。侵害が疑われる場合はPlexトークンをローテーション。

**影響範囲:** Plex Media Server 1.43.3.10861 より前。**開示日:** 2026年10月中旬。
