### Microsoft 2026年10月 Patch Tuesday(開示日: 2026-10-13)
- **詳細:** 規模の報告は一致していません(ある情報源: 約1,411件・ゼロデイ3件、別の情報源: 約1,417件・緊急76件、ベンダー系ページ: Exchange Server の権限昇格 CVE-2026-96940〈CVSS 8.8〉のみ)。悪用が報告された脆弱性の一つが CVE-2026-96951(Windows Shell の Mark-of-the-Web〔MotW〕セキュリティ機能バイパス)ですが、**この CVE は独立して確認できていません。**
- **原理・根本原因:** セキュリティ機能バイパス型。シェルが「インターネットから取得」の目印を維持・考慮せず、細工されたファイルを開いた際に SmartScreen/保護ビュー等の警告が省略される。
- **影響範囲:** サポート対象の Windows クライアント/サーバー、Exchange Server(CVE-2026-96940)。
- **対策:** 10月の累積更新プログラムおよび Exchange セキュリティ更新を適用。正確な一覧は MSRC Security Update Guide を確認。信頼できないファイルを開かないよう利用者へ周知。

## 悪用確認済み/最近の項目

### SonicWall SMA 1000 — CVE-2026-102255(CVSS 10.0)、開示日 約2026-10-07〜08
- **原理・根本原因:** WorkPlace インターフェースにおける認証前のサーバーサイドリクエストフォージェリ(SSRF)。未認証の第三者が機器に内部向けリクエストを発行させ、内部サービスが露出し得る。
- **影響範囲:** SMA 6210、7210、8200v のうち 12.4.3-03526 以前、または 12.5.0-02952 以前。SMA 100 シリーズおよびファイアウォールの SSL-VPN は対象外。
- **対策:** 12.4.3-03670 / 12.5.0-03082 以降へアップグレード(SNWLID-2026-0017。一部の CERT は異なるホットフィックス番号を記載しているため要確認)。回避策の記載なし。同アドバイザリで CVE-2026-102256(認証後 OS コマンドインジェクション 7.8)、CVE-2026-102257(Zip Slip 7.2)、CVE-2026-102258(格納型 XSS 5.5)も修正。
- **状況:** 研究者が10月9日に悪用試行を報告。ベンダーは当時、悪用の確証はないとしていた。

### Citrix NetScaler ADC / Gateway — CVE-2026-88779(CVSS 4.0: 8.7)、開示日 2026-10-04(CISA KEV 同日追加)
- **原理・根本原因:** SAML 処理におけるメモリオーバーフロー。繰り返しの誘発で機器がクラッシュ(サービス拒否)する。コード実行の可否は調査中。
- **影響範囲:** SAML SP または IdP として構成された機器。NetScaler 14.1(14.1-73.41 未満)、13.1(13.1-64.28 未満)。FIPS/NDcPP の 13.1 は 13.1-37.282。ビルド番号は情報源により異なる。
- **対策:** 修正ビルドへ更新(CVE-2026-88771/88772 対応で最近更新した機器も再更新が必要。両者は 2026-09-27 に KEV 追加済みのゼロデイ)。米連邦機関の期限は 2026-10-07。

### Fortinet FortiMail — CVE-2026-104286(CVSS 9.8)、開示日 2026-10-01(CISA KEV 同日追加)
- **原理・根本原因:** Identity-Based Encryption(IBE)サービスにおけるパストラバーサルと NULL バイト処理の不備により、未認証で細工した Web リクエストから任意ファイル書き込みが可能。
- **影響範囲:** FortiMail 8.0.0〜8.0.1、7.6.0〜7.6.6、7.4.0〜7.4.8(一部情報源では 7.2.x も)。
- **対策:** 7.4.9 / 7.6.7 / 8.0.2 へ更新(リリース済みか情報源で食い違い)。それまで IBE の無効化または公開範囲の制限、侵害調査を実施。アドバイザリ FG-IR-26-175。

### Zammad — CVE-2026-102489、CVE-2026-102490(CISA KEV 2026-10-02 追加)
- **原理:** セッション固定(102489)と不適切な権限管理によるローカルでの root への権限昇格(102490)。
- **影響範囲・対策:** Zammad ヘルプデスク環境。公式アドバイザリの修正版へ更新(バージョン未確認)。更新後にセッションを再発行。

### Bricksforge WordPress プラグイン — CVE-2026-85097(CVSS 10.0)
- **原理:** 認証不要の任意ファイルアップロードによりサーバー側でコード実行に至る。2026-10-07 から悪用試行を確認(Patchstack)。
- **対策:** 修正版へ更新、またはプラグインを削除。Web ルート内の不審なファイルを確認。影響バージョン範囲は未確認。
