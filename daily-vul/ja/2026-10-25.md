## 1. 最新 / 最優先

### 1.1 Plex Media Server「Plex2Shell」— 4件の脆弱性の連鎖(悪用確認済み、CISA KEV 追加)
- **公開日 / 状況:** 直近数日(2026-10-19〜10-24 の週)に CISA KEV へ追加。Plex は広範囲で悪用中と発表。2026-10-16 に公開 PoC が出回り、大規模な悪用が始まった。ベンダー修正は 2026-08-03 に公開済み。
- **原理 / 根本原因:** Plex Media Server の4つの独立した弱点を連鎖させることで、認証不要のリモート攻撃者がサーバー上でリモートコード実行に至る。侵害されたホストでは暗号資産マイナーやプロキシソフトが稼働していた。
- **影響:** 1.43.3.10861 より前の Plex Media Server(Windows、Linux、NAS 等)。Shadowserver によれば、インターネットに公開され未修正の可能性があるインスタンスが 36,000 超。
- **対策:**
  - 1.43.3.10861 以降へ更新。
  - サーバーを直接インターネットへ公開せず、FW/VPN でアクセス制限。
  - 侵害指標の確認: Codecs フォルダ内の見覚えのない `.so`/`.dll`、`proxystream.st` への外向き通信。検出時は再構築と認証情報のローテーション。

### 1.2 Palo Alto Networks PAN-OS GlobalProtect — CVE-2026-0257(認証バイパス、ランサムウェアによる悪用継続)
- **公開日:** ベンダーアドバイザリは 2026-05-13。CISA KEV 登録済み。6月以降 Qilin 等のランサムウェアグループによる悪用が報告され、2026-10-24 の脅威ブリーフでも注目されている。2026-10-14 の CISA KEV 追加分にも PAN-OS が含まれる。
- **原理 / 根本原因:** 認証オーバーライド Cookie 機能が有効な場合、PAN-OS は復号できる Cookie を、自装置が発行したものか検証せずに受け入れる。そのため攻撃者は有効な認証情報や MFA なしで VPN セッションを取得できる。
- **影響:** GlobalProtect ポータル/ゲートウェイで認証オーバーライド Cookie が有効(特定の証明書構成)な PAN-OS 10.2、11.1、11.2、12.1 および Prisma Access。Panorama と Cloud NGFW は対象外。
- **対策:** ベンダーの修正版表に従い更新。暫定策: 認証オーバーライドの無効化、または専用証明書のみを使用。VPN セッションログで不審なセッションを確認。
- **深刻度:** ベンダー CVSS 7.8(4.7 から引き上げ)。一部集計サイトは 9.1 と記載。

### 2.1 Microsoft Windows Shell MotW バイパス — CVE-2026-96951(悪用されたゼロデイ)
- **公開日:** 2026-10-13(10月のパッチ Tuesday)。
- **原理:** セキュリティ機能のバイパス。細工されたコンテンツにより Mark-of-the-Web 保護を回避し、ダウンロードしたファイルが通常の警告なしに実行される。CVSS 8.8。パッチ前に悪用された。
- **影響:** Microsoft アドバイザリ記載のサポート対象 Windows。
- **対策:** 2026年10月の累積更新プログラムを適用。SmartScreen/Defender を有効に保ち、ダウンロードファイルの警告に関するユーザー教育を行う。
