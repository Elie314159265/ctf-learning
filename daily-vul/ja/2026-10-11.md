## 1. CVE-2026-107406 — Citrix NetScaler ADC / Gateway(SAML構成)

**原理・根本原因:** SAML認証トラフィックの処理に欠陥があり、特定の構成下でリモートコード実行またはサービス拒否(DoS)につながる可能性があります。参照した情報源にはベンダーによる詳細な根本原因の記載がなく(#2と同じSAML処理経路のメモリ処理系の問題とされています)。

**対策:**
- 修正版へアップグレード: 14.1系は 14.1-73.46 以降、13.1系は 13.1-64.29 以降、14.1-FIPS は 14.1-73.46 FIPS、13.1-FIPS / 13.1-NDcPP は 13.1.37.283 以降。
- 影響確認: SAML SP(サービスプロバイダ)またはIdPとして構成されている場合のみ影響(構成内の `add authentication samlAction` / `samlIdPProfile` を確認)。
- Citrixはアドバイザリ時点で悪用の証拠はないとしており、個別の回避策は確認できませんでした。

**影響範囲:** SAML SP/IdP構成の NetScaler ADC / Gateway 14.1系・13.1系(FIPS/NDcPP含む)の修正版より前のビルド。2026-10-09頃に開示(CISAのCitrixアラートが同日更新)。

## 2. CVE-2026-88779 — Citrix NetScaler ADC / Gateway SAMLメモリバッファの欠陥(悪用確認)

**原理・根本原因:** SAML SP/IdP処理経路におけるメモリバッファ処理の欠陥で、単独で対象アプライアンスのサービス拒否を引き起こし得ます。CISAが2026-09-27に注意喚起したNetScalerゼロデイ群の一部です。

**対策:**
- 14.1-73.41 または 13.1-64.28 以降へアップグレード。FIPS は 14.1-73.41 FIPS、13.1-FIPS / NDcPP は 13.1-37.282 以降。
- Citrixは補完策として既知の悪意あるIPをブロックするGlobal Deny Listを提供。
- 米国連邦機関はCISA KEVの手続きに従い対応が必要。

**影響範囲:** SAML構成の NetScaler ADC / Gateway のうち、13.1-37.282(FIPS/NDcPP)、13.1-64.28、14.1-73.41、14.1-73.41 FIPS より前。2026-10-04にCISA KEVへ追加、悪用確認済み。(一部媒体は「CVE-2026-8877」と誤記しています。)

## 3. CVE-2026-102489 / CVE-2026-102490 — Zammad セッション固定と権限昇格(悪用確認)

**原理・根本原因:** CVE-2026-102489 はセッション管理の欠陥(セッション固定/ハイジャック)で、アプリケーション実行ユーザー権限でのコード実行につながり得ます。CVE-2026-102490 は不適切な権限管理により、そのユーザーからrootへのローカル権限昇格を許します。連鎖するとホスト全体の侵害に至ります。

**対策:**
- Zammad 7.2.0 へアップグレード(強化策が含まれると報告)。ただしCVE-2026-102490が完全に修正されるかは情報源で食い違い、2026-10-05時点で正式なベンダーアドバイザリは確認できませんでした。
- DIVDの助言: バージョン7へ移行するか、インスタンスを停止。ネットワーク露出の制限、最小権限での稼働、予期しない特権プロセスの監視。
- Zammad GmbHは影響バージョンや悪用可能性に関するDIVDの評価に一部異議を唱えているため、公式リリースノートに従ってください。

**影響範囲:** CVE-2026-102489: Zammad 6.3.0〜6.5.4(7.0.0〜7.1.3は存在するがベンダー見解では悪用不可)。CVE-2026-102490: 1.5.0〜7.1.0-alpha と報告(CVE本文はより広範)。両方とも2026-10-02にCISA KEVへ追加。

## 4. CVE-2026-104286 — Fortinet FortiMail パストラバーサル/任意ファイル書き込み(ゼロデイ)

**原理・根本原因:** リクエスト処理におけるファイルパス検証の不備により、認証なしのリモートの攻撃者がアプライアンス上の任意の場所にファイルを書き込めます(パストラバーサル、CWE-22)。コード実行や永続化につながり得ます。

**対策:**
- 2026-10-01公開のFortinetアドバイザリに従い、修正版へアップグレード(影響ブランチから脱出)。
- 管理/Webインターフェースのインターネット公開を制限。予期しないファイルや設定変更を確認し、公開状態で未パッチだった機器は侵害の可能性ありとして扱う。

**影響範囲:** FortiMail 8.0.0〜8.0.1、7.6.0〜7.6.6、7.4.0〜7.4.8、7.2.0〜7.2.9。2026-10-01開示、実環境で悪用、同日CISA KEV追加(連邦機関の期限 2026-10-04)。
