## 最新情報（直近24〜48時間）

### 1. PAN-OS CVE-2026-0257 — ランサムウェアによる悪用報告（Palo Alto Networks）
- **開示日:** 2026年前半に公表済み（CISA KEV の対応期限は 2026-06-01）。Unit 42 が 2026-10-20 に脅威ブリーフを更新し、ランサムウェア関連グループ（Qilin、Inc など）による悪用試行を報告。
- **原理・根本原因:** GlobalProtect ポータル/ゲートウェイの認証バイパス。認証オーバーライドCookieが有効で、特定の証明書構成がある場合のみ成立し、未認可の第三者がVPNセッションを確立できる可能性がある。
- **影響範囲:** GlobalProtect ポータル/ゲートウェイを構成した PAN-OS ファイアウォール（PA-Series / VM-Series）。Panorama と Cloud NGFW は影響なし。10.2、11.1、11.2、12.1 系（修正版は公式アドバイザリ参照）。
- **対策:** 該当ブランチの修正版へアップグレード。不可の場合は認証オーバーライドCookieを無効化、または専用かつ安全に保管された証明書を使用。VPNログで不審な接続元IPやログイン後の挙動を確認。

## 今週のその他の注目項目

### 3. Cisco Secure Email Gateway CVE-2026-76519（CVSS 9.8）— 悪用確認済み
- **開示日:** 2026-10-13/14（2026-10-14 に CISA KEV 追加）。
- **根本原因:** 相対パストラバーサルにより、認証なしでアプライアンス上へファイル書き込みが可能。
- **影響範囲:** AsyncOS 搭載の物理/仮想 Cisco Secure Email Gateway。File Reputation が有効でメールポリシーに割り当てられ、かつ Content Scanner Tools が 25.3.0.5525 未満の場合のみ。
- **対策:** Content Scanner Tools を 25.3.0.5525 以降へ更新（回避策なし）。ログに "Suspected compromise indicator was found" がある場合は、アップグレードで証拠が失われるため先に Cisco TAC へ連絡。アドバイザリ: cisco-sa-esa-afw-zqYJkjxp。

### 4. Microsoft Windows Shell CVE-2026-96951（CVSS 8.8）— ゼロデイ、2026-10-13 パッチチューズデー
- **根本原因・種別:** 確認した情報源では詳細不明（Windows Shell の悪用確認済みゼロデイと報告）。
- **影響範囲:** サポート対象の Windows（Microsoft Security Update Guide 参照）。
- **対策:** 2026年10月の累積更新プログラムを適用。CISA KEV の連邦機関期限は 2026-10-16。パッチチューズデーの CVE 総数は情報源により大きく異なります。

### 5. Ivanti Connect Secure CVE-2026-104935 — 認証バイパス
- **開示日:** 2026-10-13 に CISA KEV 追加。
- **根本原因:** 不適切な認証により、有効な資格情報なしでアクセス可能。
- **影響範囲・修正版:** 確認した情報源では不明。Ivanti のアドバイザリ参照。
- **対策:** 最新の Connect Secure パッチを適用し、整合性チェックツールを実行、アクセスログを確認。

### 6. Palo Alto Networks PAN-OS CVE-2026-0322 — コードインジェクション（管理インターフェース）
- **開示日:** 2026-10-14 に CISA KEV 追加。
- **根本原因:** コードインジェクションにより、認証済みの管理インターフェース利用者が root 権限でコードを実行可能。
- **影響範囲:** PA-Series、VM-Series、Panorama（10.2〜12.2 で修正版が報告）。Cloud NGFW と Prisma Access は影響なし。
- **対策:** 修正版へアップグレードし、管理インターフェースへのアクセスを信頼できる内部ネットワークに制限。

### 7. Ahsay AhsayCBS CVE-2026-105133（不適切な認証）および CVE-2026-105134（コマンドインジェクション）
- **開示日:** 2026-10-14 に CISA KEV 追加（連邦機関の期限 2026-10-17）。
- **根本原因:** バックアップサーバーの管理サービスにおける認証の不備とコマンドインジェクションの組み合わせ。
- **影響範囲・修正版:** Ahsay のアドバイザリ参照。
- **対策:** 最新の AhsayCBS へアップグレードし、管理コンソールをインターネットに公開しない。
