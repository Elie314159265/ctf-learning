## 1. CVE-2026-109618 & CVE-2026-109619 — PHPエンジンのメモリ安全性の欠陥(「PHP2Shell」)

**原理・根本原因:** PHPエンジンのリクエスト処理に存在する2件の欠陥です。CVE-2026-109618 は、メモリ不足時の処理により、内部のリクエストデータが部分的にしか初期化されていない状態で処理が中断され、その後のクリーンアップが不正なデータを正当なものとして扱ってしまう問題です。CVE-2026-109619 は、リクエストが所有する状態が、その参照先メモリより長く残存し、同じワーカー上の後続リクエストが通常の初期化前にその古い状態を使用してしまう問題です。いずれも認証不要のリモートコード実行につながり得ます。

**対策:**
- PHP 8.5.12、8.4.27、8.3.36、8.2.35(またはそれ以降)へアップグレードしてください。完全な対策はパッチ適用のみです。
- PHP 8.1、8.0、7.4 には公式リリースがありません。ソースのバックポートは公開されているため、ディストリビューションの更新を適用するか、サポート対象のブランチへ移行してください。
- 設定による緩和(例: セッションアップロード進捗の無効化)は侵入経路の一つを塞ぐだけで、代替にはなりません。
- インターネットに公開されたPHPアプリケーションや共有ホスティングを優先し、Webログやドキュメントルートに予期しない新規ファイルがないか確認してください。

**影響範囲:** 上記の修正版より前のすべてのPHP(サポート終了ブランチを含む)。2026-10-21 公開(当初は10-22予定だったが、詳細の漏えいにより前倒し)。ベンダー各社は悪用の試行を報告しています。PHPは両脆弱性を 9.2 と評価していますが、漏えい情報に基づくより高いスコアを引用する報道もあります。

## 2. CVE-2026-111497(ほか9件)— Node.js Brotliデコーダのリモートコード実行

**原理・根本原因:** Brotli展開処理にメモリ安全性の欠陥があり、細工された圧縮データによってメモリが破壊され、Node.js はこれがリモートコード実行を可能にし得るとしています。

**対策:**
- Node.js 22.x、24.x、26.x の各ラインを最新のセキュリティリリースへ更新してください。
- 信頼できないBrotliデータを展開するランタイム(コンテナやアプリケーションに同梱されたものを含む)を棚卸ししてください。

**影響範囲:** 2026-10-21 のセキュリティリリース以前の Node.js 22.x、24.x、26.x。本稿執筆時点で悪用は確認されていません。

## 3. CVE-2026-96652、-96654、-96655、-96656 — Plex Media Server「Plex2Shell」チェーン

**原理・根本原因:** 複数の欠陥の連鎖です。CVE-2026-96654 は検索エンドポイントにおけるURLインジェクションで、他のプラグインの関数を呼び出せてしまいます。CVE-2026-96656 はトランスコーダ設定における任意ファイル書き込みで、管理者権限の攻撃者が共有ライブラリを配置でき、サーバーが後にそれを読み込むことでコード実行に至ります。これらの連鎖によりホスト上でのコード実行が可能になります。

**対策:**
- Plex Media Server 1.43.3.10861 以降(2026-08-04 リリース)へ更新してください。
- サーバーをインターネットへ直接公開せず、ホスト上に予期しない暗号資産マイニングのプロセスがないか確認してください。
- CISAの連邦機関向け期限: CVE-2026-96654/-96656 は 2026-10-23、その他は 2026-11-03。

**影響範囲:** 1.43.3.10861 より前の Plex Media Server。悪用報告は 2026-10-17 頃から(当初は研究者のハニーポットで、マイナーが展開)。2026-10-20 に CISA KEV へ追加。

## 4. CVE-2026-106931 — SiteGuard Server Edition のOSコマンドインジェクション

**原理・根本原因:** 既定で有効な統計機能が、攻撃者の影響下にある入力を十分な無害化なしにOSコマンドへ渡しており(CWE-78)、WAFホスト上で root/SYSTEM 権限のコマンド実行が可能になります。

**対策:**
- SiteGuard Server Edition 8.00 Update 5(Apache/Nginx/IIS)または 7.00 Update 6(FreeBSD上のApache/Nginx)へ更新してください。古い版・サポート終了版向けにはファイル置換パッチも提供されています。
- 統計機能を無効化すると露出を排除できます。
- ベンダーは、修復により攻撃の痕跡が消える可能性があると警告しています。パッチ適用前にログとディスクの証拠を保全してください。
- CISAの連邦機関向け期限: 2026-10-23。

**影響範囲:** SiteGuard Server Edition 2.20 以降 8.00 Update 5 未満(FreeBSD は 7.00 Update 6 未満)。IIS版 3.10〜4.00 Update 4 は影響を受けないと報じられています。JPCERT/CC が注意喚起を出しています。2026-10-20 に CISA KEV へ追加。

## 5. CVE-2026-110936 — Siemens Software Center の制御されないDLL検索パス

**原理・根本原因:** アプリケーションが、ローカルユーザーが影響を与え得る検索パスからDLLを読み込むため(CWE-427)、配置されたライブラリがアプリケーションの権限で実行されます。Siemens は、実環境での悪用をClickFix型ソーシャルエンジニアリングキャンペーン(ユーザーを騙してローカルで操作を実行させる手口)と関連付けています。

**対策:**
- Siemens Software Center を V4.0.9.8 以降へ更新してください。
- コピー&ペーストを促す「修正」手順への注意喚起を行い、アプリケーションの読み込みパス上のディレクトリへの書き込み権限を制限してください。
- Siemens は、自社のシステムや更新チャネルが侵害されたことはないとしています。

**影響範囲:** V4.0.9.8 未満の Siemens Software Center(Windows)。2026-10-20 に CISA KEV へ追加(連邦機関向け期限 2026-11-03)。
