## 1. CVE-2026-105133 / CVE-2026-105134 — AhsayCBS の認証バイパスとOSコマンドインジェクション

**原理・根本原因:** CVE-2026-105133 は、APIコンポーネントのシステムパスワード確認処理における不適切な認証の問題で、リクエストパラメータの扱いが不十分なため、リモートから認証確認を回避できます。CVE-2026-105134 はレプリケーション受信APIにおけるOSコマンドインジェクションで、信頼できない入力が十分なサニタイズなしにシステムコマンドへ渡り、リモートコード実行につながります。攻撃者はこれらを利用してWebシェルや暗号資産マイナーを設置していると報告されています。

**緩和策:**
- AhsayCBS を 10.3.4 以降に更新する。
- 更新までは、管理・API・レプリケーション用エンドポイントへのアクセスを制限し、インターネットに公開しない。
- 露出していたホストで、不審なWebシェル、プロセス、マイナーの活動を調査する。

**影響範囲:** AhsayCBS 10.3.2 以前(10.3.0〜10.3.2とする情報源もあるが未確認)。深刻度は情報源により異なり、CVE-2026-105133 は 6.9〜7.3、CVE-2026-105134 は CVSS v4 9.3。2026-10-07 からHuntressが悪用を観測。開示はその数日前。

## 2. CVE-2026-88779 — Citrix NetScaler ADC / Gateway のSAML関連メモリ境界処理の不備(DoS)

**原理・根本原因:** メモリバッファの境界内での操作に対する制限が不適切で、アプライアンスがSAML SP(サービスプロバイダ)またはIdPとして構成されている場合に到達可能です。悪用するとコード実行ではなくアプライアンスのクラッシュ(サービス拒否)を引き起こします。9月下旬のNetScalerゼロデイ(CVE-2026-88771 / CVE-2026-88772)に続くものです。

**緩和策:**
- 14.1-73.41 以降、13.1-64.28 以降、14.1-73.41 FIPS 以降、または 13.1-37.282(FIPS/NDcPP)以降へ更新する。
- 9月の修正版(14.1-73.37、13.1-64.23)を適用済みでも、SAML構成の場合は再度の更新が必要。
- 暫定策:Citrixは 14.1-73.37〜73.40 および 13.1-64.23〜64.27 でGlobal Deny Listの仮想パッチシグネチャの利用を提案。
- Citrix管理のクラウドサービスはベンダー側で更新される。

**影響範囲:** NetScaler ADC/Gateway 14.1(14.1-73.41 未満)、13.1(13.1-64.28 未満)、ADC FIPS/NDcPP 13.1(13.1-37.282 未満)、NetScalerを使うSecure Private Access ハイブリッド環境。SAML SP/IdP構成の機器のみ該当。CISA KEV追加は2026-10-04(報道により日付に若干のずれあり)。Citrixブルテン CTX697174。

## 3. CVE-2026-104286 — Fortinet FortiMail のパストラバーサル(ゼロデイ)

**原理・根本原因:** FortiMailのIBE(Identity-Based Encryption)用Webパスにおけるパストラバーサルの欠陥により、認証されていないリモートの攻撃者が細工したHTTP(S)リクエストで基盤システム上に任意のファイルを書き込めます。これは永続化や乗っ取りに悪用され得ます。

**緩和策:**
- Fortinetの修正版(8.0.2、7.6.7、7.4.9)を入手可能になり次第適用する。全てが公開済みかは報道が食い違うため、アドバイザリ FG-IR-26-175 を確認。
- FortiMail 7.2 には修正がなく、修正対象ブランチへの移行が必要。
- 暫定策:IBEサービスの無効化、管理・Webメールへのアクセスを信頼できるネットワークに限定、必要に応じてWAFでIBEパスへのトラバーサル文字列を遮断。
- ログとFortinetのIOC(不審な送信元IP、予期しないrootのcronジョブ、不審なアカウント)を確認する。緩和しても侵害されていない証明にはならない。

**影響範囲:** FortiMail 8.0.0〜8.0.1、7.6.0〜7.6.6、7.4.0〜7.4.8、7.2.0〜7.2.9。Fortinetが開示し、2026-10-01にCISA KEV追加(連邦機関の期限 2026-10-04)。

## 4. CVE-2026-102489 / CVE-2026-102490 — Zammad のセッション固定と権限昇格

**原理・根本原因:** CVE-2026-102489 はセッション固定の問題で、報告によればアプリケーションのサービスユーザー権限でのコード実行につながり得ます。CVE-2026-102490 は不適切な権限管理により、そのユーザーからrootへのローカル権限昇格を許します。連鎖するとホスト全体の侵害に至ります。Zammad GmbHは開示内容の一部(影響バージョン、単独での悪用可能性、開示の進め方)に公に異議を唱えており、詳細は暫定的です。

**緩和策:**
- Zammad 7.x の最新版へ更新する(DIVDはバージョン7への更新、または公開システムの停止を推奨)。公式の修正版一覧はZammadのGitHubセキュリティアドバイザリを確認。
- ヘルプデスクのインターネット公開を制限し、セッション・認証情報をローテーションし、ホスト上の予期しないroot権限の変更を監査する。

**影響範囲(報告ベース、未検証):** CVE-2026-102489:Zammad 6.3.0〜6.5.x、CVE-2026-102490:1.5.0〜7.1.0-alpha と報告(ベンダーは7.0.0〜7.1.3は悪用不可と主張)。2026-10-02にCISA KEV追加(連邦機関の期限 2026-10-05)。

## 5. CVE-2026-76504 — Cisco Catalyst SD-WAN Manager のAPI認証バイパス

**原理・根本原因:** 特定のAPIエンドポイントの認証ルールが、認証されていないリモートの攻撃者が送る細工したHTTPリクエストによって回避され、管理者権限でのAPIアクセスが得られます。

**緩和策:**
- ブランチごとの最初の修正版へ更新:20.9.10.1、20.12.8.2、20.15.6.1、20.18.4.1、26.1.2.1、26.2.1。20.9より前はサポート終了のため移行が必要。
- 回避策はなし。信頼できないネットワークからManagerへのアクセスを制限する。
- パッチ適用で過去のアクセスは消えないため、ログ確認と侵害調査を行う。Cisco管理のクラウドは20.15.605で対応済み。

**影響範囲:** Catalyst SD-WAN Manager 26.2、26.1、20.18、20.15、20.12、20.9およびそれ以前(設定に依存せず該当)。CISA KEV追加は9月下旬(報道では2026-09-30、期限 2026-10-03)。今週も報道が継続。

## 6. CVE-2026-21858 — n8n の認証バイパス

**原理・根本原因:** ワークフロー自動化基盤n8nの認証バイパスで、VulnCheckが実環境での悪用を報告しています。具体的な仕組みと対象バージョンは今回の調査では確認できていません。

**緩和策:** プロジェクトのアドバイザリに従い最新版へ更新し、インスタンスを公開せず認証/VPNの背後に置く。露出の疑いがあればワークフローに保存された認証情報をローテーションする。

**影響範囲:** n8n(バージョンはベンダーのアドバイザリで要確認)。VulnCheckによる2026年10月初旬時点の状況。
