## 1. CVE-2026-85102・CVE-2026-93616 — Check Point Quantum Security Gateway / Management Server 連鎖型認証前RCE

**原理・根本原因:** CVE-2026-85102は、Security GatewayのVPN証明書処理における証明書信頼検証の不備で、未認証の攻撃者がVPN証明書の処理経路を通じてコード実行に到達できます。CVE-2026-93616は、Check Point Managementのウェブサービスにおける認証前パストラバーサルの欠陥です。ディレクトリトラバーサルと安全でないファイルアップロード処理が組み合わさることで、未認証の攻撃者が任意の場所からスクリプトを実行させ、任意のJavaクラスをロードさせることができます。いずれも、インターネットに公開されたゲートウェイや管理基盤に対して認証を完全に回避できる欠陥です。

**対応(緩和策):**
- 両CVEに対するCheck Pointのホットフィックスを直ちに適用する(サポート記事sk1000171を参照)。CVE-2026-85102の修正は2026-09-09にリリースされ、CVE-2026-93616のホットフィックスは悪用が確認された後に公開された。
- 管理インターフェースの露出を信頼できるネットワークに限定し、2026-07-23まで遡ってログを確認する(CVE-2026-93616は修正版が存在する前からゼロデイとして悪用されていた)。

**対象:** Security Gateway(CVE-2026-85102)、および Security Management Server、Multi-Domain Security Management Server、Log Server、Multi-Domain Log Server、SmartEvent(CVE-2026-93616)。対象バージョンはR82.20、R82.10 JHF Take 44、R82 Take 126、R81.20 Take 166以前(R80.x/R81系も対象)。Check Point Spark顧客への攻撃や、ピンポイントの標的型攻撃で悪用が確認されている。両CVEとも2026-09-22にCISA KEVへ追加され、連邦機関の対応期限は2026-09-25。

## 2. CVE-2026-93952 — Arista VeloCloud Orchestrator(VCO) 未認証での特権アクセス(CVSS 10.0)

**原理・根本原因:** オンプレミス版VeloCloud Orchestratorにおける入力検証不備の欠陥(CWE-20)により、ログイン資格情報を持たないリモートの攻撃者がVCOホスト上の特権的な内部機能に到達でき、オーケストレータおよびそれが管理するデータの機密性・完全性・可用性が侵害されます。この露出は、Edgeデバイスが事前共有鍵ではなく証明書(Certificate AcquireまたはCertificate Requiredモード)でOrchestratorに認証する構成に限定されます。

**対応(緩和策):**
- 5.2系および6.4系で提供された修正版へ直ちにアップグレードする。6.1系・7.0系向けの修正は2026-09-22時点でまだ提供されていないため、これらの系統についてはベンダー推奨の暫定緩和策を適用する。
- AristaのHosted版・Dedicated版VCOはベンダー側で既にパッチ済み。
- 証明書ベースのEdge認証を直ちに是正できない場合は、暫定措置として管理プレーンのネットワーク露出を制限する。

**対象:** 証明書ベースのEdge認証が構成されたオンプレミス版VeloCloud Orchestrator。外部からの報告により発見され、実悪用が確認された。2026-09-22に開示およびCISA KEVへ追加、連邦機関の対応期限は2026-09-25。本レポート作成時点で公開PoCは確認されていない。

## 3. CVE-2026-94127 — F5 BIG-IP APM ヒープバッファオーバーフローから未認証RCEへ

**原理・根本原因:** Traffic Management Microkernelのデータプレーン内にあるヒープバッファオーバーフロー(CWE-122)は、Access Policy Manager(APM)アクセスポリシーとOAuthプロファイルの両方が設定された仮想サーバーに対して、細工したトラフィックを送信することでトリガーされます。この欠陥は認証ロジックではなくパケット・トラフィック処理に存在するため、攻撃者は有効な資格情報を持たずにヒープメモリを破壊し、リモートコード実行を達成できます。影響を受けるのはデータプレーンのみ(コントロールプレーンは対象外)で、Appliance Mode構成も含まれます。

**対応(緩和策):**
- 影響を受けるBIG-IP APMブランチ向けのF5エンジニアリングホットフィックスを直ちに適用する。
- 直ちにホットフィックスを適用できない場合は、F5が公開しているiRuleを対象の仮想サーバーに暫定緩和策として適用する。

**対象:** 該当ホットフィックス未適用のBIG-IP APM 21.1.0、17.5.x、17.1.x系で、APMアクセスポリシーとOAuthプロファイルを組み合わせた仮想サーバー。実悪用が確認されており、上記のCheck Point・Aristaの項目とともに2026-09-22にCISA KEVへ追加。連邦機関の対応期限は2026-09-25。

## 4. CVE-2026-7273 — Zyxel GS1900シリーズスイッチ スタックバッファオーバーフロー(大規模侵害)

**原理・根本原因:** スイッチのWeb管理インターフェースを処理するCGIプログラムが、攻撃者が指定した入力に対して境界チェックを行っていません。そのため、未認証でLAN上に隣接する攻撃者が細工したHTTPリクエストを送信することで、スタックバッファをオーバーフローさせ、デバイス上で任意のOSコマンドを実行できます。

**対応(緩和策):**
- お使いのGS1900モデルに応じたパッチ済みファームウェアへ更新する(修正版は2026-06-16にリリース済み。例:GS1900-48HPv2 → 2.90(ABTQ.2)C0、GS1900-10HP → 2.90(AAZI.2)C0、GS1900-16 → 2.90(AAHJ.2)C0、GS1900-24 → 2.90(AAHL.2)C0)。
- 全デバイスの資格情報をローテーションする(この攻撃はハッシュ化されたroot権限の資格情報を窃取する)。また、管理インターフェースをインターネット・WANへ直接露出させないようにする。

**対象:** ファームウェア2.90(XXXX.1)C0以前を実行するZyxel GS1900シリーズスイッチ。中国語話者の脅威アクターと疑われる集団が2026-08-17以降この欠陥を悪用し、48か国で約1,000台のスイッチから設定・資格情報データを侵害・窃取した。2026-09-21にCISA KEVへ追加、連邦機関の対応期限は2026-09-24。

## 5. CVE-2026-32996 — Veeam Agent for Microsoft Windows ローカル権限昇格

**原理・根本原因:** Veeam Endpoint Backupサービスは、特権的なクライアント操作を処理するローカルgRPC名前付きパイプ(`\\.\pipe\Veeam\VAW\ServiceConnectionPipe`)を公開しています。このサービスは、クライアントが指定したセッションUIDに管理者レベルの昇格されたアイデンティティを関連付けますが、そのUIDを実際のリクエスト元プロセスやパイプ接続に安全に紐付けていません。そのため、権限の低いローカルユーザーが特権セッションになりすまし、NT AUTHORITY\SYSTEM権限でコマンドを実行できます。

**対応(緩和策):**
- Veeam Backup & Replicationをバージョン13.0.2.29以降へアップグレードする。これによりVeeam Agent for Windowsも修正を含むビルド13.0.3.1220へ更新される。

**対象:** Veeam Agent for Microsoft Windows 13.0.1.2067以前の13.x系ビルド。技術詳細とエクスプロイトコードが2026-09-14に一般公開され、以降、既に侵害された、あるいはマルチテナントのWindowsホスト上でのローカル権限昇格を狙った実悪用が確認されている。

## 6. CVE-2025-39964・CVE-2026-53266 — 実悪用が確認されたLinuxカーネルの欠陥

**原理・根本原因:** CVE-2025-39964は、カーネルのAF_ALG暗号ソケットインターフェースにおける競合状態です。ソケットへの並行書き込みによりソケットごとの状態が破損し、システムクラッシュや暗号処理結果の密かな改変につながる可能性があります。CVE-2026-53266は、カーネルの`ebtables` SNAT(送信元NAT)実装における境界外書き込みです。ARPアドレスの書き換えにより、書き込み可能かどうかを事前に確認しないまま、共有されたファイルバックのメモリページが変更される可能性があり、権限昇格やサービス拒否に悪用され得るメモリ破損です。

**対応(緩和策):**
- これらの修正を含むディストリビューションのカーネル更新を、提供され次第適用する。Red Hatをはじめとする各社が実悪用を確認しているため、信頼できないローカルユーザーが存在する、あるいは暗号処理・netfilter機能が露出しているシステムを優先する。

**対象:** 主要ディストリビューションにおける、修正版より前のLinuxカーネルバージョン。2026-09-18にCISA KEVへ追加、連邦機関の対応期限は2026-09-21(本レポート作成時点で既に経過)。

## 7. CVE-2026-58704 — Google Pixel セルラーモデム ゼロクリック権限昇格

**原理・根本原因:** Pixelのセルラーモデムコンポーネントにおけるロジックエラーにより、権限チェックが回避されます。これにより、近接(隣接)する攻撃者が追加の実行権限を必要とせず、かつユーザー操作も一切必要とせずにデバイス上で権限を昇格できます。モデム・ベースバンドレベルでのゼロクリック攻撃です。

**対応(緩和策):**
- 2026-09-15に提供されたPixelセキュリティアップデートを適用する。アップデートの適用以外にユーザー操作は不要。

**対象:** 2026年9月のセキュリティアップデート以前の、脆弱なモデムコンポーネントを搭載したGoogle Pixelデバイス。Googleは「限定的な標的型の悪用」を報告しており、商用スパイウェアや国家支援型の攻撃手法と整合する特徴を示している。CISAはこの欠陥をKEVカタログへ追加し、連邦機関に3日間の対応期限を設定した。

## 8. CVE-2026-86059 — 認可チェック欠如によるDokployの資格情報・シークレット漏えい

**原理・根本原因:** 「保護された」複数のtRPCプロシージャ(`github.one`、`gitlab.one`、`gitea.one`、`bitbucket.one`)が、`getAccessibleGitProviderIds`によるスコープ制限や組織メンバーシップの検証を適用せずに、平文の資格情報を含むGitプロバイダのレコード全体を返却します。そのため、Gitプロバイダへのアクセス権を持たない組織メンバーであっても、認証済みであれば他のプロバイダのシークレットを取得できます。さらに、`application.one`ルートは、プライベートキー・OAuthトークン・クライアントシークレット・アプリパスワードを含むネストされたプロバイダ関連情報を返却するため、アプリケーションの読み取り権限しか持たないメンバーが、本来意図されたプロバイダ割り当て制限を回避できます。

**対応(緩和策):**
- 両方の認可欠如の経路を修正したDokploy 0.29.13以降へアップグレードする。
- 影響を受けるDokployインスタンスに保存されているGitプロバイダの資格情報(OAuthトークン、クライアントシークレット、アプリパスワード、プライベートキー)をローテーションする。過剰な権限を持つ組織メンバーに既に露出していた可能性があるため。

**対象:** 0.29.13より前のDokploy PaaS導入環境。2026-09-22にGitHub Security Advisoryを通じて公開開示。本レポート作成時点で公開されたエクスプロイトコードや実悪用は確認されていないが、接続されたソースコード・CI/CDシステムの資格情報が直接露出する欠陥である点に注意が必要。

## 9. CVE-2026-81963・CVE-2026-85880 — Windows Update Stack / ALPC ローカル権限昇格(継続情報:本日が連邦機関対応期限)

**原理・根本原因:** CVE-2026-81963はWindows Update Stackにおける権限昇格の欠陥、CVE-2026-85880はWindows Advanced Local Procedure Call(ALPC)サブシステムにおけるヒープバッファオーバーフローです。いずれも、権限の低いローカル攻撃者がユーザー操作なしにSYSTEM権限まで昇格できるもので、両方ともMicrosoftの修正版が提供される前から実際に悪用されていたことが確認されています。

**対応(緩和策):** 未適用であれば、2026-09-08にリリースされたMicrosoftの2026年9月の累積更新プログラムを適用する。

**対象:** CVE-2026-81963は現行のWindows 11リリースおよびWindows Server 2025に、CVE-2026-85880はより古いWindows 10・Windows Server系統に影響する。Microsoft史上最大規模となった約970件のCVEを含む9月のPatch Tuesdayの一部。両方とも2026-09-08にCISA KEVへ追加され、連邦機関の対応期限は本日2026-09-22。初回開示は今週の対象期間より前だが、この理由から本レポートに含めている。

## 11. CVE-2026-78006・CVE-2026-78159 — The Events Calendar(WordPressプラグイン) 未認証での乗っ取り連鎖

**原理・根本原因:** プラグインのウィジェットレンダリング機能における2つの独立した脆弱性連鎖により、ログイン・登録・ユーザー操作を一切必要としない未認証の訪問者が、リモートコード実行や管理者アカウントの乗っ取りにつながるコードパスへ到達できます。そこからマルウェアの展開、サイト改ざん、データ窃取、サーバー侵害へと発展する可能性があります。

**対応(緩和策):**
- 両方の連鎖に対する修正を含むThe Events Calendarバージョン6.17.4.1以降へ更新する。
- 未更新のサイト向けに、Wordfence無料版のファイアウォールルールによる対応が2026-09-21より展開開始されている。

**対象:** The Events Calendar WordPressプラグイン、バージョン6.17.4.1未満(有効インストール数60万以上)。脆弱性は2026-08-21・22にベンダーへ報告され、2026-08-24に確認、その後まもなくパッチが提供された。本レポート作成時点で実悪用は確認されていないが、認証前に悪用可能な連鎖である点から、速やかなパッチ適用が重要。
