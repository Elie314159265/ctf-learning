## 1. CVE-2026-104935 — Ivanti Connect Secure Zero-Day

**Principle / root cause:** A vulnerability in the Connect Secure VPN appliance that attackers have chained with two other flaws (including a privilege-escalation issue) to compromise appliances. Reporting says it was partially fixed in 25.1.3.0 (July 2026) and then backported to other supported branches while exploitation was already occurring.

**Mitigation:**
- Upgrade to a fixed build (reported: 22.8R2.5, 25.1.1.2, 25.1.3.0, 25.1.3.1 or later).
- Run Ivanti's Integrity Checker Tool and hunt for compromise, since exploitation reportedly began 2026-10-03 (found by Volexity).
- A separate privilege-escalation flaw in the chain is reported as still unpatched; follow Ivanti's guidance and apply the fix when released.

**Affected:** Ivanti Connect Secure. Version lists conflict between sources (CVE record: versions before 25.1.3.0; other reports: 22.8R2.4 and earlier, 25.1.2.2 and earlier, 25.1.1.1 and earlier). Check Ivanti's advisory.
**Disclosure date:** 2026-10-13 (CISA KEV same day).

## 2. CVE-2026-96951 — Windows Shell Security Feature Bypass (Mark of the Web)

**Principle / root cause:** Windows Shell mishandles certain crafted files so that Mark of the Web protections (download warnings, Protected View, SmartScreen-style blocking) are not applied. A user opening a malicious file delivered via email, chat, collaboration tools or download loses those safeguards. Reported as the third exploited Windows Shell flaw this year, and possibly related to an incomplete earlier fix.

**Mitigation:**
- Apply the October 2026 Microsoft security updates to all Windows endpoints/servers.
- Train users to treat unexpected files cautiously; filter risky attachment types at email/web gateways.
- CISA's federal remediation deadline was 2026-10-16.

**Affected:** Supported Windows versions (see Microsoft's Security Update Guide for exact builds).
**Disclosure date:** 2026-10-13 (Patch Tuesday; the release was reported as unusually large, 1,400+ CVEs).

## 3. CVE-2026-110447 — Nextcloud "Collabora Online – Built-in CODE Server" Command Injection

**Principle / root cause:** The app's proxy script launches the local document server when none is listening. Improper handling of request input in that path allows unauthenticated command injection, but only while the local server is down (restart, upgrade, crash). Attackers have used it to drop PHP web shells.

**Mitigation:**
- Update the app (richdocumentscode) to 26.4.303 or later, or remove it. Merely disabling the app does not close the hole.
- Check for unexpected PHP files and run Nextcloud's integrity check; rotate credentials if compromise is suspected.

**Affected:** Collabora Online – Built-in CODE Server app, all versions before 26.4.303.
**Disclosure date:** Advisory/CVE 2026-10-14; fix released 2026-09-11; earliest observed attack reported 2026-09-10.

## 5. MariaDB Server — Multiple Critical Flaws (unconfirmed)

**Reported:** Roundups list CVE-2026-85748, CVE-2026-92262 and CVE-2026-85746 at CVSS 9.9 (authenticated, network-reachable, scope-changed). A scanner plugin ties CVE-2026-85748 to MariaDB 12.3.0–12.3.2 and 13.0.0–13.0.1 (fixed 12.3.3 / 13.0.2), but the root cause and the other IDs could not be verified. No exploitation reported.

**Mitigation:** Upgrade to the latest MariaDB maintenance release or distribution-patched packages; restrict network access to database ports and limit privileges.
