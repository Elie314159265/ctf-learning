## 1. CVE-2026-105133 & CVE-2026-105134 — AhsayCBS Authentication Bypass and OS Command Injection

**Principle / root cause:** CVE-2026-105133 is an improper-authentication flaw in a system-password check function of the API component: a request parameter is not handled safely, so the check can be bypassed remotely. CVE-2026-105134 is an OS command injection in the Replication Receiver API, where untrusted input reaches a system command without sufficient sanitization, leading to remote code execution. Threat actors are reported to use these to deploy web shells and a cryptominer.

**Mitigation:**
- Upgrade AhsayCBS to 10.3.4 or later.
- Until patched, restrict network access to the management, API and replication endpoints (do not expose them to the internet).
- Hunt for unexpected web shells, new processes and cryptominer activity on hosts that were exposed.

**Affected:** AhsayCBS up to and including 10.3.2 (one source narrows this to 10.3.0–10.3.2; unverified). Severity sources disagree: CVE-2026-105133 is 6.9–7.3; CVE-2026-105134 is CVSS v4 9.3. Exploitation observed starting 2026-10-07 (Huntress); disclosed in the days prior.

## 2. CVE-2026-88779 — Citrix NetScaler ADC / Gateway SAML Memory-Bounds Flaw (DoS)

**Principle / root cause:** An improper restriction of operations within the bounds of a memory buffer, reachable when the appliance is configured as a SAML service provider or SAML identity provider. Exploitation crashes the appliance (denial of service) rather than giving code execution. It follows the late-September NetScaler zero-days (CVE-2026-88771 / CVE-2026-88772).

**Mitigation:**
- Upgrade to 14.1-73.41 or later, 13.1-64.28 or later, 14.1-73.41 FIPS or later, or 13.1-37.282 (FIPS/NDcPP) or later.
- Organizations that already installed the September fixes (14.1-73.37, 13.1-64.23) must upgrade again if SAML is configured.
- Interim: Citrix suggests Global Deny List virtual-patching signatures on 14.1-73.37–73.40 and 13.1-64.23–64.27.
- Citrix-managed cloud services are updated by the provider.

**Affected:** NetScaler ADC and Gateway 14.1 before 14.1-73.41; 13.1 before 13.1-64.28; ADC FIPS/NDcPP 13.1 before 13.1-37.282; Secure Private Access hybrid deployments using NetScaler. Only appliances configured for SAML SP/IdP are exposed. Added to CISA KEV 2026-10-04 (reported dates vary slightly); Citrix bulletin CTX697174.

## 3. CVE-2026-104286 — Fortinet FortiMail Path Traversal (Zero-Day)

**Principle / root cause:** A path traversal weakness in the FortiMail Identity-Based Encryption (IBE) web path lets an unauthenticated remote attacker write arbitrary files on the underlying system through crafted HTTP(S) requests, which can be leveraged for persistence and takeover.

**Mitigation:**
- Apply Fortinet's fixed releases (8.0.2, 7.6.7, 7.4.9) as soon as they are available; reports conflict on whether all are released yet — check advisory FG-IR-26-175.
- FortiMail 7.2 has no fix; migrate to a fixed branch.
- Interim: disable the IBE service, restrict management/webmail access to trusted networks, and optionally filter traversal sequences in requests to the IBE path with a WAF.
- Review logs and Fortinet's indicators of compromise (suspicious source IPs, unexpected root cron jobs, unexpected accounts); mitigation does not prove a device is clean.

**Affected:** FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9. Disclosed by Fortinet and added to CISA KEV on 2026-10-01 (federal due date 2026-10-04).

## 4. CVE-2026-102489 & CVE-2026-102490 — Zammad Session Fixation and Privilege Escalation

**Principle / root cause:** CVE-2026-102489 is a session fixation flaw that, according to reports, can lead to code execution as the application's service user; CVE-2026-102490 is an improper privilege management issue allowing local escalation from that user to root. Chained, they enable full host compromise. Zammad GmbH publicly disputes parts of the disclosure (affected versions, standalone exploitability, handling), so details are provisional.

**Mitigation:**
- Upgrade to the latest Zammad 7.x release (DIVD recommends version 7 or taking exposed systems offline); watch Zammad's GitHub security advisories for the official fixed-version list.
- Restrict internet exposure of the helpdesk, rotate sessions/credentials, and audit hosts for unexpected root-level changes.

**Affected (reported, unverified):** CVE-2026-102489: Zammad 6.3.0–6.5.x; CVE-2026-102490: reported 1.5.0 up to 7.1.0-alpha (vendor says 7.0.0–7.1.3 not exploitable). Added to CISA KEV 2026-10-02 (federal due date 2026-10-05).

## 5. CVE-2026-76504 — Cisco Catalyst SD-WAN Manager API Authentication Bypass

**Principle / root cause:** An authentication rule for a specific API endpoint can be bypassed by an unauthenticated remote attacker sending a crafted HTTP request, yielding administrative API access.

**Mitigation:**
- Upgrade to the first fixed release for your branch: 20.9.10.1, 20.12.8.2, 20.15.6.1, 20.18.4.1, 26.1.2.1, or 26.2.1. Releases earlier than 20.9 are out of maintenance and must migrate.
- No workaround exists; restrict access to the Manager from untrusted networks.
- Patching does not remove prior access — review logs and audit for compromise. Cisco-managed cloud was fixed in 20.15.605.

**Affected:** Catalyst SD-WAN Manager 26.2, 26.1, 20.18, 20.15, 20.12, 20.9 and earlier, regardless of configuration. Added to CISA KEV in late September (reported 2026-09-30, due 2026-10-03); coverage continued into this week.

## 6. CVE-2026-21858 — n8n Authentication Bypass

**Principle / root cause:** An authentication bypass in the n8n workflow-automation platform; VulnCheck reports in-the-wild exploitation. Exact mechanism and versions were not confirmed in this run.

**Mitigation:** Update n8n to the latest release per the project's advisory, keep instances off the public internet or behind authentication/VPN, and rotate credentials stored in workflows if exposure is suspected.

**Affected:** n8n (versions to be confirmed against the vendor advisory). Status per VulnCheck, early October 2026.
