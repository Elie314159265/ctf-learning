## 1. CVE-2026-102255 — SonicWall SMA1000 pre-auth SSRF (CVSS 10.0)

**Principle / root cause:** A server-side request forgery in the Appliance WorkPlace web interface lets an unauthenticated remote party make the appliance issue requests on its behalf and reach internal-only functionality. The same release fixes three other flaws, including CVE-2026-102256, a post-authentication OS command injection.

**Mitigation:** Upgrade to 12.4.3-03670 or later, or 12.5.0-03082 or later. Limit internet exposure of management and WorkPlace interfaces. Recall that SMA1000 products were chained and exploited earlier (CVE-2026-83548/83549 in September; CVE-2026-15409/15410 in July), so patch promptly.

**Affected:** SMA 6210, 7210 and 8200v running 12.4.3-03526 and older, or 12.5.0-02952 and older.

**Disclosed:** 2026-10-06. SonicWall states no evidence of exploitation of this release's flaws.

## 2. CVE-2026-21589 — Atlassian Data Center unauthenticated arbitrary file read

**Principle / root cause:** An unauthenticated file-read weakness in self-managed Atlassian products allows reading files from the server if the file's exact name and path are known. A public technical write-up (watchTowr) was followed within hours by exploitation attempts; reported volume is mostly reconnaissance (sources cite 15 attempts/3 IPs up to 158 attempts/26 IPs by 2026-10-07).

**Mitigation:** Apply Atlassian's fixed releases for your product; restrict access to self-managed instances from the internet (VPN/allowlist); review logs for unusual file-access requests; rotate any credentials/secrets stored in readable config files if exposure is suspected.

**Affected:** Bitbucket, Confluence, Jira Service Management, Jira Software, Bamboo and Crowd Data Center, plus Crucible and Fisheye (reported as all versions prior to the fix).

**Disclosed:** around 2026-10-06/07.

## 3. Citrix NetScaler ADC / Gateway — CVE-2026-88779 (new), plus CVE-2026-88771 / -88772 / -107406

**Principle / root cause:**
- CVE-2026-88779 (CVSS 8.7): memory-buffer overflow that can cause denial of service on appliances configured as a SAML Service Provider or Identity Provider. Added to CISA KEV on 2026-10-04.
- CVE-2026-88771: improper input validation leading to unauthenticated command execution; CVE-2026-88772: memory overflow leading to RCE/DoS when DTLS is enabled. Both (CVSS v4 9.5) were exploited as zero-days; Citrix published fixes 2026-09-27.
- CVE-2026-107406: reported as a critical NetScaler RCE/DoS issue; CISA's alert was updated 2026-10-09 to include it. Exploitation not confirmed; details unverified.

**Mitigation:** Upgrade to NetScaler 14.1-73.37 or later, or 13.1-64.23 or later (FIPS/NDcPP builds have separate minimum builds — check Citrix's bulletin). Hunt for compromise on unpatched appliances before and after patching.

**Affected:** NetScaler ADC and Gateway 14.1 before 14.1-73.37; 13.1 before 13.1-64.23; certain FIPS/NDcPP builds.

**Disclosed:** fixes 2026-09-27; CVE-2026-88779 KEV 2026-10-04.

## 4. Zammad — CVE-2026-102489 / CVE-2026-102490

**Principle / root cause:** CVE-2026-102489 (critical) is a session-handling weakness (session fixation / session-cookie leakage) that could lead to account takeover and potentially code execution; a public PoC is reported to exist. CVE-2026-102490 is an improper privilege management flaw (local privilege escalation) with confirmed exploitation. Both were added to CISA KEV on 2026-10-02.

**Mitigation:** Upgrade Zammad to the latest patched release per the vendor advisory; invalidate active sessions after patching; restrict host access.

**Affected:** Zammad (self-hosted); exact version ranges not verified — see vendor advisory.

**Disclosed:** KEV addition 2026-10-02.

## 5. CVE-2026-104286 — Fortinet FortiMail path traversal (exploited zero-day)

**Principle / root cause:** Path traversal in the HTTP/HTTPS handling lets an unauthenticated remote attacker write arbitrary files to the underlying system, which can lead to compromise of the mail gateway.

**Mitigation:** Fixed releases (8.0.2, 7.6.7, 7.4.9 or later) were reported as upcoming in some sources and released in others — check Fortinet advisory FG-IR-26-175. Until patched: remove public access to management interfaces, disable IBE support as per Fortinet workarounds, and review systems against Fortinet's published indicators of compromise.

**Affected:** FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8 (one source also lists 7.2.x).

**Disclosed:** 2026-10-01; CISA KEV with federal due date 2026-10-04.

## 6. AhsayCBS — CVE-2026-105133 / CVE-2026-105134

**Principle / root cause:** Authentication bypass and unauthenticated OS command injection (CVE-2026-105134 reported CVSS 10.0) in the backup management platform. Attackers are reported to use them to install web shells and cryptominers.

**Mitigation:** Update to AhsayCBS 10.3.4 or later; restrict internet exposure of the console; hunt for web shells and unexpected miner processes.

**Affected:** AhsayCBS 10.3.0–10.3.2 reported (verify).

**Disclosed:** early October 2026 (Huntress reporting).

## 7. CVE-2026-76504 — Cisco Catalyst SD-WAN Manager authentication bypass (carry-over)

**Principle / root cause:** A URI-encoding handling flaw (CWE-177) lets a crafted request bypass the authentication rule on a specific API endpoint, granting admin-level API access. Exploited since September; CISA KEV 2026-09-30.

**Mitigation:** No workaround. Upgrade to 20.9.10.1, 20.12.8.2, 20.15.6.1, 20.18.4.1, 26.1.2.1 or 26.2.1 (releases before 20.9 must migrate). Treat Managers reachable from untrusted networks in September as potentially compromised: review logs, audit accounts and rotate credentials.

**Affected:** All deployments regardless of configuration.

**Disclosed:** September 2026 (KEV 2026-09-30).
