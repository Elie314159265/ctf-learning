## Most recent / highest priority (last 24–72 hours)

## 1. CVE-2026-90436 — Apache Axis 1.x SOAP Fault Deserialization RCE (Confluence Data Center, N-able N-central)

**Principle / root cause:** Apache Axis 1.x, a long-unsupported SOAP engine, deserializes data contained in inbound SOAP *fault* messages without adequately restricting what object types may be instantiated (CWE-502, deserialization of untrusted data). Because Axis is embedded in other products, any product exposing an Axis-backed SOAP endpoint to untrusted clients inherits an unauthenticated remote code execution path. The CVE was assigned with an "UNSUPPORTED WHEN ASSIGNED" tag: the Axis 1.x line is end-of-life.

**Mitigation:**
- **Confluence Data Center:** upgrade to **9.2.28** or to **10.x** (which removed the feature). If patching must wait, disable the *Remote API (XML-RPC & SOAP)* setting in the administration console — only instances with this setting enabled are affected.
- **N-able N-central:** follow N-able's advisory; reporting indicates exploitation involves servers with *Legacy API* mode enabled, so disable Legacy API where possible and restrict network exposure of the N-central server.
- **Any other software embedding Axis 1.x:** there is **no fixed 1.x release**. Migrate to a supported SOAP stack (e.g. Axis2) or rebuild with the upstream fix commit; otherwise remove the SOAP endpoint from untrusted networks.
- Hunt for unexpected child processes of the Confluence/N-central Java process and new web-shell-like files.

**Affected:** Apache Axis 1.x through 1.4; Atlassian Confluence Data Center 1.x–9.x with Remote API enabled (fixed 9.2.28; 10.x and Cloud unaffected); N-able N-central (bundles Axis). Rapid7 observed exploitation against a Confluence customer on **2026-11-13** and reports N-central has also been exploited.

**Disclosure date:** Atlassian advisory and Apache disclosure during the week of 2026-11-09; in-the-wild exploitation confirmed 2026-11-13 → reported publicly 2026-11-14/16.

## 2. CVE-2026-123039 — Check Point Gaia DynamicCLI Missing Authorization (chained with PHP2Shell)

**Principle / root cause:** The DynamicCLI inter-process communication (IPC) interface on Check Point Gaia OS does not verify that the calling process is authorized to request privileged operations (missing authorization, CWE-862). A process running with low privileges on the appliance can therefore have actions carried out as root. On its own this is a local privilege escalation (CVSS 7.8), but attackers chained it with the **PHP2Shell** flaws (CVE-2026-109618 / CVE-2026-109619, CVSS 4.0 9.2) in the PHP runtime bundled with Check Point web-facing features (Mobile Access Portal, SSL Network Extender, etc.) to go from unauthenticated network access to root. Check Point Research reported post-exploitation use of web shells, the "TSGA" backdoor, and a destructive wiper aimed at VMware ESXi hosts.

**Mitigation:**
- Install the **November 2026 Jumbo Hotfix** for your Gaia version (covers both PHP2Shell and CVE-2026-123039; see SK1000302 and Check Point advisories CPAI-2026-15172 / CPAI-2026-15184).
- Temporary workaround per Check Point: stop the `dynamic_server` process and prevent it from restarting until the hotfix is applied.
- Restrict exposure of Mobile Access / portal interfaces; review gateways for web shells and unknown persistent processes; check ESXi hosts reachable from gateways.
- CISA's federal remediation deadline is **2026-11-16 (today)**.

**Affected:** Check Point Security Gateways running Gaia OS with the vulnerable DynamicCLI component; PHP2Shell exposure applies where Mobile Access Portal, Remote Access VPN with SSL Network Extender, Captive Portal / UserCheck or similar web features are enabled. Check Point says roughly two dozen customers were attacked.

**Disclosure date:** Added to CISA KEV on 2026-11-13 (PHP2Shell first disclosed ~2026-10-23).

## 3. CVE-2026-114713 — UnrealIRCd labeled-response Delimiter Injection

**Principle / root cause:** The `labeled-response` module, which echoes the IRCv3 `label` message tag back in replies, does not escape delimiter characters in that tag (CWE-140, improper neutralization of delimiters). On a network with two or more linked servers, an ordinary user can cause content they control to be interpreted as server-to-server protocol commands, which are trusted with server/IRC-operator authority — allowing actions such as forced disconnects (KILL) and network bans (GLINE). The project calls it the most severe defect ever found in UnrealIRCd.

**Mitigation:**
- Upgrade to **UnrealIRCd 6.2.7.1** (released 2026-11-07) or apply the official hot-patch.
- If you cannot patch immediately, apply the project's published spamfilter workaround as a stopgap.
- UnrealIRCd 5 is reported as similarly affected and is end-of-life — migrate.

**Affected:** UnrealIRCd 6.0.0 up to (but not including) 6.2.7.1; UnrealIRCd 5.x (EOL). Exploited starting one day after public disclosure.

**Disclosure date:** 2026-11-07 (fix release); added to CISA KEV 2026-11-13 with a deadline of 2026-11-16.

## 4. CVE-2026-116606 & CVE-2026-111560 — Barracuda Email Security Gateway Pre-Auth Root Chain

**Principle / root cause:** CVE-2026-116606 is an authentication bypass in the ESG configuration-backup restore function: an unauthenticated party can restore a crafted configuration and overwrite global settings, effectively gaining administrative control (CVSS 4.0 9.3; some agencies rate 9.8). CVE-2026-111560 is an OS command injection (CWE-78) in administrative code shared across several Barracuda appliance product lines, letting an administrator-level user run commands as root. Chained, they give an unauthenticated attacker root on the appliance.

**Mitigation:**
- Upgrade ESG to **9.4.0.030 or later** (fixes both).
- Apply corresponding updates for other Barracuda products that share the CVE-2026-111560 code (Load Balancer ADC, Web Application Firewall, Message Archiver).
- Do not expose administrative interfaces to the internet; review appliances for unexpected configuration changes and persistence.

**Affected:** Barracuda Email Security Gateway prior to 9.4.0.030 (both CVEs); Barracuda Load Balancer ADC, WAF, and Message Archiver (CVE-2026-111560). Barracuda confirmed exploitation against a small number of organizations on 2026-11-09; CISA KEV 2026-11-10; Singapore CSA issued an active-exploitation alert on **2026-11-16**.

**Disclosure date:** Early November 2026 (advisory predates 2026-11-03); exploitation confirmed 2026-11-09.

## Other notable items this week

## 5. CVE-2026-124194 — Microsoft Outlook Spoofing / NTLM Hash Disclosure (Zero-Day)

**Principle / root cause:** Classic Outlook for Windows can be induced, by a crafted message, to initiate an outbound authentication attempt to an attacker-controlled resource, leaking the user's Net-NTLM hash. The stolen hash can be cracked offline or relayed to other services. Microsoft classifies it as spoofing (CVSS 6.5) and confirmed exploitation before the patch.

**Mitigation:**
- Apply the November 10, 2026 Office updates (e.g. LTSC 2021 build 16.0.14334.21048, LTSC 2024 build 16.0.17932.21140, Microsoft 365 Apps Current Channel 2610 build 20527.20196 or later; confirm against Microsoft's build table).
- Block outbound SMB (TCP 445) to the internet; add high-value users to the *Protected Users* group; enforce SMB signing / EPA and consider restricting outbound NTLM.

**Affected:** Classic Outlook for Windows in Microsoft 365 Apps for Enterprise, Office LTSC 2021, Office LTSC 2024 (32/64-bit). New Outlook, Outlook on the web, Mac and mobile are not listed.

**Disclosure date:** 2026-11-10 (Patch Tuesday). The same Patch Tuesday fixed ~1,100+ CVEs including ~63–64 critical (Exchange Server, Windows LDAP RCE, etc.); prioritise Exchange and LDAP-exposed systems.

## 6. CVE-2026-125350 — Google Chrome XML Use-After-Free (Zero-Day)

**Principle / root cause:** A use-after-free (CWE-416) in Chrome's XML handling: an object is freed while a pointer to it remains in use, so a crafted web page can cause the renderer to operate on freed memory, potentially leading to code execution inside the renderer sandbox. Google states it is exploited in the wild — the eighth exploited Chrome zero-day of 2026. A second XML use-after-free (CVE-2026-125346) was fixed in the same release.

**Mitigation:** Update Chrome to **157.0.8103.50/.51** or later and restart the browser; update Chromium-based browsers (Edge, Brave, Opera, Vivaldi) as their vendors ship the fix.

**Affected:** Google Chrome on Windows, macOS, Linux prior to 157.0.8103.50; Chromium-based browsers until patched.

**Disclosure date:** Fix released 2026-11-09; CISA KEV 2026-11-10 (federal deadline 2026-11-24).

## 7. CVE-2026-119618 — Apache HTTP Server mod_http2 Heap Corruption

**Principle / root cause:** A memory-safety error in mod_http2's header-assignment logic allows malformed HTTP/2 header data from a client to corrupt heap memory, which may lead to remote code execution in the server worker process. The 2.4.71 release also fixes CVE-2026-106023 (important, mod_md / ACME certificate module) and CVE-2026-109163 (low, one-byte stack overwrite in mod_vhost_alias).

**Mitigation:** Upgrade to **Apache HTTP Server 2.4.71** (or your distribution's backport). If you cannot upgrade immediately, disable HTTP/2 (remove `h2`/`h2c` from `Protocols`) on exposed virtual hosts.

**Affected:** Apache httpd 2.4.69–2.4.70 per the official Apache security page (some secondary reports cite 2.4.55–2.4.70; treat the wider range as unconfirmed but check older builds with HTTP/2 enabled).

**Disclosure date:** 2026-11-11. No known exploitation.

## 8. SAP November Patch Day — ICM2SHELL (CVE-2026-76964 / CVE-2026-89126), PROXYGATE (CVE-2026-89103), CVE-2026-120017

**Principle / root cause:** ICM2SHELL is a single defect in SAP kernel code that reassembles fragmented WebSocket messages in the Internet Communication Manager (ICM) and SAP Web Dispatcher: invalid length fields in crafted requests can cause heap out-of-bounds writes, allowing unauthenticated remote code execution. PROXYGATE (CVE-2026-89103) is a pre-authentication RCE in SAP Gateway. CVE-2026-120017 is a CVSS 10.0 flaw affecting systems configured for SAML single sign-on.

**Mitigation:** Apply the SAP Security Notes from the 2026-11-10 patch day (kernel updates for ICM / Web Dispatcher; Gateway and SAML notes). Restrict internet exposure of Web Dispatcher/ICM and Gateway ports until patched.

**Affected:** SAP NetWeaver AS ABAP (ICM), SAP Web Dispatcher, SAP Gateway, SAML-SSO-configured systems — kernel versions vary per note.

**Disclosure date:** 2026-11-10. Not known to be exploited (a separate SAP Commerce Cloud CVSS 10 flaw was reported exploited shortly after patch day).

## 9. CVE-2026-20320 (Cisco BroadWorks) & CVE-2026-111793 (Openwave Webtop)

**Principle / root cause:** Cisco BroadWorks contains an unauthenticated, out-of-band blind XML External Entity (XXE) injection: the XML parser resolves external entities in untrusted input, letting a remote attacker exfiltrate sensitive configuration data. Openwave Webtop Media Transcoder has an "incorrect resource transfer between spheres" flaw allowing an authenticated user to have unintended document types processed by bypassing the webmail front end.

**Mitigation:** Cisco BroadWorks — upgrade Application Delivery Platform and related components to **RI.2026.07** or later. Openwave Webtop — update Media Transcoder to **1.1.22.0** or later per vendor guidance.

**Affected:** Cisco BroadWorks before RI.2026.07 (originally disclosed 2026-08-19); Openwave Webtop Media Transcoder before 1.1.22.0.

**Disclosure date:** Added to CISA KEV 2026-11-10 (deadline 2026-11-24).

## 10. CVE-2026-123158 — OpenSSH "sshole" Password Authentication Bypass on musl libc

**Principle / root cause:** On Linux systems built with musl libc and without PAM (typical of Alpine Linux), sshd lacked a workaround for a libc behaviour difference in password-hash handling; with certain combinations of account password fields, password authentication can succeed without the correct password. Exposure requires password authentication to be enabled. First exploitation attempts arrived under nine hours after publication, with root access confirmed on a honeypot.

**Mitigation:** Upgrade to **OpenSSH 10.6p2** or your distribution's backport (Alpine: edge 10.6_p2-r0, 3.24 10.3_p1-r2, 3.23 10.2_p1-r1, 3.22 10.0_p1-r11, 3.21 9.9_p2-r1, plus 3.16–3.20 backports — check the package release, not the version banner). **Restart sshd** after upgrading. Disable password authentication in favour of keys where possible, and review accounts with locked/empty password fields.

**Affected:** OpenSSH before 10.6p2 on musl-based Linux without PAM (Alpine Linux and Alpine-based containers primarily). glibc+PAM distributions are generally not affected.

**Disclosure date:** 2026-11-05; CISA KEV 2026-11-09.

## 11. CISA KEV 2026-11-09 batch — GPUStack, FreeSWITCH, IBM Aspera Faspex

- **CVE-2026-102895 — GPUStack authentication bypass (9.8).** The server trusts requests appearing to come from loopback; behind a reverse proxy (TCP peer is local) or via a client-supplied real-IP header, remote requests are treated as local and granted admin. **Fix:** upgrade to 2.2.0+ (2.2.2 recommended by some sources); do not let clients set the real-IP header. Exploitation seen against 2.1.1.
- **CVE-2026-116779 — SignalWire FreeSWITCH code injection (9.8).** Content in SIP MESSAGE requests can reach FreeSWITCH API command handling, allowing remote execution of API commands. **Fix:** upgrade to 1.11.3+; restrict SIP exposure and MESSAGE handling.
- **CVE-2026-123218 — IBM Aspera Faspex incorrect authorization (9.8).** Authorization checks are missing on certain operations. **Fix:** Faspex 5.0.19 PL1 or later (confirm with IBM bulletin). Affects 5.0.0–5.0.19.

**Disclosure date:** All added to CISA KEV 2026-11-09 (deadline 2026-11-12).
