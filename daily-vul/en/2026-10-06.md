## 🔴 Newest / Highest Priority

### 1. Fortinet FortiMail — CVE-2026-104286 (CVSS 9.8, exploited in the wild / CISA KEV)
- **Disclosure date:** 2026-10-01 (Fortinet advisory FG-IR-26-175)
- **Principle / root cause:** Improper path handling (path traversal combined with improper neutralization of NULL bytes) in an HTTP/HTTPS-reachable component. An unauthenticated remote party can cause files to be written to arbitrary locations on the appliance, which can lead to takeover of the mail gateway.
- **Affected:** FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9.
- **Fixes:** At disclosure, no fixed builds were released. Fortinet lists 7.4.9, 7.6.7 and 8.0.2 as upcoming fixed releases. 7.2 users should migrate to 7.4 or later.
- **Mitigation:** Disable the IBE (Identity-Based Encryption) feature via CLI; do not expose the management/web interfaces to the internet; restrict access by ACL/VPN; review the appliance for unexpected files and unusual admin activity; upgrade as soon as fixed builds ship.

### 2. Citrix NetScaler ADC / Gateway — SAML-related memory flaw (reported as CVE-2026-88779, CVSS 8.7; exploited / CISA KEV) — ⚠ identifier unverified
- **Disclosure date:** ~2026-10-04 (per secondary reporting). My searches returned conflicting identifiers for NetScaler SAML issues (e.g. CVE-2026-3055, CVE-2026-8451/8452 from earlier in 2026), so verify the CVE ID and fixed builds against Citrix's official bulletin.
- **Principle / root cause:** Insufficient input validation / memory-handling error in the SAML Service Provider or Identity Provider handling, causing memory overflow/over-read; reported impact is denial of service of authentication and remote access, with targeted exploitation of unpatched appliances.
- **Affected:** NetScaler ADC and Gateway configured as a SAML SP or SAML IdP (versions per the Citrix bulletin; earlier related SAML-IdP issues affected builds before 14.1-72.61 and 13.1-63.18).
- **Mitigation:** Apply the fixed builds from the Citrix bulletin; check whether SAML SP/IdP profiles are configured (`add authentication samlAction` / `samlIdPProfile`) and prioritize those appliances; monitor for appliance crashes/restarts and abnormal authentication errors.
