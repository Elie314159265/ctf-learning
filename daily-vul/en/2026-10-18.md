## 1. CVE-2026-0322 — PAN-OS Management Interface Code Injection

**Principle / root cause:** Improper control of generated code (CWE-94) in the PAN-OS management interface. An authenticated, high-privilege user with network access to the management interface can cause the device to execute attacker-influenced code with root privileges.

**Mitigation:**
- Upgrade to the fixed PAN-OS release listed in Palo Alto Networks' advisory (published 2026-10-14).
- Restrict management interface access to trusted internal networks only; never expose it to the internet.
- No workaround is known; review admin accounts and credentials.

**Affected:** Multiple supported PAN-OS branches on PA-Series, VM-Series and Panorama. Cloud NGFW and Prisma Access are reported unaffected. Exact version ranges: see the vendor advisory. Disclosed 2026-10-14.

## 2. CVE-2026-76519 — Cisco Secure Email Gateway Path Traversal (Exploited)

**Principle / root cause:** Relative path traversal in the Advanced Malware Protection feature. Processing a specially crafted email attachment lets an unauthenticated remote attacker write files outside the intended directory, leading to command execution as root.

**Mitigation:**
- Update Content Scanner Tools to 25.3.0.5525 or later, per Cisco's advisory.
- Exposure applies when File Reputation is enabled and assigned to a mail policy; review for signs of compromise on appliances processing external mail.
- A related SQL injection, CVE-2026-76461, is reported in the same Cisco advisory bundle; review it as well.

**Affected:** Cisco Secure Email Gateway with Content Scanner Tools earlier than 25.3.0.5525 and File Reputation enabled. Advisory 2026-10-14; CISA KEV deadline 2026-10-17 (passed).

## 4. CVE-2026-104935 — Ivanti Connect Secure Authentication Bypass (Zero-Day)

**Principle / root cause:** Authentication bypass in the Connect Secure gateway: the web layer trusts a client-supplied request header when deciding how to route and authenticate the request, so an unauthenticated remote attacker can reach functionality that should require login. Attackers have used it for credential theft and data exfiltration. Volexity reports the actor also used a separate, still-unpatched privilege-escalation flaw.

**Mitigation:**
- Upgrade to 22.8R2.5, 25.1.1.2, 25.1.3.0 or 25.1.3.1, depending on branch. 25.1.3.0 runs only on the new hardware platform (ISA4500/6500/8500) or on rebuilt virtual appliances.
- Run Ivanti's integrity checker and hunt for compromise; exploitation reportedly began around 2026-10-01 to 10-03.
- Rotate credentials and sessions for accounts that passed through the appliance.

**Affected:** Ivanti Connect Secure 22.8R2.4 and earlier, 25.1.2.2 and earlier, 25.1.1.1 and earlier (22.7.x and below reported unaffected). Disclosed 2026-10-13; CISA KEV deadline 2026-10-16.

## 5. CVE-2026-96951 — Windows Shell Mark of the Web Bypass (Zero-Day)

**Principle / root cause:** A command-injection weakness in Windows Shell lets a crafted file avoid the Mark of the Web checks (SmartScreen / Protected View warnings and blocking). A user must open the file, delivered by email, chat or download. Researchers note it may be a follow-on to incomplete earlier fixes; no actor attribution yet.

**Mitigation:**
- Install the October 2026 cumulative Windows updates.
- Train users not to open unexpected files, and keep mail and web filtering enabled.

**Affected:** Supported Windows client and server versions covered by the October 2026 updates. Patched 2026-10-13; CISA KEV; federal deadline 2026-10-16.

## 7. CVE-2026-104286 — FortiMail Path Traversal / Null Byte Handling (Zero-Day)

**Principle / root cause:** Path traversal (CWE-22) combined with improper null-byte neutralization (CWE-158) in the management interface (advisory FG-IR-26-175). Fortinet confirmed exploitation in the wild when disclosing it on 2026-10-01.

**Mitigation:**
- Upgrade to 8.0.2, 7.6.7 or 7.4.9 as they become available (release notes for 7.6.7 and 7.4.9 are reported to exist; check the advisory). 7.2 users should move to 7.4 or later.
- Workarounds: disable IBE (identity-based encryption) via CLI; block internet access to the management interface or restrict it to a trusted network.

**Affected:** FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9. Disclosed 2026-10-01; CISA KEV 2026-10-01 (deadline 2026-10-04).
