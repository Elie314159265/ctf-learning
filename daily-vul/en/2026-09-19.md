## 1. CVE-2025-39682, CVE-2025-39964 & CVE-2026-53266 — Linux Kernel (Actively Exploited Trio)

**Principle / root cause:**
- **CVE-2025-39682** (CVSS 9.8) is an improper-condition check in the kernel's TLS receive path: a corner case where a zero-length record retrieved from the internal `rx_list` bypasses the intended `recvmsg()` record-type handling, which can lead to memory disclosure or a crash.
- **CVE-2025-39964** (CVSS 7.8) is a race condition that allows concurrent writes to the same `AF_ALG` (kernel crypto API) socket from multiple threads, corrupting cryptographic operation state and causing a crash or incorrect cryptographic results.
- **CVE-2026-53266** (CVSS 8.8) is an out-of-bounds write in netfilter's bridge `ebtables` SNAT target: during an optional ARP sender hardware-address rewrite, the kernel can call an internal buffer-write routine without first confirming the destination memory range is writable, and under specific socket-buffer conditions this can write into a page it should not touch.

All three require some form of local access or a reachable kernel subsystem (TLS socket handling, crypto sockets, or netfilter bridging) rather than being remote, pre-authentication flaws, but each can be leveraged for denial-of-service, information disclosure, or — for the out-of-bounds write — potential memory corruption leading to further compromise.

**Mitigation:**
- Apply the vendor/distribution kernel updates that incorporate the fixes for these three CVEs as soon as they are available for your distribution.
- CISA requires forensic triage (not just patching) for affected federal systems, given confirmed active exploitation — treat any system that may have been exposed as a possible-compromise scenario rather than routine patching.

**Affected:** Linux kernel — CVE-2025-39682 affects 6.0 through 6.16.3 (plus 6.17-rc1/rc2); CVE-2025-39964 affects a broad range from 2.6.38 through 6.16.9 (plus 6.17-rc6); CVE-2026-53266 affects kernels with the netfilter bridge `ebtables` SNAT target enabled. Two of the three CVE identifiers were originally assigned in 2025, indicating the underlying bugs were known for some time before exploitation was confirmed. All three added to CISA's KEV catalog on 2026-09-18 under Binding Operational Directive 26-04, with a federal remediation deadline of 2026-09-21.

## 2. CVE-2026-77179 & CVE-2026-79994 — Docker Sandboxes macOS Virtual-Machine Escape

**Principle / root cause:** Docker Sandboxes uses a `virtio-fs` host server to share a project directory into its guest VM. On macOS, that host server improperly follows symlinks when reopening a previously unlinked file from a stored path (CWE-59, improper link resolution). A malicious process running inside the sandboxed guest can replace a parent directory with a symlink, causing the host server to reopen a path outside the intended shared workspace. This lets guest code read or modify arbitrary files on the host with the privileges of the account running the virtual machine, and potentially escalate to full host code execution.

**Mitigation:**
- Upgrade Docker Desktop / Docker Sandboxes to version 0.42.0 or later.
- Treat any AI-agent or CI workload that executes untrusted code inside a pre-0.42.0 Sandbox on macOS as a potential host-compromise vector until updated.

**Affected:** Docker Sandboxes versions 0.28.0 up to (but not including) 0.42.0, on macOS only. Fixed in 0.42.0, released 2026-09-07; publicly detailed 2026-09-17. No confirmed in-the-wild exploitation reported at time of writing, but the flaw is notable for its relevance to AI coding-agent sandboxes that routinely execute untrusted, model-generated code.

## 3. CVE-2026-86710 — "Login with QR" WordPress Plugin Authentication Bypass

**Principle / root cause:** The plugin's QR-code login flow accepts an `autologin_code` parameter and checks it only against a value stored in the target user's metadata, rather than cryptographically verifying that the code was actually issued by the server for that login attempt (CWE-287, improper authentication). Because the check is a simple value lookup rather than a signed, single-use token verification, any value that happens to match what is stored for a user — including values an attacker can influence or guess — can be used to authenticate as that user, including administrators, without credentials.

**Mitigation:**
- Update to a fixed version once released; until then, deactivate the plugin on production sites.
- Review recent admin-account activity and login logs for unexplained authentications via the QR-login flow.

**Affected:** "Login with QR" WordPress plugin, versions up to and including 1.0.0. Disclosed 2026-09-17 (WPScan-assigned). No confirmed in-the-wild exploitation yet, but the plugin's low install base has historically meant slow patch adoption for similar WordPress authentication-bypass bugs — treat as an imminent target.

## 4. CVE-2026-58704 — Google Pixel Cellular Modem Privilege Escalation (Federal Deadline Today)

**Principle / root cause:** A logic flaw in the Pixel cellular modem's permission-checking code allows a privilege/authorization bypass reachable from radio/adjacent-network range, without requiring additional execution privileges or any interaction from the device owner.

**Mitigation:** Update Pixel devices to the September 2026 security patch level (2026-09-05 or later).

**Affected:** Pixel devices with the vulnerable modem stack, prior to the September 2026 patch. Limited, targeted in-the-wild exploitation reported, consistent with spyware-style tradecraft. Added to CISA KEV 2026-09-16; the federal civilian remediation deadline is today, 2026-09-19 — included here for that reason even though the underlying disclosure is not new this cycle.

## 5. CVE-2026-76460 — Cisco ISE/ISE-PIC Unauthenticated Root Auth Bypass (Federal Deadline Today)

**Principle / root cause:** An internal API endpoint on Cisco Identity Services Engine performs insufficient authentication checks. A crafted HTTP request lets a remote, unauthenticated attacker bypass web-management authentication entirely, ultimately reaching functionality that allows commands to run with root privileges.

**Mitigation:** Upgrade to ISE/ISE-PIC 3.5 Patch 4, 3.4 Patch 7, 3.3 Patch 12, 3.2 Patch 11, or 3.1 Patch 12; where immediate patching isn't possible, restrict management-interface access via infrastructure ACLs.

**Affected:** Cisco ISE and ISE-PIC prior to the patched releases above. Actively exploited as a zero-day; CISA KEV added 2026-09-16, federal deadline today, 2026-09-19 — included here as a same-day reminder alongside item 4.

## 6. CVE-2026-87886 — Acronis Backup Plugin (cPanel & WHM / Plesk) Insecure File Permissions (Federal Deadline Today)

**Principle / root cause:** The Acronis Backup integrations for cPanel & WHM and Plesk (Linux) create temporary files, logs, and backup archives with overly permissive (world-readable/writable) file permissions (CWE-276). Any local, authenticated low-privilege user on the same host can read sensitive data from these files or tamper with them to escalate privileges.

**Mitigation:** Update the cPanel & WHM plugin to build 1.9.3.1021+ and the Plesk extension to build 1.8.11.638+; audit hosting servers for existing world-readable backup/log artifacts and rotate any credentials that may have been exposed.

**Affected:** Acronis Backup plugin for cPanel & WHM (Linux) before 1.9.3.1021; Acronis Backup extension for Plesk (Linux) before 1.8.11.638. Exploitation confirmed in the wild; CISA KEV added 2026-09-16, federal deadline today, 2026-09-19.

## 7. CVE-2026-76461 — Cisco Secure Email Gateway SQL Injection to Root RCE (Zero-Day)

**Principle / root cause:** Cisco AsyncOS for Secure Email Gateway insufficiently validates certain fields while parsing inbound email messages, allowing SQL statements to be smuggled into backend query processing (SQL injection). The resulting database access is further leveraged to execute arbitrary operating-system commands with root privileges. Because affected gateways process externally delivered email as part of normal operation, exploitation requires no authentication and no administrative-interface access — only that the gateway process a specially crafted email.

**Mitigation:** Apply Cisco's fixed AsyncOS releases (15.5.5-0141, 16.0.4-3021, or 16.5.0-780); review mail-gateway logs for anomalous processing errors or unexpected outbound connections, since Cisco identified the issue while investigating a support case, suggesting some exploitation predates public disclosure.

**Affected:** Cisco Secure Email Gateway appliances (physical, virtual, and cloud-based) running vulnerable AsyncOS releases. Disclosed and added to CISA KEV on 2026-09-14, with a federal remediation deadline of 2026-09-17 (already passed) — included here as it remains one of the most severe unauthenticated, zero-click flaws disclosed this cycle.
