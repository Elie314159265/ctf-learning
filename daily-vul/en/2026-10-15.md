## Newest items (last 24–48 hours)

### 1. CVE-2026-104935 — Ivanti Connect Secure Authentication Bypass (Zero-Day)

**Principle / root cause:** Authentication bypass by spoofing (CWE-290). A remote, unauthenticated party can impersonate a trusted identity and get commands executed on the appliance. Reporting says threat actor UTA0576 chained it with two other flaws, including a privilege-escalation flaw not yet patched, to obtain root-level code execution even on otherwise patched devices.

**Mitigation:**
- Upgrade to a fixed release (see below) immediately.
- Review appliance logs and integrity-check tooling for signs of compromise; consider rebuilding appliances that show indicators.
- Watch for Ivanti's fix for the still-unpatched chained privilege-escalation flaw.

**Affected:** Ivanti Connect Secure 25.1.2.2 and earlier, 25.1.1.1 and earlier, 22.8R2.4 and earlier. Fixed in 25.1.3.0, 25.1.3.1, 22.8R2.5. 22.7R2.14 and earlier appear unaffected.

**Disclosure:** 2026-10-13 (Ivanti advisory; discovered by Volexity). Exploitation observed since about 2026-10-01 to 2026-10-03. CISA KEV 2026-10-13; federal deadline reported as 2026-10-16.

### 2. CVE-2026-96951 — Windows Shell Security Feature Bypass (Exploited Zero-Day)

**Principle / root cause:** A command-injection weakness (improper neutralization of special elements) in Windows Shell lets a crafted file or link strip the Mark-of-the-Web. As a result SmartScreen and Protected View warnings are not shown for downloaded content. User interaction (opening the file) is still required.

**Mitigation:**
- Deploy the October 2026 cumulative updates.
- Reinforce user guidance on files from email, chat and web links; keep attachment and macro-blocking controls enabled.
- Hunt for downloaded files that lack expected Mark-of-the-Web metadata.

**Affected:** Supported Windows versions (see the MSRC entry for the exact list).

**Disclosure:** 2026-10-13 (Patch Tuesday). Exploited in the wild; CISA KEV 2026-10-13. The release is reported as record-sized (about 1,410+ CVEs, 75 Critical, three zero-days, 23 Office preview-pane flaws); counts vary by source.

### 3. Cisco Secure Email Gateway — Critical Path Traversal, Exploited

**Principle / root cause:** Relative path traversal (CWE-23): insufficient validation of file paths lets a remote party read or manipulate files outside the intended directory. Cisco warned on 2026-10-14 that a critical (CVSS 9.8) flaw is exploited. CISA lists it as CVE-2026-76519; an adjacent advisory set (Sept 2026) lists CVE-2026-76440 for path traversal, and sources disagree on which CVE maps to the exploited bug. Verify against the Cisco advisory.

**Mitigation:**
- Upgrade to the fixed releases in Cisco's advisory. Per earlier-advisory reporting: Secure Email Gateway 15.5.5-014 (verify exact build) and 16.5.0-780; Secure Email and Web Manager 15.5.5-006 and 16.5.0-429. 16.0 has no fixed release; migrate to a supported branch.
- No workarounds were reported; restrict management/appliance exposure and review logs.

**Affected:** Cisco Secure Email Gateway (and related Secure Email and Web Manager) on the branches above.

**Disclosure:** 2026-10-14; CISA KEV 2026-10-14.

### 4. PAN-OS Code Injection (CVE-2026-0322, unverified)

CISA's 2026-10-14 alert reportedly lists a Palo Alto Networks PAN-OS code-injection vulnerability, CVE-2026-0322. We could not corroborate this identifier or its details from secondary sources. Treat as exploited per CISA KEV; consult Palo Alto Networks' security advisories for affected PAN-OS versions and fixes, apply patches, and restrict management-interface exposure.

### 5. CVE-2026-105133 / CVE-2026-105134 — AhsayCBS Authentication Bypass + Code Execution

**Principle / root cause:** Two chained flaws in the AhsayCBS backup management console: CVE-2026-105133 bypasses authentication; CVE-2026-105134 then allows remote code execution as SYSTEM. Attackers have dropped web shells and cryptominers and created fake services for persistence (Huntress).

**Mitigation:**
- Ahsay confirmed on 2026-10-10 that 10.3.4.0 did not fully fix the issues. Apply hotfix 10.3.4.45 and reboot the server.
- Remove console exposure from the internet; hunt for unexpected JSP files, rogue services (e.g. fake "Edge update" services) and miners.

**Affected:** AhsayCBS up to 10.3.2 and, per later findings, 10.3.4.0.

**Disclosure:** Exploitation first seen 2026-10-07; CISA KEV 2026-10-14 (earlier reports said not yet listed).

## Other notable items from the week

### 6. CVE-2026-102489 / CVE-2026-102490 — Zammad Helpdesk

**Principle / root cause:** Session hijacking leading to code execution as the application user (CVE-2026-102489), chainable with a local privilege escalation to root (CVE-2026-102490). Assigned by DIVD, which reports an AI-assisted intrusion chaining both. Zammad GmbH disputes affected versions and exploitability; as of 2026-10-05 no vendor advisory or confirmed fix for CVE-2026-102490 was found.

**Mitigation:** Update Zammad to the latest release, restrict exposure, review hosts for compromise, and follow the vendor/DIVD guidance as it evolves.

**Affected:** Zammad 6.3.0–6.5.4 (also reported in 7.0.0–7.1.3). **Disclosure:** CISA KEV 2026-10-02.

### 7. CVE-2026-88779 — Citrix NetScaler ADC / Gateway

**Principle / root cause:** Memory overflow (CWE-119) reachable without authentication on appliances configured as a SAML service provider or identity provider; observed attacks crash appliances and may aid exploitation of a related flaw (CVE-2026-88771).

**Mitigation:** Apply Citrix's patched builds per the security bulletin; Citrix-managed cloud services are not affected.

**Affected:** NetScaler ADC and Gateway with SAML SP/IdP configuration. **Disclosure:** CISA KEV 2026-10-04 (federal deadline 2026-10-07).

### 8. CVE-2026-70229 — Active Directory Domain Services RCE

Reported by PDQ as a Critical RCE in AD DS (CVSS 8.1) exploitable without credentials under specific network conditions; patched in the 2026-10-13 updates. No exploitation reported. Severity labeling differs by source; check the MSRC entry. Apply the October updates to domain controllers first.
