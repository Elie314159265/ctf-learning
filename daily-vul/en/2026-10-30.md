## 1. CVE-2026-76418 — Cisco Secure Firewall ASA / FTD SSL VPN Denial of Service

- **Disclosure date:** 2026-10-28 (Cisco learned of exploitation earlier in October).
- **Principle / root cause:** Improper handling of requests in the SSL VPN service lets an unauthenticated remote party cause the device to reload unexpectedly, i.e. denial of service of the VPN/firewall.
- **Affected:** Cisco ASA 9.16–9.24; FTD 7.0–10.1 (reportedly when SSL VPN secondary authentication is configured).
- **Mitigation:** Apply Cisco's fixed releases or hot fixes (reported fixed ASA builds include 9.16.4.104, 9.18.4.96, 9.20.4.50, 9.22.3.200, 9.23.1.48, 9.24.1.27; FTD 7.0.11, 7.2.13, 7.4.9, 7.6.7, 7.7.14, 10.0.3, 10.1.1 — unverified). No workaround reported. Check exposure of SSL VPN endpoints.
- **Caveat:** Other coverage tracks the same SSL VPN DoS as CVE-2026-20349 with differing version lists. Confirm the CVE ID and fixed releases in Cisco's advisory.

## 2. CVE-2026-46300 "Fragnesia" — Linux Kernel XFRM ESP-in-TCP Local Privilege Escalation

- **Disclosure / KEV date:** Added to CISA KEV 2026-10-28; federal deadline 2026-10-31. Kernel fixes have reportedly been available since May 2026.
- **Principle / root cause:** A flaw in the kernel's XFRM/IPsec ESP-over-TCP handling allows a local unprivileged user to escalate to root. Reported as chained with the PHP flaws (item 5) in attacks: code execution in a web worker, then local root.
- **Affected:** Linux kernels with the XFRM ESP-in-TCP feature prior to the fixed stable releases; distribution kernels vary.
- **Mitigation:** Install distribution kernel updates and reboot; where patching is delayed, restrict untrusted local/container access.

## 3. CVE-2026-97229 — GitLab CI/CD Regex Engine Integer Overflow (Unauthenticated RCE)

- **Disclosure date:** Late October 2026 (CISA reportedly flagged it 2026-10-29; sources conflict on whether exploitation is confirmed or it is in KEV).
- **Principle / root cause:** An integer overflow in the regular-expression compiler used when processing CI/CD configuration can lead to memory corruption and code execution without authentication.
- **Affected:** Self-managed GitLab CE/EE 19.2 before 19.2.8, 19.3 before 19.3.5, 19.4 before 19.4.2. GitLab.com already patched; Dedicated covered.
- **Mitigation:** Upgrade to 19.2.8 / 19.3.5 / 19.4.2 (use 19.3.5, not 19.3.4, which has an unrelated merge-request page bug). Restrict internet exposure of GitLab and review for anomalous CI configs.

## 4. CVE-2026-118539 — Drupal Commerce Core Access Bypass

- **Disclosure date:** Late October 2026.
- **Principle / root cause:** Authorization/access-control check missing or flawed in Commerce Core, allowing access to resources (e.g. orders) the user should not reach. Rated highly critical by Drupal; exploitation reported.
- **Affected:** Commerce Core 8.x-2.x up to and including 2.41 (before 8.x-2.41 fix) and 3.0.0–3.3.12 (fixed in 3.3.13), per sources.
- **Mitigation:** Update to 3.3.13 / 8.x-2.41 (or later) and audit orders and access logs for anomalies. Not in KEV as of 2026-10-30 per one source.

## 5. CVE-2026-109618 & CVE-2026-109619 — PHP Memory-Safety Flaws ("PHP2Shell")

- **Disclosure date:** 2026-10-21 (patched same day); CISA KEV 2026-10-26.
- **Principle / root cause:** Both are use-after-free (CWE-416) class bugs. 109618: an out-of-memory condition during request (multipart) parsing leaves internal data partly initialized, and cleanup treats it as valid. 109619: request-owned state outlives its backing memory and is reused by a later request in the same worker. CVSS 4.0 9.2; code execution reportedly validated against PHP-FPM.
- **Affected:** PHP before 8.5.12, 8.4.27, 8.3.36, 8.2.35; 8.1 and older (unsupported; some sources say back to 5.4) unless vendor-backported.
- **Mitigation:** Upgrade to 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 or apply vendor backports (Red Hat, CloudLinux, cPanel, Ubuntu). Interim: use container/cgroup memory limits that kill only the affected worker; avoid RLIMIT_AS/RLIMIT_DATA. Migrate off EOL PHP.
