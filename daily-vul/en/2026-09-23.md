## 1. CVE-2026-94127 — F5 BIG-IP APM Heap-Based Buffer Overflow (Unauthenticated RCE)

**Principle / root cause:** On a BIG-IP virtual server that combines an Access Policy Manager (APM) access policy with an OAuth profile, the OAuth-handling code writes attacker-influenced data into a heap buffer without validating its size (CWE-122). The oversized write corrupts adjacent heap memory inside the Traffic Management Microkernel (TMM) data plane. Because an attacker can influence the content that overflows into the corrupted region, the memory corruption can be steered into arbitrary code execution — without any authentication.

**Mitigation:**
- Apply F5's fix per advisory K000162872 as soon as available for your branch.
- Until patched, request F5's iRule-based interim mitigation from F5 Support for any affected virtual server.
- Audit which virtual servers combine an APM access policy with an OAuth profile; this is the only exposed configuration.

**Affected:** BIG-IP APM 17.1.0–17.1.3, 17.5.0–17.5.1, and 21.1.0, only when a virtual server is configured with both an APM access policy and an OAuth profile. Disclosed by F5 on 2026-09-02 (discovered internally); confirmed under active exploitation, corroborated by the Canadian Centre for Cyber Security; added to CISA KEV on 2026-09-22.

## 2. CVE-2026-85102 & CVE-2026-93616 — Check Point Security Gateway / Management Server Zero-Days

**Principle / root cause:** CVE-2026-85102 is a pre-authentication flaw in VPN certificate handling on Check Point Security Gateway (notably Spark firewalls) that permits authentication bypass leading to remote code execution. CVE-2026-93616 is a pre-authentication path-traversal vulnerability in the Check Point Management web service: crafted paths let an unauthenticated attacker cause the server to execute a script from an arbitrary location and load an arbitrary Java class, effectively achieving code execution on the management plane.

**Mitigation:**
- Apply Check Point's emergency hotfixes for both CVEs immediately (available since early September 2026 for CVE-2026-85102, and following the July 2026 limited-attack disclosure for CVE-2026-93616).
- Restrict internet exposure of Security Gateway VPN portals and Management Server web interfaces; review logs for anomalous authentication or script-execution activity, particularly traffic from VPN/proxy anonymization infrastructure.

**Affected:** Check Point Security Gateway / Spark Firewalls (CVE-2026-85102); Security Management Server, Multi-Domain Security Management Server, Log Server, Multi-Domain Log Server, and SmartEvent (CVE-2026-93616). Spark-targeted exploitation waves observed starting 2026-09-12; both CVEs added to CISA KEV on 2026-09-22.

## 3. CVE-2026-93952 — Arista VeloCloud Orchestrator Unauthenticated Privileged Access

**Principle / root cause:** Improper input validation in the VeloCloud Orchestrator (VCO) web interface allows a remote, unauthenticated attacker to reach internal, privileged functionality that should require operator/tenant credentials. The exposure specifically affects orchestrators configured to authenticate their managed Edge devices using certificates, and a successful attack can compromise the orchestrator and, transitively, the Edge devices it manages.

**Mitigation:**
- Apply the fixed releases on the 5.2 and 6.4 trains immediately; monitor Arista's advisory for the 6.1 and 7.0 train fixes and apply as soon as released.
- Restrict network access to the VCO web interface to trusted management networks as an interim measure.

**Affected:** VeloCloud Orchestrator deployments (self-hosted) that authenticate Edges via certificates; Arista-hosted and Dedicated VCO instances have already been patched by Arista. Actively exploited (discovered via external report); added to CISA KEV on 2026-09-22. CVSS 10.0.

## 4. CVE-2026-7273 — Zyxel GS1900 Series Switches Stack-Based Buffer Overflow

**Principle / root cause:** The CGI program on Zyxel GS1900 switches fails to validate the length of user-supplied input before copying it into a fixed-size stack buffer (CWE-121). An attacker on the local network can send an oversized, specially crafted HTTP request that overwrites adjacent stack memory, giving the attacker control over the CGI process's execution flow and ultimately allowing arbitrary OS command execution — without authentication.

**Mitigation:**
- Upgrade GS1900-48HPv2 (and other affected models) to firmware 2.90(ABTQ.2)C0 or later.
- Restrict management-interface access to trusted management VLANs/networks; review switches for unauthorized configuration changes or credential exposure since mid-August 2026.

**Affected:** Zyxel GS1900 series switches, firmware 2.90(ABTQ.1)C0 and earlier. A suspected Chinese-speaking threat actor has exploited this flaw since 2026-08-17, compromising and exfiltrating configuration data and hashed root credentials from an estimated 996 switches across 48 countries. Added to CISA KEV on 2026-09-21 with a 2026-09-24 federal remediation deadline.

## 5. CVE-2026-89422 — Erlang/OTP TLS 1.3 Unsolicited PSK Authentication Bypass

**Principle / root cause:** An Erlang/OTP `ssl` client negotiating TLS 1.3 can be tricked into accepting a `pre_shared_key` extension in the ServerHello that it never offered. This routes the client's state machine directly into a resumption path (`maybe_resumption/1` → `wait_finished`), skipping all certificate-related processing — certificate chain validation, `verify_fun`, hostname verification, `partial_chain`, CRL checking, and OCSP stapling are all bypassed. As a result, a peer with no valid certificate or private key can complete a "successful" handshake and be treated as the trusted server, enabling man-in-the-middle impersonation (CWE-322: Key Exchange without Entity Authentication).

**Mitigation:**
- Upgrade to OTP 27.3.4.18, 28.5.0.7, 29.1.1, or later (corresponding `ssl` app versions 11.2.12.13, 11.6.0.6, 11.7.7).
- As a temporary mitigation, restrict affected TLS clients to TLS 1.2 until patched, since the flaw is specific to the TLS 1.3 resumption path.

**Affected:** Erlang/OTP `ssl` from OTP 22.2 up to (but not including) the fixed releases above, using default client configuration. Publicly disclosed 2026-09-22; no known in-the-wild exploitation reported at time of writing, but patch promptly given the severity (CVSS 9.3) and ubiquity of Erlang/OTP in messaging and telecom infrastructure.

## 6. CVE-2026-94301 — Apache MINA `resolveProxyClass` Allow-List Bypass (Incomplete Patch)

**Principle / root cause:** This is an incomplete-fix issue: an earlier Apache MINA vulnerability (CVE-2026-47065) added an `acceptMatchers` allow-list intended to restrict which classes could be deserialized/proxied, but the fix for `resolveProxyClass()` handling of `java.lang.reflect.Proxy` objects was only committed to the MINA 2.2.x branch. The 2.0.x and 2.1.x maintenance branches — including releases that already claimed to fix the original issue — remain bypassable, allowing an attacker to circumvent the allow-list via proxy objects and reach unauthorized deserialization/code paths, potentially leading to arbitrary code execution.

**Mitigation:**
- Migrate to the Apache MINA 2.2.x branch (e.g., 2.2.8 or later), which contains the complete fix.
- If migration isn't immediately possible, apply the strictest feasible deserialization allow-list and avoid exposing MINA-based services to untrusted networks.

**Affected:** Apache MINA 2.0.x and 2.1.x branches, including versions up to 2.0.30 and 2.1.14 (i.e., releases that patched CVE-2026-47065 but not this bypass). Disclosed around 2026-09-22; no confirmed in-the-wild exploitation at time of writing. CVSS 9.8.

## 7. CVE-2026-94545 (GHSA-vcvr-r3jv-pc5j) — Next.js `next/og` ImageResponse Remote Code Execution

**Principle / root cause:** The Node.js implementation of `ImageResponse` in `next/og` renders SVG-like markup to generate dynamic images (e.g., Open Graph images). When application code places attacker-controlled data into SVG elements, attributes, or styles without adequate sanitization, the rendering pipeline can be manipulated to achieve remote code execution — requiring no authentication and no user interaction.

**Mitigation:**
- Upgrade to Next.js 16.3.6 or later (or 15.5.26, which ships related hardening even though Next.js 15.x is not itself vulnerable to the RCE).
- Audit any use of `next/og` `ImageResponse` for attacker-influenced input flowing into SVG content, and treat that input as untrusted pending the upgrade.

**Affected:** Next.js versions ≥16.2.0 and <16.3.6. Fixed via an out-of-band security release on 2026-09-22; no known in-the-wild exploitation reported at time of writing, but the combination of no-auth/no-interaction and Critical severity (CVSS v4) makes prompt patching important, especially for public-facing apps generating dynamic OG images from user input.

## 8. CVE-2026-86473 — Apache Airflow Logout Session-Revocation Bypass

**Principle / root cause:** Airflow's Core API logout endpoint only revokes the session token when it is presented via the `_token` cookie. If a client instead authenticates using the same token as an `Authorization` bearer header, the logout endpoint returns a normal success response but does not actually revoke the token (CWE-613: Insufficient Session Expiration). An attacker who has obtained a copy of a bearer token retains valid access for the token's full lifetime (24 hours by default, configurable) even after the legitimate user believes they have logged out.

**Mitigation:**
- Upgrade to Apache Airflow 3.3.2 or later.
- Reduce default token lifetime where feasible, and treat any previously issued bearer tokens as potentially still valid until the configured expiry after upgrading.

**Affected:** Apache Airflow deployments prior to 3.3.2. Disclosed 2026-09-21; no known in-the-wild exploitation reported at time of writing. CVSS 9.1.

## 9. CVE-2026-32996 — Veeam Agent for Microsoft Windows Local Privilege Escalation

**Principle / root cause:** The Veeam Endpoint Backup service communicates with clients over a local gRPC named pipe. When handling elevated client sessions, the service caches an elevated "administrator" principal against a client-supplied session UID that is not properly bound to the specific requesting user or connection (CWE-284-class access-control flaw). A low-privileged local user can leverage this to have their own session treated as the cached elevated principal, escalating to `NT AUTHORITY\SYSTEM`.

**Mitigation:**
- Upgrade Veeam Backup & Replication to 13.0.2.29 or later, which updates Veeam Agent for Windows to build 13.0.3.1220 containing the fix.
- Treat this as urgent on any host where local/low-privileged access is possible (shared workstations, multi-tenant build hosts), since public PoC code is already circulating.

**Affected:** Veeam Agent for Microsoft Windows 13.0.1.2067 and earlier version-13 builds. Public PoC released 2026-09-14; reporting as of the week of 2026-09-22 indicates active exploitation in the wild, chained into post-compromise privilege-escalation activity.

## 10. CVE-2026-76460 — Cisco Identity Services Engine Authentication Bypass (Continuity)

**Principle / root cause:** An ISE/ISE-PIC API endpoint incorrectly trusts a privileged internal API without enforcing authentication (CWE-648: Incorrect Use of Privileged APIs). A crafted, unauthenticated request to the exposed API bypasses the web-based management authentication entirely, and Cisco states successful exploitation can lead to command execution with root privileges on the appliance.

**Mitigation:** Upgrade to a fixed Cisco ISE release immediately — there is no effective workaround; infrastructure ACLs restricting management-plane access are only a partial, temporary reduction of exposure.

**Affected:** Cisco Identity Services Engine (ISE) and ISE-PIC, all currently supported unpatched releases. CVSS 10.0. Actively exploited; added to CISA KEV on 2026-09-16 with an unusually short (3-day) federal remediation deadline of 2026-09-19.

## 11. CVE-2026-87886 — Acronis Backup Plugin Incorrect Default Permissions (Continuity)

**Principle / root cause:** The Acronis Backup integrations for cPanel & WHM, Plesk, and DirectAdmin (Linux) ship with insecure default file permissions (CWE-276). An attacker who already has authenticated, low-privileged access to the Linux host can leverage the overly permissive files to escalate privileges, without requiring any user interaction.

**Mitigation:** Upgrade to Acronis Backup plugin for cPanel & WHM build 1.9.3.1021+, Plesk extension build 1.8.11.638+, or DirectAdmin plugin build 1.2.3.238+.

**Affected:** Acronis Backup integrations for cPanel & WHM, Plesk, and DirectAdmin on Linux, prior to the builds above. CVSS 7.8. Exploitation observed in the wild against cPanel & WHM deployments; added to CISA KEV on 2026-09-16.

**Principle / root cause:** An unauthenticated, network-reachable component of Cisco Secure Email Gateway is vulnerable to SQL injection. The injected SQL is leveraged to achieve command execution with root privileges on the appliance, without any credentials.

**Mitigation:** Apply Cisco's fixed software release immediately if not already done; federal agencies were required to remediate by 2026-09-17 under CISA's KEV deadline.

**Affected:** Cisco Secure Email Gateway, unpatched releases. CVSS 9.8. Disclosed and confirmed under active exploitation 2026-09-14; added to CISA KEV the same day. Included here as continuity context since it falls just outside the strict 7-day window but its federal remediation deadline and ongoing exploitation remain highly relevant this week.
