## 1. CVE-2026-76460 — Cisco ISE/ISE-PIC Unauthenticated Root Auth Bypass (Zero-Day)

**Principle / root cause:** An internal API endpoint on Cisco Identity Services Engine performs insufficient authentication checks. A crafted HTTP request to that API lets a remote, unauthenticated attacker bypass web-management authentication entirely, reaching functionality that ultimately allows commands to be executed with root privileges — regardless of how the device is configured.

**Mitigation:**
- Upgrade to ISE/ISE-PIC 3.5 Patch 4, 3.4 Patch 7, 3.3 Patch 12, 3.2 Patch 11, or 3.1 Patch 12.
- Where immediate patching isn't possible, restrict access to the management interface using infrastructure ACLs (iACLs) as an interim measure.
- Because ISE controls network access policy, treat any exposed/unpatched instance as a likely full-network compromise: rotate credentials, review policy changes, and check logs for signs of tampering (including log deletion).

**Affected:** Cisco ISE and ISE-PIC prior to the patched releases above. Actively exploited in the wild as a zero-day; added to CISA KEV on 2026-09-16.

## 2. CVE-2026-87886 — Acronis Backup Plugin (cPanel/Plesk) Insecure File Permissions

**Principle / root cause:** The Acronis Backup integrations for cPanel & WHM and Plesk (Linux) create temporary files, logs, and backup archives with overly permissive (world-readable/writable) file permissions (CWE-276: Incorrect Default Permissions). Any local, authenticated low-privilege user on the same host can read sensitive data from these files or tamper with them to escalate privileges — no user interaction required.

**Mitigation:**
- Update the Acronis Backup plugin for cPanel & WHM to build 1.9.3.1021+ and the Plesk extension to build 1.8.11.638+.
- Audit hosting servers for existing world-readable backup/log artifacts and rotate any credentials that may have been exposed.

**Affected:** Acronis Backup plugin for cPanel & WHM (Linux) before 1.9.3.1021; Acronis Backup extension for Plesk (Linux) before 1.8.11.638. Exploitation confirmed in the wild; added to CISA KEV on 2026-09-16 with a federal remediation deadline of 2026-09-19.

## 3. CVE-2026-58704 — Google Pixel Cellular Modem Privilege Escalation (Targeted Zero-Click)

**Principle / root cause:** A logic error in the Pixel cellular modem's permission-checking code allows a permission/authorization bypass. An attacker within radio/adjacent-network range can escalate privileges without needing any additional execution privileges and without any interaction from the device owner — consistent with a zero-click attack path.

**Mitigation:**
- Update Pixel devices to the September 2026 security patch level (2026-09-05 patch or later).

**Affected:** Pixel devices with the vulnerable cellular modem stack, prior to the September 2026 patch. Indications of limited, targeted in-the-wild exploitation; added to CISA KEV on 2026-09-16 (federal deadline 2026-09-19). Patched alongside 109 other Android/Pixel security issues in the same update.

## 4. CVE-2026-76461 — Cisco Secure Email Gateway SQL Injection to Root RCE (Zero-Day)

**Principle / root cause:** Cisco AsyncOS for Secure Email Gateway insufficiently validates certain fields while parsing inbound email messages. A specially crafted email can smuggle SQL statements into backend query processing (SQL injection), and the resulting database access is further leveraged to execute arbitrary operating-system commands with root privileges — all without authentication, and simply by having the gateway process the malicious message.

**Mitigation:**
- Apply Cisco's fixed AsyncOS software as detailed in Cisco's advisory (published 2026-09-14).
- Review mail-gateway logs for anomalous processing errors or unexpected outbound connections around the disclosure window; Cisco identified the issue while investigating a support case, suggesting some exploitation may predate public disclosure.

**Affected:** Cisco Secure Email Gateway appliances running vulnerable AsyncOS releases. Cisco PSIRT confirmed active exploitation before the advisory was published; not yet listed in CISA KEV at time of writing but treated as urgent given root-level, unauthenticated impact.

## 5. CVE-2026-85706 — GitLab Repository Commits API Path Traversal (Unauthenticated File Read)

**Principle / root cause:** GitLab's repository commits API insufficiently confines requested file paths and, under certain conditions, does not enforce authentication on the endpoint (path traversal, CVSS 10.0). A crafted request can escape the intended repository directory and read arbitrary files accessible to the GitLab server process — including configuration files, SSH keys, database credentials, deploy tokens, and CI/CD variables.

**Mitigation:**
- Upgrade self-managed GitLab to 19.1.8, 19.2.6, 19.3.2, or later immediately.
- Treat any unpatched, internet-facing instance as potentially compromised: rotate CI/CD secrets, deploy tokens, SSH keys, and database credentials, and review access logs for the commits API.

**Affected:** Self-managed GitLab Community Edition and Enterprise Edition prior to the fixed versions above (GitLab.com SaaS was patched centrally). Fixed 2026-09-10; active probing observed from 2026-09-11; added to CISA KEV the same day with a 2026-09-14 federal remediation deadline.

## 6. CVE-2026-84869 — ConnectWise ScreenConnect Client Unauthorized File Transfer/Execution

**Principle / root cause:** The ScreenConnect client has improper privilege management and a missing authorization check around remote-session file transfer. During an active remote-support session, a party can transfer a file to the connected device and execute it without the host user's confirmation or any additional authorization — bypassing the consent step normal remote-access tooling relies on.

**Mitigation:**
- Update ScreenConnect to version 26.6.5 or later.
- Review remote-session logs for unexpected file transfers, particularly script payloads (e.g., VBScript) delivered immediately after a new connection is established.

**Affected:** ScreenConnect versions prior to 26.6.5. Actively exploited (Huntress reported real-world incidents delivering malicious VBScript payloads); added to CISA KEV on 2026-09-11 with a 2026-09-14 federal remediation deadline.

## 7. CVE-2026-42016 & CVE-2026-42018 — JFrog Artifactory Authorization/Authentication Flaws

**Principle / root cause:** CVE-2026-42016 is an incorrect-authorization bug: Artifactory validates a token's signature and issuer but not its intended scope, letting a token meant for limited use be replayed for broader privileged actions (privilege escalation). CVE-2026-42018 is an improper-authentication flaw in which, when anonymous access is disabled, the server can still return an internal anonymous-user token to an unauthenticated caller, granting unintended access.

**Mitigation:**
- Apply JFrog's fixed Artifactory releases per the vendor advisory.
- Rotate access tokens and review token-scope usage logs, particularly for tokens exhibiting privileges beyond their intended scope.

**Affected:** Self-hosted JFrog Artifactory versions prior to the fixed releases. Actively exploited; added to CISA KEV on 2026-09-11. (Distinct from CVE-2026-82329, the Artifactory auth-bypass flaw covered in the 2026-09-03 report.)

## 8. CVE-2026-67276 / CVE-2026-67277 / CVE-2026-86060 — MikroTik RouterOS SSH Auth Bypass Chain ("MikroTrick")

**Principle / root cause:** CVE-2026-67276 is an SSH public-key authentication bypass that lets an attacker authenticate as an existing RouterOS user without possessing that user's private key. Chained with a related privilege-escalation weakness (CVE-2026-86060) and a further unauthenticated flaw (CVE-2026-67277), attackers can obtain full administrative control of a RouterOS device whose SSH service is reachable from the internet — a two-stage chain researchers have named "MikroTrick."

**Mitigation:**
- Update to the patched RouterOS builds released 2026-09-03 or later.
- Restrict SSH exposure to trusted management networks; audit for unexpected SSH users (reports note attacker-created accounts suffixed "-2" as an indicator of compromise).

**Affected:** MikroTik RouterOS devices with SSH exposed to public networks, prior to the 2026-09-03 patched builds. Over 122,500 internet-facing RouterOS SSH instances were counted in a single scan around 2026-09-05; exploitation began as early as 2026-09-02, before patches were available. Added to CISA KEV on 2026-09-10.

## 9. CVE-2025-25249 — Fortinet FortiOS / FortiSwitchManager Heap-Based Buffer Overflow

**Principle / root cause:** FortiOS and FortiSwitchManager contain a heap-based buffer overflow (memory corruption) reachable via specially crafted network packets. Successful exploitation can allow an attacker to execute unauthorized code or commands on the affected device.

**Mitigation:**
- Upgrade to a fixed FortiOS/FortiSwitchManager/FortiSASE release per Fortinet's advisory.
- CISA requires forensic triage (not just patching) for affected federal environments — treat as a possible-compromise scenario rather than routine patching, given active exploitation.

**Affected:** FortiOS 6.4–7.6 and FortiSwitchManager 7.0–7.2 branches prior to fixed builds (also affects FortiSASE). Actively exploited; added to CISA KEV on 2026-09-09 with a 2026-09-12 federal deadline.

## 10. CVE-2026-19490 — Citrix NetScaler ADC/Gateway Authentication Bypass

**Principle / root cause:** NetScaler instances configured with an AAA virtual server or Gateway service (SSL VPN, ICA Proxy, CVPN, RDP Proxy) contain an authentication-bypass flaw (CWE-288, bypass using an alternate path/channel) that lets a remote, unauthenticated attacker reach functionality that should require valid credentials.

**Mitigation:**
- Apply Citrix's fix per bulletin CTX696939.
- Perform forensic triage on any internet-facing NetScaler that was unpatched during the exploitation window, not just patch-and-move-on.

**Affected:** NetScaler ADC/Gateway appliances configured as described above, prior to the fix. Disclosed 2026-08-19; exploited in the wild since at least 2026-09-03; added to CISA KEV on 2026-09-09 with a 2026-09-12 federal deadline.

## 11. CVE-2026-87491 — Chrome/Chromium V8 Out-of-Bounds Write (Zero-Day)

**Principle / root cause:** An out-of-bounds write in V8, Chromium's JavaScript/WebAssembly engine, can be triggered by a specially crafted web page. Successful exploitation allows code execution inside the browser's sandbox; combined with a separate sandbox-escape bug, this class of flaw is typically used for full system compromise.

**Mitigation:**
- Update Chrome to 153.0.8010.36/.37 (Windows/macOS) or 153.0.8010.36 (Linux) or later; other Chromium-based browsers should apply the equivalent upstream fix.

**Affected:** Chrome/Chromium prior to the fixed builds above. Confirmed exploited in the wild (Google has not disclosed attacker identity or targets); patched 2026-09-08 alongside five other Critical-rated bugs and numerous High-severity fixes; added to CISA KEV on 2026-09-09.

## 12. CVE-2026-20079 (with CVE-2026-20316) — Cisco Secure Firewall Management Center Auth Bypass to Root RCE

**Principle / root cause:** A system process created at FMC boot time leaves a partial session record in an internal database. If no legitimate user authenticates after boot, this partial session can persist and be escalated into credentials usable by an attacker, who can then invoke a broad set of privileged CGI scripts via crafted HTTP requests to the web interface — resulting in unauthenticated root-level command execution.

**Mitigation:**
- Apply Cisco's fixed FMC software (available since 2026-07-29) immediately if not already applied.
- Given confirmed exploitation by both state-sponsored and financially motivated (ransomware) actors since before the March 2026 initial disclosure, treat unpatched/exposed instances as likely already compromised and conduct incident-response triage, not just patching.

**Affected:** Cisco Secure Firewall Management Center running vulnerable software prior to the July 2026 fixes. First disclosed March 2026 with no known exploitation at the time; Cisco confirmed active exploitation in August 2026; added to CISA KEV on 2026-09-09 alongside the related CVE-2026-20316.
