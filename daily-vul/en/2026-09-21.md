## 1. CVE-2025-39682, CVE-2026-53266, CVE-2025-39964 — Linux Kernel Trio (FCEB Deadline Today)

**Principle / root cause:**
- **CVE-2025-39682** (most severe, CVSS 9.8): an improper-condition check in the kernel's TLS (Transport Layer Security) receive path. A zero-length record retrieved from the internal `rx_list` bypasses the record-type handling that `recvmsg()` is supposed to enforce, letting an attacker desynchronize the kernel's view of TLS record boundaries.
- **CVE-2026-53266** (CVSS 8.8): an out-of-bounds write in the netfilter bridge `ebtables` SNAT (source NAT) target, reachable by a local/namespaced actor able to configure bridge netfilter rules, corrupting kernel memory.
- **CVE-2025-39964** (CVSS 7.8): a race condition in the kernel that allows an attacker to win a timing window and manipulate shared kernel state improperly.

All three are logic/memory-safety defects in widely-deployed kernel subsystems (networking and netfilter) rather than userspace bugs, so successful exploitation can lead to memory corruption, information disclosure, or privilege escalation from within a container or unprivileged process.

**Mitigation:**
- Apply the kernel security updates from your distribution that backport fixes for these three CVEs.
- CISA additionally requires forensic triage (not just patching) for these entries under BOD 26-04 — review affected systems for indicators of prior compromise, not only patch status.
- Restrict who can load netfilter/`ebtables` rules and who can access TLS-consuming services where not already restricted (defense in depth while patching rolls out).

**Affected:** Linux kernel builds prior to the fixed versions shipped by each distribution; CVE-2025-39682 and CVE-2025-39964 carry 2025 CVE identifiers but were only confirmed as exploited and catalogued in September 2026. Added to the CISA KEV catalog on 2026-09-18; the Federal Civilian Executive Branch remediation deadline is 2026-09-21 (today).

## 2. CVE-2026-76460 — Cisco ISE/ISE-PIC Unauthenticated API Authentication Bypass (Zero-Day, CVSS 10.0)

**Principle / root cause:** An API endpoint in Cisco Identity Services Engine (ISE) and ISE Passive Identity Connector (ISE-PIC) suffers from insufficient authentication control. A remote, unauthenticated attacker can send a specially crafted request directly to that API and bypass the web-based management interface entirely, without any valid administrator credentials. Because ISE is a network access control / zero-trust policy engine, a bypass here can cascade into command execution as root on the appliance. The flaw affects ISE/ISE-PIC "regardless of device configuration."

**Mitigation:**
- Upgrade to the fixed ISE/ISE-PIC release for your 3.1–3.5 branch immediately — this was disclosed and patched simultaneously due to active exploitation.
- Where immediate upgrade isn't possible, apply infrastructure access control lists (iACLs) restricting management/API-plane reachability to trusted networks only; treat this as a temporary measure, not a substitute for patching.

**Affected:** Cisco ISE and ISE-PIC, versions 3.1 through 3.5. Publicly disclosed with emergency patches on 2026-09-16 after Cisco confirmed active, unauthenticated exploitation in the wild; added to CISA KEV the same day.

## 3. CVE-2026-76461 — Cisco Secure Email Gateway SQL Injection to Root RCE

**Principle / root cause:** Cisco AsyncOS, which powers Secure Email Gateway appliances, does not sufficiently validate certain data while parsing inbound email messages (CWE-89, SQL injection). Because the gateway parses every message that reaches it as part of normal mail processing, an attacker can embed malicious SQL statements inside an ordinary-looking email; no authentication or administrative access is required. The injected SQL is leveraged to reach operating-system command execution with root privileges on the appliance.

**Mitigation:**
- Apply Cisco's emergency AsyncOS updates (15.5.5-0141, 16.0.4-3021, or 16.5.0-780, as applicable to your branch) immediately — no workaround exists.
- Treat any internet-facing, unpatched Secure Email Gateway as compromised until proven otherwise; review mail-processing logs for anomalous SQL errors or unexpected outbound connections.

**Affected:** Cisco AsyncOS Software for Secure Email Gateway, versions 15.5, 16.0, and 16.5 and earlier, on both physical and virtual appliances. Advisory published 2026-09-14 with confirmed active exploitation; added to CISA KEV the same day (remediation deadline 2026-09-25).

## 4. CVE-2026-88856 & CVE-2026-88857 — OrdaSoft Joomla Gallery Extension (Code Injection + Unrestricted File Upload)

**Principle / root cause:** CVE-2026-88856 is a code-injection flaw (CWE-94): the extension's `updateOSGallery()` function, reachable via `task=update_osgallery`, reads a JSON request body and calls the value of a `method` field as a live PHP function — passing an attacker-controlled `package` field as its argument — with no allow-list or `is_callable()` restriction, meaning any single-argument-compatible PHP function (including command-execution functions) can be invoked. CVE-2026-88857 is an unrestricted file-upload flaw (CWE-434): the `saveWatermark()` function writes an uploaded file into a web-accessible directory using the attacker-supplied filename verbatim, with no extension check, content check, or filename sanitization, letting a script disguised with an image content-type be uploaded and then executed by requesting its path directly. Both require an authenticated user with `core.manage`-level privileges.

**Mitigation:**
- Update the OrdaSoft Joomla Gallery extension to version 6.2.7 or later.
- Restrict `core.manage` privileges to trusted administrators only, and audit recent gallery-management activity for unexpected uploads or update-API calls.

**Affected:** OrdaSoft Joomla Gallery free extension for Joomla, versions prior to 6.2.7. Published 2026-09-20; CVSS 9.4 each; no confirmed in-the-wild exploitation reported yet, but the combination (privileged-only but trivially chainable) makes this a near-term risk for sites with loosely managed contributor accounts.

## 5. CVE-2026-93031 — WP Cloud Plugins (Use-your-Drive / Out-of-the-Box / Share-one-Drive / Lets-Box) Arbitrary File Upload

**Principle / root cause:** These WordPress cloud-storage-integration plugins register their file-import action (`download_file_to_uploads`) for unauthenticated AJAX handling via `wp_ajax_nopriv_`, and the associated `can_import()` capability check is missing. In addition, the imported file's extension and content are never validated against the site's allowed MIME types before being written into the uploads directory. Together, this lets a low-privileged (subscriber-level) or, depending on configuration, unauthenticated actor import an executable file disguised as an ordinary upload, enabling remote code execution.

**Mitigation:**
- Update to the patched version of whichever plugin variant (Use-your-Drive, Out-of-the-Box, Share-one-Drive, or Lets-Box) is installed.
- Audit the uploads directory for unexpected PHP or other executable files, and review recent subscriber-level account activity.

**Affected:** WP Cloud Plugins' Use-your-Drive (Google Drive), Out-of-the-Box (Dropbox), Share-one-Drive (OneDrive), and Lets-Box (Box) WordPress plugins, versions 2.0 through 3.8.3. Disclosed around 2026-09-19; CVSS 8.8.

## 6. CVE-2026-86462, CVE-2026-82311 & CVE-2026-82310 — Apache Airflow FAB Provider Session/Token Invalidation Failures

**Principle / root cause:** Three related logic flaws in the Flask-AppBuilder (FAB) authentication provider used by Apache Airflow mean that revoking a user's access does not actually revoke it. In CVE-2026-86462/CVE-2026-82311, changing a user's password through the admin PATCH endpoint fails to invalidate that user's existing database-backed session cookies — in one variant because the cleanup logic compares a string session identifier against an integer database identifier, so the comparison always fails silently. In CVE-2026-82310, deactivating a user account does not revoke tokens already issued to it, so the Core API continues to accept an existing, unexpired token belonging to a deactivated user. In all three cases, an attacker who already holds a stolen session cookie or token can keep acting as the victim even after an administrator believes access has been cut off.

**Mitigation:**
- Upgrade `apache-airflow-providers-fab` to version 3.9.0 or later.
- After the upgrade, consider force-expiring all existing sessions/tokens as a precaution if credential compromise is suspected, since previously issued sessions may have survived password changes or deactivation under the old logic.

**Affected:** Apache Airflow deployments using `apache-airflow-providers-fab` prior to 3.9.0. Disclosed 2026-09-20/21.

## 7. CVE-2026-87886 — Acronis Backup Plugin Local Privilege Escalation

**Principle / root cause:** Acronis Backup's integrations for cPanel & WHM, Plesk, and DirectAdmin (all on Linux) ship with insecure default file permissions. A local, low-privileged user on the host — including another hosting customer on a shared server — can leverage these permissions to escalate privileges without any user interaction from an administrator. Because these plugins are commonly deployed by hosting providers and MSPs, a single vulnerable server can expose many downstream customers to cross-tenant impact.

**Mitigation:**
- Update to Acronis Backup plugin for cPanel & WHM (Linux) build 1.9.3.1021+, Acronis Backup extension for Plesk (Linux) build 1.8.11.638+, or Acronis Backup plugin for DirectAdmin (Linux) build 1.2.3.238+, as applicable.
- Hosting providers should audit shared servers for signs of unauthorized privilege escalation since active exploitation was confirmed.

**Affected:** Acronis Backup plugin/extension for cPanel & WHM, Plesk, and DirectAdmin on Linux, versions prior to the builds above. Acronis confirmed active exploitation against cPanel & WHM deployments; added to CISA KEV on 2026-09-16 (FCEB deadline was 2026-09-19).

## 8. CVE-2026-85046 — Google Chrome V8 Type Confusion (Continuity Note)

**Principle / root cause:** A type-confusion bug in V8, Chrome's JavaScript/WebAssembly engine, allowed an attacker-controlled web page to corrupt memory and potentially achieve code execution in the renderer process. Google confirmed the flaw was exploited in the wild before a patch was available (Chrome's sixth zero-day of 2026).

**Mitigation:** Ensure Chrome is updated to 152.0.7977.82/.83 or later (auto-update should have applied this by now).

**Affected:** Chrome versions prior to 152.0.7977.82. Originally disclosed 2026-09-03/04; included here because its CISA KEV remediation deadline fell within this week's window, on 2026-09-18.

## 9. CVE-2026-75650 "StyleSmuggler" — Adobe Commerce / Magento Template Injection RCE (Continuity Note)

**Principle / root cause:** Magento's template engine treats CSS "style" properties as harmless layout data and does not run them through the same safeguards as other template input. An attacker can smuggle a malicious payload through a style property so that it survives into the dependency-injection machinery, which can then be steered into executing attacker-supplied PHP — triggered when the platform renders a transactional email template such as the "Payment Transaction Failed Reminder" notice.

**Mitigation:** Apply Hotfix VULN-39341 / bulletin APSB26-146 if not already applied; this remains an active target for backdoor and web-shell deployment.

**Affected:** Adobe Commerce, Adobe Commerce B2B, and Magento Open Source, versions 2.4.4 through 2.4.9. Active exploitation began 2026-09-04, with public proof-of-concept research reproductions circulating since 2026-09-08; included here as continuity since exploitation and mitigation efforts remain ongoing into this week.
