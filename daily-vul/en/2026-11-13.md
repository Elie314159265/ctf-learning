## Newest items (last 24–48 hours)

### 1. CVE-2026-123039 — Check Point Gaia OS DynamicCLI Local Privilege Escalation (chained with PHP2Shell)

**Principle / root cause:** The Gaia OS DynamicCLI service exposes a local socket that accepts command requests. It does not properly restrict which local callers can submit requests, so a low-privileged local process can have commands run as root. Attackers chained it with the "PHP2Shell" flaws (CVE-2026-109618 / CVE-2026-109619, CVSS 9.2) in the Mobile Access web portal. PHP2Shell gives initial code execution as the portal service account, and CVE-2026-123039 then escalates that to root on the gateway.

**Observed activity:** Check Point Research reports scanning and exploitation starting 2026-10-30, first against Israeli organizations and from 2026-11-02 against organizations in several countries. Post-exploitation included webshells, a backdoor reported as "TSGA", and in some cases a wiper aimed at VMware ESXi hosts. Check Point counts a few dozen affected customers.

**Mitigation:**
- Install the November 2026 Jumbo Hotfix Accumulator on all Management Servers and Security Gateways. Reported fixed takes: R82.20 Take 14, R82.10 Take 52, R82 Take 132, R81.20 Take 174 (or later). Start with gateways that have internet-facing Mobile Access portals.
- If you cannot patch at once, Check Point advises stopping the `dynamic_server` process and keeping it from restarting.
- The standalone PHP2Shell hotfix has been available since 2026-10-23. Gateways that stayed unpatched with Mobile Access exposed should be treated as possibly compromised: hunt for webshells and unknown persistence, and check connected ESXi infrastructure.

**Affected:** Check Point Quantum Security Gateways / Gaia OS. PHP2Shell affects R80 through R82.20. Disclosed and patched in early November 2026; added to CISA KEV on 2026-11-13.

### 2. CVE-2026-114713 — UnrealIRCd labeled-response Injection

**Principle / root cause:** The `labeled-response` module echoes the client-supplied IRCv3 `label` message tag back into server replies without escaping it. On networks with two or more linked servers, an ordinary user can therefore inject content that linked servers read as server-to-server protocol commands. Those commands run with server authority, so the user can act with IRCOp/server privileges (for example, disconnecting other users).

**Mitigation:**
- Upgrade to UnrealIRCd 6.2.7.1, or apply the vendor's no-restart hot-patch. The same release fixes eight other security issues.
- UnrealIRCd 5 (EOL since 2023) is reportedly also affected. Blacklist the `labeled-response` module, restart, and migrate to version 6.

**Affected:** UnrealIRCd 6.0.0 through 6.2.7. The vendor rates it Critical; scores of 7.3 and 8.6 both circulate. Active exploitation confirmed by the project; added to CISA KEV on 2026-11-13.

### 3. CVE-2026-119618 — Apache HTTP Server mod_http2 Race Condition (potential RCE)

**Principle / root cause:** A race condition in the HTTP/2 implementation (mod_http2) lets concurrent stream handling on one connection corrupt heap memory. Heap corruption in a network-facing server can lead to remote code execution by an unauthenticated client. Only servers with HTTP/2 enabled (`h2` in the `Protocols` directive) are exposed. The flaw was found by Anthropic's OSS scanning and confirmed by Google Cloud's vulnerability research team.

**Mitigation:**
- Upgrade to Apache HTTP Server 2.4.71 (released 2026-11-11) or your distribution's patched package. Some distributions (for example Debian stable branches and Amazon Linux) were still rolling out fixes at time of writing.
- Until you can patch, disable HTTP/2 by removing `h2`/`h2c` from `Protocols`. Apache's advisory lists no other workaround.
- The standalone `mod_h2` GitHub module (2.0.8–2.0.42) has no fixed release and its repository is archived. Move to the module bundled with httpd 2.4.71.

**Affected:** Apache httpd 2.4.55 through 2.4.70 with mod_http2 enabled, and standalone mod_h2 2.0.8–2.0.42. No confirmed in-the-wild exploitation. Reports conflict on whether public research shows only memory corruption or more.

### 4. CVE-2026-126325 — PTC Windchill / FlexPLM Deserialization RCE

**Principle / root cause:** The applications deserialize untrusted data supplied by a remote client without enough validation (CWE-502 / CWE-20). Unsafe deserialization lets attacker-chosen object graphs trigger code paths during reconstruction, which can lead to remote code execution on the PLM server.

**Mitigation:**
- Apply the patches in PTC's advisory (knowledge-base articles CS473270 / CS483249 are cited).
- Restrict network access to Windchill/FlexPLM servers to trusted users and networks. Do not expose them to the internet.

**Affected:** Windchill 11.0 M030, 11.1 M020, 11.2.1.0, 12.0.2.0, 12.1.2.0, 13.0.2.0, 13.1.0.0–13.1.4.0. FlexPLM, same series up to 13.1.3.0. Sources disagree on the upper bounds. Disclosed 2026-11-12. Not known to be exploited and not in CISA KEV. Don't confuse it with an earlier, separately exploited Windchill/FlexPLM deserialization zero-day.

### 5. CVE-2026-116606 & CVE-2026-111560 — Barracuda Appliances Auth Bypass + Command Injection

**Principle / root cause:** CVE-2026-116606 is a pre-authentication authorization bypass in Barracuda Email Security Gateway (ESG): a remote unauthenticated request can reach functions meant for authenticated administrators. CVE-2026-111560 is an OS command-injection flaw in which input reaching a privileged function is passed to a system shell without proper neutralization. Chained, the two give an unauthenticated attacker root on the appliance.

**Mitigation:**
- Update ESG to 9.4.0.030 or later. For CVE-2026-111560 on ADC, BMA, WAF, WSG and WCC, apply the fixes in Barracuda's advisory. Secondary sources did not list fixed versions for these.
- Barracuda reports exploitation at a small number of organizations (advisory updated 2026-11-09). Check exposed appliances for signs of compromise.

**Affected:** Barracuda ESG before 9.4.0.030 (both CVEs). CVE-2026-111560 also affects Barracuda ADC, Message Archiver (BMA), WAF, Web Security Gateway (WSG) and WCC. Added to CISA KEV 2026-11-10 with a federal deadline of 2026-11-13 (today).

## Other notable items from this week

### 6. CVE-2026-124194 — Microsoft Outlook Spoofing / NTLM Hash Disclosure (Zero-Day)

**Principle / root cause:** When a specially crafted message file is opened, Outlook connects to an attacker-controlled remote location without showing the normal external-content warning. During that connection Windows sends the user's NTLMv2 authentication hash, which the attacker can capture for offline cracking or relay. The victim must open the file; the Preview Pane is not an attack vector.

**Mitigation:**
- Install the November 2026 (2026-11-10) Outlook/Office security updates.
- Defense in depth: block outbound SMB (TCP 445) and NTLM to the internet, enforce SMB signing and NTLM relay protections, and consider adding high-value users to the Protected Users group.

**Affected:** Supported Microsoft Outlook / Microsoft 365 Apps / Office versions listed in MSRC for this CVE. Actively exploited; CISA KEV due date 2026-11-24.

### 7. CVE-2026-125350 — Google Chrome XML Use-After-Free (Zero-Day)

**Principle / root cause:** A use-after-free in Chrome's XML handling: memory is freed and then still referenced, so a crafted web page can corrupt memory and run code inside the renderer sandbox.

**Mitigation:** Update Chrome to 157.0.8103.50/.51 (Windows/macOS) or 157.0.8103.50 (Linux) or later, and relaunch the browser. Update other Chromium-based browsers when their vendors ship the fix.

**Affected:** Chrome before 157.0.8103.50. Reported 2026-11-06, patched 2026-11-09, CISA KEV 2026-11-10. The 8th exploited Chrome zero-day of 2026.

### 8. CVE-2026-20320 — Cisco BroadWorks XML External Entity (XXE)

**Principle / root cause:** The Open Client Interface – Provisioning (OCI-P) service parses XML without disabling external entity resolution. An unauthenticated remote attacker can make the parser load external entities and read sensitive configuration with the privileges of the BroadWorks user.

**Mitigation:** Upgrade to BroadWorks release RI.2026.07 (fix available since 2026-08-19). Cisco lists no workaround. Restrict OCI-P exposure to trusted provisioning systems.

**Affected:** Cisco BroadWorks before RI.2026.07. Added to CISA KEV 2026-11-10 (deadline 2026-11-24). Researchers attribute exploitation to a threat actor targeting telecom providers; the attribution is unconfirmed by Cisco or CISA.

### 9. CVE-2026-111793 — Openwave Messaging Webtop Media Transcoder Restriction Bypass

**Principle / root cause:** The media transcoder does not enforce restrictions on which document types it processes. Authenticated users can submit unintended file types that the component then handles.

**Mitigation:** Upgrade to Media Transcoder 1.1.22.0 or later. Openwave recommends the latest supported Media Server 2.0 release.

**Affected:** Versions below 1.1.22.0. CISA KEV 2026-11-10 (deadline 2026-11-24).

### 10. Microsoft November 2026 Patch Tuesday — Critical Non-Exploited Items

### 11. CVE-2026-123158 — OpenSSH "SSHole" Password Authentication Bypass (musl / Alpine)

**Principle / root cause:** On Linux systems that use musl libc and build OpenSSH without PAM (mainly Alpine Linux), the password-check path mishandles some unusual password inputs. Reportedly, the way musl's password-hashing functions handle errors means sshd can treat a failed comparison as success, so a remote attacker can log in to some accounts without the correct password. glibc-based distributions (Debian, Ubuntu, RHEL, Fedora) are not named as affected.

**Mitigation:**
- Upgrade to OpenSSH 10.6p2 (released 2026-11-05) or Alpine's backported packages: edge 10.6_p2-r0, 3.24 10.3_p1-r2, 3.23 10.2_p1-r1, 3.22 10.0_p1-r11, 3.21 9.9_p2-r1, 3.20 9.7_p1-r6. Check the package revision, not the SSH version banner, which stays the same after a backport.
- Interim: set `PasswordAuthentication no` (and consider disabling keyboard-interactive auth), then restart sshd.
- Check container images and embedded devices built on Alpine/musl.

**Affected:** OpenSSH before 10.6p2 on musl-based systems without PAM. CVSS 8.1. CISA KEV 2026-11-09 (federal deadline 2026-11-12).

### 12. CVE-2026-102895 — GPUStack Authentication Bypass

**Principle / root cause:** An authentication check in the GPUStack management API can be bypassed, giving remote attackers administrator privileges over the GPU cluster and the model-serving platform.
**Mitigation:** Upgrade to GPUStack 2.2.0 or later. Do not expose the management interface to the internet.
**Affected:** GPUStack before 2.2.0 (exploitation seen against 2.1.1). CISA KEV 2026-11-09.

### 13. CVE-2026-116779 — SignalWire FreeSWITCH Code Injection

**Principle / root cause:** Input reaching a FreeSWITCH command or scripting interface is not sanitized, so any authenticated account (for example, a SIP user) can inject code. The impact is arbitrary code execution, credential exposure and call control.
**Mitigation:** Upgrade to FreeSWITCH 1.11.3 or later. Review SIP account credentials and restrict who can register.
**Affected:** FreeSWITCH before 1.11.3. CISA KEV 2026-11-09.

### 14. CVE-2026-123218 — IBM Aspera Faspex Authorization Bypass

**Principle / root cause:** Missing or incorrect authorization checks let an attacker reach administrative functions and gain admin privileges in the file-transfer platform.
**Mitigation:** Upgrade to Aspera Faspex 5.0.19 PL1 or later.
**Affected:** Aspera Faspex 5.0.0 through 5.0.19. CISA KEV 2026-11-09. One aggregator lists it as not exploited, which conflicts with the KEV listing.

### 15. CVE-2026-19868 — SonicWall SonicOS SSLVPN SAML / MFA Bypass

**Principle / root cause:** SSLVPN is configured to require SAML (which may enforce MFA), but someone with valid credentials for a different authentication method can still log in, skipping the SAML/MFA step (CWE-308, single-factor authentication).
**Mitigation:** Upgrade to SonicOS 7.3.4-7013 (Gen7) or 8.2.3-8015 (Gen8). SonicWall lists no workaround. Rotate VPN credentials and review VPN login logs.
**Affected:** SonicOS Gen7 7.3.3-7015 and older, and Gen8 8.2.2-8015 and older, when SAML is enabled for SSLVPN logins. CISA KEV 2026-11-06 (deadline 2026-11-20).
