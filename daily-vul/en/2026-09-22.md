## 1. CVE-2026-85102 & CVE-2026-93616 — Check Point Quantum Security Gateway and Management Server Chained Pre-Auth RCE

**Principle / root cause:** CVE-2026-85102 is an improper certificate-trust-validation flaw in the Security Gateway's VPN certificate handling, allowing an unauthenticated attacker to reach code execution through the VPN certificate path. CVE-2026-93616 is a pre-authentication path-traversal flaw in the Check Point Management web service: directory traversal combined with unsafe file-upload handling lets an unauthenticated attacker cause the service to execute a script from an arbitrary location and load an arbitrary Java class. Both flaws let attackers skip authentication entirely on internet-facing gateway or management infrastructure.

**Mitigation:**
- Apply Check Point's hotfixes for both CVEs immediately (see support article sk1000171); CVE-2026-85102 fixes were released 2026-09-09, and a hotfix for CVE-2026-93616 followed once exploitation was confirmed.
- Restrict management-interface exposure to trusted networks only, and review logs for exploitation dating back to 2026-07-23 (CVE-2026-93616 was abused as a zero-day before a fix existed).

**Affected:** Security Gateway (CVE-2026-85102) and Security Management Server, Multi-Domain Security Management Server, Log Server, Multi-Domain Log Server, and SmartEvent (CVE-2026-93616) — versions through R82.20, R82.10 JHF Take 44, R82 Take 126, R81.20 Take 166, and earlier (R80.x/R81 lines also affected). Exploitation observed against Check Point Spark customers and in pinpointed targeted attacks; both CVEs added to CISA KEV on 2026-09-22 with a federal remediation deadline of 2026-09-25.

## 2. CVE-2026-93952 — Arista VeloCloud Orchestrator (VCO) Unauthenticated Privileged Access (CVSS 10.0)

**Principle / root cause:** An improper input-validation flaw (CWE-20) in on-premises VeloCloud Orchestrator lets a remote attacker with no login credentials reach privileged internal functionality on the VCO host, compromising confidentiality, integrity, and availability of the orchestrator and the data it manages. Exposure is specific to deployments where Edge devices authenticate to the Orchestrator using certificates (Certificate Acquire / Certificate Required modes) rather than a pre-shared key.

**Mitigation:**
- Upgrade to the fixed releases on the 5.2 and 6.4 trains immediately; fixes for the 6.1 and 7.0 trains were still pending as of 2026-09-22 — apply vendor-recommended interim mitigations for those trains.
- Arista's Hosted and Dedicated VCO offerings have already been patched by the vendor.
- If certificate-based Edge authentication cannot be immediately remediated, restrict management-plane network exposure as a stop-gap.

**Affected:** On-premises VeloCloud Orchestrator with certificate-based Edge authentication configured. Discovered through external reporting and confirmed under active exploitation; disclosed and added to CISA KEV on 2026-09-22, with a federal remediation deadline of 2026-09-25. No public PoC confirmed at time of writing.

## 3. CVE-2026-94127 — F5 BIG-IP APM Heap-Based Buffer Overflow to Unauthenticated RCE

**Principle / root cause:** A heap-based buffer overflow (CWE-122) inside the Traffic Management Microkernel's data plane is triggered by specially crafted traffic sent to a virtual server that has both an Access Policy Manager (APM) access policy and an OAuth profile attached. Because the flaw sits in packet/traffic processing rather than authentication logic, an attacker needs no valid credentials to corrupt heap memory and achieve remote code execution. Only the data plane is affected (not the control plane), and Appliance Mode deployments are included.

**Mitigation:**
- Install F5's engineering hotfixes for the affected BIG-IP APM branches immediately.
- Where an immediate hotfix cannot be applied, use F5's published iRule as a temporary mitigation on affected virtual servers.

**Affected:** BIG-IP APM 21.1.0, 17.5.x, and 17.1.x branches lacking the relevant hotfix, on virtual servers combining an APM access policy with an OAuth profile. Actively exploited; added to CISA KEV on 2026-09-22 alongside the Check Point and Arista entries above, with a federal remediation deadline of 2026-09-25.

## 4. CVE-2026-7273 — Zyxel GS1900 Series Switches Stack-Based Buffer Overflow (Mass Compromise)

**Principle / root cause:** The CGI program handling the switch's web management interface fails to bound-check attacker-supplied input, allowing a specially crafted HTTP request from an unauthenticated, LAN-adjacent attacker to overflow a stack buffer and execute arbitrary operating-system commands on the device.

**Mitigation:**
- Update to the patched firmware for your specific GS1900 model (fixes were released 2026-06-16; e.g., GS1900-48HPv2 → 2.90(ABTQ.2)C0, GS1900-10HP → 2.90(AAZI.2)C0, GS1900-16 → 2.90(AAHJ.2)C0, GS1900-24 → 2.90(AAHL.2)C0).
- Rotate all device credentials (the attack exfiltrates hashed root-level credentials), and remove the management interface from direct internet/WAN exposure.

**Affected:** Zyxel GS1900 series switches running firmware 2.90(XXXX.1)C0 or earlier. A suspected Chinese-speaking threat actor has exploited this flaw since 2026-08-17, compromising and exfiltrating configuration/credential data from nearly 1,000 switches across 48 countries. Added to CISA KEV on 2026-09-21; federal remediation deadline 2026-09-24.

## 5. CVE-2026-32996 — Veeam Agent for Microsoft Windows Local Privilege Escalation

**Principle / root cause:** The Veeam Endpoint Backup service exposes a local gRPC named pipe (`\\.\pipe\Veeam\VAW\ServiceConnectionPipe`) that handles privileged client operations. The service associates an elevated, administrator-level identity with a client-supplied session UID without securely binding that UID to the actual requesting process or pipe connection, letting a low-privileged local user impersonate a privileged session and run commands as NT AUTHORITY\SYSTEM.

**Mitigation:**
- Upgrade Veeam Backup & Replication to 13.0.2.29 or later, which also updates the Veeam Agent for Windows to build 13.0.3.1220 containing the fix.

**Affected:** Veeam Agent for Microsoft Windows 13.0.1.2067 and earlier 13.x builds. Technical details and exploit code were publicly released 2026-09-14; active exploitation for local privilege escalation on already-compromised or multi-tenant Windows hosts has since been observed.

## 6. CVE-2025-39964 & CVE-2026-53266 — Linux Kernel Flaws Under Active Exploitation

**Principle / root cause:** CVE-2025-39964 is a race condition in the kernel's AF_ALG cryptographic socket interface — concurrent writes to a socket can corrupt per-socket state, potentially crashing the system or silently altering cryptographic results. CVE-2026-53266 is an out-of-bounds write in the kernel's `ebtables` SNAT (source NAT) implementation, where an ARP address rewrite can modify shared, file-backed memory pages without first verifying that memory range is writable — memory corruption that can be leveraged for privilege escalation or denial of service.

**Mitigation:**
- Apply the distribution kernel updates that include these fixes as soon as available; Red Hat and other vendors have confirmed active exploitation, so prioritize systems with untrusted local users or exposed cryptographic/netfilter functionality.

**Affected:** Linux kernel versions prior to the patched releases across major distributions. Added to CISA KEV on 2026-09-18 with a federal remediation deadline of 2026-09-21 (already passed as of this report).

## 7. CVE-2026-58704 — Google Pixel Cellular Modem Zero-Click Privilege Escalation

**Principle / root cause:** A logic error in the Pixel's cellular modem component causes a permission check to be bypassed, allowing a nearby (proximal/adjacent) attacker to escalate privileges on the device without any additional execution privileges and, critically, without any user interaction — a zero-click attack at the modem/baseband level.

**Mitigation:**
- Install the Pixel security update that shipped 2026-09-15; no user action beyond applying the update is required.

**Affected:** Google Pixel devices with the vulnerable modem component, prior to the September 2026 security update. Google reports "limited, targeted exploitation" consistent with commercial-spyware or state-sponsored tradecraft; CISA added the flaw to its KEV catalog and gave federal agencies a 3-day remediation window.

## 8. CVE-2026-86059 — Dokploy Credential and Secret Disclosure via Missing Authorization Checks

**Principle / root cause:** Several "protected" tRPC procedures (`github.one`, `gitlab.one`, `gitea.one`, `bitbucket.one`) return full Git-provider records — including plaintext credentials — without applying the `getAccessibleGitProviderIds` scoping check or verifying organization membership, so any authenticated organization member (even without Git-provider access) can retrieve another provider's secrets. Separately, the `application.one` route returns nested provider relations containing private keys, OAuth tokens, client secrets, and app passwords, letting a member with only application read-access bypass intended provider-assignment restrictions.

**Mitigation:**
- Upgrade to Dokploy 0.29.13 or later, which fixes both missing-authorization paths.
- Rotate any Git-provider credentials (OAuth tokens, client secrets, app passwords, private keys) stored in an affected Dokploy instance, since they may already have been exposed to over-privileged organization members.

**Affected:** Dokploy platform-as-a-service deployments prior to 0.29.13. Publicly disclosed 2026-09-22 via GitHub Security Advisory; no confirmed public exploit code or in-the-wild exploitation at time of writing, but the flaw directly exposes credentials for connected source-code and CI/CD systems.

## 9. CVE-2026-81963 & CVE-2026-85880 — Windows Update Stack / ALPC Local Privilege Escalation (Continuity — Federal Deadline Today)

**Principle / root cause:** CVE-2026-81963 is an elevation-of-privilege flaw in the Windows Update Stack, and CVE-2026-85880 is a heap buffer overflow in the Windows Advanced Local Procedure Call (ALPC) subsystem. Both allow a local attacker with only low privileges to escalate to SYSTEM with no user interaction required, and both were confirmed exploited in the wild before Microsoft's fixes shipped.

**Mitigation:** Apply Microsoft's September 2026 cumulative updates (released 2026-09-08) if not already installed.

**Affected:** CVE-2026-81963 affects current Windows 11 releases and Windows Server 2025; CVE-2026-85880 affects older Windows 10 and Windows Server branches. Part of Microsoft's record-setting ~970-CVE September Patch Tuesday. Both added to CISA KEV on 2026-09-08 with the federal remediation deadline falling today, 2026-09-22 — included here for that reason even though initial disclosure predates this week's window.

## 10. CVE-2026-85046 — Google Chrome / V8 Type Confusion (Continuity Note)

Already patched earlier this month (Stable Channel update, 2026-09-03): a type-confusion bug in Chrome's V8 JavaScript/WebAssembly engine that can be triggered via a crafted web page to achieve arbitrary code execution inside the renderer sandbox. It is the sixth actively exploited Chrome zero-day Google has patched in 2026. Its CISA KEV remediation deadline of 2026-09-18 fell within this report's coverage window, which is why it is noted here.

**Mitigation:** Confirm Chrome is updated to 152.0.7977.82/.83 (Windows/macOS) or 152.0.7977.82 (Linux) or later.

**Affected:** Chrome versions prior to the fixed builds above, and Chromium-based browsers that have not incorporated the equivalent V8 fix.

## 11. CVE-2026-78006 & CVE-2026-78159 — The Events Calendar (WordPress Plugin) Unauthenticated Takeover Chains

**Principle / root cause:** Two independent vulnerability chains in the plugin's widget-rendering functionality allow an unauthenticated visitor — with no login, registration, or user interaction required — to reach code paths that can lead to remote code execution and administrator-account takeover, from which malware deployment, site defacement, data theft, and server compromise can follow.

**Mitigation:**
- Update to The Events Calendar version 6.17.4.1 or later, which contains fixes for both reported chains.
- Free-tier Wordfence firewall rule coverage for these issues began rolling out 2026-09-21 for sites that have not yet updated.

**Affected:** The Events Calendar WordPress plugin, versions prior to 6.17.4.1 (600,000+ active installations). Vulnerabilities were reported to the vendor on 2026-08-21/22, acknowledged 2026-08-24, and patched shortly after; no confirmed in-the-wild exploitation as of this report, but the pre-auth nature of the chains makes prompt patching important.
