## 1. CVE-2026-107406 — Citrix NetScaler ADC / Gateway (SAML configurations)

**Principle / root cause:** A flaw in NetScaler's handling of SAML authentication traffic that, under specific configurations, can lead to remote code execution or denial of service. Vendor-level root-cause detail was not available in the sources reviewed (it is described as a memory-handling class issue in the same SAML code path as #2).

**Mitigation:**
- Upgrade to fixed builds: 14.1-73.46 or later (14.1), 13.1-64.29 or later (13.1), 14.1-73.46 FIPS (14.1-FIPS), 13.1.37.283 or later (13.1-FIPS / 13.1-NDcPP).
- Check exposure: appliances are affected only if configured as a SAML Service Provider or Identity Provider (look for `add authentication samlAction` / `samlIdPProfile` in the configuration).
- Citrix reports no evidence of exploitation as of the advisory; no separate workaround was identified.

**Affected:** NetScaler ADC and NetScaler Gateway 14.1 and 13.1 lines (including FIPS / NDcPP builds) prior to the fixed builds, with SAML SP/IdP configured. Disclosed around 2026-10-09 (CISA's Citrix alert was updated that day).

## 2. CVE-2026-88779 — Citrix NetScaler ADC / Gateway SAML Memory-Buffer Flaw (Exploited)

**Principle / root cause:** A memory-buffer handling flaw in the SAML SP/IdP processing path that can independently cause denial of service on affected appliances. Part of the broader set of NetScaler zero-day issues CISA flagged on 2026-09-27.

**Mitigation:**
- Upgrade to 14.1-73.41 or 13.1-64.28 (or later); FIPS: 14.1-73.41 FIPS; 13.1-FIPS / NDcPP: 13.1-37.282 or later.
- Citrix also provides Global Deny Lists for known malicious IPs as a supplementary control.
- US federal agencies were required to remediate per the CISA KEV process.

**Affected:** NetScaler ADC / Gateway prior to 13.1-37.282 (FIPS/NDcPP), 13.1-64.28, 14.1-73.41, and 14.1-73.41 FIPS, with SAML configured. Added to CISA KEV 2026-10-04; actively exploited. (Note: one outlet printed the ID as "CVE-2026-8877", which appears to be a typo.)

## 3. CVE-2026-102489 & CVE-2026-102490 — Zammad Helpdesk Session Fixation and Privilege Escalation (Exploited)

**Principle / root cause:** CVE-2026-102489 is a session-handling (session fixation / hijack) weakness that can lead to code execution as the application user. CVE-2026-102490 is an improper privilege management flaw allowing local escalation from that application user to root. Chained, they give an attacker full host compromise.

**Mitigation:**
- Upgrade to Zammad 7.2.0 (reported to include the hardening); sources conflict on whether this fully fixes CVE-2026-102490 and no formal vendor advisory was found as of 2026-10-05.
- DIVD's guidance reportedly: move to version 7 or take the instance offline; restrict network exposure; run Zammad under least privilege and monitor for unexpected privileged processes.
- Zammad GmbH publicly disputes parts of the affected-version and exploitability assessment — follow the vendor's release notes.

**Affected:** CVE-2026-102489: Zammad 6.3.0–6.5.4 (7.0.0–7.1.3 reportedly present but not exploitable per vendor). CVE-2026-102490: reported as 1.5.0 through 7.1.0-alpha (CVE description broader). Both added to CISA KEV on 2026-10-02.

## 4. CVE-2026-104286 — Fortinet FortiMail Path Traversal / Arbitrary File Write (Zero-Day)

**Principle / root cause:** Improper validation of file paths in request handling lets an unauthenticated remote party cause files to be written to arbitrary locations on the appliance (path traversal, CWE-22), which can lead to code execution or persistence.

**Mitigation:**
- Apply Fortinet's fixed releases per advisory published 2026-10-01 (upgrade out of all affected branches).
- Restrict management/web interfaces from the internet; review appliances for unexpected files or configuration changes; treat unpatched exposed devices as potentially compromised.

**Affected:** FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9. Disclosed 2026-10-01; exploited in the wild; added to CISA KEV 2026-10-01 (federal deadline 2026-10-04).
