## 1. CVE-2026-83548 & CVE-2026-83549 — SonicWall SMA1000 Chained SSRF + Command Injection (Zero-Day)

**Principle / root cause:** CVE-2026-83548 is a pre-authentication server-side request forgery (SSRF) in the SMA1000 "Work Place" web interface: a remote, unauthenticated request can reach internal functionality that was never meant to be directly reachable. CVE-2026-83549 is an OS command-injection flaw in the Appliance Management Console that, used alone, requires an authenticated administrator. Chained together, the SSRF is used to indirectly reach and trigger the command-injection path, giving an unauthenticated attacker remote code execution on the appliance.

**Mitigation:**
- Apply SonicWall's hotfixes immediately: 12.4.3-03526, 12.5.0-02952, or later.
- Treat any unpatched, internet-facing SMA1000 appliance as a priority-1 incident; SonicWall and CISA both flag this for immediate action.

**Affected:** SonicWall SMA1000 series appliances (6210, 7210, 8200v). Disclosed via SonicWall advisory SNWLID-2026-0016 on 2026-09-01; actively exploited in the wild as a zero-day; added to CISA KEV on 2026-09-02.

## 2. CVE-2026-9586 — Sangoma Switchvox Unauthenticated SQL Injection to RCE

**Principle / root cause:** An unauthenticated web endpoint (`/pa`) parses XML request bodies and inserts a user-controlled `PhoneIP` field directly into backend PostgreSQL queries without sanitization or parameterization (SQL injection, CWE-89). The injected SQL runs with PostgreSQL superuser privileges, which is further leveraged to execute operating-system commands on the host.

**Mitigation:**
- Upgrade to Switchvox 8.4.0.2 or later — the fix has been available since 2026-07-14, but adoption has been slow.
- Restrict network exposure of the Switchvox management interface; monitor for unexpected reverse-shell or process-enumeration activity.

**Affected:** Switchvox SMB Edition 8.3 (build 104997) and earlier. Mass exploitation began 2026-08-30 (attackers deploying reverse shells); added to CISA KEV on 2026-09-02. An estimated ~4,000 internet-exposed instances remained unpatched at the time exploitation began.

## 3. CVE-2026-49869 — Kestra OSS Unauthenticated Command Injection

**Principle / root cause:** Kestra's authentication filter checks whether a request path *ends with* `/configs` rather than matching it exactly, allowing a crafted request path to bypass the authentication filter and reach the flow-creation API without credentials. A malicious workflow definition can then invoke default script-execution plugins, resulting in code execution — with root privileges inside the worker container.

**Mitigation:**
- Upgrade to Kestra 1.0.45 or 1.3.21 (or later).
- Restrict network exposure of the Kestra API to trusted networks until patched.

**Affected:** Kestra OSS workflow-orchestration platform, versions prior to the fixed releases. Actively exploited; added to CISA KEV on 2026-09-02.

## 4. CVE-2026-59822 — BerriAI LiteLLM MCP Authentication Bypass

**Principle / root cause:** LiteLLM's MCP (Model Context Protocol) Streamable HTTP endpoint accepts a fabricated `Authorization` header. A failed key-validation check falls back to an "OAuth2 passthrough" code path that substitutes an empty/anonymous authentication object instead of rejecting the request — allowing unauthenticated callers to reach MCP tooling and, through it, any backend services those tools are wired to.

**Mitigation:**
- Upgrade LiteLLM to version 1.84.0 or later.
- Audit MCP tool-invocation logs for unauthenticated or anomalous sessions.

**Affected:** LiteLLM AI gateway deployments prior to 1.84.0. Actively exploited; added to CISA KEV on 2026-09-02. Notable as an actively-exploited flaw in AI-infrastructure tooling specifically.

## 5. CVE-2026-48710 — Starlette (Python ASGI Framework) Request/Response Smuggling

**Principle / root cause:** Starlette reconstructs `request.url` from the raw `Host` header without validating it against the path the request was actually routed on. Because low-level routing uses the real HTTP path while application code often trusts the reconstructed `request.url.path`, a malformed `Host` header can desynchronize the two views of the request — enabling request smuggling and, in applications that gate access based on the reconstructed URL, authentication bypass.

**Mitigation:**
- Upgrade Starlette to version 1.0.1 or later.
- Validate and normalize `Host` headers at the reverse-proxy/edge layer as defense in depth.

**Affected:** Applications built on Starlette prior to 1.0.1 (including many FastAPI deployments, which use Starlette internally — confirm your pinned Starlette version). Actively exploited despite the moderate CVSS; added to CISA KEV on 2026-09-02.

## 6. CVE-2026-20212 — Cisco Nexus 9000 Unauthenticated Root RCE

**Principle / root cause:** On Nexus 9000 switches using a Silicon One ASIC, an internal service binds to an unrestricted IP address, leaving TCP ports 43210/43211 reachable within the default L3 VRF. No credentials are required to reach the service; specially crafted input sent to it is processed with root privileges, and the same exposure can also be used to crash the underlying process and force a device reload (denial of service).

**Mitigation:**
- Upgrade to the NX-OS release fixed in Cisco advisory cisco-sa-n9k-s1-rce-EH8dEtr.
- Interim mitigation: apply infrastructure ACLs (iACLs) denying inbound TCP to ports 43210/43211 on switch management addresses.

**Affected:** Nexus 9000 switches with a Silicon One ASIC, prior to the fixed NX-OS release. Disclosed 2026-09-02; Cisco PSIRT reports no known public exploitation yet — patch proactively.

## 7. CVE-2026-62911 — Microsoft Exchange Server Authentication Bypass by Capture-Replay

**Principle / root cause:** An internet-reachable MRSProxy endpoint fails to enforce Extended Protection for Authentication (CWE-294, authentication bypass by capture-replay). An attacker able to capture NTLM authentication material associated with the Exchange machine account (e.g., via a relay or coercion technique) can replay that material against Exchange and be treated as an already-authenticated, elevated identity.

**Mitigation:**
- Apply Microsoft's fix, delivered via recent cumulative updates for the affected Exchange versions.
- Enable Extended Protection for Authentication, and restrict internet exposure of MRSProxy/EWS-related endpoints.

**Affected:** Exchange Server 2016 CU23, Exchange Server 2019 CU14/CU15, Exchange Server Subscription Edition RTM. Public exploit code exists and mass internet scanning is underway; roughly 21,900 unique IPs were flagged as still vulnerable/exposed as of 2026-08-31. Not yet confirmed in CISA KEV at time of writing, but high risk of imminent addition — treat as urgent. (CVSS vector corroborated via secondary sources; confirm against Microsoft's own advisory where possible.)

**Affected:** Self-hosted JFrog Artifactory prior to 7.161.20 (SaaS/cloud-hosted Artifactory is not affected). Already listed in CISA KEV.

## 9. CVE-2026-19949 — All-in-One WP Migration and Backup (WordPress Plugin) Second-Order SQL Injection

**Principle / root cause:** The plugin's archive-restoration logic incorrectly parses escaped backslashes and quotation marks when rewriting database content during a site export/import. An unauthenticated attacker can plant crafted data via WordPress trackbacks that lies dormant until an administrator performs a routine export/import; at that point the injected SQL can expose the plugin's secret import key through a public comment. That key then lets the attacker import a malicious `.wpress` archive containing executable code, resulting in full site takeover — a second-order (stored, delayed-trigger) SQL injection chain.

**Mitigation:**
- Update to version 7.110 or later immediately.
- Sites that cannot update promptly should disable trackbacks/pingbacks and monitor for unexpected export/import activity.

**Affected:** All-in-One WP Migration and Backup, versions ≤7.109 (5M+ active installs). Fixed version released 2026-08-20; publicly detailed by Wordfence on 2026-09-02. As of 2026-09-03, only around 35% of installs have updated, leaving an estimated 3.25 million sites exposed. No confirmed in-the-wild exploitation yet, but the gap between patch availability and adoption makes this a likely near-term target.

## 11. CVE-2026-72529 & CVE-2026-72530 — TrueConf Server (Federal Patch Deadline Today)

**Principle / root cause:** CVE-2026-72529 exposes an undocumented function on TCP/4307 that lets an unauthenticated remote attacker execute an arbitrary script with no credentials at all. CVE-2026-72530 allows an attacker who has achieved code execution inside TrueConf's sandboxed/isolated execution environment to escape that sandbox and run arbitrary commands on the host operating system with system privileges. The two are typically chained for full host compromise.

**Mitigation:** Update to TrueConf Server 5.3.9, 5.4.9, 5.5.5, or later (fixes shipped in June 2026).

**Affected:** TrueConf Server, all versions since 2022 prior to the fixes above. Actively exploited since at least July 2026 by the "Head Mare" hacktivist group (malicious client-installer replacement and backdoor deployment). Added to CISA KEV in late August 2026; the federal remediation deadline for the more severe CVE-2026-72529 falls today, 2026-09-03 — included here for that reason even though initial disclosure predates this week's window.
