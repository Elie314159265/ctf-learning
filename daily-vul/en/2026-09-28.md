## Most recent (last 24–48 hours)

### CVE-2026-88771 / CVE-2026-88772 — Citrix NetScaler (actively exploited)
- **Disclosure / KEV listing:** 2026-09-27 (CISA KEV)
- **Affected:** Citrix NetScaler products (exact builds: see Citrix advisory)
- **Principle / root cause:** Two NetScaler vulnerabilities confirmed exploited in the wild; vulnerability class not confirmed from available sources.

### CVE-2026-7273 — Zyxel GS1900 Series Switches
- **Disclosure / KEV listing:** 2026-09-21 (CISA KEV), actively exploited
- **Root cause:** Stack-based buffer overflow (memory safety: input copied into a fixed-size stack buffer without adequate bounds checking), potentially leading to code execution or crash.
- **Mitigation:** Update to Zyxel's fixed firmware; do not expose the switch management interface to untrusted networks.

### CVE-2026-76460 — Cisco Identity Services Engine (CVSS 10)
- **Status:** Reported as actively exploited in September 2026 (exact disclosure date not confirmed by available sources).
- **Mitigation:** Apply Cisco's fixed ISE release/hotfix, restrict access to ISE administrative and API interfaces, and review for compromise.
