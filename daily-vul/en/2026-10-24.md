## 1. CVE-2026-109618 & CVE-2026-109619 — "PHP2Shell" PHP Core Memory-Safety Flaws

**Principle / root cause:** Two memory-safety bugs in PHP core reachable without authentication. CVE-2026-109618: out-of-memory handling can interrupt PHP while internal request data is only partially initialized, and request cleanup then treats the invalid data as valid (memory corruption). CVE-2026-109619: request-owned internal state can survive after its backing memory is freed, and a later request served by the same worker can use the stale state before normal initialization resets it (use-after-free style). Both can lead to remote code execution on web-facing PHP.

**Mitigation:**
- Upgrade to PHP 8.5.12, 8.4.27, 8.3.36 or 8.2.35 (released 2026-10-21).
- PHP 8.1 and older are end-of-life upstream; migrate, or obtain backported fixes from your distribution/LTS vendor.
- Cover all SAPIs (PHP-FPM, mod_php, php-cgi, FrankenPHP, LiteSpeed) and containers/base images; restart workers after patching. Inventory CMS hosts (WordPress, Drupal, Joomla), which researchers showed to be exposed.

**Affected:** PHP 8.2–8.5 prior to the fixed releases; older branches likely affected but unsupported (pre-release claims of "since PHP 5" are unconfirmed). **Disclosed:** 2026-10-21 (details leaked before the release). CISA KEV status as of 10-22: not listed.

## 2. CVE-2026-110264 — GitLab Critical Remote Code Execution (Regular Expression Compiler)

**Principle / root cause:** An integer overflow in GitLab's regular expression compiler component leads to memory corruption and remote code execution (verify; a closely related issue, CVE-2026-97229, was fixed on 2026-10-12 and servers patched only for that remain vulnerable to this one per one source).

**Mitigation:** Upgrade; no workaround is documented. Fixed: 19.5.1, 19.4.3, 19.3.6, 19.2.9, 19.1.9, 19.0.10, 18.11.13. Review CI/CD runner and project-import exposure while patching.

**Affected:** GitLab CE/EE from 7.0 up to (not including) the fixed versions above. **Disclosed:** 2026-10-21. Exploitation: none confirmed, no public PoC reported.

## 3. Plex2Shell — Plex Media Server Vulnerability Chain (CVE-2026-96652, -96654, -96655, -96656)

**Principle / root cause:** A chain of weaknesses (including improper neutralization of encoded URI schemes and external control of file names/paths) that together allow remote code execution on the media server. Exploitation reportedly began shortly after technical details became public, with attackers deploying cryptocurrency miners and proxy software.

**Mitigation:** Update Plex Media Server to 1.43.3.10861 or later (including Docker/NAS/Linux installs, which do not auto-update). Do not expose the server directly to the internet; review hosts for unknown miner/proxy processes.

**Affected:** Plex Media Server before 1.43.3.10861. **Dates:** exploitation reports from ~2026-10-17; CISA KEV 2026-10-20 (some deadlines 2026-10-23 / 2026-11-03). Evidence of wide exploitation is partly from a single honeypot (verify).

## 4. CVE-2026-106931 — SiteGuard Server Edition Command Injection

**Principle / root cause:** OS command injection from insufficient neutralization of input passed to system commands. **Mitigation:** apply the vendor's fixed version; restrict management interface access. **Affected:** SiteGuard Server Edition (check vendor advisory for versions). **Disclosed/KEV:** 2026-10-20; federal remediation due 2026-10-23.

## 5. CVE-2026-110936 — Siemens Software Center DLL Sideloading

**Principle / root cause:** The application loads DLLs from a location an attacker can influence, so a planted library runs with the application's privileges (local privilege escalation / code execution). **Mitigation:** apply Siemens' update; restrict write access to install/working directories. **Affected:** Siemens Software Center (versions per Siemens advisory). **KEV:** 2026-10-20; federal deadline 2026-11-03.

## 6. CVE-2026-0257 — PAN-OS GlobalProtect Authentication Bypass (renewed exploitation)

**Principle / root cause:** Authentication bypass in the GlobalProtect component. Unit 42 (updated 2026-10-20) reports ransomware operators now attempting exploitation. **Mitigation:** upgrade to the fixed PAN-OS releases published since May 2026; restrict GlobalProtect portal exposure; hunt for unauthorized access. **Affected:** PAN-OS GlobalProtect deployments on unpatched versions (see Palo Alto advisory).
