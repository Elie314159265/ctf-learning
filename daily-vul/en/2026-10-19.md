# Daily Vulnerability Summary — 2026-10-19

Coverage window: 2026-10-12 to 2026-10-19. No PoC or exploitation details are included (public repository). Details come from search-result summaries of secondary sources; primary sources could not be fetched. Items marked "unverified" need confirmation against vendor advisories.

## Newest / actively exploited (last 24–72 hours)

### 1. BeyondTrust Remote Support — authentication bypass (CVE-2026-102764)
- **Disclosure:** CISA alert and KEV addition on 2026-10-16.
- **Principle / root cause:** Authentication bypass that lets a remote, unauthenticated actor gain initial access. CISA reports follow-on persistence, privilege escalation and lateral movement.
- **Affected:** BeyondTrust Remote Support 26.2.3 and earlier.
- **Mitigation:** Apply the vendor patch (fixed releases reported for supported versions, 24.3.1 and later). Restrict internet exposure of the management interface, review for unexpected accounts/sessions, and follow CISA KEV guidance.

### 2. Nextcloud Collabora app — unauthenticated OS command execution (CVE-2026-110447)
- **Disclosure:** Reported around 2026-10-16/17 (approximate).
- **Principle / root cause:** Improper input handling allows an unauthenticated attacker to run OS commands on the server (CVSS 9.2). Press reports say it is being used to plant web shells; not confirmed in CISA KEV.
- **Affected:** Nextcloud servers with the Collabora integration. Exact versions unverified.
- **Mitigation:** Update to the fixed Nextcloud/Collabora app release, or disable the app until patched. Check the web root for unexpected files and review logs.

### 3. Ivanti Connect Secure (CVE-2026-104935) and Palo Alto PAN-OS (CVE-2026-0322) — unverified
- **Disclosure:** KEV additions reported 2026-10-13 (Ivanti) and 2026-10-14 (PAN-OS). Only a low-confidence aggregator listed Ivanti; PAN-OS is corroborated by a separate KEV report.
- **Principle / root cause:** Vulnerability class not confirmed.
- **Affected:** Versions not confirmed; see vendor advisories.
- **Mitigation:** Apply vendor patches and check the vendor advisories for interim mitigations.

### 4. Other CISA KEV additions, 2026-10-14

## Microsoft Patch Tuesday — 2026-10-13

Sources disagree on the CVE total (roughly 1,100–1,800); check the Microsoft Security Update Guide.

- **CVE-2026-96951 — Windows Shell Mark-of-the-Web bypass (exploited in the wild).** Command injection in Shell handling lets files evade the "downloaded from internet" protections and warnings. CISA KEV added it, with a federal deadline of 2026-10-16. Severity is reported variously (CVSS 8.8–9.5). Affects supported Windows versions; **mitigation:** install the October 2026 cumulative updates.
- **CVE-2026-10839 — .NET untrusted search path (publicly disclosed).** Lets an authenticated attacker bypass Windows Defender Application Control enforcement. **Mitigation:** apply the .NET/Windows updates.
- **CVE-2026-92707 — MessagePack-CSharp denial of service (publicly disclosed).** **Mitigation:** update the MessagePack-CSharp package/affected components.
- **CVE-2026-21413 — Raw Image Extension heap buffer overflow (CVSS 9.8).** Remote code execution when a thumbnail of a malicious RAW image is generated. **Mitigation:** update the extension through the Microsoft Store/Windows Update. (This CVE number is from an older ID range, so verify it.)
