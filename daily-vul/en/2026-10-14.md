## Newest items (last 24–48 hours)

### 1. CVE-2026-104935 — Ivanti Connect Secure: Unauthenticated Remote Command Execution (Zero-Day)
- **Disclosure:** Ivanti acknowledged limited exploitation; CISA added it to KEV on 2026-10-13 (due 2026-10-16).
- **Principle / root cause:** A flaw in the VPN appliance's network-facing service lets a remote, unauthenticated party cause arbitrary command execution on the appliance. The specific defect class is not confirmed in available sources.
- **Affected:** Ivanti Connect Secure, 22.x and 25.x lines (exact affected builds unverified).
- **Mitigation:** Install the fixed 22.x / 25.x releases listed in Ivanti's advisory. Run Ivanti's Integrity Checker Tool, review logs, and consider factory reset and credential rotation if compromise is suspected. Restrict management exposure.

### 2. CVE-2026-96951 — Windows Shell Security Feature Bypass (Mark of the Web)
- **Disclosure:** 2026-10-13 (Microsoft October Patch Tuesday); exploited in the wild; CISA KEV with deadline 2026-10-16.
- **Principle / root cause:** A Windows Shell logic flaw allows content from untrusted sources to lose or evade the Mark-of-the-Web origin tag, so the usual SmartScreen and Protected View warnings do not appear. It requires a user to open a delivered file, and typically serves as one stage in a phishing chain.
- **Affected:** Supported Windows client and server releases (exact list unverified; see MSRC).
- **Mitigation:** Apply the October 2026 cumulative updates. Block risky attachment types at the mail gateway and keep user awareness training current.
- **Context:** Patch Tuesday fixed a record number of CVEs (reported counts range 1,407–1,415). Two other items were publicly disclosed: CVE-2026-108398 (.NET Framework) and CVE-2026-92707 (MessagePack-CSharp, denial of service). Reports conflict on whether CVE-2026-92707 is exploited. Windows 11 24H2 Home/Pro reached end of service.

### 3. CVE-2026-0322 (PAN-OS) and CVE-2026-76519 (Cisco Secure Email Gateway) — Added to CISA KEV 2026-10-14
- CISA's 2026-10-14 alert lists a PAN-OS code injection flaw and a Cisco Secure Email Gateway path traversal flaw as exploited. I could not find vendor details for either ID, and search results for the Cisco product showed other CVE numbers, so confirm the IDs.
- **Mitigation:** Consult the Palo Alto Networks and Cisco PSIRT advisories, apply the fixed releases, and restrict management-interface exposure. Path traversal flaws are generally caused by missing normalization of user-supplied file paths; code injection by unsanitized input reaching an interpreter.

### 4. CVE-2026-105133 & CVE-2026-105134 — AhsayCBS Authentication Bypass + Code Execution
- **Disclosure:** Exploitation first seen 2026-10-07 (Huntress); KEV 2026-10-14.
- **Principle:** One flaw bypasses authentication on the backup management console. The second allows code execution, reportedly as SYSTEM. Chained, they give unauthenticated RCE. Observed post-exploitation: web shells and a cryptominer.
- **Affected:** AhsayCBS up to 10.3.2; reports conflict on 10.3.4. Ahsay said on 2026-10-10 that v10.3.4.0 did not fully fix the issues.
- **Mitigation:** Apply hotfix v10.3.4.45 and reboot. Restrict the management interface to trusted networks and hunt for unexpected JSP files and mining processes.

## Other notable items this week

### 5. CVE-2026-104286 — Fortinet FortiMail Path Traversal / Unauthenticated File Write (CVSS 9.8)
- **Disclosure:** KEV 2026-10-01; exploited as a zero-day (Fortinet FG-IR-26-175).
- **Root cause:** Insufficient validation of file paths lets an unauthenticated request write files outside the intended directory.
- **Affected:** FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9 (upper bounds vary by source).
- **Mitigation:** Upgrade to 8.0.2, 7.6.7, or 7.4.9 as released. No 7.2 fix was reported, so plan a migration. Workarounds: disable IBE and restrict management access.

### 6. Citrix NetScaler ADC / Gateway — CVE-2026-88771, CVE-2026-88772, CVE-2026-88779
- **Disclosure:** Zero-days exploited, per CISA alert of 2026-09-27; CVE-2026-88779 (CVSS 8.7, targeted exploitation) added to KEV 2026-10-04.
- **Mitigation:** Apply Citrix's fixed builds from the bulletin, then check for compromise indicators and rotate secrets. Fixed versions were not confirmed here.

### 7. CVE-2026-102255 — SonicWall SMA1000 Pre-Authentication SSRF (CVSS 10.0)
- **Disclosure:** Hotfix released 2026-10-06; attack traffic reported by 2026-10-09.
- **Root cause:** A server-side request forgery lets an unauthenticated request reach internal functionality.
- **Mitigation:** Install the hotfix from SonicWall's advisory and restrict external exposure of management and Work Place interfaces.

### 8. Flax Typhoon campaign and other KEV additions
- Five flaws exploited by the China-linked Flax Typhoon group were added to KEV around 2026-10-08/09 (deadline 2026-10-11). I could not retrieve the CVE list.
- Zammad CVE-2026-102489 / CVE-2026-102490 were added to KEV on 2026-10-02. Update Zammad to the latest release.
- Unverified: one aggregator mentions CVE-2026-21589 (Confluence/Jira/Bitbucket) exploited after a public PoC. Check Atlassian's advisories.

## General recommendations
1. Prioritize internet-facing edge devices (VPN, mail gateway, ADC, backup consoles): patch, then hunt for prior compromise.
2. Restrict management interfaces to trusted networks.
3. Track CISA KEV deadlines and treat them as a priority list.
