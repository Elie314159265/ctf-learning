## 1. CVE-2026-88771 & CVE-2026-88772 — Citrix NetScaler ADC / Gateway

**Principle / root cause:** CVE-2026-88772 (CVSS 9.5) is a memory-overflow flaw in the appliance's DTLS (Datagram TLS) protocol handling. Malformed network input from an unauthenticated remote party can corrupt memory and may lead to code execution. CVE-2026-88771 is a companion flaw added to the KEV catalog at the same time; its mechanism was not confirmed in available sources. Public write-ups of exploitation exist, which raises the risk of broad opportunistic attacks.

**Mitigation:**
- Apply Citrix's fixed builds for your NetScaler release train as soon as possible. Check the Citrix security bulletin for exact build numbers.
- If patching is delayed, restrict or disable DTLS-enabled listeners (for example DTLS VPN or Gateway virtual servers) where operationally possible.
- Hunt for compromise on exposed appliances: unexpected processes or files, new admin accounts, and unusual outbound connections. Plan to rotate secrets on any appliance that may have been exposed.

**Affected:** NetScaler ADC and NetScaler Gateway appliances with DTLS-enabled services; exact version ranges are in the Citrix bulletin (not retrievable here). **Disclosed:** 2026-09-27 (CISA KEV).

## 2. CVE-2026-104286 — Fortinet FortiMail (unverified)

**Principle / root cause (as reported):** An unauthenticated arbitrary file-write flaw (CVSS 9.8) that allows an unauthenticated attacker to place files on the underlying system. This can be turned into code or command execution. Reported as exploited as a zero-day. We could not confirm the details independently.

**Mitigation:** Check the Fortinet PSIRT advisory for FortiMail. Apply fixed releases when available. Until then, restrict management and web interfaces to trusted networks and review the appliance for unexpected files or accounts.

**Affected:** FortiMail; versions not confirmed. **Disclosed:** reported early Oct 2026.

## 5. CVE-2026-86950 — Apple CoreGraphics out-of-bounds write

**Principle / root cause:** An out-of-bounds write in CoreGraphics. Processing a maliciously crafted file can corrupt memory and lead to arbitrary code execution. Apple fixed it with improved bounds checking. Apple says it may have been used in an "extremely sophisticated" attack against specific targeted individuals on iOS versions before iOS 27. The issue was reported by Meta Product Security.

**Mitigation:** Update to iOS 26.7.1, iPadOS 26.7.1, macOS Tahoe 26.7.1, or macOS Sequoia 15.8.1 (or iOS/iPadOS 27 where available). Prioritize devices belonging to high-risk users (executives, journalists, officials). Consider Lockdown Mode for them.

**Affected:** iOS and iPadOS 26.7 and earlier, and supported macOS Tahoe and Sequoia releases before the fixed versions. **Disclosed:** September 2026 (exact date not confirmed).

## 6. Context — exploited edge-device flaws added to CISA KEV on 2026-09-22 (just outside the window)

- **CVE-2026-94127 — F5 BIG-IP APM (CVSS 9.8):** Heap-based buffer overflow that allows unauthenticated code execution. It affects deployments where an access policy and OAuth profile are configured on a virtual server, with APM acting as an OAuth Authorization Server. Exploited in the wild. Disclosed 2026-09-22. Apply F5's emergency fixed releases.
- **CVE-2026-85102 / CVE-2026-93616 — Check Point:** Management servers and Spark firewalls were attacked. Apply the vendor hotfixes.
- **CVE-2026-93952 — Arista VeloCloud Orchestrator:** Improper input validation on on-premises deployments that may expose privileged internal functionality. Apply the vendor fix.

## General recommendations
- Prioritize patching of internet-facing edge and management appliances (Citrix, Fortinet, Cisco, F5, Check Point) and track the CISA KEV catalog.
- Restrict management interfaces to trusted networks or VPN.
- After patching, check for signs of prior compromise, since several of these flaws were exploited before fixes were available.
