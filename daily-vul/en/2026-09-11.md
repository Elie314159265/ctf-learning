## 1. CVE-2026-57967 — Apache ActiveMQ Artemis Session Hijacking via CORE Protocol

**Principle / root cause:** The ActiveMQ Artemis broker's CORE wire protocol supports a `SESSION_REATTACH` operation intended to let a client resume an existing session after a network interruption. The broker does not adequately verify that the client requesting reattachment is the original, authenticated owner of the session — it accepts a crafted `SESSION_REATTACH` packet from an unauthenticated attacker and grants continued access to all activity associated with that session (CWE-306, missing authentication for a critical function). This lets a remote, unauthenticated attacker effectively step into an already-authenticated session and act with its privileges.

**Mitigation:**
- Upgrade to Apache Artemis / ActiveMQ Artemis 2.57.0 or later.
- Restrict network access to the broker's CORE protocol port to trusted hosts as defense in depth until patched.

**Affected:** Apache Artemis 2.50.0–2.56.0 and Apache ActiveMQ Artemis 1.0.0–2.44.0. Disclosed 2026-09-11; no confirmed in-the-wild exploitation reported yet, but the low complexity and lack of authentication make rapid weaponization likely — patch proactively.

## 2. CVE-2026-67277 & CVE-2026-86060 — MikroTik RouterOS "MikroTrick" Exploit Chain

**Principle / root cause:** CVE-2026-67277 is a missing-authentication flaw in RouterOS's bandwidth-test (`btest`) service: unauthenticated network input can reach a code path normally reserved for logged-in users, and a related uninitialized-memory leak combined with an integer-underflow in size validation can expose kernel memory or crash the device. CVE-2026-86060 is a separate argument-injection flaw in the SSH login path, triggered by usernames beginning with a specific disallowed character, which lets an unauthenticated SSH session alter RouterOS's internal trust/policy mask — leading to privilege escalation. Researchers (CERT Polska) showed the two bugs can be chained for full, unauthenticated device takeover.

**Mitigation:**
- Upgrade to RouterOS 6.49.21 (Long-term), 7.23.4 (Long-term), or 7.24.2 (Stable) or later.
- Disable or firewall the bandwidth-test service and restrict SSH management access to trusted networks.

**Affected:** MikroTik RouterOS versions prior to the fixed releases above. Publicly detailed by CERT Polska on 2026-09-07 (dubbed "MikroTrick"); confirmed under active exploitation to hijack routers; added to CISA KEV on 2026-09-10.

## 3. CVE-2025-25249 — Fortinet FortiOS/FortiSwitchManager/FortiSASE Heap Buffer Overflow

**Principle / root cause:** A heap-based buffer overflow (CWE-122) exists in FortiOS and related products: specially crafted network packets cause more data to be written into a heap buffer than it was sized to hold, corrupting adjacent memory. Depending on the memory layout at the time, this can crash the device or be leveraged by an attacker to redirect program execution and run arbitrary code.

**Mitigation:**
- Upgrade FortiOS, FortiSwitchManager, and FortiSASE to the fixed versions identified in Fortinet's advisory (fixes span the 6.4–7.6 FortiOS branches and corresponding FortiSwitchManager/FortiSASE releases).
- Restrict management-plane exposure of affected devices and monitor for unexpected processes consistent with remote-access-trojan deployment.

**Affected:** FortiOS 7.6.0–7.6.3, 7.4.0–7.4.8, 7.2.0–7.2.11, 7.0.0–7.0.17, 6.4.0–6.4.16; FortiSASE 25.2.b and 25.1.a.2; FortiSwitchManager 7.2.0–7.2.6 and 7.0.0–7.0.5. Originally a 2025-dated CVE, but confirmed under active exploitation deploying the "PivotC2" remote access trojan; added to CISA KEV on 2026-09-09 with a 2026-09-12 federal remediation deadline.

## 4. CVE-2026-19490 — Citrix NetScaler ADC/Gateway Authentication Bypass

**Principle / root cause:** An alternate-path authentication bypass (CWE-288) affects NetScaler appliances configured as a Gateway or AAA (Authentication, Authorization, Auditing) virtual server, including those used for SSL VPN, ICA Proxy, CVPN, or RDP Proxy. Under certain firmware and SAML-configuration conditions, a request can reach an alternate code path that fails to enforce the same login checks as the primary authentication flow, letting a remote, unauthenticated attacker bypass login entirely and reach services normally gated behind the VPN/gateway.

**Mitigation:**
- Apply Citrix's fixed NetScaler firmware builds immediately.
- Since NetScaler Gateway/AAA appliances typically sit at the network edge, treat any unpatched instance as a priority incident; review authentication logs for anomalous session creation without corresponding login events.

**Affected:** Citrix NetScaler ADC and NetScaler Gateway appliances configured as Gateway or AAA virtual servers. Publicly detailed 2026-08-21; confirmed under active, in-the-wild exploitation; added to CISA KEV on 2026-09-09.

## 5. CVE-2026-20079 & CVE-2026-20316 — Cisco Secure Firewall Management Center (FMC) Chained Compromise

**Principle / root cause:** CVE-2026-20079 (CVSS 10.0) stems from an improperly-handled system process created at FMC boot time: a partial management-session record is left in the underlying database, and if no legitimate user authenticates after boot, an unauthenticated remote attacker can send crafted HTTP requests to the web interface to upgrade that leftover session into one with root-level command execution. CVE-2026-20316 (CVSS 8.9) is a separate, unrelated static-credential issue — a hard-coded, low-privileged account baked into FMC lets an unauthenticated attacker log into the web interface and read sensitive data outright. Cisco and outside researchers report the two flaws are being used together by intrusion actors to gain initial access and then escalate to root.

**Mitigation:**
- Apply Cisco's fixes (available since 2026-07-29) immediately if not already deployed.
- Treat any internet-reachable, unpatched FMC instance as compromised until proven otherwise; hunt for indicators including web shells, JAR-based command executors, Netcat reverse shells, and proxy tooling; rotate credentials and review for unauthorized admin accounts.

**Affected:** Cisco Secure Firewall Management Center software prior to the July 2026 fixed releases. Both CVEs are confirmed under active exploitation by state-sponsored and ransomware-affiliated actors; CVE-2026-20316 was added to CISA KEV on 2026-07-29 and CVE-2026-20079 on (reporting places renewed CISA/vendor confirmation around) 2026-09-09/10 — both flagged prominently this week due to Cisco's fresh confirmation of active, chained exploitation.

## 6. CVE-2026-86218 (with CVE-2026-86206/86207) — N-able N-central Pre-Authentication Remote Code Execution

**Principle / root cause:** CVE-2026-86218 is a static/unsanitized code-injection flaw in N-central (an RMM platform used by managed service providers) that lets an unauthenticated attacker submit input that is evaluated as executable code by the server, resulting in remote code execution with no credentials required. Separately, CVE-2026-86206 and CVE-2026-86207 can be chained to bypass authentication entirely and create a new, attacker-controlled System Administrator account. Because N-central is typically used to manage large fleets of downstream customer endpoints, compromise of the appliance itself creates a supply-chain-style pivot point into every managed environment.

**Mitigation:**
- Upgrade on-premises N-central to 2026.3.1.14 (or the 2026.3 Hotfix 4 baseline) immediately.
- Audit internet exposure of N-central servers and review logs for signs of compromise dating back to early September 2026, including unexpected admin account creation.

**Affected:** N-able N-central on-premises deployments prior to the September 2026 hotfixes. This is the fourth N-central hotfix in five weeks. Patched 2026-09-05; confirmed actively exploited, including at least one investigated compromise of a "fully patched" environment (root cause under investigation); added to CISA KEV with a federal remediation deadline of today, 2026-09-11.

## 7. CVE-2026-87491 & CVE-2026-85046 — Google Chrome V8 Zero-Days (Sandbox Escape Chain)

**Principle / root cause:** Both are memory-safety bugs in V8, Chrome's JavaScript/WebAssembly engine. CVE-2026-85046 is a type-confusion flaw (the engine misinterprets the type of an object in memory, letting crafted script coerce it into unintended behavior); CVE-2026-87491 is an out-of-bounds write (crafted input causes the engine to write past the bounds of an allocated buffer). Either can be triggered simply by a victim visiting a malicious web page, and can be leveraged for arbitrary code execution inside Chrome's renderer sandbox — typically the first stage of a longer chain aiming to escape the sandbox entirely.

**Mitigation:** Update Chrome to 153.0.8010.36/.37 (or later) — this also carries the fix for CVE-2026-85046 from the prior 152.0.7977.82/.83 release if not already applied. Apply the same updates to Chromium-based browsers (Edge, Brave, Opera, etc.) as their vendors ship them.

**Affected:** Chrome versions prior to 152.0.7977.82 (CVE-2026-85046, patched 2026-09-03) and prior to 153.0.8010.36 (CVE-2026-87491, patched 2026-09-08). Both confirmed exploited in the wild as zero-days — Google has not disclosed attribution or targeting details for either. This marks the seventh actively-exploited Chrome zero-day patched in 2026.

## 8. CVE-2026-81963 & CVE-2026-85880 — Microsoft Windows Zero-Days (September Patch Tuesday)

**Principle / root cause:** CVE-2026-81963 is an improper link-resolution ("link following") flaw in the Windows Update Stack: a local attacker can arrange for the update process to follow a manipulated file-system link, causing it to act on an attacker-chosen file with the Update Stack's elevated privileges. CVE-2026-85880 is a heap-based buffer overflow in Windows Advanced Local Procedure Call (ALPC), the OS facility used for local inter-process communication — malformed input can corrupt heap memory in a way that is leveraged for privilege escalation. Both let a local attacker who already has low-privileged code execution escalate to SYSTEM.

**Mitigation:** Apply Microsoft's September 2026 cumulative updates, released as part of the largest Patch Tuesday on record (roughly 973–974 CVEs addressed, 105–113 rated Critical).

**Affected:** CVE-2026-81963 affects current Windows 11 releases and Windows Server 2025; CVE-2026-85880 affects older Windows 10 and Windows Server branches. Both confirmed exploited in the wild before patches were available (zero-days); patched 2026-09-08; added to CISA KEV the same day with a 2026-09-22 federal remediation deadline. (Separately, a proof-of-concept technique against Windows Defender dubbed "ShieldCrash" was also disclosed this cycle, describing a path to SYSTEM-level file reads; no vendor fix has shipped for it as of this writing.)

## 9. CVE-2026-75650 — Adobe Commerce / Magento Open Source Template Injection Zero-Day

**Principle / root cause:** The flaw abuses Magento's email-templating system: a specially crafted value can be injected into the data used to generate a routine transactional email (a "Payment Transaction Failed Reminder" notice), causing the template engine to evaluate attacker-controlled content as executable PHP rather than as inert text. Because the template renders automatically as part of normal order/payment processing, no authentication or user interaction is required — the attacker only needs to trigger the vulnerable email path.

**Mitigation:** Apply Adobe's APSB26-146 update immediately; there is no viable workaround given the CVSS 10.0 rating and confirmed active exploitation.

**Affected:** Adobe Commerce and B2B editions 2.4.4 through 2.4.9, and Magento Open Source 2.4.6 through 2.4.9. Zero-day exploitation began 2026-09-04 (identified by Sansec); Adobe patched it 2026-09-07. Attackers have already been observed deploying both a stealthy Rust-based backdoor and conventional PHP web shells — treat any unpatched, internet-facing store as potentially already compromised and inspect for persistence mechanisms even after patching.

## 10. SAP September 2026 Security Patch Day — Four Critical Flaws

**Principle / root cause:** SAP's September patch day addressed 19 security notes, four of them critical. CVE-2026-44756 (CVSS 10.0) is a memory-corruption issue in SAP's "Extended Passport" processing within the Kernel/Web Dispatcher, reachable without authentication. CVE-2026-58240 ("S4GET", CVSS 9.8) is a logic flaw in the NetWeaver Message Server — the internal broker that routes SAP GUI logon requests — that allows unauthenticated remote code execution and affects the kernel family used by current S/4HANA releases. CVE-2026-76969 (CVSS 9.4) can expose credentials in multitenant applications built on the SAP Cloud Application Programming Model's multitenancy library. CVE-2026-66768 (CVSS 9.0) is an improper access-control issue in SAP GUI for Java.

**Mitigation:** Apply the September 2026 SAP Security Notes for the affected Kernel, Web Dispatcher, NetWeaver, CAP (`@sap/cds-mtxs`), and SAP GUI for Java components without delay, prioritizing CVE-2026-44756 and CVE-2026-58240 given their unauthenticated, remote-code-execution impact.

**Affected:** SAP Kernel 7.22/7.53/7.54/7.77/7.89/7.93/8.04 and Web Dispatcher 9.16–9.20 (CVE-2026-44756); NetWeaver Message Server on kernel 9.16/9.18/9.19/9.20 (CVE-2026-58240, affecting all current S/4HANA 2025 systems); CAP multitenant applications using `@sap/cds-mtxs` (CVE-2026-76969); SAP GUI for Java (CVE-2026-66768). Patched 2026-09-08; no confirmed in-the-wild exploitation reported yet, but the unauthenticated RCE flaws warrant urgent patching given SAP systems' typical business-criticality.

## 11. CVE-2026-1357 — WPvivid Backup & Migration (WordPress Plugin) Unauthenticated RCE

**Principle / root cause:** Two chained flaws — a cryptographic "fail-open" in the plugin's RSA-based decryption handling, and insufficient path sanitization when saving uploaded files — allow an unauthenticated attacker to upload and place an arbitrary (including executable PHP) file via the plugin's `send_to_site` action, achieving full remote code execution. Exploitation depends on the site having the non-default "receive backup from another site" feature enabled, and the attacker must act within a roughly 24-hour validity window for the cryptographic key involved.

**Mitigation:** Update WPvivid Backup & Migration to version 0.9.124 or later; disable the "receive backup from another site" feature on sites that don't actively use it.

**Affected:** WPvivid Backup & Migration versions up to and including 0.9.123 (900,000+ active installs). Widely reported this week; exact original disclosure timeline is inconsistent across secondary sources (some place initial reporting earlier in 2026), so treat the precise disclosure date as unconfirmed and prioritize the version check over the date when assessing exposure.

## 13. CVE-2026-32475 — Elementor Pro (WordPress Plugin) Arbitrary File Upload (Continuity Note)

**Principle / root cause:** Elementor Pro's Forms module validates and processes uploaded files across two separate code loops that handle "no file submitted" conditions differently. A crafted multipart form submission can exploit this inconsistency so that a file upload which should be rejected is instead accepted and written to a web-accessible path with an executable extension — giving an unauthenticated attacker remote code execution.

**Mitigation:** Update Elementor Pro to version 4.2.2 or later.

**Affected:** Elementor Pro Forms module, versions through 4.2.1 (roughly 10 million installs). Confirmed on 2026-07-16, publicly detailed and patched 2026-08-19; already being exploited to hack sites, and as of early September roughly two-thirds of installs remained unpatched — included here as a live, high-prevalence risk despite the disclosure predating this week's window.
