## 1. CVE-2026-102489 & CVE-2026-102490 — Zammad Session Fixation and Improper Privilege Management

**Principle / root cause:** CVE-2026-102489 is a session-handling flaw (session fixation/hijacking) that can lead to code execution as the Zammad service user (reported CVSS 9.4). CVE-2026-102490 is an improper privilege management flaw that lets the Zammad local account gain administrator privileges on the underlying operating system. Chained, they allow an attacker to move from web session compromise to code execution and then full host control. They were used in a real breach of the Dutch Vulnerability Disclosure Institute (DIVD) on 2026-09-21.

**Mitigation:**
- Upgrade Zammad to the latest patched release per the vendor advisory.
- Review hosts for unexpected sessions, new admin/privileged accounts, and unusual outbound data transfer; rotate secrets and sessions if compromise is suspected.
- Limit network exposure of the Zammad instance and run it with least privilege.

**Affected:** CVE-2026-102489: Zammad 6.3.0 to 6.5.4. CVE-2026-102490: Zammad 1.5.0 up to pre-release 7.1.0-alpha. **Disclosure:** technical details and CVEs published 2026-09-30; added to CISA KEV 2026-10-02.

## 2. CVE-2026-104286 — Fortinet FortiMail Path Traversal / Arbitrary File Write (Zero-Day)

**Principle / root cause:** Improper handling of path traversal sequences and null bytes in HTTP/HTTPS requests lets an unauthenticated remote attacker write arbitrary files on the underlying system, which can lead to code execution. CVSS 9.8.

**Mitigation:**
- Fixed releases 8.0.2, 7.6.7 and 7.4.9 were announced but not yet released at the time of reporting; watch Fortinet PSIRT and apply immediately on release.
- Users of 7.2 should upgrade to 7.4 or later.
- Meanwhile restrict management/web interface exposure to trusted networks and monitor for unexpected file writes or new files on appliances.
- CISA set a federal remediation deadline of 2026-10-04.

**Affected:** FortiMail email security gateway (7.2, 7.4, 7.6, 8.0 branches awaiting fixes). **Disclosure:** exploitation reported ~2026-10-01; added to CISA KEV 2026-10-01.

## 3. CVE-2026-88771 & CVE-2026-88772 — Citrix NetScaler ADC / Gateway Zero-Days

**Principle / root cause:** CVE-2026-88771 is an improper input validation flaw allowing unauthenticated remote command execution, exposed even in default configuration. CVE-2026-88772 is a memory overflow that can cause remote code execution or denial of service when DTLS is enabled (the default on VPN virtual servers). Each can independently give remote code execution. Both CVSS v4.0 9.5.

**Mitigation:**
- Upgrade to NetScaler 14.1-73.37 or later, or 13.1-64.23 or later; FIPS builds: 14.1-73.37 FIPS or later; 13.1 FIPS/NDcPP: 13.1-37.279 or later.
- Assume compromise on unpatched internet-facing appliances: hunt for webshells/persistence and rotate credentials and secrets.

**Affected:** NetScaler ADC and NetScaler Gateway builds earlier than the fixed versions above. **Disclosure:** patches and confirmation of exploitation 2026-09-27; added to CISA KEV.

## 4. CVE-2026-86950 — Apple Core Graphics Out-of-Bounds Write (Zero-Day)

**Principle / root cause:** An out-of-bounds write in Core Graphics when processing a specially crafted file can lead to arbitrary code execution. Apple reports it may have been used in an "extremely sophisticated attack" against specific targeted individuals; reported by Meta Product Security.

**Mitigation:**
- Update to iOS 26.7.1, iPadOS 26.7.1, macOS Tahoe 26.7.1, or macOS Sequoia 15.8.1.
- High-risk users should consider Lockdown Mode.

**Affected:** iOS/iPadOS and macOS releases earlier than the fixed versions (iOS 27 / macOS 27 branches appear unaffected). **Disclosure:** 2026-09-28.
