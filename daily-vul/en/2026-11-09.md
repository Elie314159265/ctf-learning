## Newest items (last 24–72 hours)

### 1. Apple CVE-2024-27834 added to CISA KEV (2026-11-04)
- **Disclosure / KEV date:** Added to CISA KEV around 2026-11-04 (federal due date reported as 2026-11-18). The flaw itself is an older (2024) Apple bug; secondary reports link its exploitation to a state-linked actor targeting un-updated devices (unverified).
- **Mechanism / root cause:** Memory-safety weakness in Apple's WebKit/Safari engine, per the CVE's 2024 listing; it is abused when a device processes malicious web content.
- **Affected:** Safari, iOS/iPadOS and macOS builds that never received the 2024 security updates.
- **Mitigation:** Update devices to current iOS/iPadOS/macOS/Safari releases; retire devices that can no longer be updated; consider Lockdown Mode for high-risk users.

## Other notable items this week

### 3. WordPress core CVE-2026-119977 – upgrade-window race condition (KEV added 2026-11-03)
- **Disclosure date:** CVE published ~2026-10-31; fix released ~2026-10-28; added to CISA KEV 2026-11-03 (federal due date 2026-11-06, forensic triage recommended).
- **Root cause:** Time-of-check/time-of-use race (CWE-367) in the core update process; state can change between validation and use during an upgrade, allowing an unauthenticated party to achieve code execution on the server.
- **Affected:** WordPress core 4.7 through 7.1.3 (per secondary sources). Severity disputed: 8.1 High (Wordfence CVSS 3.1) vs "Low" per the WordPress project.
- **Mitigation:** Upgrade to 7.1.4 (7.0.8 on the 7.0 branch; confirm other branches in the official release notes). Review sites that updated or were updating recently for unexpected files/admin users; consider limiting exposure during upgrades.

### 4. Ivanti Connect Secure CVE-2026-111357 and CVE-2026-118527 – exploited chain (patched 2026-10-29; KEV deadlines 2026-11-02 / 2026-11-13)
- **Mechanism:** Two flaws chained with an authentication-bypass (CVE-2026-104935) so an unauthenticated attacker can gain root control of the appliance. CVSS reported as 8.8 (CVE-2026-111357) and 4.3 (CVE-2026-118527).
- **Affected:** Ivanti Connect Secure 25.1.1.2 and earlier; 22.8R2.5 and earlier. The October 13 fixes do **not** remediate these two CVEs.
- **Mitigation:** Upgrade to 25.1.1.3 or 22.8R2.6; run Ivanti's integrity checker; if compromise is suspected, rebuild the appliance and rotate credentials/secrets; restrict management exposure.

### 5. Brotli "Node2Shell" CVE-2026-111497 – out-of-bounds write in decoder (patched 2026-10-21; exploitation reported)
- **Disclosure date:** Node.js fixes 2026-10-21; widely reported from 2026-10-27; KEV timing reported inconsistently (late Oct / early Nov; due date 2026-11-10 in one source).
- **Root cause:** The Brotli decoder mishandles an invalid block switch as "need more input" and keeps appending to a small internal buffer, writing out of bounds (CWE-787 / CWE-252). Reachable wherever untrusted compressed data is decompressed automatically. CVSS 9.8 (NVD) / 9.2 (CVSS 4.0).
- **Affected:** Google Brotli 1.0.3–1.0.9, 1.1.0, 1.2.0 and software embedding it: Node.js (pre-22.23.4 / 24.22.1 / 26.12.1), Bun (pre-1.4.4), Python, Envoy, and others.
- **Mitigation:** Upgrade Brotli to 1.0.10 / 1.1.1 / 1.2.1 or the vendor-patched runtime; rebuild containers and statically linked binaries; check distro advisories for backports.

### 6. PHP CVE-2026-109618 / CVE-2026-109619 (reported exploited; listed in KEV since ~2026-10-26)
- Reported as incorrect global-state reset after memory is freed (use-after-free class). Details are thin in available sources.
- **Mitigation:** Apply the latest PHP patch release for your branch; check distro advisories.
