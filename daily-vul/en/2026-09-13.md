## 1. CVE-2026-85706 — GitLab Commits API Unauthenticated Arbitrary File Read (Path Traversal)

**Principle / root cause:** The repository "commits" REST API (`/api/v4/projects/{id}/repository/commits/...`) fails to properly confine file paths to the intended repository directory and, under certain configurations, does not enforce authentication at all. A single crafted HTTP request can escape the intended path and read arbitrary files from the underlying server filesystem — no account or user interaction required (CWE-22/CWE-306 class issue).

**Mitigation:**
- Upgrade self-managed GitLab immediately to 19.3.2, 19.2.6, 19.1.8, or later.
- GitLab.com (SaaS) was already patched centrally; self-hosted instances are the ones at risk.
- Treat any unpatched, internet-facing instance as compromised-until-proven-otherwise and review access/audit logs for anomalous commits-API requests.

**Affected:** Self-managed GitLab Community Edition and Enterprise Edition prior to the fixed versions above. Fix released 2026-09-10; in-the-wild probing observed from 06:00 UTC 2026-09-11 (hours after disclosure); added to CISA KEV on 2026-09-11 with a 2026-09-14 remediation deadline under BOD 26-04.

## 2. CVE-2026-20079 — Cisco Secure Firewall Management Center Authentication Bypass to Root RCE

**Principle / root cause:** At boot time, an internal system process creates a session record in the appliance's session database before any user has logged in. If no legitimate login occurs first, that placeholder session can be reached and upgraded by a remote, unauthenticated attacker sending crafted HTTP requests to the web interface, who can then invoke a broad set of privileged administrative scripts — resulting in root-level command execution.

**Mitigation:**
- Apply Cisco's hotfixes for the affected release trains (7.0.9, 7.2.11, 7.4.6, 7.6.5, 7.7.12, 10.0.1) immediately — there is no workaround.
- Restrict management-interface exposure to trusted networks only, and audit for unexpected admin sessions or CGI script invocations.

**Affected:** Cisco Secure Firewall Management Center (FMC) software, versions prior to the fixed releases. Active exploitation observed since August 2026 by multiple threat clusters, including the Sandworm-linked group, the Qilin ransomware operation, and a separate credential-theft cluster; added to CISA KEV 2026-09-09 with a 2026-09-12 federal deadline.

## 3. CVE-2026-85102 & CVE-2026-85103 — Check Point VPN Certificate Trust Validation Flaws

**Principle / root cause:** During VPN tunnel negotiation (both Remote Access and Site-to-Site), the gateway fails to properly validate the trust chain of a certificate presented by the remote peer (CWE-295, improper certificate validation). An attacker who can present a crafted certificate during negotiation may be able to reach code execution on the Security Gateway without any valid credentials.

**Mitigation:**
- Apply the vendor's Jumbo Hotfix Accumulator: R82.10 Take 44+, R82 Take 126+, or R81.20 Take 166+ (plus corresponding Spark Firewall builds), or ensure Live Patch has already applied the fix automatically.
- Review VPN gateway configurations and restrict trusted peer certificate sources where feasible as defense in depth.

**Affected:** Check Point Quantum Security Gateway, Spark Firewall, and Security Management Server using Remote Access or Site-to-Site VPN, across the branches listed above. Disclosed by Check Point's own research team 2026-09-09, with patches available the same day; no evidence of active exploitation or public PoC as of this writing.

## 4. CVE-2026-19490 — Citrix NetScaler ADC/Gateway Authentication Bypass

**Principle / root cause:** An alternate request path exists that reaches authenticated functionality on NetScaler appliances configured as an AAA virtual server or as a Gateway (SSL VPN, ICA Proxy, CVPN, or RDP Proxy) without enforcing the expected authentication checks (CWE-288, authentication bypass using an alternate path).

**Mitigation:**
- Apply Citrix's fixed builds immediately.
- Assume compromise on any unpatched, internet-facing appliance: isolate it, preserve logs/evidence, rotate credentials, and review downstream systems reachable through the gateway.

**Affected:** NetScaler ADC and NetScaler Gateway appliances configured as AAA or Gateway virtual servers. Honeypot telemetry recorded a surge in exploitation attempts around 2026-09-08; added to CISA KEV 2026-09-09 with a 2026-09-12 federal deadline.

## 5. CVE-2026-86060 & CVE-2026-67277 ("MikroTrick") — MikroTik RouterOS SSH Privilege Escalation + Kernel Memory Leak

**Principle / root cause:** CVE-2026-86060 is an SSH privilege-escalation flaw: a specially crafted username during SSH session setup is mishandled, letting an attacker manipulate the session to obtain full administrative privileges. CVE-2026-67277 affects the RouterOS bandwidth-test service, allowing an unauthenticated attacker to leak kernel memory or remotely crash/restart the router. Chained together ("MikroTrick"), they allow full takeover of an internet-reachable router.

**Mitigation:**
- Upgrade to RouterOS 7.25beta3, 7.24.2, 7.23.4, or 6.49.21 (fixed 2026-09-03) or later.
- Restrict SSH and bandwidth-test service exposure to trusted management networks.

**Affected:** MikroTik RouterOS devices with SSH or the bandwidth-test service reachable from the internet, prior to the fixed versions. Actively exploited in the wild per CERT Polska; added to CISA KEV 2026-09-10 with a remediation deadline of 2026-09-13 (today).

## 6. CVE-2026-87491 — Google Chrome V8 Out-of-Bounds Write (Zero-Day)

**Principle / root cause:** An out-of-bounds write in the V8 JavaScript/WebAssembly engine (CWE-787) allows a specially crafted HTML page to corrupt memory and achieve arbitrary code execution inside Chrome's sandbox.

**Mitigation:** Update Chrome to 153.0.8010.36/.37 or later (Stable channel, released 2026-09-08); Chromium-based browsers should apply equivalent upstream fixes.

**Affected:** Chrome versions prior to 153.0.8010.36. Exploited in the wild since at least 2026-09-01 by two independently-operating threat actors (tracked as UTA0560 and JungleBamboo/APT31) in spear-phishing campaigns as part of a multi-stage Chrome/Windows exploit chain; added to CISA KEV 2026-09-09.

## 7. CVE-2025-25249 — Fortinet FortiOS/FortiSwitchManager Heap-Based Buffer Overflow

**Principle / root cause:** The `cw_acd` daemon fails to validate the length of attacker-supplied input before copying it into a fixed-size heap buffer (classic heap-based buffer overflow, CWE-122), allowing a remote, unauthenticated attacker to execute arbitrary code via specially crafted network packets sent to the management interface or other exposed services.

**Mitigation:** Upgrade FortiOS and FortiSwitchManager past the affected version ranges per Fortinet's advisory; restrict management-interface access to trusted networks as a compensating control.

**Affected:** FortiOS 7.6.0–7.6.3, 7.4.0–7.4.8, 7.2.0–7.2.11, 7.0.0–7.0.17, 6.4.x (all); FortiSwitchManager 7.2.0–7.2.6, 7.0.0–7.0.5. Actively exploited; added to CISA KEV 2026-09-09 with a 2026-09-12 federal deadline.

## 8. CVE-2026-81963 & CVE-2026-85880 — Microsoft Windows Zero-Days (September 2026 Patch Tuesday)

**Principle / root cause:** CVE-2026-81963 is an improper link resolution ("link following") flaw in the Windows Update Stack that lets a local attacker cause the update process to follow a malicious link and overwrite a system component with an attacker-controlled file, elevating to SYSTEM. CVE-2026-85880 is a heap-based buffer overflow in the Windows Advanced Local Procedure Call (ALPC) component that lets an attacker running low-privilege code (e.g., inside an AppContainer sandbox) escape the sandbox and elevate privileges to SYSTEM.

**Mitigation:** Apply the September 2026 cumulative updates immediately — both flaws are confirmed exploited in the wild, though Microsoft has not disclosed attacker identity or scale.

**Affected:** Supported Windows client and server versions prior to the September 2026 cumulative updates. Part of a record-setting Patch Tuesday (973–974 total CVEs, 113+ rated critical, 21+ critical RCEs across Office/Windows Graphics components); both zero-days added to CISA KEV 2026-09-08, the same day fixes shipped.

## 9. CVE-2026-42018 (with CVE-2026-42016) — JFrog Artifactory Authentication Bypass Chain

**Principle / root cause:** CVE-2026-42018 lets a remote, unauthenticated attacker obtain an internal anonymous-user API token even when anonymous access has been administratively disabled — the server issues the token before checking whether anonymous access is actually permitted (CWE-287, improper authentication). Attackers chain this token with CVE-2026-42016 (a separate privilege-escalation flaw) to gain full administrative control of the Artifactory instance.

**Mitigation:** Upgrade to the fixed release for your branch (7.111.20, 7.117.27, 7.125.19, 7.133.28, or 7.146.8, or later); rotate all tokens/credentials and audit for anomalous build-server activity regardless of patch status, given confirmed prior exploitation.

**Affected:** Self-hosted JFrog Artifactory instances prior to the fixed versions. Chained exploitation observed 2026-08-15 through 2026-09-08, deploying Rust-based backdoors on compromised build servers that can persist across a first patch pass; publicized in detail around 2026-09-12. This is a distinct, newer authentication-bypass path from the CVE-2026-82329 issue covered in prior weekly reports.

## 10. CVE-2026-85046 — Google Chrome V8 Type Confusion (Continuity Note)

**Principle / root cause:** A type-confusion bug in V8 (CWE-843) allowed arbitrary code execution inside the Chrome sandbox via a crafted web page — mechanically similar in class to CVE-2026-87491 above but a distinct flaw, patched earlier in this window.

**Mitigation:** Confirm Chrome is updated past the version that fixed CVE-2026-85046 (released 2026-09-03/04); this is superseded by, but not the same as, the newer CVE-2026-87491 fix in Chrome 153.

**Affected:** Chrome versions prior to the 2026-09-03/04 fix. Actively exploited as a zero-day; added to CISA KEV 2026-09-04 with a federal deadline of 2026-09-18.
