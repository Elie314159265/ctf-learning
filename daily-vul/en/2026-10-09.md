## 1. CVE-2026-104286 — Fortinet FortiMail Unauthenticated Arbitrary File Write (Zero-Day)

**Principle / root cause:** Improper validation in a FortiMail HTTP/HTTPS-facing component (reported to be tied to the identity-based encryption, IBE, feature) lets an unauthenticated remote party cause files to be written to arbitrary locations on the appliance. Arbitrary file write on a mail gateway can lead to code execution and persistence.

**Mitigation:**
- Fortinet advisory FG-IR-26-175 (2026-10-01) lists fixes as upcoming: 8.0.2, 7.6.7, 7.4.9. 7.2 users are advised to move to the 7.4 branch or later. Check whether these have shipped.
- Until patched: disable the IBE feature from the CLI, and block internet access to the management/web interfaces or restrict them to trusted private networks.
- Hunt for signs of compromise (unexpected files, new accounts, outbound connections); workaround alone does not remove an existing foothold.

**Affected:** FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9. **Disclosed:** 2026-10-01; added to CISA KEV the same day (federal due date 2026-10-04).

## 2. CVE-2026-76504 — Cisco Catalyst SD-WAN Manager API Authentication Bypass (Zero-Day)

**Principle / root cause:** Improper handling of URI encoding in the management API allows an unauthenticated remote request to be treated as authenticated, granting administrative API access.

**Mitigation:**
- No workaround; all deployments are affected regardless of configuration.
- Upgrade to a fixed build: 20.9.10.1, 20.12.8.2, 20.15.6.1, 20.18.4.1, 26.1.2.1, or 26.2.1. Releases before 20.9 must migrate.
- Restrict Manager exposure to untrusted networks; review logs against Cisco's published indicators of compromise; audit credentials and configuration, since patching does not remove prior access. Treat Managers that were reachable from untrusted networks in September as potentially compromised.

**Affected:** Cisco Catalyst SD-WAN Manager (formerly vManage). **Disclosed:** 2026-09-30 by Cisco; exploited in the wild; added to CISA KEV (reports differ on exact date, around 2026-09-30 to 2026-10-01).

## 3. CVE-2026-102489 & CVE-2026-102490 — Zammad Session Fixation and Local Privilege Escalation

**Principle / root cause:** CVE-2026-102489 is a session fixation weakness that can lead to code execution as the application's service user in affected versions. CVE-2026-102490 is an improper privilege management flaw allowing local escalation to root. Together they form a chain from web access to full host compromise. The disclosure (by DIVD) is disputed: Zammad GmbH disagrees on affected versions and exploitability of the second flaw.

**Mitigation:**
- Upgrade to Zammad 7.2.0 (released 2026-09-23), which most sources cite as the fixed release; older 6.x versions are reportedly out of support.
- As of 2026-10-05 no formal vendor advisory was found and a vendor fix for CVE-2026-102490 was not confirmed; DIVD advises upgrading to 7.x or taking exposed instances offline. Limit network exposure and run the service with minimal privileges.

**Affected:** CVE-2026-102489: Zammad 6.3.0–6.5.4 (also present but reportedly not exploitable in 7.0.0–7.1.3). CVE-2026-102490: reported as all versions (disputed). **Disclosed/KEV:** added to CISA KEV 2026-10-02 (federal due date 2026-10-05).

## 4. CVE-2026-88779 — Citrix NetScaler ADC / Gateway Unauthenticated Denial of Service

**Principle / root cause:** A memory-buffer handling flaw that lets an unauthenticated remote party crash or exhaust the appliance, causing denial of service.

**Mitigation:** Apply the latest Citrix security bulletin builds (see item 5 for builds fixing the related RCE flaws; confirm the fixed build for this CVE in Citrix's bulletin, which was not retrievable here). Restrict exposure of gateway/VPN virtual servers where feasible.

**Affected:** NetScaler ADC and Gateway (specific versions not confirmed). **Disclosed:** added to CISA KEV 2026-10-04.

## 5. CVE-2026-88771 & CVE-2026-88772 — Citrix NetScaler ADC / Gateway (context from 2026-09-27)

**Principle / root cause:** Critical memory-safety flaws reported as remote-code-execution zero-days. CVE-2026-88771 affects all vulnerable deployments including default configuration; CVE-2026-88772 applies when DTLS is enabled (default on VPN virtual servers).

**Mitigation:** No workaround or IOCs published. Upgrade to 14.1-73.37+ or 13.1-64.23+; FIPS: 14.1-73.37 FIPS+; 13.1 FIPS/NDcPP: 13.1-37.279+. One report mentions a further overflow fixed in 14.1-73.41 / 13.1-64.28 (unverified ID); prefer the newest builds.

**Affected:** NetScaler ADC and Gateway 14.1 and 13.1 prior to the builds above. **Disclosed:** CISA KEV 2026-09-27.
