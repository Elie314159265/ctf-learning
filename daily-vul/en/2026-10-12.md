## 1. CVE-2026-104286 — Fortinet FortiMail Path Traversal / Arbitrary File Write (Zero-Day)

**Principle / root cause:** A path-traversal flaw (CWE-22, with improper NULL-byte handling, CWE-158) in the FortiMail Identity-Based Encryption (IBE) feature. Crafted HTTP/HTTPS requests from an unauthenticated remote party can cause files to be written to arbitrary locations on the appliance. Researchers report post-exploitation artifacts consistent with code execution through replacement of shared-library loading configuration.

**Mitigation:**
- Upgrade to the fixed FortiMail release listed in Fortinet's PSIRT advisory (fixed build numbers were not confirmed in sources used here).
- Until patched, restrict or disable exposure of the IBE web interface to untrusted networks; hunt for unexpected files and modified library-preload configuration on appliances.

**Affected:** FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9. Disclosed 2026-10-01; added to CISA KEV the same day.

## 2. Flax Typhoon-linked KEV additions (older CVEs)

**Principle / root cause:** CISA added five older vulnerabilities to KEV after reports that the China-linked actor Flax Typhoon (associated with Integrity Technology Group) abuses them; a joint advisory from the US, UK, Australia, Canada, New Zealand, Japan and Spain accompanied this. Root causes: ProFTPD improper access control in file-copy functionality (CVE-2015-3306); ONLYOFFICE Docs path traversal (CVE-2021-3199); Strapi cleartext storage of sensitive data (CVE-2023-22894); Apache Struts command injection (CVE-2016-3081); ISC BIND reachable assertion enabling denial of service (CVE-2015-5477).

**Mitigation:**
- Upgrade or retire any internet-facing instance of these products; these are long-fixed flaws, so exposure indicates unpatched/legacy systems.
- Inventory legacy FTP, DNS, document-server, CMS and Java web frameworks; review logs for compromise indicators published in the joint advisory.

**Affected:** ProFTPD (mod_copy), ONLYOFFICE Docs, Strapi, Apache Struts 2, ISC BIND (older, unpatched versions). Added to KEV around 2026-10-08/09; the federal deadline reported (2026-10-11) is unconfirmed.

## 3. CVE-2026-0257 — Palo Alto PAN-OS GlobalProtect Authentication Bypass

**Principle / root cause:** When GlobalProtect "authentication override cookies" are enabled and the same certificate is used for cookie protection as for the portal/gateway, an attacker can forge valid cookies and establish VPN sessions without credentials. The feature is not enabled by default. Exploitation reportedly dates back to May 2026, with attackers obtaining internal VPN addresses.

**Mitigation:**
- Apply Palo Alto's fixed PAN-OS releases (e.g. 12.1.4-h6/12.1.7, 11.2.4-h17 and later hotfixes, 11.1.4-h33 and later, 10.2.7-h34 and later per the branch; confirm against the vendor advisory).
- Workaround: use a dedicated certificate for authentication-override cookies (never the portal/gateway certificate), or disable cookie generation and acceptance.
- Review VPN logs for sessions without matching authentication events.

**Affected:** PAN-OS 12.1, 11.2, 11.1, 10.2 prior to the fixed builds; some Prisma Access branches. Panorama and Cloud NGFW are not affected. One source mentions ransomware use; this could not be confirmed.

## 4. CVE-2026-88779 and CVE-2026-107406 — Citrix NetScaler ADC / Gateway

**Principle / root cause:** Memory-handling flaws in the SAML processing code of appliances configured as a SAML Identity Provider or Service Provider. CVE-2026-88779 (disclosed ~2026-10-03, KEV 2026-10-04) is described as a memory-buffer issue causing denial of service, with reports that it may also permit remote code execution and targeted exploitation. CVE-2026-107406 is a memory overflow (CVSS v4 9.5) potentially leading to RCE or DoS; Citrix is not aware of exploitation.

**Mitigation:**
- 88779: update to 14.1-73.41 / 13.1-64.28 or later (FIPS: 14.1-73.41 FIPS; 13.1 FIPS/NDcPP 13.1-37.282).
- 107406: update to 14.1-73.46 / 13.1-64.29 or later (13.1 FIPS/NDcPP 13.1-37.283).
- Confirm exact builds in Citrix bulletins; check whether SAML IdP/SP profiles are configured.

**Affected:** NetScaler ADC and Gateway 14.1 and 13.1 branches earlier than the builds above (including FIPS/NDcPP variants).

## 5. CVE-2026-105133 / CVE-2026-105134 — AhsayCBS Authentication Bypass and OS Command Injection

**Principle / root cause:** CVE-2026-105134 is an OS command injection in the Replication Receiver component reachable without authentication (CVSS 10.0 per NVD); CVE-2026-105133 is reported as an authentication bypass (details limited). Huntress reports in-the-wild exploitation to deploy webshells and XMRig cryptominers.

**Mitigation:** Upgrade to AhsayCBS 10.3.4; restrict management/replication ports to trusted networks; hunt for webshells and mining processes.

**Affected:** AhsayCBS backup server versions prior to 10.3.4.

---

## 6. CVE-2026-102489 / CVE-2026-102490 — Zammad Session Fixation and Privilege Escalation

**Principle / root cause:** A session-fixation flaw (CVE-2026-102489) and an improper privilege-management flaw allowing local escalation to root (CVE-2026-102490), which CISA notes can be chained. Disclosed by the Dutch Institute for Vulnerability Disclosure (DIVD), which says its own systems were breached. The vendor disputes affected versions and standalone exploitability; as of 2026-10-05 no formal advisory or confirmed fix for CVE-2026-102490 was found.

**Mitigation:** Monitor Zammad's release notes for fixes; restrict access to the helpdesk to trusted networks, review sessions and system accounts for abuse, and run Zammad with least privilege.

**Affected:** Zammad helpdesk (affected versions disputed). CISA KEV 2026-10-02.
