### 1. PHP "php2shell" — CVE-2026-109618 / CVE-2026-109619 (unverified)
- **Disclosure:** 2026-10-21 (fixes reportedly released the same day). Exploitation attempts reportedly seen from 2026-10-17, before disclosure.
- **Severity:** CVSS v4.0 9.2 (reported); unauthenticated remote code execution.
- **Principle / root cause:** Not confirmed in available sources. Reported as two critical flaws in PHP that together permit unauthenticated RCE.
- **Affected:** PHP versions not confirmed. Check the PHP security advisory.
- **Mitigation:** Upgrade to the fixed PHP release from php.net or your OS vendor; apply WAF rules from your vendor; review web roots for unexpected PHP files.
- **Note:** A targeted search could not corroborate these IDs. Treat as unverified until confirmed on php.net/NVD.

### 2. BeyondTrust Remote Support — CVE-2026-102764
- **Disclosure:** Vendor advisory BT26-05; SaaS patched by 2026-10-09; added to CISA KEV 2026-10-16.
- **Severity:** Critical authentication bypass (CWE-290 per Rapid7 / Canadian Cyber Centre); exploited in the wild, reportedly since August by a China-linked actor.
- **Principle:** Weak verification of the origin or identity of a request lets an attacker be treated as authenticated.
- **Affected:** Remote Support self-hosted 24.3.1 through 26.2.3. Versions older than 24.3.1 must be upgraded first.
- **Mitigation:** Apply patch BT26-05-RS (or upgrade to 26.2.4+, per one source). Treat appliances as potentially compromised: rotate credentials and secrets stored on the appliance, review downstream systems for lateral movement, and check for log deletion.

### 3. Nextcloud Built-in CODE Server (richdocumentscode) — CVE-2026-110447
- **Disclosure:** Published October 2026; fix 26.4.303 reportedly released 2026-09-11. Active exploitation reported (web shells installed on self-hosted servers).
- **Severity:** CVSS v4.0 9.2; unauthenticated OS command injection.
- **Principle:** The proxy component that launches the bundled Collabora server passes unsanitized input to the OS when the server is not running.
- **Affected:** Nextcloud "Built-in CODE Server" app versions before 26.4.303. Standalone Collabora, Docker, RPM/DEB and Nextcloud AIO deployments are reported unaffected.
- **Mitigation:** Update the app to 26.4.303+ or remove it (one source says merely disabling it does not close the hole). Inspect the app directory for unexpected files and rotate secrets if found.

### Palo Alto Networks PAN-OS GlobalProtect — CVE-2026-0257
- **Disclosure:** Originally disclosed and added to KEV around 2026-05-29; Unit 42 updated its threat brief on 2026-10-20 reporting ransomware operators (Qilin, Inc) exploiting it. Older, but exploitation is ongoing.
- **Principle:** Authentication bypass in GlobalProtect when authentication-override cookies are enabled with a particular certificate configuration. CVSS raised from 4.7 to 7.8.
- **Affected:** PAN-OS with GlobalProtect portal/gateway and that cookie configuration. Panorama and Cloud NGFW are not affected.
- **Mitigation:** Upgrade to the fixed release for your branch (see the Palo Alto advisory for the mapping); use a dedicated certificate for override cookies or disable the feature.
