## 1. CVE-2026-86708 — ManageEngine Applications Manager Hard-Coded Cloud Credential Exposure

**Principle / root cause:** The Applications Manager installer package ships with an embedded Google Cloud service-account private key (CWE-321, use of a hard-coded cryptographic key). Anyone who obtains a copy of the installer can extract the key and use it to authenticate as that service account directly against Google Cloud APIs, without ever touching the target's own environment.

**Mitigation:**
- Upgrade to the fixed Applications Manager build above 182200 as soon as Zoho publishes it for your branch.
- Treat the embedded key as already compromised: rotate/revoke any associated Google Cloud service-account credentials and review Cloud IAM audit logs for unexpected activity tied to that account.

**Affected:** ManageEngine Applications Manager versions 182200 and earlier. Disclosed ~2026-09-24; no confirmed in-the-wild exploitation at the time of writing, but the flaw requires no interaction with the victim's infrastructure, so risk is treated as high.

## 2. CVE-2026-59167 — SunEditor Sanitizer Bypass (Stored XSS)

**Principle / root cause:** SunEditor's HTML sanitizer (in `src/lib/core.js`) does not consistently reject namespaced or custom HTML element names, so event-handler attributes (e.g., `onclick`) can survive sanitization when attached to a crafted, non-standard element tag. When an application renders attacker-supplied editor content and a victim interacts with the page, the retained handler executes JavaScript in the victim's browser session under the application's origin (CWE-79, stored cross-site scripting).

**Mitigation:**
- Upgrade `suneditor` to 2.47.11 or later.
- Any application that stores and later re-renders SunEditor-generated HTML for other users should treat this as a priority patch, since the impact is stored (persistent) XSS.

**Affected:** `suneditor` npm package, versions prior to 2.47.11. Published 2026-09-23; no confirmed exploitation reported yet.

## 3. CVE-2026-86248 — Apache Tomcat CLIENT_CERT Authentication Bypass

**Principle / root cause:** When OCSP "soft fail" is disabled, Tomcat's `CLIENT_CERT` authentication does not fail closed as expected in certain revocation-check error scenarios. In effect, a client certificate that should be rejected (because its revocation status could not be confirmed) may still be accepted, undermining the assumption that CLIENT_CERT-gated resources require a valid, non-revoked certificate.

**Mitigation:**
- Upgrade to Tomcat 11.0.26, 10.1.60, or 9.0.122.
- Deployments relying on mutual-TLS client-certificate authentication with OCSP revocation checking should prioritize this update and audit recent access to CLIENT_CERT-protected resources.

**Affected:** Apache Tomcat 11.0.0-M14–11.0.25, 10.1.22–10.1.59, 9.0.92–9.0.121. Made public 2026-09-23; no confirmed in-the-wild exploitation reported yet.

## 4. CVE-2026-12227 — Visual Composer Website Builder Unauthenticated Local File Inclusion

**Principle / root cause:** The plugin's front-end template-loading logic (`PageTemplatesController`, hooked into WordPress's `template_include` filter) honors an attacker-controlled `vcv-template` request parameter (with `vcv-template-type`) without adequately restricting which files on disk it may resolve to. This allows an unauthenticated visitor to make the server include arbitrary files; where an attacker can also place or reuse a file containing PHP (e.g., an uploaded "image" with embedded PHP), this escalates to remote code execution.

**Mitigation:**
- Update to the fixed Visual Composer Website Builder release as soon as available; check the plugin's changelog for the version that resolves this issue.
- As interim mitigation, restrict or monitor requests containing `vcv-template`/`vcv-template-type` parameters at the web server or WAF layer, and audit for unexpected file uploads.

**Affected:** Visual Composer Website Builder (WordPress plugin) ≤45.16.0. Disclosed this week; public technical write-ups and proof-of-concept exist, increasing near-term exploitation risk — patch promptly.

## 5. CVE-2026-19804 — s2Member Unauthenticated Remote Code Execution

**Principle / root cause:** The plugin's "Signup Tracking Codes" feature evaluates (`eval`s) a template that incorporates the user-supplied `first_name` field. Existing input sanitization strips regex backreferences but not PHP tags, so a crafted `first_name` value can inject executable PHP into the evaluated template. This is compounded by disclosure of the site's global proxy-verification key, which lets an attacker forge PayPal postback requests to trigger the vulnerable code path without a genuine transaction.

**Mitigation:**
- Update s2Member to the vendor's fixed release above build 260814.
- Rotate the site's proxy/postback verification key after updating, since the previously disclosed key should be considered compromised.

**Affected:** s2Member (WordPress membership/paywall plugin), versions up to and including build 260814. Disclosed this week; a related privilege-escalation issue (CVE-2026-1994, password-reset abuse) was fixed earlier in 2026 — sites should confirm both fixes are applied.

## 6. CVE-2026-90898 — Bifrost AI Gateway Unauthenticated Remote Code Execution

**Principle / root cause:** Bifrost's management API, which ships with authentication disabled by default, exposes an endpoint (`/api/mcp/client`) for registering MCP (Model Context Protocol) clients. Registering a "stdio" type client causes Bifrost to immediately launch the attacker-specified command as the gateway's own process user — before any protocol handshake or credential check occurs. Because the gateway also holds API keys for every connected AI provider, code execution on the gateway exposes those credentials too.

**Mitigation:**
- Upgrade Bifrost's HTTP transport to 2.1.0 or later.
- Enable management-API authentication explicitly and do not expose the management port beyond localhost/trusted networks, even after patching.
- A related flaw (CVE-2026-86242, disclosed 2026-09-06, allowing unauthenticated plugin registration from an attacker-controlled URL) shares the same root cause and should be remediated together.

**Affected:** Bifrost HTTP transport, all versions before 2.1.0, when management authentication is left at its default (disabled) setting. Disclosed 2026-09-22; notable as an actively-targeted flaw in AI-infrastructure tooling, a growing target category.

## 7. CVE-2026-7273 — Zyxel GS1900 Series Switches Stack-Based Buffer Overflow (Continuity: Active Exploitation)

**Principle / root cause:** A stack-based buffer overflow in the switch firmware's CGI web-management program lets a LAN-adjacent, unauthenticated attacker send a crafted HTTP request that overflows a fixed-size buffer, corrupting adjacent stack memory in a way that enables arbitrary OS command execution on the device.

**Mitigation:**
- Apply Zyxel's firmware update for the GS1900 series.
- Restrict management-interface access to trusted management VLANs/networks only; do not expose switch web management to untrusted LAN segments or the internet.

**Affected:** Zyxel GS1900 series switches running vulnerable firmware. A suspected China-linked actor has exploited this flaw since 2026-08-17, compromising and exfiltrating configuration/credential data from nearly 1,000 switches across dozens of countries using an obfuscated Python-based collector delivered via TFTP. Added to CISA KEV on 2026-09-21 with a short federal remediation deadline.

## 8. CVE-2026-32996 — Veeam Agent for Microsoft Windows Local Privilege Escalation

**Principle / root cause:** The Veeam Endpoint Backup service communicates over a local named pipe and caches an "elevated administrator" session marker keyed to a session UID that is not cryptographically bound to the specific requesting user or connection. Because that UID is written to a service log file that standard (non-administrator) users can read, a local low-privileged user can recover a valid UID and replay it to have the service treat their session as already-elevated, resulting in SYSTEM-level command execution.

**Mitigation:**
- Update to Veeam Backup & Replication 13.0.2.29 / Windows agent build 13.0.3.1220 or later.
- Until patched, restrict interactive/local access to hosts running the affected agent and tighten permissions on the service's log directory.

**Affected:** Veeam Agent for Microsoft Windows 13.0.1.2067 and earlier v13 builds. Public technical details and PoC were released 2026-09-14; active exploitation attempts were being reported by researchers as of ~2026-09-22.

## 9. CVE-2026-76460 — Cisco ISE Authentication Bypass (Continuity: Active Exploitation)

**Principle / root cause:** A specific API endpoint in the Cisco Identity Services Engine (ISE) web management interface fails to enforce authentication before processing requests (CWE-648, incorrect use of privileged APIs). A remote, unauthenticated attacker who can reach the endpoint can invoke privileged administrative functionality directly, gaining access equivalent to an authenticated ISE administrator — including the ability to manipulate network-access policy across the enterprise.

**Mitigation:**
- Apply the fixed releases: 3.1 Patch 12, 3.2 Patch 11, 3.3 Patch 12, 3.4 Patch 7, 3.5 Patch 4, or later. ISE 3.0 has reached end of software maintenance and must be migrated off.
- Restrict network reachability of the ISE management interface to trusted administrative networks.

**Affected:** Cisco ISE and ISE Passive Identity Connector, versions prior to the fixes above. Added to CISA KEV on 2026-09-16; continued exploitation and analysis were still being reported this week.

## 10. CVE-2026-76461 — Cisco Secure Email Gateway SQL Injection to Root RCE (Continuity: Active Exploitation)

**Principle / root cause:** AsyncOS's email-parsing logic does not sufficiently validate certain data extracted from incoming messages before using it in backend SQL queries (CWE-89, SQL injection). Because the vulnerable parsing occurs automatically for all inbound mail, an unauthenticated attacker can trigger it simply by sending a specially crafted email to a vulnerable gateway — no administrative access or interaction is required. Successful SQL injection is further leveraged to execute operating-system commands with root privileges.

**Mitigation:**
- Apply Cisco's fixed AsyncOS releases (15.5.5-014, 16.0.4-302, 16.5.0-780, or later for the corresponding branch).
- Review gateway and mail logs for signs of anomalous processing or configuration changes, since root-level compromise can allow attackers to erase evidence.

**Affected:** Cisco Secure Email Gateway appliances running vulnerable AsyncOS releases. Cisco's advisory was published 2026-09-14 following discovery during a support case, with active exploitation confirmed around the same time; exploitation activity and remediation guidance continued to be discussed through this week.

## 11. CVE-2026-87886 — Acronis Backup Plugin Insecure Default Permissions (Continuity: Active Exploitation)

**Principle / root cause:** The Acronis Backup plugin for cPanel/WHM, Plesk, and DirectAdmin installs certain files or directories with overly permissive access controls (CWE-276, incorrect default permissions). An attacker who already holds low-privileged, authenticated access to the shared-hosting server can leverage this weak permission configuration to escalate to a higher-privileged Linux account.

**Mitigation:**
- Upgrade to the fixed builds: cPanel/WHM plugin 1.9.3.1021+, Plesk extension 1.8.11.638+, DirectAdmin plugin 1.2.3.238+.
- Audit shared-hosting environments for signs of privilege-escalation activity involving the Acronis plugin since exploitation was confirmed.

**Affected:** Acronis Backup plugin/extension for cPanel & WHM, Plesk, and DirectAdmin (Linux) prior to the fixed builds. Added to CISA KEV on 2026-09-16 after Acronis confirmed in-the-wild exploitation against cPanel/WHM deployments specifically.

## 12. CVE-2026-69399 — Microsoft Azure Arc Elevation of Privilege (Continuity)

**Principle / root cause:** Azure Arc, used to extend Azure management to hybrid/on-premises and edge resources, contained a flaw (CWE-441, unintended proxy or intermediary) that could let a network attacker cause the service to act as an unintended proxy, enabling elevation of privilege without authentication or user interaction.

**Mitigation:** No customer action beyond normal Azure Arc agent updates is generally required for cloud-service-side fixes; confirm connected-machine agents are on a current, supported version and review Azure Arc RBAC assignments as good practice.

**Affected:** Microsoft Azure Arc service. Publicly disclosed 2026-09-17, at the edge of this week's window; included for its maximum CVSS score and because hybrid-cloud management planes are a high-value target. Microsoft manages remediation for the cloud-hosted service component.
