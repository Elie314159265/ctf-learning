## 1. CVE-2026-75650 — Adobe Commerce / Magento "StyleSmuggler" Unauthenticated RCE

**Principle / root cause:** An improper-neutralization flaw (CWE-1336) in Magento's template engine allows attacker-controlled content injected through a "styles" property to be written to disk as part of normal platform operation. Because the template engine does not adequately sandbox this style data, an attacker can smuggle PHP code inside it. The payload later executes when Magento renders a specific transactional email template (the "Payment Transaction Failed Reminder" notification), giving an unauthenticated remote attacker full code execution and letting them install a persistent backdoor.

**Mitigation:**
- Apply Adobe's hotfix VULN-39341 (bulletin APSB26-146) immediately via Composer.
- Because exploitation began three days before the patch existed, treat any unpatched instance as potentially already compromised: check for unexpected files, unfamiliar admin/API users, and unusual outbound connections (reports describe a Rust-based backdoor and a PHP web shell being dropped).

**Affected:** Adobe Commerce, Adobe Commerce B2B, and Magento Open Source versions 2.4.4 through 2.4.9. Actively exploited in the wild starting 2026-09-04; hotfix released 2026-09-07.

## 2. CVE-2026-86218 — N-able N-central Unauthenticated Pre-Auth RCE

**Principle / root cause:** A static/hardcoded value used in a code-generation or code-loading path lets an unauthenticated attacker inject and execute arbitrary code on the N-central server before any authentication check occurs. This is the fourth N-central hotfix issued in five weeks, indicating the platform's update/plugin-loading architecture has repeatedly failed to isolate untrusted input from code execution paths.

**Mitigation:**
- Apply N-central 2026.3 Hotfix 4 (released 2026-09-05) immediately; earlier hotfixes (including HF3) do not close this specific flaw.
- Because a fully patched customer environment was reportedly still compromised via an as-yet-unpatched variant discovered during incident response, treat any on-premises N-central deployment as high-risk until HF4 is confirmed applied, and review for unauthorized administrative activity or new endpoint agents pushed to managed devices.

**Affected:** On-premises N-able N-central instances prior to 2026.3 Hotfix 4. Actively exploited; discovered via a customer compromise investigation starting 2026-09-04; added to CISA KEV on 2026-09-09 with a 2026-09-11 federal remediation deadline.

## 3. CVE-2026-20079 & CVE-2026-20316 — Cisco Secure Firewall Management Center Auth Bypass Chain

**Principle / root cause:** CVE-2026-20079 stems from a system process on the FMC web interface that is improperly initialized at device boot time, letting an unauthenticated network attacker send crafted HTTP requests that bypass authentication and execute scripts/commands with root privileges. CVE-2026-20316 is a separate flaw involving static, non-removable credentials in the same product. Combined, the two let an attacker skip authentication entirely and then use the embedded credentials to expand access, deploying web shells, credential-theft tooling, and (in one observed cluster) a variant of the Cyclops Blink malware.

**Mitigation:**
- Apply Cisco's hotfixes for affected FMC releases (7.0.9, 7.2.11, 7.4.6, 7.6.5, 7.7.12, or 10.0.1) — there is no workaround.
- Assume compromise if the appliance was internet-reachable and unpatched during the exploitation window; hunt for unexpected web shells, JAR-based command execution artifacts, new local accounts, and unexpected reverse-shell/proxy traffic.

**Affected:** Cisco Secure Firewall Management Center software on the versions above. CVE-2026-20079 was originally disclosed 2026-03-04, but Cisco PSIRT confirmed active exploitation dating to August 2026 in an advisory update on 2026-09-09 (added to CISA KEV the same day). Exploitation is attributed to multiple clusters, including the Sandworm and Qilin groups.

## 4. CVE-2026-81963 & CVE-2026-85880 — Windows Local Privilege Escalation Zero-Days (September Patch Tuesday)

**Principle / root cause:** CVE-2026-81963 is an improper link-resolution ("link following") flaw in the Windows Update Stack: a local process can manipulate a filesystem link so that an operation intended for one file is redirected to another, letting a low-privileged process trigger actions with SYSTEM-level effect. CVE-2026-85880 is a heap-based buffer overflow in Windows Advanced Local Procedure Call (ALPC), the inter-process messaging mechanism Windows components use to talk to privileged services; an attacker who can already run code in a low-privilege sandbox (an AppContainer) can corrupt heap memory in the ALPC handler to escape that sandbox and gain SYSTEM privileges.

**Mitigation:**
- Install the 2026-09-08 Windows cumulative updates, which fix both issues, as soon as possible.
- Both flaws require existing local code execution to exploit, so they are typically the second stage of an attack chain — prioritize patching alongside efforts to prevent initial footholds (phishing, browser exploits, etc.).

**Affected:** Supported Windows client and server versions prior to the 2026-09-08 cumulative update. Both were confirmed exploited in the wild before the patch shipped; part of a record 964–974 CVEs fixed in this Patch Tuesday. Added to CISA KEV on 2026-09-08 with a 2026-09-22 federal remediation deadline.

## 5. CVE-2026-87491 — Google Chrome V8 Out-of-Bounds Write (Zero-Day)

**Principle / root cause:** A memory-safety defect in V8 (Chrome's JavaScript/WebAssembly engine) allows script running on a malicious web page to write outside the bounds of an allocated buffer. Out-of-bounds writes of this kind can corrupt adjacent memory structures, letting an attacker execute arbitrary code within the browser's renderer sandbox simply by getting a victim to load a crafted page.

**Mitigation:** Update Chrome to 153.0.8010.36/.37 (Windows/macOS) or 153.0.8010.36 (Linux), and apply the equivalent fix in any Chromium-based browser (Edge, Brave, Opera, etc.) once available.

**Affected:** Chrome versions prior to 153.0.8010.36. Actively exploited in the wild; patched 2026-09-08. This is the seventh actively-exploited Chrome zero-day disclosed in 2026 and the second within five days (following CVE-2026-85046 below).

## 6. CVE-2026-85046 — Google Chrome V8 Type Confusion (Zero-Day)

**Principle / root cause:** A type-confusion bug in V8 occurs when the engine treats a memory object as one data type while it is actually another, letting crafted JavaScript trick V8 into performing operations that violate the object's real memory layout. This can be leveraged for arbitrary read/write primitives and ultimately code execution inside Chrome's sandbox.

**Mitigation:** Update Chrome to 152.0.7977.82/.83 (Windows/macOS) or 152.0.7977.82 (Linux).

**Affected:** Chrome versions prior to 152.0.7977.82. Actively exploited in the wild; patched 2026-09-03. Added to CISA KEV on 2026-09-04.

## 7. CVE-2026-19490 — Citrix NetScaler ADC/Gateway Authentication Bypass

**Principle / root cause:** Classified as CWE-288 (authentication bypass using an alternate path), the flaw allows a remote, unauthenticated attacker to reach an alternate request path that does not enforce the same authentication checks as the normal login flow, when the appliance is configured as a Gateway or AAA virtual server (on newer builds, only when a SAML action is also configured; on older builds, any Gateway/AAA configuration is enough).

**Mitigation:**
- Upgrade to NetScaler ADC/Gateway 14.1-73.32, 13.1-63.21, or later (patches released 2026-08-19).
- Because a credible public PoC now circulates and exploitation is confirmed, treat any unpatched appliance as compromised-until-proven-otherwise; review authentication logs for anomalous session creation.

**Affected:** NetScaler ADC and NetScaler Gateway versions prior to 14.1-73.32 / 13.1-63.21. Active exploitation reported starting 2026-09-04, following publication of a working PoC; added to CISA KEV on 2026-09-09.

## 8. CVE-2025-25249 — Fortinet FortiOS / FortiSwitchManager / FortiSASE Heap Buffer Overflow

**Principle / root cause:** The affected component fails to validate the length of attacker-supplied input before copying it into a fixed-size heap buffer. Because no authentication is required to reach the vulnerable code path, a specially crafted network packet can overflow the buffer, corrupting adjacent heap memory to achieve remote code execution.

**Mitigation:**
- Upgrade FortiOS, FortiSwitchManager, or FortiSASE to a fixed release per Fortinet's advisory.
- Restrict management-plane exposure to trusted networks; monitor for indicators associated with the PivotC2 post-exploitation RAT that has been observed deployed via this flaw.

**Affected:** FortiOS 6.4 (all versions), 7.0.0–7.0.17, 7.2.0–7.2.11, 7.4.0–7.4.8, 7.6.0–7.6.3; FortiSwitchManager 7.0.0–7.0.5 and 7.2.0–7.2.6. Actively exploited; added to CISA KEV on 2026-09-09 with a 2026-09-12 federal remediation deadline, despite the CVE having been originally issued against 2025.

## 9. CVE-2026-32475 (Elementor Pro) & CVE-2026-14894 (Super Forms) — WordPress Plugin Mass-Exploitation Surge

**Principle / root cause:** Both flaws are unauthenticated arbitrary file-upload vulnerabilities (missing file-type validation and missing capability checks on AJAX/file-handling endpoints) that let an attacker upload a PHP web shell disguised as a legitimate file, achieving remote code execution once the file is accessed. Both were patched weeks ago (Elementor Pro 4.2.2, Super Forms 6.3.314), but Wordfence reported over 440,000 combined exploitation attempts against unpatched sites in the days around 2026-09-07, indicating a fresh, coordinated scanning/exploitation campaign against the patch gap.

**Mitigation:**
- Update Elementor Pro to 4.2.2+ and Super Forms to 6.3.314+ immediately.
- Scan for unfamiliar PHP files in uploads directories and unexpected admin users, even on sites believed to be already patched.

**Affected:** Elementor Pro ≤4.2.1 (CVE-2026-32475, CVSS 9.8) and Super Forms ≤6.3.313 (CVE-2026-14894, CVSS 9.8). Both underlying flaws were disclosed/patched in mid-2026; the mass-exploitation wave was newly reported this week (2026-09-07).

## 10. Android September 2026 Security Bulletin

**Mitigation:** Install the 2026-09-05 (or later) security patch level once available from your device manufacturer.

**Affected:** Android devices on security patch levels prior to 2026-09-05. Published 2026-09-08; no confirmed in-the-wild exploitation of these specific new CVEs at time of writing.
