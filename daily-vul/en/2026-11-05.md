## 1. CVE-2026-119977 — WordPress Core Update-Process Race Condition (TOCTOU)

**Principle / root cause:** A time-of-check/time-of-use race condition in the WordPress core update (upgrade/staging) process. State validated at one moment can change before it is used, letting an attacker who wins the timing window influence what is processed during an update. Exploitation requires high attack complexity.

**Mitigation:**
- Update to WordPress 7.1.4 (7.1 branch) or 7.0.8 (7.0 branch) or later.
- Confirm automatic core updates are enabled; review sites for unexpected file changes after update windows.

**Affected:** WordPress core 7.1.0–7.1.3 and 7.0.0–7.0.7 (per third-party reports).
**Disclosure:** Added to CISA KEV on 2026-11-03; federal due date 2026-11-06.
**Note:** CNA is Wordfence. One outlet (SecurityWeek) associates the same race condition with CVE-2026-97229, which other sources assign to GitLab (item 3); the ID mapping is unreconciled.

## 2. CVE-2026-111357 & CVE-2026-118527 — Ivanti Connect Secure Exploit Chain

**Principle / root cause:** Part of a three-flaw chain with authentication bypass CVE-2026-104935. Attackers first gain access via the auth bypass, then abuse CVE-2026-118527 (an authenticated file-upload weakness that places malicious content in a predictable location), then CVE-2026-111357 (a privilege-escalation flaw) to obtain full root control of the VPN appliance.

**Mitigation:**
- Upgrade to Ivanti Connect Secure 25.1.1.3 (25.1.x) or 22.8R2.6 (22.8R2.x).
- Run Ivanti's Integrity Checker Tool, review appliances for signs of compromise, and rotate credentials/secrets stored on or reachable from affected appliances if compromise is suspected.

**Affected:** Ivanti Connect Secure (25.1.x and 22.8R2.x builds prior to the fixed releases).
**Disclosure:** Ivanti patched 2026-10-29; both added to CISA KEV 2026-10-30. Federal due dates: 2026-11-02 (CVE-2026-111357) and 2026-11-13 (CVE-2026-118527).
**Note:** CVSS for CVE-2026-111357 differs by source (8.8 Ivanti vs 7.0 MITRE/NVD).

## 3. CVE-2026-97229 — GitLab Integer Overflow / Wraparound

**Principle / root cause:** An integer overflow/wraparound weakness in GitLab Community and Enterprise Editions. Arithmetic on an attacker-influenced value exceeds its type's range, leading to unintended memory/logic behavior; reported as remote code execution capable and rated CVSS 10.0.

**Mitigation:**
- Upgrade to the latest patched GitLab release per GitLab's security release notes.
- Restrict exposure of self-managed instances to trusted networks until patched; review logs for anomalous activity.

**Affected:** Self-managed GitLab CE/EE (exact versions per GitLab advisory; not confirmed here).
**Disclosure:** Added to CISA KEV 2026-10-29; federal due date 2026-11-01 (passed).

## 4. CVE-2026-76418 — Cisco ASA / FTD SSL VPN Denial of Service

**Principle / root cause:** An unauthenticated remote attacker can cause Cisco Secure Firewall ASA and Secure Firewall Threat Defense (FTD) devices running SSL VPN to crash or reload by sending traffic that triggers improper handling in the VPN service.

**Mitigation:**
- Install the fixed ASA/FTD releases listed in Cisco's advisory.
- Where patching is delayed, limit SSL VPN exposure and monitor for unexpected device reloads.

**Affected:** Cisco ASA and FTD with SSL VPN enabled (versions per Cisco advisory).
**Disclosure:** Added to CISA KEV 2026-10-29; federal due date 2026-11-01 (passed). A correction notice was issued to the KEV bulletin.

## 5. CVE-2026-98432 — Linux Kernel IPv4 TCP Use-After-Free (Remote)

**Principle / root cause:** A race condition in how the kernel frees IPv4 options attached to an incoming TCP connection request. When request-socket migration is in play (net.ipv4.tcp_migrate_req=1, or a BPF reuseport migrate program), the options can be freed while still referenced, resulting in a use-after-free. Upstream fix: free the options after an RCU grace period. The flaw dates back to Linux 4.4.

**Mitigation:**
- Install your distribution's fixed kernel and reboot.
- Interim: disable MPTCP where not needed (net.mptcp.enabled=0) and set net.ipv4.tcp_migrate_req=0. This removes the currently known remote path but does not fix the bug.

**Affected:** Linux kernels since 4.4 (pre-fix). As of 2026-10-30, fixed kernels were reported for Debian, SUSE, Oracle Linux and Amazon Linux 2023 (some releases); Ubuntu and RHEL had not yet shipped fixes. Check current distro advisories.
**Disclosure:** CVE published 2026-10-15 (fix committed 2026-10-05); a remote-root exploit against MPTCP listeners was publicly disclosed 2026-10-27. In-the-wild exploitation status is reported inconsistently.

## 6. CVE-2026-41709 — VMware ESX/ESXi Low-Severity Flaw Used for Concealment

**Principle / root cause:** A low-severity (CVSS 2.7) flaw on ESX hosts that, per reports, is being used by threat actors after compromise to hide malicious activity on hypervisors.

**Mitigation:**
- Apply Broadcom's fixed ESXi builds for 8.0 and 9.0.
- Monitor hypervisor logging and integrity; restrict management-plane access.

**Affected:** VMware ESX/ESXi 8.0 and 9.0 (builds per Broadcom advisory).
**Disclosure:** Added to CISA KEV 2026-10-28; one source gives the federal due date as 2026-11-11.
