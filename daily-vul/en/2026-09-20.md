## 1. CVE-2026-93603 — vm2 (npm) Sandbox Escape to Remote Code Execution

**Principle / root cause:** vm2 is a popular Node.js library used to run untrusted JavaScript in an isolated "sandbox." The flaw is in how vm2's bridge code handles a host function called from inside the sandbox without an explicit receiver (`this`). When a non-strict host-provided function is invoked this way, the underlying JavaScript engine substitutes the real, non-sandboxed global object as `this`; vm2 then wraps and hands that object back into the sandbox instead of blocking it. Untrusted sandboxed code can use this live reference to reach the host process object and invoke privileged host APIs — a complete escape from the sandbox boundary the library exists to enforce, resulting in arbitrary code execution on the host. Two related CVEs (CVE-2026-93605, CVE-2026-93606) describe overlapping escape paths in the same bridge/NodeVM code.

**Mitigation:**
- Upgrade to vm2 3.12.1 or later, which corrects the receiver-handling logic.
- Treat any application that exposes non-strict host functions to a vm2 sandbox as high risk; the vm2 project itself has long recommended migrating to actively maintained isolation mechanisms (e.g., `isolated-vm`, separate worker processes with OS-level sandboxing) rather than relying on vm2 for security boundaries against untrusted code.
- Audit any service that executes user-supplied "plugin," "script," or "formula" code through vm2 for signs of anomalous process/child_process activity.

**Affected:** vm2 (npm package) through 3.12.0. Disclosed 2026-09-18; CVSS 10.0. Given vm2's use in plugin systems, low-code platforms, and CI/build tooling, this has significant blast-radius potential wherever it processes third-party or user-submitted code.

## 2. CVE-2025-39682, CVE-2026-53266, CVE-2025-39964 — Linux Kernel: Three Actively Exploited Flaws

**Principle / root cause:**
- **CVE-2025-39682 (CVSS 9.8)** — In the kernel's TLS offload ("kTLS") receive path (`net/tls/tls_sw.c`), an improper check for a zero-length TLS record retrieved from an internal `rx_list` queue lets such a record bypass the normal `recvmsg()` record-type handling. This can corrupt kernel memory state and has been leveraged for local root privilege escalation. kTLS is widely used by high-performance, internet-facing servers to offload TLS processing, giving this a broad attack surface.
- **CVE-2026-53266 (CVSS 8.8)** — An out-of-bounds write in the `ebtables` SNAT (Source NAT) ARP-rewrite code path, triggerable by a local attacker to cause memory corruption, denial of service, or local privilege escalation.
- **CVE-2025-39964 (CVSS 7.8)** — A race condition in the kernel's AF_ALG cryptographic socket interface: concurrent writes to the same AF_ALG socket can interleave unpredictably, leaving internal kernel state inconsistent and exploitable for privilege escalation.

**Mitigation:**
- Apply the kernel updates/backports that address these three CVEs for your distribution as soon as they are available; CISA's federal deadline is 2026-09-21.
- CISA has also flagged these for forensic triage, not just patching — review systems for signs of prior exploitation (unexpected privilege escalation, unusual kTLS-consuming workloads) rather than assuming patching alone is sufficient.

**Affected:** Linux kernel builds containing the vulnerable kTLS, ebtables, and AF_ALG code prior to the respective fixes. All three added to CISA KEV on 2026-09-18 with confirmed active exploitation.

## 3. CVE-2026-76460 — Cisco Identity Services Engine (ISE) Authentication Bypass Zero-Day

**Principle / root cause:** An API endpoint in Cisco ISE and ISE Passive Identity Connector (ISE-PIC) does not apply sufficient authentication controls. A remote, unauthenticated attacker can send crafted requests directly to this endpoint to bypass authentication entirely, regardless of how the appliance is otherwise configured. Once authenticated access is bypassed, the flaw can be leveraged to execute commands with root privileges — enabling attackers to also erase or hide indicators of compromise on the appliance.

**Mitigation:**
- Upgrade to ISE/ISE-PIC 3.5 Patch 4, 3.4 Patch 7, 3.3 Patch 12, 3.2 Patch 11, or 3.1 Patch 12.
- No workaround eliminates the flaw; as an interim measure, apply infrastructure access control lists (iACLs) restricting network reachability to the affected management interface until patched.

**Affected:** Cisco ISE and ISE-PIC, all currently supported release trains prior to the patched versions above. Actively exploited as a zero-day; Cisco PSIRT confirmed in-the-wild exploitation and CISA added it to KEV with a 3-day federal remediation deadline (the second Cisco zero-day disclosed within roughly 24 hours of a prior one that week, alongside the Secure Email Gateway flaw below).

## 4. CVE-2026-87886 — Acronis Backup Plugin Local Privilege Escalation

**Principle / root cause:** The Acronis Backup plugin/extension for cPanel & WHM, Plesk, and DirectAdmin ships with incorrect default file permissions (CWE-276) on Linux hosting servers. An attacker who already has low-privileged, authenticated local access to the server (a very common scenario on shared hosting) can leverage these overly permissive files to cross a privilege boundary and gain substantially elevated access, without any additional user interaction required.

**Mitigation:**
- Update to Acronis Backup plugin for cPanel & WHM build 1.9.3.1021+, Plesk extension build 1.8.11.638+, or DirectAdmin plugin build 1.2.3.238+.
- On shared-hosting environments, audit for unexpected privilege changes or unauthorized administrative actions since exploitation began.

**Affected:** The three plugin/extension variants listed above, all versions prior to the fixed builds. Exploitation observed in the wild specifically against the cPanel & WHM variant. Added to CISA KEV 2026-09-16, federal deadline 2026-09-19.

## 5. CVE-2026-76461 — Cisco Secure Email Gateway SQL Injection to Root RCE

**Principle / root cause:** Cisco AsyncOS for Secure Email Gateway insufficiently validates content during email parsing. A remote, unauthenticated attacker can send a specially crafted email containing malicious SQL statements through a vulnerable gateway; the injected SQL is processed with sufficient privilege that it results in arbitrary command execution as root on the appliance — no credentials or user interaction required.

**Mitigation:**
- Upgrade AsyncOS to 15.5.5-014 (for 15.5 and earlier), 16.0.4-302 (16.0 branch), or 16.5.0-780 (16.5 branch).
- Review mail-gateway logs for anomalous inbound messages and unexpected process activity predating the patch.

**Affected:** Cisco Secure Email Gateway appliances running affected AsyncOS branches. Cisco's advisory was published 2026-09-14 and the CVE was added to CISA KEV the same day — an indicator that it was being exploited as a zero-day before public disclosure.

## 6. CVE-2026-19490 — Citrix NetScaler ADC/Gateway Authentication Bypass (Continuity)

**Principle / root cause:** An authentication bypass using an alternate path or channel (CWE-288) in NetScaler appliances configured as an AAA virtual server or Gateway service (SSL VPN, ICA Proxy, CVPN, RDP Proxy) lets a remote, unauthenticated attacker reach functionality that should require valid credentials.

**Mitigation:** Apply Citrix's fixed builds immediately; treat any NetScaler exposed to exploitation since early September as requiring forensic review, not just patching.

**Affected:** NetScaler ADC and Gateway appliances in the affected configurations. Exploited in the wild since approximately 2026-09-03; added to CISA KEV 2026-09-09 with a federal deadline of 2026-09-12 (already passed) — included here because remediation is still incomplete industry-wide and the exploitation window continues.

## 7. CVE-2026-20079 — Cisco Secure Firewall Management Center Authentication Bypass (Continuity)

**Principle / root cause:** A system process created improperly at FMC boot time leaves a partial administrative session recorded in an internal sessions database. If no legitimate user logs in after a boot, this stale partial session persists and can be manipulated by a remote, unauthenticated attacker sending crafted HTTP requests into full administrative access, ultimately yielding root command execution on the underlying OS. A related flaw, CVE-2026-20316, was disclosed alongside it.

**Mitigation:** Apply Cisco's fixed software; there is no effective workaround. Given confirmed exploitation reaching back to at least July 2026, review FMC systems for prior compromise.

**Affected:** Cisco Secure Firewall Management Center (on-prem) deployments prior to the fix. Exploited by both nation-state and financially motivated (ransomware) actors; added to CISA KEV 2026-09-09, federal deadline 2026-09-12 (already passed).

## 8. CVE-2026-87491 — Google Chrome/Chromium V8 Out-of-Bounds Write (Continuity)

**Principle / root cause:** An out-of-bounds write in the V8 JavaScript engine can be triggered by attacker-controlled web content, potentially corrupting memory in a way that enables further exploitation (typically chained with a sandbox-escape bug for full compromise).

**Mitigation:** Ensure Chrome/Chromium-based browsers are fully updated; browser auto-update should already have applied the fix, but verify the installed version manually on managed fleets.

**Affected:** Chrome/Chromium versions prior to the fixed release. Actively exploited; added to CISA KEV 2026-09-09.

## 9. CVE-2025-25249 — Fortinet Multiple Products Heap-Based Buffer Overflow (Continuity)

**Principle / root cause:** A heap-based buffer overflow (CWE-122) in affected Fortinet products allows an attacker to write past the bounds of an allocated heap buffer, corrupting adjacent memory in ways that can lead to denial of service or code execution depending on the affected component and exploitation technique.

**Mitigation:** Apply Fortinet's security updates for the affected products/versions per the vendor advisory.

**Affected:** Multiple Fortinet products (see Fortinet's advisory for exact version ranges). Actively exploited; added to CISA KEV 2026-09-09.
