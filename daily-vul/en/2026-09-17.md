## 1. CVE-2026-76460 — Cisco ISE / ISE-PIC Unauthenticated Root Access (Zero-Day, CVSS 10.0)

**Principle / root cause:** A specific REST API endpoint on Cisco Identity Services Engine fails to enforce authentication controls correctly. A remote attacker can send a crafted request directly to that endpoint and bypass the web-based management login entirely, regardless of how the device is configured. Once past the login boundary, the flaw allows the attacker to escalate to root-level command execution on the appliance itself.

**Mitigation:**
- Upgrade immediately to a fixed release: 3.1 Patch 12, 3.2 Patch 11, 3.3 Patch 12, 3.4 Patch 7, or 3.5 Patch 4.
- Cisco states there is no workaround; patching is the only remediation.
- Because ISE sits at the center of network access policy, treat any compromised instance as a full network-trust breach: rotate credentials/certificates issued or verified by ISE and review policy/logging integrity.

**Affected:** Cisco ISE and ISE-PIC, all supported configurations. Cisco confirmed active exploitation; added to CISA KEV on 2026-09-16 with a federal remediation deadline of 2026-09-19. Successful exploitation has been observed enabling policy modification, credential extraction, log deletion, and lateral movement.

## 2. CVE-2026-58704 — Google Pixel Cellular Modem Privilege Escalation (Spyware-Linked)

**Principle / root cause:** A logic error in the Pixel cellular modem's authorization checks allows permission verification to be bypassed under certain conditions. Because the flaw sits in baseband/modem-adjacent code, it can potentially be triggered without any user interaction (a "zero-click" exploitation path), letting an attacker escalate privileges on the device.

**Mitigation:**
- Update affected Pixel devices to the September 2026 security patch level (2026-09-05) or later.
- Organizations issuing Pixel devices to high-risk personnel should prioritize this update given reported ties to targeted, spyware-style tradecraft.

**Affected:** Google Pixel devices from the Pixel 6 series through the Pixel 11 family, plus Pixel Tablet and Pixel Fold, with a security patch level prior to 2026-09-05. Disclosed in Google's September 2026 Android/Pixel bulletin; confirmed under active, limited/targeted exploitation. Added to CISA KEV on 2026-09-16 with a federal deadline of 2026-09-19.

## 3. CVE-2026-87886 — Acronis Backup Plugin (cPanel/Plesk) Local Privilege Escalation

**Principle / root cause:** The Acronis Backup integration for cPanel & WHM and the Acronis Backup extension for Plesk (both on Linux) ship with overly permissive default file/directory permissions (CWE-276). An attacker who already holds low-privileged, authenticated local access to the server can leverage these loose permissions to cross a privilege boundary and obtain substantially greater control, without needing further user interaction.

**Mitigation:**
- Update the Acronis Backup plugin for cPanel & WHM (Linux) to build 1.9.3.1021 / 1.9.3 HF3 or later.
- Update the Acronis Backup extension for Plesk (Linux) to build 1.8.11.638 or later.
- Audit hosting accounts for unexpected privilege changes on servers where the plugin is installed.

**Affected:** Acronis Backup plugin for cPanel & WHM (Linux) prior to build 1.9.3.1021, and the Plesk extension prior to build 1.8.11.638. Acronis confirmed in-the-wild exploitation against cPanel & WHM deployments specifically. Added to CISA KEV on 2026-09-16, federal deadline 2026-09-19.

## 4. CVE-2026-76461 — Cisco Secure Email Gateway SQL Injection to Root RCE (Zero-Day)

**Principle / root cause:** The email-parsing logic in Cisco AsyncOS Software for Secure Email Gateway inserts attacker-influenced content from an incoming email into backend SQL queries without adequate sanitization (SQL injection, CWE-89). By simply sending a crafted email through an affected gateway, an unauthenticated remote attacker can inject SQL that is ultimately used to execute operating-system commands with root privileges on the appliance.

**Mitigation:**
- Upgrade to Cisco AsyncOS for Secure Email Gateway 15.5.5-014, 16.0.4-302, or 16.5.0-780 (or later).
- Review `mail_logs` on every appliance, including each node in a cluster, for suspicious SQL statements — Cisco specifically flags entries resembling `COPY … TO PROGRAM` as an indicator of compromise.

**Affected:** Cisco Secure Email Gateway (AsyncOS Software) prior to the fixed builds above. Cisco PSIRT became aware of active exploitation and disclosed the flaw on 2026-09-14; added to CISA KEV the same day.

## 5. CVE-2026-85706 — GitLab CE/EE Path Traversal (Arbitrary File Read)

**Principle / root cause:** The repository commits API in GitLab CE and EE fails to properly constrain path components supplied in a request, allowing a path-traversal sequence to escape the intended repository directory. Under certain conditions, this lets an unauthenticated attacker read arbitrary files from the GitLab server's filesystem — potentially including configuration files and credentials, which can be leveraged for further compromise.

**Mitigation:**
- Upgrade self-managed GitLab to 19.3.2, 19.2.6, or 19.1.8 (or later), released 2026-09-10.
- Treat this as urgent: internet-wide scanning for vulnerable instances began within a day of disclosure. Rotate any secrets that may have been readable via the flaw (CI/CD variables, tokens, SSH/TLS keys) as a precaution.

**Affected:** Self-managed GitLab CE/EE prior to the fixed versions above (GitLab.com/SaaS was patched centrally). Disclosed 2026-09-10; added to CISA KEV on 2026-09-11 following confirmed active exploitation.

## 6. CVE-2026-87719 — GitLab EE Insecure Deserialization via GraphQL Subscriptions

**Principle / root cause:** GitLab EE's GraphQL subscription serializer does not adequately validate subscription arguments before using them to perform a server-side object lookup (insecure deserialization, CWE-502). An authenticated user with access to the Duo Chat feature can submit a specially crafted subscription argument to bypass the intended serialization controls, potentially exposing Advanced Search configuration data and associated credentials.

**Mitigation:**
- Upgrade to GitLab EE 19.3.2, 19.2.6, or 19.1.8 (or later) — the same patch release that fixes CVE-2026-85706.
- Rotate any Advanced Search / Elasticsearch credentials that may have been exposed.

**Affected:** GitLab EE 18.3 through 19.3 (prior to the fixed builds); GitLab CE is not affected since it lacks Duo Chat/Advanced Search. Fixed 2026-09-10 alongside CVE-2026-85706; no confirmed in-the-wild exploitation reported as of this writing, but treat as high priority given its severity and the co-disclosed file-read bug already under attack.

## 7. CVE-2026-20079 & CVE-2026-20316 — Cisco Secure FMC Boot-Session Abuse and Hard-Coded Credential Chain

**Principle / root cause:** CVE-2026-20079 (CVSS 10.0) exploits a startup process on Cisco Secure Firewall Management Center that creates a partial internal session in the platform's database; if no administrator logs in immediately after boot, that orphaned session can be upgraded and abused to invoke privileged CGI scripts, ultimately achieving root command execution via a crafted license-validation workflow. CVE-2026-20316 (CWE-259, hard-coded credentials) is a separate flaw allowing authentication to the FMC web interface with a built-in, low-privileged account; it has been chained with other FMC issues to escalate access. Together, these give attackers a practical path from unauthenticated network access to full appliance compromise.

**Mitigation:**
- Apply Cisco's hot fixes for the affected FMC release train (7.0, 7.2, 7.4, 7.6, 7.7, 10.0) immediately via Cisco Software Center — there is no workaround.
- Cisco warns that patching alone does not remediate an already-compromised device; conduct forensic triage on any internet-exposed FMC instance.

**Affected:** Cisco Secure Firewall Management Center, all currently supported release trains (Cloud-Delivered FMC and several other Cisco Secure Firewall products are not affected). Cisco Talos has attributed exploitation to multiple distinct intrusion clusters, including a Sandworm-linked APT group and a Qilin ransomware affiliate, with reporting on this attribution published 2026-09-10; both CVEs are in CISA KEV.

## 8. CVE-2025-25249 — Fortinet FortiOS / FortiSwitchManager Heap Overflow (PivotC2 RAT Campaign)

**Principle / root cause:** Insufficient bounds checking in the packet-processing logic of FortiOS/FortiSwitchManager's `cw_acd` daemon allows specially crafted network packets to write past the end of an allocated heap buffer (heap-based buffer overflow, CWE-122). No authentication is required to reach the vulnerable code path, and successful exploitation can lead to arbitrary code execution on the device.

**Mitigation:**
- Upgrade to FortiOS 7.6.1/7.6.2/7.6.3 or later fixed release for your branch (7.4, 7.2, 7.0, or 6.4 lines — consult Fortinet's advisory for the exact fixed build per branch).
- Restrict management-plane and any unnecessary network exposure of affected devices.

**Affected:** FortiOS 7.6.0–7.6.3, 7.4.0–7.4.8, 7.2.0–7.2.11, 7.0.0–7.0.17, 6.4.x, and FortiSwitchManager 7.2.0–7.2.6 and 7.0.0–7.0.5, prior to fixed builds. Added to CISA KEV on 2026-09-09. Ongoing reporting (into this week's window) links the flaw to a campaign deploying a Node.js-based remote access trojan dubbed "PivotC2," with roughly 3,000 IPs targeted and 178 confirmed device infections, concentrated in the US.

## 9. CVE-2026-19490 — Citrix NetScaler ADC/Gateway Authentication Bypass (Continuity Note)

Disclosed by Citrix on 2026-08-19 (CTX696939) as an authentication-bypass flaw (CWE-288) affecting NetScaler instances configured as an AAA virtual server or Gateway (SSL VPN/ICA Proxy/CVPN/RDP Proxy). A public PoC appeared 2026-09-02, and active exploitation was confirmed within the following day. Added to CISA KEV on 2026-09-09 with a federal deadline of 2026-09-12 — included here because exploitation and remediation activity continued into this week. **Mitigation:** upgrade to NetScaler ADC/Gateway 14.1-73.32, 13.1-63.21, or later (FIPS builds: 14.1-73.32 FIPS or 13.1-37.277 FIPS or later).

## 10. Microsoft September 2026 Patch Tuesday — Two Exploited Zero-Days (Continuity Note)

Microsoft's September 2026 update, released 2026-09-08 (just outside this week's primary window but relevant context), fixed a record ~966 vulnerabilities including two zero-days already under active exploitation: **CVE-2026-81963**, a Windows Update Stack elevation-of-privilege flaw caused by improper link resolution ("link following") that lets a local attacker manipulate which file the system actually opens; and **CVE-2026-85880**, a heap buffer overflow in the Windows Advanced Local Procedure Call (ALPC) component that can grant SYSTEM privileges to a local attacker. Neither provides unauthenticated remote entry on its own, but both are valuable to an attacker who already has a foothold. **Mitigation:** apply the September 2026 cumulative Windows updates.
