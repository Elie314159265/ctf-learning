## 1. CVE-2026-58115 — Node-RED on Siemens SIMATIC IoT2050 Missing Authentication

**Principle / root cause:** The Node-RED HTTP interface on the affected industrial gateways does not require authentication (missing authentication for a critical function). An unauthenticated network attacker can therefore reach programming nodes that can run operating-system commands, giving remote code execution.

**Mitigation:**
- Update to Industrial OS / Node-RED version V4.3.4.1 or later (Siemens advisory SSA-834709), or remove the software.
- Do not expose Node-RED to the internet; enforce authentication and restrict access to trusted networks.
- Review deployed flows for unexpected entries and check for persistence that survives reboot.

**Affected:** SIMATIC IoT2050 Advanced devices with Node-RED, versions earlier than V4.3.4.1. Scope for generic Node-RED installs outside this product is unconfirmed. **Disclosure / exploitation:** VulnCheck observed exploitation from 2026-10-30 (malicious flows deploying a Linux bot, backdoors and web shells); reported publicly 2026-11-03/04. Listed in VulnCheck KEV; not in CISA KEV as of 2026-11-03.

## 2. CVE-2026-119977 — WordPress Core Upgrade Race Condition

**Principle / root cause:** A time-of-check/time-of-use race condition (CWE-367) in the WordPress core update mechanism can permit remote code execution during a full-package upgrade. Severity ratings differ: Wordfence's record gives CVSS 8.1 (High), while the WordPress project rates it Low.

**Mitigation:**
- Update to WordPress 7.1.4 (released 2026-10-28); check release notes for fixed versions on older branches.
- CISA advises forensic triage: check sites for signs of compromise, not only patching. No separate workaround was published.

**Affected:** WordPress Core 4.7 through 7.1.3. **Disclosure:** added to CISA KEV on 2026-11-03 on evidence of active exploitation; federal deadline 2026-11-06. This is reportedly the fourth WordPress core flaw added to KEV since July.

## 3. CVE-2024-27834 — Apple WebKit (Safari, iOS and other Apple platforms)

**Principle / root cause:** A 2024 WebKit vulnerability allowing memory-safety-related compromise via maliciously crafted web content. Reporting links it to APT29-attributed activity against devices running outdated OS versions (the "Poisoned Source" campaign per Sekoia).

**Mitigation:** Update iOS, iPadOS, macOS and Safari to current releases; replace devices that can no longer receive updates.

**Affected:** Unpatched Apple devices/browsers (older OS versions). **Disclosure:** added to CISA KEV 2026-11-04; federal deadline 2026-11-18.

## 4. Barracuda Email Security Gateway — CVE-2026-116606 & CVE-2026-111560

**Principle / root cause:** CVE-2026-116606 (CVSS 9.3, ESG only) is an authorization bypass in a backup-restore import function that can alter core device settings. CVE-2026-111560 (CVSS 8.6) is a command-injection flaw that affects several Barracuda products. Chained, they lead to root-level command execution. Sources differ on whether authentication is required; Mandiant states the ESG bug is exploitable without it.

**Mitigation:**
- Apply Barracuda patches BNSF-40425 (firmware 9.4.017 and later) or BNSF-40430 (earlier versions). Other patched products include Load Balancer ADC, Message Archiver and WAF Control Center.
- Restrict administrative interfaces to trusted internal networks.

**Affected:** Barracuda ESG, Load Balancer ADC, Message Archiver, WAF Control Center (exact thresholds vary by source; verify against the vendor advisory). **Disclosure:** patches released 2026-11-02 (some outlets say 11-03). No confirmed exploitation as of 2026-11-05.

## 5. Ivanti Connect Secure — CVE-2026-111357, CVE-2026-118527 (with CVE-2026-104935)

**Principle / root cause:** A zero-day chain observed by Volexity (actor UTA0576) in early October combined an authentication bypass (CVE-2026-104935) with a privilege-escalation / missing-authentication flaw (CVE-2026-111357) and an authenticated file-upload flaw (CVE-2026-118527), giving root-level control. Attackers reportedly used the chain's own HTTPS requests for command and results, leaving no separate backdoor.

**Mitigation:**
- Upgrade to 25.1.1.3 or 22.8R2.6 (or later). The 2026-10-13 fixes (25.1.1.2 / 22.8R2.5) do **not** remediate the two newer flaws.
- Follow Ivanti's advisory and run its integrity checks; hunt for anomalous requests to the web interface.

**Affected:** Ivanti Connect Secure prior to the fixed builds. **Disclosure:** Ivanti patched 2026-10-29; added to CISA KEV 2026-10-30 (deadlines 2026-11-02 and 2026-11-13). Included for context as KEV deadlines fall in this window.
