## 1. CVE-2026-85046 & CVE-2026-85880 — "GRIMWEDGE" Chrome–Windows Zero-Day Chain (Newest Disclosure)

**Principle / root cause:** A China-linked threat actor ran a spear-phishing campaign against NGOs that abused a reflected cross-site scripting (XSS) flaw on a legitimate U.S. university website to redirect victims to attacker infrastructure. There, a multi-stage exploit chain first used CVE-2026-85046, a V8 (Chrome's JavaScript/WebAssembly engine) memory-corruption bug, to gain arbitrary read/write inside the browser's sandbox, then used CVE-2026-85880 — the same Windows ALPC (Advanced Local Procedure Call) heap-overflow flaw fixed in this month's Patch Tuesday — to escape the sandbox and inject code into the browser process with SYSTEM-level privileges. The resulting "GRIMWEDGE" backdoor is a persistent, in-memory JavaScript implant that polls a command-and-control server for further instructions.

**Mitigation:**
- Ensure Chrome/Chromium and Windows are fully patched (Chrome 153.0.8010.x or later; Windows September 2026 cumulative updates).
- Treat both flaws as already weaponized in targeted attacks; prioritize patching for any user-facing browser and endpoint fleet, not just internet-facing servers.
- For NGOs and similarly targeted sectors, review email/web-gateway logs for unexpected redirects through third-party (e.g., .edu) domains.

**Affected:** Google Chrome/Chromium builds prior to the fix for CVE-2026-85046; Windows versions affected by the ALPC flaw (see item 4). Campaign first reported 2026-09-15; both underlying CVEs were already patched by vendors before the campaign was publicized, but exploitation predates general disclosure.

## 2. CVE-2026-76461 — Cisco Secure Email Gateway Unauthenticated Root RCE (Federal Deadline Tomorrow)

**Principle / root cause:** Cisco AsyncOS Software for Secure Email Gateway insufficiently validates attacker-controlled content during email parsing, allowing a specially crafted email to inject SQL statements into the gateway's backend (CWE-89, SQL injection). Because the parsing and database logic run with elevated system privileges, the injected statements can be leveraged to execute arbitrary operating-system commands as root — with no authentication or user interaction required beyond the gateway receiving the malicious message.

**Mitigation:**
- Upgrade AsyncOS to 15.5.5-014 (15.5 branch or earlier), 16.0.4-302 (16.0 branch), or 16.5.0-780 (16.5 branch, Cisco's recommended target). No workaround exists.
- Treat any internet-facing Secure Email Gateway as high priority; CISA's federal remediation deadline is 2026-09-17.

**Affected:** Physical and virtual Cisco Secure Email Gateway appliances, all configurations. Cisco Secure Email and Web Manager and Cisco Secure Web Appliance are not affected. Actively exploited in the wild; added to CISA KEV in the days before 2026-09-16.

## 3–5. Microsoft September 2026 Patch Tuesday (2026-09-08) — Record Size, Two Exploited Zero-Days, One Wormable DNS Bug

Microsoft's largest Patch Tuesday on record fixed roughly 966–995 CVEs, including 105+ rated Critical. Three items stand out:

**CVE-2026-81963 (Windows Update Stack, exploited zero-day):** Improper link resolution and access-control checks in the component that installs Windows updates allow a local, low-privileged attacker to manipulate file operations performed by the update process and gain SYSTEM privileges. This is the first Windows Update Stack elevation-of-privilege bug (of several patched since 2022) confirmed exploited before a fix existed.

**CVE-2026-85880 (Windows ALPC, exploited zero-day):** A heap-based buffer overflow in Advanced Local Procedure Call handling lets code already running inside a low-privilege sandbox (e.g., an AppContainer, or a compromised browser renderer as in GRIMWEDGE above) escape that sandbox and reach SYSTEM privileges without user interaction.

**CVE-2026-69730 ("SigRed successor," Windows DNS Server, CVSS 9.8):** A use-after-free bug in Windows DNS Server lets an unauthenticated remote attacker send a specially crafted network packet to execute code on the server, no credentials or interaction needed. Security researchers describe it as spiritually similar to 2020's SigRed (CVE-2020-1350) because of its self-propagating, wormable potential across DNS infrastructure. Not yet confirmed exploited, but Microsoft and researchers expect exploitation attempts.

**Mitigation:** Apply the 2026-09-08 cumulative Windows updates immediately; prioritize CVE-2026-81963 and CVE-2026-85880 (already exploited) and CVE-2026-69730 (wormable, internet/perimeter-facing DNS servers especially).

**Affected:** CVE-2026-81963 — Windows 11 (various versions) and Windows Server 2025. CVE-2026-85880 — Windows 10 and Windows Server 2012/2016/2019/2022. CVE-2026-69730 — Windows Server DNS role, broadly across supported versions. Both zero-days were added to CISA KEV on 2026-09-08 with a 2026-09-22 federal remediation deadline.

## 6–7. CVE-2026-20079 & CVE-2026-20316 — Cisco Secure Firewall Management Center, Chained for Full Compromise

**Principle / root cause:** CVE-2026-20079 (CVSS 10.0) stems from a system process created at boot time that leaves a partial, unauthenticated management-tool session in the FMC's internal database; if no administrator logs in after a reboot, that session persists and can be escalated by a remote, unauthenticated attacker into usable privileges, ultimately allowing arbitrary script execution and root access to the underlying OS via crafted HTTP requests. CVE-2026-20316 is a separate issue: a low-privilege account ships with static, unchangeable credentials, letting a remote attacker log in directly and access data available to that account. Cisco Talos observed multiple threat clusters — including a Russian state-sponsored group and actors deploying Qilin ransomware — chaining these to perform reconnaissance, steal credentials, and establish persistence.

**Mitigation:**
- Install the vendor-fixed software release or applicable Cisco hot fix for both CVEs; there is no workaround for CVE-2026-20079.
- Audit FMC device logs for unexpected sessions created without a prior admin login, and rotate any credentials tied to the built-in low-privilege account.

**Affected:** On-premises Cisco Secure Firewall Management Center deployments. Both actively exploited; CVE-2026-20316 was added to CISA KEV in late July 2026, CVE-2026-20079 in August/September 2026, with continued attack reporting through this week.

## 8. CVE-2026-67276 & CVE-2026-86060 — "MikroTrick" MikroTik RouterOS SSH Authentication Bypass Chain

**Principle / root cause:** CVE-2026-67276 is a flaw in how RouterOS validates SSH public-key authentication: it checks only part of an authorized RSA key (the modulus) rather than the full key material (also the exponent), which — combined with how the device verifies the client's signature — lets an attacker who knows an authorized user's public modulus construct a different key pair that RouterOS still accepts as that user, without ever possessing the real private key. CVE-2026-86060 is a separate argument-handling bug in the SSH login path that can be used afterward to escalate the resulting session to full administrative control.

**Mitigation:**
- Update to RouterOS 6.49.21 (Long-term), 7.23.4 (Long-term), or 7.24.2 (Stable) or later immediately.
- Restrict SSH management access to trusted networks/VPNs; audit for unexpected SSH user accounts (reports note attacker-created accounts have been observed).

**Affected:** MikroTik RouterOS devices with SSH reachable from the internet, prior versions to the fixes above. Real-world exploitation began around 2026-09-02, ahead of the 2026-09-05 public disclosure; Shadowserver observed roughly 122,500 internet-exposed, SSH-reachable devices as of 2026-09-05 (exposure count, not confirmed-compromised count).

## 9. CVE-2026-19490 — Citrix NetScaler ADC/Gateway Authentication Bypass (Continuity, Now Under Mass Exploitation)

**Principle / root cause:** An alternate authentication path (CWE-288) exists on NetScaler instances configured as a Gateway or AAA virtual server, allowing a remote, unauthenticated attacker to reach protected functionality without passing the normal login checks.

**Mitigation:** Upgrade to NetScaler ADC/Gateway 14.1-73.32, 13.1-63.21, or later.

**Affected:** NetScaler ADC and Gateway 14.1 releases prior to 14.1-73.32 and 13.1 releases prior to 13.1-63.21. Advisory published 2026-08-19; a credible public PoC triggered exploitation from around 2026-09-03; added to CISA KEV on 2026-09-09 with a 2026-09-12 federal deadline.

## 10. CVE-2025-25249 — Fortinet FortiOS / FortiSwitchManager Heap-Based Buffer Overflow (Continuity)

**Principle / root cause:** A heap-based buffer overflow in the `cw_acd` daemon lets a remote, unauthenticated attacker send specially crafted network packets that corrupt heap memory, resulting in arbitrary code or command execution.

**Mitigation:** Update FortiOS and FortiSwitchManager to fixed releases per Fortinet's advisory; restrict management-plane exposure to the internet.

**Affected:** FortiOS 6.4 (all versions), 7.0.0–7.0.17, 7.2.0–7.2.11, 7.4.0–7.4.8, 7.6.0–7.6.3; FortiSwitchManager 7.0.0–7.0.5, 7.2.0–7.2.6. Actively exploited to deploy the "PivotC2" remote access trojan; added to CISA KEV on 2026-09-09 with a 2026-09-12 federal deadline.

## 11. CVE-2026-87491 — Google Chrome V8 Out-of-Bounds Write Zero-Day (Continuity)

**Principle / root cause:** An out-of-bounds write in V8 lets a specially crafted HTML page corrupt memory in a way that enables arbitrary code execution inside the browser's sandbox.

**Mitigation:** Update Chrome to 153.0.8010.36/.37 (Windows/macOS) or 153.0.8010.36 (Linux) or later; Chromium-based browsers should confirm they have picked up the equivalent fix.

**Affected:** Chrome/Chromium prior to the fixed builds. This was the seventh Chrome zero-day patched in 2026, fixed as part of a 230-fix Stable Channel release on 2026-09-08; added to CISA KEV on 2026-09-09 with a 2026-09-23 federal deadline. (Distinct from CVE-2026-85046, the separate V8 bug used in the GRIMWEDGE chain above.)
