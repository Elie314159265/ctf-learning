## 1. CVE-2026-90436 — Apache Axis 1.x Unsafe Reflection → Unauthenticated RCE (Actively Exploited)

**Principle / root cause:** Apache Axis 1.x (an end-of-life SOAP engine) contains an unsafe-reflection flaw (CWE-470, "use of externally-controlled input to select classes or code"). When processing a SOAP fault, Axis reads a caller-supplied `exceptionName` element and loads the class it names; if an accompanying `String` element is present, Axis instantiates that class through its single-`String` constructor *before* verifying the object is actually an `AxisFault`. An unauthenticated attacker can thereby cause the server to construct an arbitrary class with attacker-chosen input, leading to remote code execution.

**Mitigation:**
- Axis 1.x is EOL and the Apache Software Foundation does not plan a fixed 1.x release. Migrate to a maintained SOAP engine (e.g., Apache Axis2), or deploy an Axis 1.x build with the patch applied.
- **Atlassian Confluence Data Center:** versions 1.x–9.x are affected only when "Remote API (XML-RPC & SOAP)" is enabled; disable it if unused, or update to 9.2.28 (or the fixed release for your branch).
- **N-able N-central:** upgrade to 2026.4 HF3 on an emergency basis.
- Inventory all products that bundle the Axis 1.x library — the exposure is not limited to the two confirmed vectors.

**Affected:** All Apache Axis 1.x versions through 1.4, and any product embedding them (confirmed: certain Atlassian Confluence Data Center and N-able N-central builds). Disclosed by the ASF on 2026-11-06; CISA assigned CVSS 9.8. Exploitation against Confluence Data Center and N-central was reported from 2026-11-13 (per Rapid7); added to CISA KEV on 2026-11-18 with a federal remediation deadline of 2026-11-21.

## 2. CVE-2026-129448 — Apache Roller XML-RPC Deserialization → Unauthenticated RCE (Actively Exploited)

**Principle / root cause:** Apache Roller (a Java blogging platform) exposes an XML-RPC endpoint that handles vendor "extension" value types and deserializes the supplied data *before* performing the authentication/authorization check. An unauthenticated attacker can submit a crafted request that is deserialized into attacker-influenced objects, resulting in remote code execution on the server. This is the same underlying defect previously tracked as CVE-2026-82384 (September 2026); CVE-2026-129448 widens the confirmed affected-version range.

**Mitigation:**
- Upgrade to Apache Roller 6.1.6 or later (6.1.7 recommended by at least one tracker).
- If an immediate upgrade is not possible, restrict or disable external access to the XML-RPC endpoint at the network/proxy layer.

**Affected:** Apache Roller 4.0.0 up to (and including) 6.1.4 per some reporting; Apache's advisory frames the range as 4.0.0 before 6.1.5. The Apache Software Foundation confirmed active in-the-wild exploitation in its advisory (~2026-11-17). A public PoC for the September-disclosed variant has circulated since late September, lowering the barrier to attack. (Not confirmed in CISA KEV at time of writing — treat as urgent regardless.)

## 3. CVE-2026-115731 — Perforce Puppet Server Report Deserialization → RCE (Actively Exploited)

**Principle / root cause:** Puppet Server's report-processing path deserializes data received from agents. A client presenting a certificate signed by the Puppet certificate authority (CA) can submit a crafted report object that, when deserialized, causes the server to execute attacker-controlled code. The code runs as the Puppet service user (not necessarily root). Because a configuration-management master holds the CA and can push changes fleet-wide, compromise here carries high lateral-movement and CA-key-theft risk.

**Mitigation:**
- Patch to the fixed releases (shipped 2026-11-03): Puppet Enterprise 2026.0.1, 2025.12.1, or 2023.8.13; Puppet Core 9.1.3 or 8.22.2.
- Treat an exploited master as a CA compromise: review issued certificates, rotate the CA/keys as appropriate, and audit for anomalous agent enrollments and report submissions.
- The OpenVox configuration-management platform is affected by the same flaw; a public PoC targeting OpenVox appeared shortly after the patch.

**Affected:** Perforce Puppet Enterprise and Puppet Server, including version 2026.0.0 and earlier affected branches, prior to the fixed releases. Rated CVSS 4.0 9.4. First signals of exploitation surfaced around 2026-11-04; added to CISA KEV on 2026-11-17 with a federal remediation deadline of 2026-12-01.

## 4. CVE-2026-125350 — Google Chrome XML Component Use-After-Free (Zero-Day, Actively Exploited)

**Principle / root cause:** A use-after-free in Chrome's XML handling. A crafted web page can cause memory that has already been freed to be reused, corrupting program state in a way that can be steered toward arbitrary code execution inside the renderer/browser sandbox. This is the first exploited Chrome zero-day of 2026 to target the XML code specifically, and the eighth exploited Chrome zero-day of the year.

**Mitigation:**
- Update Chrome to 157.0.8103.50/.51 (Windows/macOS) or 157.0.8103.50 (Linux), then fully restart the browser to apply the fix.
- Chromium-based browsers (Edge, Brave, etc.) should update once their upstream-synced builds ship.

**Affected:** Google Chrome prior to the builds above. Rated High (CVSS 8.8 per some sources). Google confirmed an exploit exists in the wild but withheld targeting/attribution details. Fix released 2026-11-09; added to CISA KEV on 2026-11-10 with a federal remediation deadline of 2026-11-24.

## 5. CVE-2026-124194 — Microsoft Outlook Spoofing → NTLM Hash Theft (Zero-Day, Actively Exploited)

**Principle / root cause:** A spoofing flaw in Microsoft Outlook. A crafted message/message-file causes Outlook, when the item is opened, to initiate an outbound connection to an attacker-controlled server without the usual external-content prompt. That connection can leak the user's NTLMv2 challenge-response material, which an attacker can then subject to offline cracking or NTLM relay against other services. Rated only CVSS 6.5 (Moderate), but widely flagged as higher-impact in practice because credential material is exposed with minimal user interaction.

**Mitigation:**
- Apply the November 2026 Office security updates for the affected builds.
- Defense in depth: block outbound SMB/NTLM to the internet at the perimeter, enforce SMB signing, and consider disabling or restricting NTLM where feasible.
- Monitor for Outlook-associated unexpected outbound SMB/NTLM authentication to external hosts.

**Affected:** Microsoft 365 Apps for Enterprise, Microsoft Office LTSC 2021, and Microsoft Office LTSC 2024. Microsoft confirmed in-the-wild exploitation; patched 2026-11-10; added to CISA KEV on 2026-11-10 with a federal remediation deadline of 2026-11-24.

## 6. CVE-2026-114713 — UnrealIRCd Server-to-Server Command Injection (Actively Exploited)

**Principle / root cause:** An improper-neutralization-of-delimiters flaw (command injection) in the open-source UnrealIRCd IRC server. On a network with two or more linked servers, a user can craft input that injects additional server-to-server (S2S) commands, which are then processed with server privileges — effectively executing privileged commands the user should not be able to issue.

**Mitigation:**
- Upgrade to UnrealIRCd 6.2.7.1, or apply the project's hot-patch bundle (released 2026-11-07).
- Single-server networks (no linked servers) are not exposed via this S2S path, but should still patch.

**Affected:** UnrealIRCd 6.0.0 through 6.2.7. Severity reported as High (CVE record lists CVSS 3.1 8.6; Red Hat rates it High). Added to CISA KEV on 2026-11-13 with a federal remediation deadline of 2026-11-16 (already past as of this report) — the KEV entry also requests forensic triage to confirm whether systems were already compromised.

## 7. CVE-2026-123039 — Check Point Security Gateway/Management Local Privilege Escalation (Actively Exploited, Chained)

**Principle / root cause:** A local privilege-escalation flaw (CVSS 7.8) in Check Point Security Gateways and Security Management products. On its own it requires existing access on the device; in observed attacks it was the second stage of a chain. Threat actors first gained a foothold through Mobile Access portals by exploiting the "PHP2Shell" bugs (CVE-2026-109618 / CVE-2026-109619), then used CVE-2026-123039 to escalate to root — reportedly deploying webshells, a backdoor, and in some cases a wiper in destructive attacks against Israeli organizations.

**Mitigation:**
- Apply the November Jumbo Hotfix for the affected Security Gateway / Security Management versions.
- Also remediate the Mobile Access "PHP2Shell" initial-access flaws (CVE-2026-109618 / CVE-2026-109619) if not already done.
- Perform compromise assessment: look for unexpected webshells, new root-level processes, and anomalous Mobile Access portal activity.

**Affected:** Check Point Security Gateways and Security Management products (per vendor advisory). Added to CISA KEV on 2026-11-13 with a federal remediation deadline of 2026-11-16 (already past as of this report).

## 8. SAP November Patch Day — ICM2SHELL (CVE-2026-76964 / CVE-2026-89126) and PROXYGATE (CVE-2026-89103)

**Principle / root cause:** SAP's November 2026 Security Patch Day included four CVSS 10.0 flaws. ICM2SHELL comprises two memory-corruption bugs: CVE-2026-76964 in the Internet Communication Manager (ICM) of SAP NetWeaver AS ABAP, and CVE-2026-89126 in SAP Web Dispatcher. An unauthenticated attacker can send specially crafted network requests with invalid length fields that trigger a heap out-of-bounds write, corrupting memory in a way that can lead to remote code execution. WebSocket support — a precondition for the exposure — is enabled by default. CVE-2026-89103 ("PROXYGATE") and CVE-2026-120017 are the other two maximum-severity items in the same bulletin.

**Mitigation:**
- Apply SAP Security Notes 3778530 (ICM, CVE-2026-76964) and 3778556 (Web Dispatcher, CVE-2026-89126), plus the notes for CVE-2026-89103 and CVE-2026-120017, from the November 2026 bulletin.
- Where patching must be staged, review exposure of ICM/Web Dispatcher endpoints to untrusted networks and restrict accordingly; follow SAP's guidance on any customer-side configuration steps.

**Affected:** SAP NetWeaver AS ABAP (ICM) and SAP Web Dispatcher, per the November 2026 notes. All rated CVSS 10.0, unauthenticated. Patched 2026-11-10. No independently confirmed in-the-wild exploitation at time of writing; one source referenced a precautionary shutdown prompted by public exploit-code claims — treat these internet-facing components as high priority.
