# Daily Vulnerability Summary — 2026-10-02

Period covered: 2026-09-25 to 2026-10-02. Sources: public news and aggregator reports (vendor/CISA pages could not be fetched during this run). Items marked **[Unverified]** rest on a single secondary source or have inconsistent details; confirm against the vendor advisory before acting. No exploit code or exploitation steps are included.

## Newest / Highest Priority (last 24–72 hours and actively exploited)

### 1. Citrix NetScaler ADC / Gateway — CVE-2026-88771 and CVE-2026-88772 (actively exploited)
- **Disclosure date:** 2026-09-27 (added to CISA KEV the same day; exploitation reported globally)
- **Principle / root cause:** CVE-2026-88771 is an improper input validation flaw that lets an unauthenticated remote attacker run commands on the appliance, reportedly in the default configuration. CVE-2026-88772 is a memory overflow in the DTLS handling path that can lead to remote code execution or denial of service; DTLS is enabled by default on VPN virtual servers.
- **Affected:** NetScaler ADC and Gateway 14.1 before 14.1-73.37; 13.1 before 13.1-64.23; FIPS/NDcPP builds of 13.1 before 13.1-37.279 and 14.1 FIPS before the 14.1-73.37 FIPS build.
- **Mitigation:** Upgrade to 14.1-73.37 / 13.1-64.23 or later (FIPS/NDcPP builds as above). Restrict management and gateway exposure where possible, and review appliances for signs of compromise (unexpected processes, new accounts, webshell-like files) since exploitation preceded the patch.

### 2. Cisco Catalyst SD-WAN Manager — authentication bypass (actively exploited) **[Unverified CVE ID]**
- **Disclosure date:** about 2026-09-30 (Cisco patch release; reported added to CISA KEV)
- **Principle / root cause:** Improper handling of URI encoding allows an unauthenticated remote attacker to bypass authentication and gain administrative access (CVSS 9.8 reported). One source cites CVE-2026-76504; searches could not confirm that ID, and Cisco's earlier 2026 SD-WAN flaws (e.g. CVE-2026-20127, CVE-2026-20182) are separate issues.
- **Affected / fixed versions:** Not confirmed in this run; see the Cisco Security Advisory for the exact releases.
- **Mitigation:** Apply the Cisco fixed release immediately, restrict management-plane access to trusted networks, and audit for unauthorized administrative sessions and configuration changes.

### 3. SolarWinds Observability Self-Hosted — CVE-2026-28324 and CVE-2026-28325
- **Disclosure date:** this week (exact date not confirmed); no exploitation reported
- **Principle / root cause:** CVE-2026-28324 (CVSS 9.8) is an insufficient integrity check leading to unauthenticated RCE on non-default, insecure configurations. CVE-2026-28325 (CVSS 8.8) is deserialization of untrusted data in installations using a specific communication mode.
- **Affected:** Observability Self-Hosted up to and including 2026.2.2.
- **Mitigation:** Upgrade to 2026.2.3; avoid insecure non-default configurations; restrict network exposure of the product.

## Other Notable Items from the Week

### 4. WatchGuard Fireware OS — critical code execution flaw **[Unverified CVE ID]**
- **Disclosure date:** about 2026-09-29/30 (vendor patch announcement; 15 fixes in total)
- **Root cause:** Reported as a code injection issue enabling remote code execution; specifics and CVE ID were not confirmed (one result points to CVE-2026-13050 but this was not matched to the advisory).
- **Affected / mitigation:** Fireware OS on Firebox appliances; update to the release in the WatchGuard advisory and limit exposure of management services.

### 5. Kiteworks Email Protection Gateway — critical code injection **[Unverified details]**
- **Disclosure date:** about 2026-09-28/29 (vendor lifted its precautionary advisory after patching; no compromise found)
- **Root cause:** Reported as a max-severity code injection flaw. A lookup returned CVE-2026-28272 (stored XSS, fixed in 9.2.0), which does not match the severity described, so the mapping is uncertain.
- **Mitigation:** Update to the latest Email Protection Gateway release; hosted customers were patched by the vendor.

### 6. Adobe Commerce / Magento — CVE-2026-71362 (exploited; KEV)
- **Disclosure:** August 2026; CISA KEV addition in September, with a federal remediation due date of 2026-09-27; exploitation continues to be reported.
- **Root cause:** Incorrect authorization (CWE-863): requests are not checked against the caller's privileges, allowing unauthenticated session switching and account takeover.
- **Affected:** Adobe Commerce, Commerce B2B and Magento Open Source through the July 2026 patch level.
- **Mitigation:** Apply Adobe's latest security update; monitor for anomalous customer-session activity.

### 7. Other KEV additions reported in the period (details not verified)
Reports mention CISA KEV additions for CVE-2026-102490 (Zammad), CVE-2026-104286 (Fortinet FortiMail path traversal), and a WSO2 flaw (CVE-2026-5430). Zammad and FortiMail IDs could not be confirmed. Check the CISA KEV catalog and vendor advisories.
