## 1. Plex2Shell — Plex Media Server SSRF / file-path chain (CVE-2026-96652, -96654, -96655, -96656)

**Principle / root cause:** Four flaws that become critical when chained. Two are server-side request forgery (SSRF) / URL-handling weaknesses in the timeline and searchOne endpoints (reachable without authentication), one is an authenticated SSRF in the transcoder, and one is a file-path handling flaw that lets an attacker place a shared library which the server later loads. Together they allow unauthenticated code execution with the privileges of the Plex process.

**Mitigation:**
- Update Plex Media Server to 1.43.3.10861 or later (the fix shipped 2026-08-03).
- Do not expose Plex directly to the internet; restrict access via VPN or reverse proxy with authentication.
- Hunt for unexpected miner processes, unknown outbound connections, and unfamiliar proxy/backdoor binaries on Plex hosts.

**Affected:** Plex Media Server builds earlier than 1.43.3.10861 (all supported OSes).

**Disclosure:** Fix 2026-08-03; public write-up 2026-10-16; exploitation observed within hours; CISA KEV 2026-10-20.

## 2. Arista VeloCloud Orchestrator — exploited zero-day (CISA-listed CVE-2026-114625)

**Principle / root cause:** CISA's 2026-10-23 alert describes a SQL injection in VeloCloud Orchestrator. Secondary sources conflict: some describe an unauthenticated OS command injection (CVE-2026-16812, severity 10.0) exploited as a zero-day, and a separate authenticated SQL injection in the Flow Metrics API (CVE-2026-17191, 8.5, not exploited). **The exact CVE mapping is unverified.** In either case, untrusted input reaches a backend query or command interpreter without proper sanitization.

**Mitigation:**
- Upgrade to the fixed releases reported by Arista: 5.2.3.14, 6.1.3.4, 6.4.2.4, or 7.0.0.1.
- Restrict Orchestrator management interfaces to trusted networks; review logs for anomalous API activity.

**Affected:** On-premises VeloCloud Orchestrator 5.2.0–5.2.3.13, 6.1.0–6.1.3.3, 6.4.0–6.4.2.3 (per secondary sources).

**Disclosure:** CISA KEV 2026-10-23 (vendor patch reportedly earlier; verify date).

## 3. PHP2Shell — PHP core flaws (CVE-2026-109618, CVE-2026-109619)

**Principle / root cause:** Two critical issues in PHP core, one involving memory exhaustion (OOM) behavior in request handling and the other combining with it (via session upload-progress handling) to reach remote code execution. The PHP team considers mod_php deployments highest risk because an unauthenticated request can trigger the issue before any application code runs. (A third ID, CVE-2026-115560, was reported in one place but could not be confirmed.)

**Mitigation:**
- Upgrade to PHP 8.5.12, 8.4.27, 8.3.36, or 8.2.35; minimal backports exist for 7.4, 8.0, 8.1, and distributions ship their own backports.
- Interim, partial only: enforce a non-overridable memory_limit (e.g. via php_admin_value), set a low post_max_size, and set session.upload_progress.enabled=0. These do not make a system safe.
- Restrict exposure of unpatched servers.

**Affected:** PHP 7.x and 8.x prior to the fixed releases above.

**Disclosure:** Advance notice and emergency patches ~2026-10-21 to 2026-10-23. Exploit code reportedly circulating; active exploitation not confirmed.

## 4. CVE-2026-101809 — Oracle E-Business Suite Workflow Notification Mailer

**Principle / root cause:** Unauthenticated flaw reachable over HTTP in the Workflow Notification Mailer component (approval-email handling), leading to full takeover of the Workflow product, with scope change affecting other components. CVSS 10.0.

**Mitigation:** Apply Oracle's October 2026 Critical Patch Update; restrict EBS external exposure; monitor for unusual Workflow/mailer requests.

**Affected:** Oracle E-Business Suite 12.2.3–12.2.15.

**Disclosure:** October 2026 CPU; no confirmed exploitation at time of writing (patch details from a single secondary source; verify with Oracle).

## 5. Brotli "HTTP2Shell" (reported CVE-2026-111497) — unverified

**Principle / root cause:** Reported flaw in Google's Brotli decompression library that researchers say can lead to code execution, affecting software embedding Brotli such as Node.js, Python, and Bun. Only a single secondary source; no vendor advisory or fixed versions could be confirmed.

**Mitigation:** Watch for updates to Brotli and downstream runtimes (Node.js, Python packages, Bun) and apply them when released; verify against vendor advisories.

**Disclosure:** ~2026-10-26. Lab exploitation only; no in-the-wild exploitation found.

## 6. CVE-2026-115927 — Tornado chunked transfer-encoding resource consumption

**Principle / root cause:** Improper handling of chunked transfer encoding allows a remote, unauthenticated client to cause excessive resource consumption (denial of service).

**Mitigation:** Upgrade Tornado to 6.6.0 or later; consider request-size/time limits at a fronting proxy.

**Affected:** Tornado web framework versions prior to 6.6.0. **Disclosure:** 2026-10-26.
