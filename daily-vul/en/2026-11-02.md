## Priority (newest / actively exploited)

### 1. PHP "php2shell" — CVE-2026-109618, CVE-2026-109619 (RCE; added to CISA KEV 2026-10-26)
- **Disclosure:** Fixes released 2026-10-21; CISA KEV addition 2026-10-26.
- **Principle / root cause:** Memory-safety and state-handling flaws in the PHP runtime. CVE-2026-109618: out-of-memory corruption during request cleanup, reachable via the session upload-progress handler. CVE-2026-109619: stale request-owned global state reused by a later request on the same worker, reachable via the multipart/form-data parser. Both can lead to unauthenticated remote code execution.
- **Affected:** PHP 8.5 < 8.5.12, 8.4 < 8.4.27, 8.3 < 8.3.36, 8.2 < 8.2.35. Older/EOL branches (e.g. 7.4, 8.0, 8.1) are reported affected with no upstream fix; ranges differ between sources.
- **Mitigation:** Upgrade to 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 or a distribution-backported fix. Migrate off EOL branches or use vendor-supported patched builds. Setting `session.upload_progress.enabled=0` only mitigates CVE-2026-109618, not 109619. Related CVE-2026-115560 (disclosed 2026-10-23) is considered unlikely to be reachable; fix expected in the next regular release, same interim setting recommended.

### 2. Brotli "HTTP2Shell" — CVE-2026-111497 (CVSS 9.2; scanning observed)
- **Disclosure:** Node.js fix 2026-10-21; emergency patches widely reported 2026-10-26.
- **Principle / root cause:** Out-of-bounds write in the Brotli decoder library when decompressing crafted data. Exposure requires application or middleware code to actually decode Brotli input. Affects software embedding Brotli (Node.js, Python bindings, proxies, other tools).
- **Affected:** Brotli 1.0.3–1.2.0. Node.js 26.x < 26.12.1, 24.x < 24.22.1, 22.x < 22.23.4 (EOL 25.x/23.x/20.x and earlier have no fix).
- **Mitigation:** Upgrade Node.js to 22.23.4 / 24.22.1 / 26.12.1; Brotli to 1.0.10 / 1.1.1 / 1.2.1; Python Brotli 1.2.1 / brotlicffi 1.2.1.0; update proxies and bundled copies. Node may still report an old `process.versions.brotli`, so check the Node version. Where patching is delayed, avoid decoding untrusted Brotli content.

### 3. Linux kernel IPv4 TCP use-after-free — CVE-2026-98432 (CVSS 9.8 CNA / 8.1 Red Hat)
- **Disclosure:** Public analysis 2026-10-27 (distribution fixes began ~2026-10-16).
- **Principle / root cause:** IP-options object freed by one CPU path while another path, protected only as an RCU reader, still uses it (no RCU grace period before free) — a use-after-free in TCP request/child socket handling. Reported as enabling unauthenticated remote root on servers with MPTCP listeners; broader exposure is not established.
- **Affected:** Linux kernels since 4.4 prior to fixes.
- **Mitigation:** Update to fixed stable kernels (5.10.272, 5.15.223, 6.1.190, 6.6.159, 6.12.113, 6.18.56, 7.2.10, 7.3) or the distribution's backported package (Oracle Linux, Debian trixie fixed 10-16; Amazon Linux 2023 kernel6.18 10-24, kernel6.12 10-29; Amazon Linux 2 pending at time of writing; RHEL 7 not affected). Reboot into the new kernel. Whether disabling MPTCP reduces risk is not established.

### 4. Ivanti Connect Secure — CVE-2026-104935 (auth bypass leading to RCE; KEV)
- **Disclosure:** Sources conflict: fixes/KEV reported 2026-10-13; one report says a chained exploit set was added to KEV 2026-10-30 with federal deadlines 11-02 and 11-13.
- **Principle / root cause:** Authentication bypass letting a remote unauthenticated party run commands on the VPN appliance; reportedly chained with other flaws to gain root, including on partially patched appliances.
- **Affected:** Connect Secure 25.1.1.1 and prior, 25.1.2.2 and prior, 22.8R2.4 and prior (22.7.x and earlier reportedly not affected; sources differ).
- **Mitigation:** Upgrade to the latest Ivanti build (reported: 22.8R2.5, 25.1.1.2, 25.1.3.0, 25.1.3.1 — confirm in Ivanti's advisory), run Ivanti's integrity checker, hunt for compromise, rotate credentials/sessions, and restrict management exposure.

### 5. Drupal Commerce Core — CVE-2026-118539 (missing authorization, CWE-862; reported exploited)
- **Disclosure:** Advisory SA-CONTRIB-2026-254, late October 2026 (exact date not confirmed). Rated Highly Critical (21/25). Sources conflict on whether exploitation is confirmed; not in KEV per one source.
- **Principle / root cause:** Missing authorization checks allow access-control bypass on online stores.
- **Affected:** Commerce Core 2.x up to 2.41 and 3.x up to 3.3.12 (some outlets say 3.3.13; 3.3.13 is the fix).
- **Mitigation:** Upgrade to 3.3.13 (3.x) or 8.x-2.41 (2.x); no workaround listed. Review orders for inconsistencies.
