## 1. CVE-2026-88771 & CVE-2026-88772 — Citrix NetScaler ADC / Gateway Remote Code Execution (Zero-Days)

**Principle / root cause:** CVE-2026-88771 is an improper input validation flaw affecting default configurations with no special feature required. CVE-2026-88772 is a memory-overflow (memory safety) flaw reachable when DTLS is enabled, which is the default on VPN virtual servers. Either can lead to unauthenticated remote code execution on the appliance. Attackers reportedly used them before disclosure to deploy web shells and gain persistence.

**Mitigation:**
- Upgrade to NetScaler ADC/Gateway 14.1-73.37 or later, 13.1-64.23 or later (13.1), 14.1-FIPS 14.1-73.37 or later, or 13.1-FIPS / 13.1-NDcPP 13.1-37.279 or later.
- Because exploitation preceded patching, hunt for web shells and unexpected persistence on internet-facing appliances; rotate credentials/sessions held by the appliance.

**Affected:** NetScaler ADC and NetScaler Gateway builds prior to the fixed versions above. Fixes published 2026-09-27; added to CISA KEV 2026-09-27.

## 2. CVE-2026-76504 — Cisco Catalyst SD-WAN Manager Authentication Bypass

**Principle / root cause:** An authentication bypass allows an unauthenticated remote attacker to obtain administrative access to the management plane. (Note: related earlier Cisco SD-WAN auth-bypass CVEs such as CVE-2026-20127 exist; this specific ID could not be cross-verified.)

**Mitigation:** Apply Cisco's fixed SD-WAN Manager releases per the vendor advisory; restrict management-plane exposure; review for unauthorized admin accounts and configuration changes.

**Affected:** Cisco Catalyst SD-WAN Manager (exact versions per Cisco advisory). Added to CISA KEV 2026-09-30.

## 3. CVE-2026-67279 & CVE-2026-86060 — MikroTik RouterOS Chained Authentication Bypass

**Principle / root cause:** CVE-2026-67279 is an improper enforcement of workflow (state) in the SSH-style session handling that lets an unauthenticated client request command execution on a channel before authentication completes. Chained with CVE-2026-86060, attackers gain full administrative console access without a password.

**Mitigation:** Install the MikroTik RouterOS fixed versions; do not expose management services (SSH/WinBox/WebFig) to the internet; restrict by source IP; audit devices for unexpected users, scripts, and scheduler entries.

**Affected:** Internet-exposed MikroTik RouterOS devices (versions per MikroTik advisory). Exploitation observed since at least 2026-09-02 (CERT Polska); added to CISA KEV in late September.

## 4. CVE-2026-65660 — Microsoft SharePoint Code Injection

**Principle / root cause:** Code injection (insufficient validation of attacker-influenced input) permits an authorized, network-reachable attacker to execute code on the SharePoint server.

**Mitigation:** Apply Microsoft's SharePoint security update; restrict external access; review server logs and files for unexpected modifications.

**Affected:** Microsoft SharePoint Server (see Microsoft advisory for versions). Exploitation confirmed as of 2026-09-25; added to CISA KEV.

---

## 5. CVE-2026-5430 (WSO2) and CVE-2026-71362 (Adobe Commerce)

**Principle / root cause:** CVE-2026-5430 is an authentication bypass where forged/insufficiently validated JWT tokens are accepted by WSO2 gateway components. CVE-2026-71362 permits unauthorized access to Adobe Commerce without an existing account or admin privileges.

**Mitigation:** Apply vendor patches/hotfixes; rotate signing keys and API credentials if exposure is suspected; review access logs for anomalous token use or admin actions.

**Affected:** WSO2 Universal Gateway and Adobe Commerce (versions per vendor bulletins). Reported under active exploitation in the last week.
