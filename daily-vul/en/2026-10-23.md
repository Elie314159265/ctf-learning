## 1. CVE-2026-109618 & CVE-2026-109619 — PHP engine memory-safety flaws ("PHP2Shell")

**Principle / root cause:** Two flaws in the PHP engine's request handling. CVE-2026-109618 involves out-of-memory handling that can interrupt PHP while internal request data is only partially initialized, after which cleanup treats that invalid data as valid. CVE-2026-109619 involves request-owned state that outlives the memory it points to, so a later request on the same worker may use stale state before normal initialization resets it. Both can lead to unauthenticated remote code execution.

**Mitigation:**
- Upgrade to PHP 8.5.12, 8.4.27, 8.3.36, or 8.2.35 (or later). Patching is the only complete fix.
- PHP 8.1, 8.0 and 7.4 receive no official release; source backports were published, so apply distribution-vendor updates or migrate to a supported branch.
- Configuration tweaks (for example disabling session upload progress) block only one entry path and are not a substitute.
- Prioritize internet-facing PHP applications and shared hosting; review web logs and web roots for unexpected new files.

**Affected:** PHP versions before the fixed releases above (all branches, including unsupported ones). Disclosed 2026-10-21 (planned for 10-22, moved up after details leaked). Vendors report exploitation attempts; PHP rates both flaws 9.2, while some outlets cite higher leaked scores.

## 2. CVE-2026-111497 (and 9 others) — Node.js Brotli decoder remote code execution

**Principle / root cause:** A memory-safety flaw in the Brotli decompression path allows crafted compressed input to corrupt memory, which Node.js states can permit remote code execution.

**Mitigation:**
- Update to the latest security releases of the Node.js 22.x, 24.x and 26.x lines.
- Inventory runtimes (including those bundled in containers and applications) that decompress untrusted Brotli data.

**Affected:** Node.js 22.x, 24.x, 26.x prior to the 2026-10-21 security releases. No known exploitation at time of writing.

## 3. CVE-2026-96652, -96654, -96655, -96656 — Plex Media Server "Plex2Shell" chain

**Principle / root cause:** A chain of flaws. CVE-2026-96654 is a URL-injection flaw in a search endpoint that lets an attacker invoke functions of other plugins; CVE-2026-96656 is an arbitrary file write in transcoder settings that lets an administrator-level actor place a shared library that the server later loads, giving code execution. Combined, the chain reaches code execution on the host.

**Mitigation:**
- Update to Plex Media Server 1.43.3.10861 or later (released 2026-08-04).
- Do not expose the server directly to the internet; check hosts for unexpected cryptominer processes.
- CISA federal deadlines: 2026-10-23 for CVE-2026-96654/-96656, 2026-11-03 for the rest.

**Affected:** Plex Media Server before 1.43.3.10861. Exploitation reports began ~2026-10-17 (initially a researcher honeypot, cryptominer deployment); added to CISA KEV 2026-10-20.

## 4. CVE-2026-106931 — SiteGuard Server Edition OS command injection

**Principle / root cause:** The statistics feature (enabled by default) passes attacker-influenced input into an operating-system command without adequate neutralization (CWE-78), yielding command execution as root/SYSTEM on the WAF host.

**Mitigation:**
- Update to SiteGuard Server Edition 8.00 Update 5 (Apache/Nginx/IIS) or 7.00 Update 6 (Apache/Nginx on FreeBSD); the vendor also offers a file-replacement patch for older/EOL versions.
- Disabling the statistics function removes the exposure.
- The vendor warns remediation may erase attack traces: preserve logs and disk evidence before patching.
- CISA federal deadline: 2026-10-23.

**Affected:** SiteGuard Server Edition 2.20 up to before 8.00 Update 5 (FreeBSD: before 7.00 Update 6); IIS editions 3.10–4.00 Update 4 are reportedly unaffected. JPCERT/CC has issued a warning. Added to CISA KEV 2026-10-20.

## 5. CVE-2026-110936 — Siemens Software Center uncontrolled DLL search path

**Principle / root cause:** The application loads DLLs from a search path that a local user can influence (CWE-427), so a planted library executes with the application's privileges. Siemens links in-the-wild use to a ClickFix social-engineering campaign (the user is tricked into running steps locally).

**Mitigation:**
- Update Siemens Software Center to V4.0.9.8 or later.
- Train users against copy-and-paste "fix" prompts; restrict write access to directories in the application's load path.
- Siemens states none of its systems or update channels were compromised.

**Affected:** Siemens Software Center versions < V4.0.9.8 (Windows). Added to CISA KEV 2026-10-20 (federal deadline 2026-11-03).

## Context items (disclosed slightly before the window, still being exploited)

- **CVE-2026-104935 — Ivanti Connect Secure.** Zero-day chained with two other flaws for unauthenticated root code execution (tracked by Volexity as UTA0576; exploited from 2026-10-03; KEV 2026-10-13). Affects 25.1.1.1 and prior, 25.1.2.2 and prior, 22.8R2.4 and prior (22.7.x and below unaffected). Upgrade to 25.1.3.0+/22.8R2.5 per Ivanti guidance; one chained privilege-escalation flaw reportedly remained unpatched. Integrity Checker results are not conclusive because logs were tampered with.
- **CVE-2026-88771 / -88772 / -88779 — Citrix NetScaler ADC/Gateway.** Unauthenticated input-validation RCE (9.5) and a SAML-related memory-buffer flaw causing DoS (8.7). Fixed in 14.1-73.41 / 13.1-64.28 or later (earlier fixed builds 14.1-73.37 / 13.1-64.23 are insufficient where SAML is configured). Use Global Deny List signatures as a temporary measure; watch for post-upgrade instability.
- **CVE-2026-104286 — Fortinet FortiMail.** Critical (9.8) zero-day exploited; KEV 2026-10-02. Affects 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9. Fixes announced for 8.0.2, 7.6.7, 7.4.9 (verify release status in Fortinet advisory FG-IR-26-175); interim: disable the IBE feature and restrict management access.
- **Unverified:** a report cites CVE-2026-114625 (VeloCloud Orchestrator SQL injection, exploited) but we could not confirm it in primary sources; related Arista VeloCloud Orchestrator advisories from July (CVE-2026-17191, CVE-2026-16812) list fixed on-prem builds 5.2.3.14, 6.1.3.4, 6.4.2.4 and later. Verify against Arista advisories.
