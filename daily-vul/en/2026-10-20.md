## 1. CVE-2026-0257 — PAN-OS GlobalProtect Authentication Bypass

**Principle / root cause:** An authentication bypass in the GlobalProtect portal/gateway, reachable over the network without credentials or user interaction. It applies when the authentication override cookie feature is enabled together with a particular certificate configuration, so the cookie-based trust check can be satisfied by someone who is not an authenticated user.

**Mitigation:**
- Install the fixed PAN-OS hotfix builds for your branch (e.g., 12.1.4-h6 / 12.1.7 on the 12.1 branch; consult the Palo Alto Networks advisory for other branches).
- Interim: disable authentication override cookies, or use a dedicated certificate exclusively for that feature.
- After patching, GlobalProtect users must re-authenticate once.

**Affected:** PAN-OS 10.2 through 12.1 and Prisma Access (per one source; sources disagree on exact ranges). Panorama and Cloud NGFW are not affected. **Disclosure:** originally published in May 2026 (CISA KEV deadline 2026-06-01); severity raised after public analysis on 2026-05-29. Unit 42 updated its threat brief on 2026-10-19 reporting ransomware groups (Qilin and Inc affiliates; Settra per public reporting) attempting exploitation — hence its inclusion as a current priority.

## 2. CVE-2026-104935 — Ivanti Connect Secure Authentication Bypass (Zero-Day)

**Principle / root cause:** An authentication bypass that lets a remote, unauthenticated attacker reach functionality enabling arbitrary command execution on the appliance. Volexity reports a threat actor (UTA0576) chaining it with two other flaws since at least 2026-10-03; Ivanti is still working on a fix for a privilege-escalation flaw used in the same chain.

**Mitigation:**
- Upgrade to 22.8R2.5, or 25.1.3.0 / 25.1.3.1 / 25.1.1.2 as applicable.
- Run Ivanti's Integrity Checker Tool and hunt for compromise, since exploitation predates the patch; consider factory reset of suspect appliances and credential rotation.

**Affected:** Connect Secure 22.8R2.4 and earlier; 25.1.2.2 and earlier; 25.1.1.1 and earlier. **Disclosure:** 2026-10-13; added to CISA KEV with a federal deadline of 2026-10-16.

## 3. CVE-2026-96951 — Windows Shell Mark-of-the-Web Bypass (Zero-Day)

**Principle / root cause:** Improper neutralization of special elements in a command (CWE-77) in Windows Shell lets a crafted file avoid the Mark of the Web label, so SmartScreen / Protected View style warnings that normally appear for downloaded content are suppressed. Requires user interaction (opening a delivered file); delivery is typically via email, chat/collaboration tools, or a malicious download.

**Mitigation:**
- Apply the October 2026 cumulative updates (2026-10-13) on all Windows systems.
- Reinforce user guidance on untrusted attachments; keep email/web filtering and EDR active.

**Affected:** Windows versions covered by the October 2026 updates (the exact build list was not retrievable — check the Microsoft Security Update Guide). Third Windows Shell flaw exploited in the wild this year per Tenable. **Disclosure:** 2026-10-13; CISA KEV 2026-10-13/14.

## 4. CVE-2026-0322 — PAN-OS Management Interface Code Injection

**Principle / root cause:** Code injection in the management interface lets an authenticated user run code as root.

**Mitigation:** Apply Palo Alto Networks' fixed releases; restrict management interface access to trusted internal networks only (no known workaround per reporting).

**Affected:** PAN-OS (version list not retrieved; see vendor advisory). **Disclosure:** added to CISA KEV 2026-10-14 (federal deadline 2026-10-17).

## 5. CVE-2026-76519 — Cisco Secure Email Gateway Path Traversal

**Principle / root cause:** A relative path traversal flaw that reportedly allows an unauthenticated remote attacker to write files and reach command execution.

**Mitigation:** Apply Cisco's fixed software release per the Cisco advisory; limit exposure of the appliance's management/web interfaces.

**Affected:** Cisco Secure Email Gateway (versions not retrieved). **Disclosure:** CISA KEV 2026-10-14.

## 6. CVE-2026-105133 / CVE-2026-105134 — AhsayCBS Improper Authentication and Command Injection

**Mitigation:** Upgrade to the vendor's fixed AhsayCBS release; do not expose the console to the internet.

**Affected:** AhsayCBS (versions not retrieved). **Disclosure:** CISA KEV 2026-10-14.

**Mitigation:** Apply the fixed Atlassian product versions from the vendor advisory; restrict external access to the instance where possible.

## 8. Plex Media Server — CVE-2026-96651, -96652, -96654, -96655, -96656

**Principle / root cause:** A set of flaws including path traversal (file read, which can expose the account's online token), server-side request forgery via an endpoint that accepts a full URL, and URL injection allowing plugin function calls. Reporting disagrees on whether they chain to unauthenticated remote code execution; one report says attackers are exploiting them and cites a public PoC from 2026-10-16, while another found no confirmed in-the-wild exploitation. Treat as potentially exploited. ~36,000 internet-exposed servers were reported unpatched.

**Mitigation:** Update to Plex Media Server 1.43.3.10861 or later (note several 1.43.3 builds exist; confirm the full build number); avoid exposing the server directly to the internet; rotate Plex tokens if compromise is suspected.

**Affected:** Plex Media Server before 1.43.3.10861. **Disclosure:** mid-October 2026.
