## Most recent (last 24–48 hours)

### 1. WordPress Core — upgrade-time race condition (CVE-2026-119977) — added to CISA KEV
- **Disclosure:** Fixed in WordPress releases on 2026-10-28; CVE published 2026-10-31; CISA KEV addition reported 2026-11-03 (federal remediation due 2026-11-06). Wordfence reported >13,000 blocked attack attempts in 24h.
- **Principle / root cause:** Time-of-check/time-of-use (TOCTOU) race condition in the core update process. During upgrades, files are staged in a predictable temporary directory under `wp-content/upgrade/`, which a remote party can race, potentially leading to code execution. CVSS 8.1 (Wordfence); WordPress itself rates it lower.
- **Affected:** WordPress core during upgrades; fixed in 7.1.4 (7.1 branch), 7.0.8 (7.0 branch), and backports to older branches (e.g. 6.3.14, 5.9.20, 4.9.35). The same release fixes 22 vulnerabilities.
- **Mitigation:** Update to the latest patched release for your branch immediately; enable auto-updates for core; review sites for unexpected files/users/admin changes since 2026-10-28; use WAF rules for update paths; restrict write access to `wp-content/upgrade/` where possible.

### 2. Debian/Ubuntu APT — package substitution by network attacker (CVE-2026-109518)
- **Disclosure:** Reported ~2026-11-03/04.
- **Principle / root cause:** Per reporting, when a download is retried an attacker able to control HTTP traffic (man-in-the-middle) can cause a package that passed verification to be replaced by a different one, which is then installed as root.
- **Affected:** APT on Debian and Ubuntu; fixed versions not confirmed from primary sources (Ubuntu releases were still shown as vulnerable at last check). CVE ID could not be independently confirmed.
- **Mitigation:** Apply APT updates from Debian/Ubuntu security trackers as they land; use HTTPS mirrors; avoid untrusted networks/proxies for package operations; monitor tracker pages for fixed versions.

### 3. HTTP2Shell — Brotli decoder out-of-bounds write (CVE-2026-111497) — exploitation reported
- **Disclosure:** Patches 2026-10-21 (Node.js), emergency .NET patches ~2026-10-26; Check Point (2026-11-02 report) describes active exploitation and automated scanning.
- **Principle / root cause:** Out-of-bounds write in Google's Brotli decompression code, reachable by sending specially formed Brotli-compressed data (e.g. HTTP request/response bodies), potentially leading to remote code execution. CVSS 9.2 (v4) / 9.8 (v3.1).
- **Affected:** Google Brotli 1.0.3–1.2.0 (sources differ on exact range); Node.js 22.x, 24.x, 26.x (Node 20 and older not fixed); Python `Brotli`/`brotlicffi`; .NET and proxy components; applications bundling their own Brotli copy.
- **Mitigation:** Upgrade to Node.js 22.23.4 / 24.22.1 / 26.12.1, Brotli 1.0.10 / 1.1.1 / 1.2.1, Python Brotli 1.2.1, brotlicffi 1.2.1.0, and Microsoft .NET patches. System-library updates do not fix bundled copies — ask vendors of bundled apps for updates. Interim: block or disable Brotli-encoded request bodies at the proxy/WAF. Note Node's `process.versions.brotli` may still show 1.1.0/1.2.0 after patching.

## Other notable items from the week

### 4. Linux kernel — Multipath TCP memory-management flaw (CVE-2026-98432)
- **Disclosure:** Within the period (exact date unconfirmed). CVSS 9.8 reported.
- **Principle:** Memory-safety flaw in the MPTCP networking code that could allow unauthenticated remote code execution as root on systems exposing MPTCP listeners. Exploitation not confirmed.
- **Affected:** Linux kernels with MPTCP enabled (versions unconfirmed).
- **Mitigation:** Install distribution kernel updates when available; disable MPTCP (`net.mptcp.enabled=0`) if unused; limit exposure of listeners.

### 5. Metabase — SQL injection in password-reset endpoint (CVE-2026-72898), CVSS 10.0
- **Disclosure:** Originally fixed/KEV-listed in August 2026; Singapore CSA re-issued an active-exploitation alert in this period.
- **Principle:** Unauthenticated SQL injection leading to administrative access.
- **Affected:** Metabase branches x.58–x.63 below the fixed releases (63.x upper bound differs by source).
- **Fixed:** x.58.24, x.59.21, x.60.17, x.61.11, x.62.9, x.63.5.
- **Mitigation:** Upgrade immediately; review logs/admin accounts for unauthorized activity; rotate credentials and database connection secrets; do not expose Metabase to the internet unnecessarily.
