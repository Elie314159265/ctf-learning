## Newest / Highest Priority

### 1. PHP2Shell — CVE-2026-109618 and CVE-2026-109619 (PHP core)
- **Disclosure date:** Patches released 2026-10-21; added to CISA KEV 2026-10-26 (federal deadline 2026-10-29). Exploitation reportedly observed before patches shipped.
- **Severity:** CVSS 9.2 (Critical); unauthenticated remote code execution on web servers.
- **Principle / root cause (conceptual):** Two flaws in PHP's handling of untrusted web requests/uploads that let an unauthenticated remote party cause server-side code to run. Reported detail is limited; see the PHP advisory for specifics.
- **Affected:** PHP versions back to 5.4, including 8.1 and older (no official fix for 8.1 and below), and 8.2–8.5 prior to the fixed releases. Web servers and CMS/hosting platforms running PHP are in scope.
- **Mitigation:** Upgrade to PHP 8.5.12, 8.4.27, 8.3.36 or 8.2.35. For unsupported branches (8.1 and older), migrate to a supported branch or apply vendor/distro backports. Review web-server logs for anomalous upload/request activity and check for unexpected files in web roots; restrict upload handling and place WAF rules where available.

### 2. Brotli "Node2Shell" — CVE-2026-111497 (Google Brotli decoder)
- **Disclosure date:** 2026-10-21 (Node.js); added to CISA KEV 2026-10-27. Fix had been committed upstream in Feb 2026 without an advisory.
- **Severity:** CVSS 4.0 9.2 (Critical) per Zscaler; CWE-787.
- **Principle / root cause:** Out-of-bounds memory write in the Brotli decompression library when processing specially crafted compressed data, potentially leading to memory corruption and remote code execution in applications that decompress untrusted input (e.g., HTTP responses/requests). Exploitation in the wild and public PoCs reported.
- **Affected:** Brotli library prior to 1.0.10 / 1.1.1 / 1.2.1; downstream products embedding it, including Node.js, .NET, PowerShell, Bun, Envoy, Istio and Python Brotli packages.
- **Mitigation:** Upgrade Brotli to fixed versions; Node.js fixed in 22.23.4, 24.22.1, 26.12.1 (and later). Update container base images and bundled dependencies; rebuild images; inventory software that statically bundles Brotli. Consider disabling Brotli content-encoding on untrusted paths until patched.
