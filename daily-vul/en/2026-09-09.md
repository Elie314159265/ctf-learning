## 1. CVE-2026-85880 & CVE-2026-81963 — Microsoft Windows Zero-Days (September 2026 Patch Tuesday)

**Principle / root cause:** CVE-2026-85880 is a heap-based buffer overflow in the Windows Advanced Local Procedure Call (ALPC) facility, the inter-process communication mechanism used heavily by system services; corrupting heap memory in a service that trusts ALPC callers can let a local, low-privileged process overwrite adjacent memory and eventually execute code with SYSTEM privileges. CVE-2026-81963 is a "link following" flaw (CWE-59) in the Windows Update Stack: the update process resolves a filesystem path/link without adequately verifying that it points to a legitimate, trusted target, so a local attacker can substitute an attacker-controlled file/link so that the update process operates on the wrong (attacker-supplied) object, resulting in privilege escalation.

**Mitigation:**
- Apply the September 2026 cumulative updates immediately — Microsoft confirmed in-the-wild exploitation for both flaws before any public technical write-up existed.
- Prioritize internet-facing and multi-user Windows systems; both are local-privilege-escalation primitives typically chained after initial access.

**Affected:** Modern supported Windows client and Server releases (exact version matrix per Microsoft's MSRC advisories for the two CVEs). Part of the record-setting September 2026 Patch Tuesday release (~974 Microsoft CVEs total, ~105–119 rated Critical), released 2026-09-08. Both zero-days added to CISA KEV the same day.

## 2. CVE-2026-75650 — Adobe Commerce & Magento Template-Engine RCE ("StyleSmuggler", Zero-Day)

**Principle / root cause:** Adobe Commerce/Magento's template-rendering engine fails to properly neutralize special template-directive syntax embedded in otherwise-untrusted input (CWE-1336, improper neutralization of special elements in a template engine). By smuggling crafted directive syntax into fields the template engine later processes, an unauthenticated attacker can get the engine to compile and execute attacker-supplied PHP code — with no login and no user interaction required.

**Mitigation:**
- Apply Adobe's Hotfix (VULN-39341) referenced in security bulletin APSB26-146 immediately; it applies to Adobe Commerce/Magento Open Source versions 2.4.4–2.4.7 and later branches through 2.4.9-2026-aug.
- Treat any unpatched, internet-facing Magento/Adobe Commerce store as compromised-until-proven-otherwise; hunt for unexpected PHP web shells and unfamiliar Linux backdoor binaries/services.

**Affected:** Adobe Commerce, Adobe Commerce B2B, and Magento Open Source, all currently supported branches up to 2.4.9-2026-aug. Active exploitation began 2026-09-04, three days before Adobe's hotfix shipped on 2026-09-07 — attackers used the window to deploy a Rust-based Linux backdoor and, separately, a PHP web shell.

## 3. CVE-2026-86218 — N-able N-central Static Code Injection (Pre-Auth RCE)

**Principle / root cause:** N-central, an on-premises remote-monitoring-and-management (RMM) console used by managed service providers, stores certain server-side scripts/configuration as "statically saved code" that is later executed by the platform. Because directives embedded in attacker-supplied input are not properly neutralized before being written into that saved code (CWE-96, static code injection), an unauthenticated attacker can inject code that N-central subsequently executes — with no credentials needed. Because N-central is designed to push changes out to every managed endpoint, a compromise of the console itself can propagate to every client network it manages.

**Mitigation:**
- Upgrade to N-central 2026.3 Hotfix 4 (fixed in versions ≥ 2026.3.1.14) immediately.
- Given this is the third N-central zero-day disclosed in roughly six weeks, MSPs should audit N-central server logs for unexpected script/config changes going back to early August 2026, not just since the patch date.

**Affected:** N-able N-central versions prior to 2026.3.1.14. Actively exploited in the wild; added to CISA KEV on 2026-09-08 alongside the two Windows zero-days and the Adobe Commerce flaw. Hotfix released 2026-09-05.

## 4. CVE-2026-44756 ("OVERPASS") — SAP Kernel Unauthenticated RCE

**Principle / root cause:** SAP's kernel-level Extended Passport Protocol (EPP) processing library — used across a wide range of SAP components by default — contains a classic buffer-overflow weakness. Because EPP is reachable remotely without authentication in typical deployments, an attacker can send crafted network input that overflows a buffer in EPP parsing and hijack execution flow, running arbitrary operating-system commands with the privileges of the SAP administrative account (effectively full host and application compromise).

**Mitigation:**
- Apply SAP's September 2026 Security Patch Day kernel updates immediately — this is a maximum-severity (CVSS 10.0), default-enabled, unauthenticated remote flaw.
- Restrict direct internet exposure of SAP application/message servers as defense in depth; monitor for anomalous EPP/kernel-level traffic.

**Affected:** A broad range of SAP technology components built on the affected kernel (NetWeaver-based stacks, S/4HANA, and others sharing the vulnerable EPP library). Patched 2026-09-08. Onapsis/researchers estimate over 10,000 internet-facing SAP systems run the vulnerable component; no confirmed in-the-wild exploitation as of this writing, but the combination of default exposure, no authentication, and full compromise makes rapid weaponization likely.

## 5. CVE-2026-61410 & CVE-2026-80238 — Dell Secure Connect Gateway Critical Flaws

**Principle / root cause:** CVE-2026-61410 is a missing-authorization flaw (CWE-862): a specially crafted request to the Secure Connect Gateway application can bypass intended restrictions and reach a code-execution path without valid credentials. CVE-2026-80238 is an execution-with-unnecessary-privileges issue (CWE-250): a low-privileged operator with SSH access to the SCG host — or an attacker who has compromised a service inside the orchestrator container — can reach an exposed Docker socket and use it to gain root on the underlying host, escaping the container boundary entirely.

**Mitigation:**
- Upgrade Secure Connect Gateway appliance to version 5.36.00.16 or later, and the application to 5.36.00.00 or later.
- Audit SSH access to SCG hosts and restrict/remove unnecessary access to the Docker socket as defense in depth.

**Affected:** Dell Secure Connect Gateway (SCG) 5.0, both Application and Virtual Appliance editions, versions prior to the fixed builds above. Disclosed via Dell advisory DSA-2026-382 on 2026-09-07/08.

## 6. CVE-2026-19593 — OpenAI Codex Desktop Git-Config Code Execution

**Principle / root cause:** Codex Desktop automatically inspects Git metadata and working-tree status whenever a user opens a workspace. If that workspace contains a repository whose `.git/config` still carries attacker-controlled settings (e.g. a configured `clean`/`smudge` filter or an `attr.tree` setting), simply opening the workspace causes Git itself to run the attacker-specified program — outside Codex's command sandbox, with no workspace-trust prompt, no command-approval step, and without the AI model being involved at all (CWE-15, external control of a system/configuration setting).

**Mitigation:**
- Update Codex Desktop to the patched release.
- Never open an untrusted or unfamiliar repository directly (e.g. from an email attachment or downloaded archive) in Codex Desktop without first inspecting its `.git/config`; note that an ordinary `git clone` does **not** copy the source repository's local config, so cloning fresh from a trusted URL is safer than opening an already-checked-out folder of unknown origin.

**Affected:** OpenAI Codex Desktop for Windows and macOS, versions prior to the fix. Publicly disclosed 2026-09-01; notable as a supply-chain-relevant flaw in AI coding-assistant tooling specifically.

## 7. CVE-2026-85046 — Google Chrome V8 Type Confusion (Zero-Day, Continuity)

**Principle / root cause:** A logic bug in V8's optimizing compilers can cause an array that should carry the `PACKED_ELEMENTS` type tag to instead be assigned the `PACKED_SMI_ELEMENTS` map. Because later-stage optimized code paths trust that type tag to decide how to read/write array memory, the mismatch (type confusion) can be turned into arbitrary read/write on the JavaScript heap, and ultimately arbitrary code execution inside the Chrome sandbox via a crafted web page.

**Mitigation:** Update Chrome (and Chromium-based browsers — Edge, Brave, Opera, Vivaldi) to 152.0.7977.82/.83 or later and restart the browser to apply the update.

**Affected:** Chrome/Chromium prior to 152.0.7977.82. The sixth actively-exploited Chrome zero-day patched in 2026. Added to CISA KEV on 2026-09-04.

## 8. CVE-2026-85596 — Traefik Kubernetes Ingress Client-Certificate Auth Bypass

**Principle / root cause:** When an Ingress resource carries the `nginx.ingress.kubernetes.io/auth-tls-secret` annotation, Traefik's Kubernetes Ingress NGINX-compatibility provider generates a named TLS option based on the Ingress's namespace and name. A naming/lookup mismatch means routes configured with `nginx.ingress.kubernetes.io/auth-tls-verify-client: "on"` can silently fall back to the entry point's default TLS configuration instead of the route-specific one — so a route intended to require a client certificate becomes reachable without presenting one.

**Mitigation:** Upgrade Traefik to 3.7.11 or later. As defense in depth, verify via a live request (using an appropriate testing tool, not a public write-up) that client-certificate-gated routes actually reject unauthenticated TLS handshakes after patching.

**Affected:** Traefik v3, versions 3.7.0 through 3.7.10, when used as a Kubernetes Ingress controller with NGINX-annotation-based client-certificate enforcement. Disclosed around 2026-09-05.

## 9. Mozilla Firefox / Thunderbird — Continued September Fixes

**Principle / root cause:** CVE-2026-84129 (CVSS 9.8) is a site-isolation failure in the DOM Navigation component, potentially allowing one site's content to improperly access another's in violation of the browser's isolation boundaries. CVE-2026-84133 (CVSS 9.8), fixed in the 2026-09-08 update cycle, is part of the same family of memory-safety and isolation fixes.

**Mitigation:** Update to Firefox 155 / ESR 153.2 and Thunderbird 155 / 153.2 or later.

**Affected:** Firefox and Thunderbird versions prior to the fixes above. CVE-2026-84129 published 2026-09-01 (MFSA 2026-82, also covered in the 2026-09-03 report); CVE-2026-84133 fixed 2026-09-08. No confirmed in-the-wild exploitation reported by Mozilla for either.

## 10. CVE-2026-20349 — Cisco Secure Firewall ASA/FTD SSL VPN DoS (Continuity)

**Principle / root cause:** Insufficient error checking (CWE-244) while processing crafted HTTP requests to the Remote Access SSL VPN service on Cisco ASA/FTD allows an unauthenticated remote attacker to trigger an unexpected device reload — simultaneously knocking out perimeter firewall enforcement and remote-access VPN connectivity.

**Mitigation:** Apply Cisco's fixed software; there is no workaround. Advisory published 2026-08-11; CISA confirmed active exploitation and added it to KEV shortly after. Included here because exploitation and remediation activity continued into this week's window.

**Affected:** Cisco Secure Firewall ASA and FTD Software with Remote Access SSL VPN enabled, versions prior to the fix.
