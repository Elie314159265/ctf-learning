## 1. CVE-2026-88771 & CVE-2026-88772 — Citrix NetScaler ADC / Gateway Zero-Day RCE

**Principle / root cause:** CVE-2026-88771 is an improper input validation flaw that lets an unauthenticated remote attacker run arbitrary commands on the appliance. CVE-2026-88772 is a memory overflow (memory-safety bug) reachable when DTLS is enabled — which is the default for VPN virtual servers — leading to remote code execution or denial of service. Citrix states that all deployments of affected versions meet the precondition, including default configurations.

**Mitigation:**
- Upgrade to the fixed builds in Citrix bulletin CTX697096 immediately.
- On 13.1-branch appliances, if `show ns variable` returns any configured variables, upgrade to 13.1-64.24 to avoid a known reboot loop.
- Treat internet-facing appliances as potentially compromised: review for signs of compromise and rotate credentials/session secrets after patching.

**Affected:** NetScaler ADC and Gateway 14.1 before 14.1-73.37; 13.1 before 13.1-64.23; 14.1-FIPS before 14.1-73.37 FIPS; 13.1-FIPS/NDcPP before 13.1-37.279.
**Disclosure:** exploitation publicly warned 2026-09-26 (watchTowr); patched and CISA alert 2026-09-27. Exploited as zero-days before the fix.

## 2. CVE-2026-86950 — Apple CoreGraphics Zero-Day (iOS / iPadOS)

**Principle / root cause:** A flaw in the CoreGraphics framework, which renders graphics, images and documents system-wide. Apple reports it may have been exploited in extremely sophisticated attacks against specific targeted individuals. Apple has not published root-cause details.

**Mitigation:**
- Update to iOS 26.7.1 / iPadOS 26.7.1 or later. Enable automatic updates.
- High-risk users should consider Lockdown Mode.

**Affected:** iPhone and iPad running iOS/iPadOS prior to 26.7.1 (other Apple platforms: check Apple's advisory).
**Disclosure:** 2026-09-28.

## 3. CVE-2026-93616 — Check Point Security Management Server Pre-Auth Path Traversal

**Principle / root cause:** A path traversal flaw (improper path validation) in the management server lets an unauthenticated remote attacker write files outside the intended directory — upload and then execute scripts — resulting in code execution on the management plane.

**Mitigation:**
- Apply the emergency R82.20 Security Hotfix, or the Jumbo Hotfix Accumulator: R82.10 Take 45, R82 Take 127, R81.20 Take 170, R81.10 Take 192.
- Standard LivePatch updates (including Take 28/29 for CVE-2026-91843) do **not** fix this issue.
- Restrict management interfaces to trusted networks; hunt for unexpected files/scripts on the server. End-of-support releases (R81 and older) have no fix — migrate.

**Affected:** Security Management Server, Multi-Domain Security Management, Log Server, Multi-Domain Log Server, SmartEvent — R82.20 without hotfix; R82.10 ≤ Take 44; R82 ≤ Take 126; R81.20 ≤ Take 166; R81.10 ≤ Take 190; R81 and older (EoS).
**Disclosure:** 2026-09-22; exploited in targeted attacks.

## 4. CVE-2026-65660 — Microsoft SharePoint Server RCE (now exploited)

**Principle / root cause:** A type-check bypass that gives code execution to an authenticated, low-privileged user. Reaching unauthenticated RCE requires chaining with a separate authentication-bypass weakness.

**Mitigation:**
- Apply the August 2026 Patch Tuesday SharePoint updates (fix shipped then); CISA's federal deadline was 2026-09-28.
- Restrict SharePoint exposure to the internet, apply hardening guidance, and review for anomalous activity.

**Affected:** Supported on-premises SharePoint Server versions lacking the August 2026 updates (confirm exact versions in the MSRC entry).
**Disclosure:** patched August 2026; exploitation confirmed and added to CISA KEV 2026-09-25.

## 5. CVE-2026-67279 & CVE-2026-86060 — MikroTik RouterOS Chained Auth Bypass

**Principle / root cause:** CVE-2026-67279 is an improper enforcement of behavioral workflow: an unauthenticated client can open a session channel and issue an execution request out of the expected sequence. CVE-2026-86060 is an argument-injection flaw in the login process. Chained, they give full administrative control of internet-exposed routers without a password.

**Mitigation:**
- Update RouterOS to the latest patched release per MikroTik's advisory.
- Do not expose SSH/management services to the internet; restrict by source IP; rotate credentials and review configuration for unauthorized changes.

**Affected:** Internet-exposed MikroTik RouterOS devices on vulnerable versions (see MikroTik advisory).
**Disclosure:** both added to CISA KEV — 2026-09-25 (CVE-2026-67279); CVE-2026-86060 was added 2026-09-10.
