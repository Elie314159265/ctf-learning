## 1. CVE-2026-104286 — Fortinet FortiMail Unauthenticated Arbitrary File Write

**Principle / root cause:** A flaw in FortiMail's web management handling lets an unauthenticated remote party write arbitrary files to the underlying system via specially crafted HTTP/HTTPS requests. Arbitrary file write on an email security gateway can typically be escalated to code execution. Fortinet's own product security team found it internally; exploitation in the wild has been confirmed.

**Mitigation:**
- Upgrade to FortiMail 8.0.2, 7.6.7, or 7.4.9 once released (fixes were still being prepared at last report). 7.2 branch users should move to 7.4 or later.
- Until then: disable Identity-Based Encryption (IBE) support and/or block internet access to the management interface.
- Hunt for unexpected files and new processes on FortiMail appliances.

**Affected:** FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9.
**Disclosure:** Around 2026-10-01 (added to CISA KEV 2026-10-01).

## 2. CVE-2026-76504 — Cisco Catalyst SD-WAN Manager Authentication Bypass

**Principle / root cause:** Improper handling of URI encoding in HTTP requests allows a request to slip past an authentication rule meant to protect a specific API endpoint, giving an unauthenticated remote attacker access with administrator privileges. Exploited before patches were available; reportedly the fifth exploited zero-day in Cisco's SD-WAN products this year.

**Mitigation:**
- Upgrade to Cisco's fixed releases; no workaround exists. Deployments on releases earlier than 20.9 must migrate to a supported release.
- Restrict management plane exposure to trusted networks and review API/admin logs for anomalous access since September.

**Affected:** All configurations of Catalyst SD-WAN Manager (formerly vManage) on releases 26.2, 26.1, 20.18, 20.15, 20.12, 20.9, and earlier than 20.9.
**Disclosure:** 2026-09-30 (CISA KEV addition early October).

## 3. CVE-2026-88771 / CVE-2026-88772 — Citrix NetScaler ADC and Gateway

**Principle / root cause:** CVE-2026-88771 is an improper input validation flaw enabling unauthenticated remote command execution on devices in a default configuration. CVE-2026-88772 is a memory overflow that can cause remote code execution or denial of service when DTLS is enabled (the default on virtual VPN servers). Both were exploited as zero-days to plant webshells; exploitation turned into indiscriminate mass attacks after a root-cause analysis and proof-of-concept for CVE-2026-88771 were published by third parties. Citrix patched eight critical/high issues in this release.

**Mitigation:**
- Apply Citrix's latest NetScaler ADC/Gateway updates immediately (consult the Citrix advisory for exact fixed builds).
- Assume compromise on unpatched exposed devices: look for webshells and unexpected files, rotate credentials and secrets stored on or reachable from the appliance, and terminate active sessions after patching.

**Affected:** NetScaler ADC and NetScaler Gateway (exact version ranges: see vendor advisory).
**Disclosure:** CISA KEV 2026-09-27; exploitation ongoing and escalating through the week.
