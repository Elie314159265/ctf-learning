## 1. CVE-2026-109618 & CVE-2026-109619 — PHP "PHP2Shell" Request-State Corruption (Unauthenticated RCE)

**Principle / root cause:** Both CVEs stem from one underlying weakness: PHP could abort ("bail out") of a request partway through updating its own internal state, leaving that state inconsistent. CVE-2026-109618 is a memory-corruption issue triggered when memory is exhausted while parsing a multipart request body, corrupting data later used by request cleanup. CVE-2026-109619 is stale state surviving from one request into the next on the same worker. Together they allow unauthenticated remote code execution on web-facing PHP. The upstream fix ("Avoid state corruption via bailout") prevents these bailouts and clears leftover state between requests.

**Mitigation:**
- Upgrade to PHP 8.5.12, 8.4.27, 8.3.36 or 8.2.35 (or later) immediately.
- For branches without an official fix (8.1 and older; backports for 7.4/8.0/8.1 are minimal, none for 5.4–7.3), migrate to a supported branch or apply distribution vendor patches.
- Restrict direct internet exposure of PHP applications where possible, apply per-request memory limits and WAF controls on large/malformed multipart bodies as an interim measure, and review hosts for signs of compromise (unexpected web shells, new files in web roots).

**Affected:** Any PHP serving HTTP (PHP-FPM, mod_php, php-cgi, FrankenPHP, LiteSpeed) older than the fixed releases; researchers trace affected code back to PHP 5.4.
**Dates:** Exploitation attempts reportedly seen from 2026-10-17 (before the patch); fixed 2026-10-21 (CISA alert 2026-10-21); added to CISA KEV 2026-10-26.

## 2. CVE-2026-111497 — Brotli Decoder Out-of-Bounds Write ("Node2Shell")

**Principle / root cause:** An out-of-bounds write (CWE-787) in Google's Brotli decompressor, rooted in an unchecked return value (CWE-252). When the decoder meets a block-switch it cannot complete, vulnerable versions fail to distinguish "malformed stream" from "need more input" and continue decoding, so a crafted compressed stream can make the decoder write past a small working buffer and corrupt adjacent memory. Exposure requires an application that decompresses attacker-controlled Brotli data (e.g., HTTP request/response bodies).

**Mitigation:**
- Brotli library: upgrade to 1.0.10, 1.1.1 or 1.2.1.
- Node.js (bundles its own copy; updating OS libbrotli does not help): 26.12.1, 24.22.1 or 22.23.4. End-of-life lines (20.x and older) have no upstream fix—migrate.
- .NET: Microsoft out-of-band updates of 2026-10-25 (8.0.33, 9.0.22, 10.0.14; 11.0 RC3). Python: Brotli 1.2.1 / brotlicffi 1.2.1.0. Bun: 1.4.4.
- Interim: reject or avoid decoding untrusted Brotli content-encoding where feasible; inventory vendored Brotli copies in containers and bundled apps.

**Affected:** Brotli 1.0.3 through 1.2.0 (sources differ slightly on the exact range) and software embedding it, including the Node.js, .NET, Python and Bun runtimes above.
**Dates:** Fixes and public disclosure around 2026-10-21 to 10-25. Public proof-of-concept reported; one report said CISA listed it in KEV, while other sources checked as of 2026-10-23 did not—confirm current KEV status.

## 3. CVE-2026-110447 — Collabora Online Built-in CODE Server (Nextcloud) OS Command Injection

**Principle / root cause:** OS command injection (CWE-78) in the proxy component of the Nextcloud "richdocumentscode" app. Untrusted input reaches a shell command without adequate neutralization. It is reachable without authentication, and only while the built-in CODE server process is not running (e.g., after restart, upgrade or crash).

**Mitigation:**
- Upgrade the Built-in CODE Server app to 26.4.303 or later, or remove the app entirely (merely disabling it is reported as insufficient).
- Hunt for web shells and unexpected files on Nextcloud hosts; rotate credentials if compromise is suspected.

**Affected:** richdocumentscode versions before 26.4.303 (26.4.302 last affected). Standalone Collabora Online servers (Docker, RPM/DEB), separate Collabora servers used with Nextcloud Office, and Nextcloud All-in-One are not affected.
**Dates:** Exploitation reported since September 2026; added to CISA KEV 2026-10-23.

## 4. CVE-2026-114625 — Arista VeloCloud Orchestrator SQL Injection

**Principle / root cause:** SQL injection — user-controlled input incorporated into database queries without parameterization, allowing query manipulation on the management orchestrator.

**Mitigation:** Apply Arista's fixed Orchestrator release per the vendor advisory; restrict management-plane access to trusted networks; review logs for anomalous queries and administrative changes. Fixed-version numbers could not be confirmed from the sources reached.

**Affected:** Arista VeloCloud Orchestrator (specific versions per vendor advisory).
**Dates:** Added to CISA KEV 2026-10-23.
