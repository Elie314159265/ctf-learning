# Daily Vulnerability Summary — 2026-10-25

Scope: publicly disclosed vulnerabilities, roughly 2026-10-18 to 2026-10-25, plus still-relevant items from earlier in the month. No PoC or exploitation details are included.

> Data-quality note: this summary was built from secondary news and aggregator sources (the primary advisory pages could not be fetched). Some CVE IDs, counts and dates conflict between sources. Verify against vendor advisories, NVD and the CISA KEV catalog before acting.

## 1. Newest / highest priority

### 1.1 Plex Media Server "Plex2Shell" — chain of four flaws (actively exploited, added to CISA KEV)
- **Disclosure / status:** Added to CISA KEV in the last days (reported week of 2026-10-19 to 10-24). Plex says exploitation is active and widespread. A public proof of concept appeared on 2026-10-16, which triggered mass exploitation. The vendor fix shipped 2026-08-03.
- **Principle / root cause:** Four separate weaknesses in Plex Media Server that, when chained, allow a remote, unauthenticated attacker to reach remote code execution on the server. Compromised hosts have been used to run cryptocurrency miners and proxy software.
- **Affected:** Plex Media Server builds earlier than 1.43.3.10861 (Windows, Linux, NAS and other platforms where PMS runs). Shadowserver counts more than 36,000 internet-exposed, potentially unpatched instances.
- **Mitigation:**
  - Upgrade to 1.43.3.10861 or later.
  - Do not expose the server directly to the internet; restrict access by firewall/VPN.
  - Hunt for indicators: unfamiliar `.so`/`.dll` files in the Codecs folder and outbound connections to `proxystream.st`. Rebuild and rotate credentials if found.

### 1.2 Palo Alto Networks PAN-OS GlobalProtect — CVE-2026-0257 (authentication bypass; ransomware exploitation continues)
- **Disclosure:** Vendor advisory 2026-05-13; in CISA KEV; exploitation by ransomware groups (e.g. Qilin) reported since June, and still highlighted in the 2026-10-24 threat briefings. PAN-OS entries were also in the CISA KEV batch of 2026-10-14.
- **Principle / root cause:** When the authentication-override cookie feature is enabled, PAN-OS accepts any cookie it can decrypt without verifying that the device itself issued it. An attacker can therefore obtain a VPN session without valid credentials or MFA.
- **Affected:** PAN-OS 10.2, 11.1, 11.2, 12.1 and Prisma Access with GlobalProtect portal/gateway and authentication override cookies enabled (certain certificate configurations). Panorama and Cloud NGFW are not affected.
- **Mitigation:** Upgrade to the fixed maintenance release in the vendor table; interim: disable authentication override, or use a dedicated certificate only for it. Review VPN session logs for unexpected sessions.
- **Severity:** vendor CVSS 7.8 (raised from 4.7); one aggregator lists 9.1.

### 1.3 CISA KEV additions of 2026-10-14
- CISA added four exploited flaws affecting Palo Alto PAN-OS, Cisco Secure Email Gateway and Ahsay AhsayCBS (per secondary reporting; federal deadline 2026-10-17). Check the vendor advisories for CVE IDs and fixed versions and patch immediately if you run these products.

## 2. Other notable items of the period

### 2.1 Microsoft Windows Shell MotW bypass — CVE-2026-96951 (exploited zero-day)
- **Disclosure:** 2026-10-13 (October Patch Tuesday).
- **Principle:** Security feature bypass; crafted content can evade Mark-of-the-Web protections so that downloaded files run without the usual warnings. CVSS 8.8. Exploited before the patch.
- **Affected:** supported Windows versions per Microsoft's advisory.
- **Mitigation:** Apply the October 2026 cumulative updates; keep SmartScreen/Defender enabled; train users on downloaded-file prompts.

### 2.2 Microsoft October 2026 Patch Tuesday (volume)
- Very large release (sources report roughly 1,100–1,770 CVEs, ~75–95 rated Critical, one confirmed exploited). Counts differ by source; use the Microsoft Security Update Guide. Prioritize internet-facing systems and the exploited item above.
