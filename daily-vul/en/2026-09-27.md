## 1. CVE-2026-88771 & CVE-2026-88772 — Citrix NetScaler ADC/Gateway Unpatched Zero-Days

**Principle / root cause:** CVE-2026-88771 is an improper input-validation flaw that lets an unauthenticated remote attacker run arbitrary commands inside the appliance's packet-processing kernel, with no extra feature or configuration required to be reachable. CVE-2026-88772 is a memory-overflow condition that can lead to remote code execution or a denial of service.

**Mitigation:** As of this report, Citrix has **not yet published an advisory or patch** — a fix was expected "early in the week of September 28." Because exploitation has reportedly been occurring since before any fix existed, patching alone will not evict an attacker already inside a compromised appliance; affected organizations should consider taking exposed NetScaler ADC/Gateway appliances offline, rotating credentials and session tokens, and hunting for indicators of compromise once Citrix's guidance is available.

**Affected:** All NetScaler ADC and NetScaler Gateway deployments (version scope not yet published by Citrix). Reported by security firm watchTowr via forensic investigation on 2026-09-26; actively exploited in the wild, with attackers reportedly harvesting active VPN session tokens and bypassing perimeter controls without credentials. Not yet listed in CISA KEV at time of writing (no patch exists to require).

## 2. CVE-2026-85102 & CVE-2026-93616 — Check Point Security Gateway & Management Pre-Auth RCE / Path Traversal

**Principle / root cause:** CVE-2026-85102 is an improper certificate-validation flaw in VPN negotiation that allows pre-authentication remote code execution. CVE-2026-93616 is a pre-authentication path-traversal flaw in Security Management Server that lets an attacker trigger execution of a script from an arbitrary filesystem path and load an arbitrary Java class.

**Mitigation:** Update to the fixed builds of R82.10, R82, or R81.20 released by Check Point on 2026-09-09.

**Affected:** Check Point Security Gateway / Spark Firewalls (CVE-2026-85102) and Security Management Server (CVE-2026-93616), on R81.20, R82, R82.10, and EOL R80–R81.10 code paths; R82.20 is not affected. Exploitation of CVE-2026-85102 against Spark customers has reportedly been observed since around 2026-09-12; both CVEs were flagged by CISA as actively exploited and added to KEV around 2026-09-22/23, with a reported remediation deadline around 2026-09-25.

## 3. CVE-2026-94127 — F5 BIG-IP APM Heap Overflow Zero-Day

**Principle / root cause:** A heap-based buffer overflow (CWE-122) in BIG-IP Access Policy Manager (APM) is reachable by an unauthenticated remote attacker sending specially crafted traffic to a virtual server that has **both** an APM access policy **and** an OAuth profile configured — exposure is configuration-dependent rather than present on every BIG-IP APM deployment.

**Mitigation:** Apply the F5 hotfix described in advisory K000162605 as soon as operationally feasible; confirm exact vulnerable/fixed point releases against that advisory, since sources only specify the 17.1.x, 17.5.x, and 21.1.0 branches at a high level.

**Affected:** BIG-IP APM instances configured with a combined APM access policy + OAuth profile, across the 17.1.x, 17.5.x, and 21.1.0 branches. F5 published its advisory on 2026-09-22 only after confirming the flaw was already being exploited as a zero-day; added to CISA KEV the same day, with a federal remediation deadline of 2026-09-25.

## 4. CVE-2026-93952 — Arista VeloCloud Orchestrator Maximum-Severity Auth Bypass

**Principle / root cause:** Improper input validation (CWE-20) allows a remote, unauthenticated attacker to access privileged internal functionality on the VeloCloud Orchestrator (VCO) host. Exposure is limited to orchestrators configured to authenticate Edge devices via certificates.

**Mitigation:** Apply the patched releases on the 5.2 and 6.4 trains (available since 2026-09-22); patches were **not yet available for the 6.1 and 7.0 trains** as of the sources reviewed — verify current status with Arista before assuming full coverage.

**Affected:** On-premises Arista VeloCloud Orchestrator deployments; Hosted/Dedicated cloud VCO instances were pre-patched and are unaffected. Confirmed actively exploited in the wild; added to CISA KEV around 2026-09-22.

## 5. CVE-2026-67279 ("MikroTrick" chain, with CVE-2026-86060) — MikroTik RouterOS SSH Auth Bypass

**Principle / root cause:** RouterOS's SSH implementation improperly transitions into the post-authentication "connection protocol" phase after a client-requested key re-exchange (rekey), even though the client never completed user authentication — letting an unauthenticated client open a session channel and issue exec requests. Chaining this with CVE-2026-86060 can escalate to full administrative takeover.

**Mitigation:** Update to RouterOS 7.24.2+ (from below 7.24.2), 7.23.4+ (from below on the 7.0.0 branch), or 6.49.21+ (from below on the 6.0.0 branch), as applicable to your deployed branch.

**Affected:** MikroTik RouterOS 7.24 below 7.24.2, 7.0.0 below 7.23.4, and 6.0.0 below 6.49.21. CERT Polska confirmed real-world attacks dating back to at least 2026-09-02; added to CISA KEV on 2026-09-25.

## 6. CVE-2026-65660 — Microsoft SharePoint Code Injection (Exploitation Surging)

**Principle / root cause:** A code-injection flaw in on-premises SharePoint allows an authenticated attacker with only low-level access to execute arbitrary code over the network without user interaction. Microsoft originally classified the issue as a lower-severity spoofing bug and later revised the severity assessment upward.

**Mitigation:** Ensure the August 2026 SharePoint cumulative security update is applied — notably, the fix predates this week's exploitation surge, so organizations that already patched in August are protected; this is a case of "patch existed, exploitation newly observed" rather than a fresh patch release.

**Affected:** On-premises Microsoft SharePoint Server. Exploitation attempts were first observed around 2026-09-24; Microsoft confirmed "reliable evidence of observed attacks" on 2026-09-25; added to CISA KEV the same day with a federal remediation deadline of 2026-09-28.

## 7. CVE-2026-87902 — WordPress Core Unauthenticated Path Traversal

**Principle / root cause:** WordPress core's page-template resolution logic fails to properly constrain path input, allowing an unauthenticated attacker to force inclusion of a readable local PHP file located outside the active theme directory — a path-traversal flaw that can lead to conditional remote code execution depending on which files are present and readable on the server.

**Mitigation:** Upgrade to WordPress 7.1.2, or the corresponding backported patch release for your branch if running an older supported series.

**Affected:** WordPress core versions 4.7.0 through 7.1.1. Fixed in 7.1.2, released 2026-09-22. Actively exploited — attackers were probing within roughly five hours of the patch going public, with file-write and shell-execution attempts observed the following day. Public PoC is available.

## 8. CVE-2026-7273 — Zyxel GS1900 Switches Stack Buffer Overflow

**Principle / root cause:** A stack-based buffer overflow in the CGI web-management program of GS1900 series switches allows a LAN-based, unauthenticated attacker to execute OS commands via a crafted HTTP request.

**Mitigation:** Update to the June 2026 firmware release for GS1900 devices — a fix has existed for months; the urgency this week is driven by confirmed ongoing exploitation, not a new patch.

**Affected:** Zyxel GS1900 series Gigabit switches, firmware 2.90(XXXX.1)C0 and earlier. A suspected Chinese-speaking threat actor has reportedly been weaponizing this flaw since 2026-08-17, compromising nearly 1,000 switches across 48 countries and exfiltrating device configurations and hashed root credentials. Added to CISA KEV on 2026-09-21.

## 9. CVE-2026-97163 — Joomla "UP" Plugin Unauthenticated Remote Code Installation

**Principle / root cause:** The UP plugin (lomart.fr) for Joomla allows an anonymous request to trigger an on-demand download of "action" code from the maintainer's GitHub repository into a plugin actions directory, which Joomla then executes (improper access control, CWE-284). Compounding the issue, the download request ran with TLS certificate verification disabled, so a network-positioned attacker able to intercept traffic could substitute a malicious archive during the fetch (path traversal, CWE-22).

**Mitigation:** Update to UP version 6.1.0 or 5.2.1, which restore both the authentication check and TLS certificate verification.

**Affected:** UP plugin for Joomla, versions 5.0.0–5.2.0 and 6.0.0–6.0.29. Disclosed 2026-09-26 by the Joomla CNA. A public PoC is available on GitHub; no confirmed in-the-wild exploitation was found in reporting at time of writing, but given the maximum CVSS score and public exploit availability this should be treated as high risk and patched promptly.

## 10. CVE-2026-100716 & CVE-2026-100717 — Froxlor Server Admin Panel Privilege Escalation & Config Injection

**Principle / root cause:** CVE-2026-100716: a root-owned data-export cron job fails to validate intermediate path components; an authenticated low-privilege customer can substitute a symlink before the cron's recursive `chown` runs, escalating to host root and enabling cross-tenant compromise on shared hosting. CVE-2026-100717: the panel's subdomain-redirect URL validation (`Validate::validateUrl`) fails to reject CR/LF sequences in the URL's userinfo (`user:pass@`) component, letting an authenticated low-privilege customer inject arbitrary content into generated nginx/Apache virtual-host configuration files — a configuration-injection flaw with potential for further code execution.

**Mitigation:** Upgrade to Froxlor 2.3.12.

**Affected:** Froxlor server administration panel, versions up to and including 2.3.11. Disclosed 2026-09-26. Both require authenticated low-privilege access as a precondition (not unauthenticated/pre-auth); no confirmed active exploitation found in reporting at time of writing, but the combination of shared-hosting relevance and near-maximum severity warrants prompt patching.

## 11. CVE-2026-100741 — hMailServer JScript Event-Script Injection

**Principle / root cause:** An eval/script-injection flaw (CWE-95) in hMailServer's JScript event-script dispatcher: a password, a POP3 message UID, or an SMTP delivery-rejection error string containing a backslash followed by an apostrophe can break out of a JScript string literal the server constructs when invoking an event handler, letting a remote unauthenticated attacker run arbitrary JScript under the service account's privileges. From version 6.2.25 onward, the default `ScriptAllowedObjects` setting of `*` permits instantiation of `WScript.Shell`, which can escalate this to command execution.

**Mitigation:** No fixed version was confirmed in available reporting — verify with the vendor directly. As an interim mitigation, disable event scripting (off by default) or avoid JScript-language event handlers, and audit any existing `OnClientValidatePassword` scripts.

**Affected:** hMailServer (Progressive Robot Ltd) versions 6.0.0 through 6.3.3 on Windows. Disclosed around 2026-09-27. Exploitation requires a non-default configuration — event scripting enabled (off by default), script language set to JScript (VBScript is the default), and an `OnClientValidatePassword` handler defined. No confirmed in-the-wild exploitation found in reporting.

## 12. "SalesBleed" — Salesforce Agentforce Prompt-Injection Chain (No CVE Assigned)

**Principle / root cause:** A chain of three flaws in Salesforce's Agentforce AI-agent platform, disclosed 2026-09-24. Indirect prompt injection via Web-to-Lead forms: a malicious lead submission contains dormant hidden instructions that activate later when an employee asks an Agentforce agent to process that lead, causing the agent to execute the injected instructions instead of (or in addition to) the legitimate request. Two of the three underlying flaws stem from weaknesses in Agentforce's "Trusted URLs" mechanism, which failed to properly validate top-level domains during URL parsing — enabling zero-click exfiltration of CRM data to attacker-controlled servers and the ability to impersonate the trusted agent to send phishing messages via Slack.

**Mitigation:** No customer action required — Salesforce fixed the issue server-side on 2026-08-19 as this is a hosted-SaaS vulnerability with no local patch to deploy. Organizations using Agentforce should nonetheless review Web-to-Lead intake for anomalous historical submissions and audit agent-initiated outbound communications.

**Affected:** Salesforce Agentforce deployments prior to the 2026-08-19 server-side fix. Publicly disclosed by Zenity Labs on 2026-09-24 (write-up published after the vendor-side fix). Salesforce states it has found no evidence of pre-patch exploitation against real customers. No CVE identifier was assigned, as Salesforce does not issue CVEs for its hosted service.

## Continuity / Context Notes

- **Linux kernel (CVE-2025-39682, CVE-2026-53266, CVE-2025-39964):** Added to CISA KEV on 2026-09-18 (just outside this week's window), but CISA's Binding Operational Directive 26-04 set a 3-day remediation window for internet-exposed assets and 14 days for internal ones, with compliance reporting deadlines falling around 2026-09-23 — inside this week's window. CVE-2026-53266 is an out-of-bounds write in the ebtables SNAT/ARP rewrite path (CVSS 8.8); CVE-2025-39964 is a race condition in crypto operations that can crash the system or corrupt cryptographic results (CVSS 7.8); CVE-2025-39682 involves improper handling of an exceptional condition in TLS processing. Public exploits are reportedly known per vendor advisories.
- **Veeam Agent for Windows (CVE-2026-32996):** A local privilege-escalation flaw (all v13 builds before 13.0.1.2067) via a client-controlled session identifier cached against an elevated admin principal on a local named pipe, letting a low-privileged local user reach SYSTEM. Public PoC released 2026-09-14 (outside window); active-exploitation reporting emerged around 2026-09-22, inside this week's window, alongside the Zyxel disclosure above. Update to Veeam Backup & Replication 13.0.2.29+ (which updates the Agent to 13.0.3.1220).
- **Cisco Secure Email Gateway (CVE-2026-76461):** Critical unauthenticated SQL injection (CVSS 9.8) triggered via a specially crafted email, leading to root command execution; disclosed and added to CISA KEV on 2026-09-14 — just outside the strict window but still an active, high-priority threat for any organization that has not yet patched.
- **Oracle PeopleSoft (CVE-2026-35273):** Original disclosure and mass exploitation by the ShinyHunters/UNC6240 threat cluster date to May–June 2026 (well outside window), but this week brought reports of attackers percent-encoding the "P" in the vulnerable endpoint path to bypass WAF rules on still-unpatched instances — a detection-evasion development rather than a new vulnerability.
- **VMware vCenter (CVE-2026-59310):** Critical directory-traversal-to-RCE in the Syslog server component, disclosed 2026-07-29. Included for situational awareness: CISA confirmed on 2026-09-15 (just before this window) that ransomware actors have joined an existing espionage-focused exploitation campaign against this flaw.
- **Microsoft Patch Tuesday (September 2026, 2026-09-08):** Outside this week's window, but a record-setting release (roughly 964–974 CVEs fixed depending on source, 110+ rated Critical) including two actively-exploited zero-days added to CISA KEV the same day — CVE-2026-81963 (Windows Update Stack elevation of privilege) and CVE-2026-85880 (Windows ALPC heap buffer overflow enabling sandbox escape). Their federal remediation deadline of 2026-09-22 fell inside this week's window, which is why they are noted here even though the underlying disclosure predates it.
- **AI/LLM infrastructure trend:** No new AI/LLM-infrastructure CVE was found strictly within this week's window, but ongoing mass exploitation of Langflow (CVE-2026-0768, unsanitized `exec()` in a custom-component endpoint) for cloud-credential theft continues, and SGLang's unauthenticated pickle-deserialization flaw (CVE-2026-86793, disclosed 2026-09-11) remains a notable recent addition to this category — following LiteLLM and Starlette KEV additions in the prior reporting cycle, AI-adjacent infrastructure continues to be a recurring source of high-severity, actively-exploited flaws.
