## 1. CVE-2026-76504 — Cisco Catalyst SD-WAN Manager API Authentication Bypass

**Principle / root cause:** An authentication bypass in the Manager's API: certain API requests can be processed without the authentication check being enforced, letting a remote, unauthenticated party reach functionality intended for authenticated administrators. Exact flawed code path: details pending.

**Mitigation:**
- Upgrade to the fixed release listed in Cisco's advisory for your software train.
- Restrict management-plane access to trusted networks; do not expose SD-WAN Manager to the internet.
- Review access/audit logs for unexpected API activity and unknown administrative accounts or changes; treat unpatched exposed instances as potentially compromised.

**Affected:** Cisco Catalyst SD-WAN Manager (specific versions: see Cisco advisory). **Disclosed:** 2026-09-30; in CISA KEV and exploited in the wild.

## 2. CVE-2026-88771 & CVE-2026-88772 — Citrix NetScaler ADC / Gateway Zero-Days

**Principle / root cause:** Per CISA's characterization, CVE-2026-88771 is improper input validation and CVE-2026-88772 is improper restriction of operations within a memory buffer (memory-safety error). Each can independently enable remote code execution on the appliance. CISA states exploitation is occurring globally.

**Mitigation:**
- Apply Citrix's fixed builds for your NetScaler branch immediately (federal deadline 2026-09-30).
- Hunt for signs of compromise (unexpected files/processes, new accounts, outbound connections); patching alone does not remove an existing implant. Rotate credentials/secrets held on the appliance and terminate active sessions after patching.

**Affected:** NetScaler ADC and NetScaler Gateway (exact builds: see Citrix bulletin). **Disclosed:** CISA KEV addition 2026-09-27.

## 3. CVE-2026-65660 — Microsoft SharePoint Server Code Injection (RCE)

**Principle / root cause:** A code-injection flaw originally rated as spoofing; later analyses show an authenticated attacker can achieve remote code execution.

**Mitigation:** Install Microsoft's security update; restrict and monitor access to SharePoint; review accounts with site-creation/authoring rights.

**Affected:** SharePoint Server Subscription Edition, 2019, 2016. **Date:** CISA KEV 2026-09-25 (federal deadline 2026-09-28) per a weekly briefing; other coverage says no exploitation was reported — verify.

## 4. MCP Python SDK — Token Pass-Through Weakness

**Principle:** The SDK's HTTP resource handling lacked token isolation, so a malicious MCP server could induce an application to forward OAuth credentials to an unintended party, violating the MCP spec rule that servers must not pass received tokens to upstream APIs (confused-deputy / credential leakage).

**Mitigation:** Upgrade to the patched SDK release from the advisory; only connect to trusted MCP servers; scope and rotate OAuth tokens. **Affected:** official MCP Python SDK (versions per advisory). **Date:** 2026-09-29.
