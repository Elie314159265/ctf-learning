## 1. CVE-2026-104286 — Fortinet FortiMail Path Traversal / Arbitrary File Write (Zero-Day)

**Principle / root cause:** Improper limitation of a pathname to a restricted directory (CWE-22) combined with improper handling of NULL bytes (CWE-158). Crafted HTTP/HTTPS requests can make the appliance write files to locations outside the intended directory, without authentication. Arbitrary file write on a mail gateway can lead to code execution and persistence.

**Mitigation:**
- Fortinet lists fixed builds 7.4.9, 7.6.7 and 8.0.2 as "upcoming"; at disclosure none were available. Check advisory FG-IR-26-175 and upgrade as soon as they ship.
- Interim: disable the IBE (Identity-Based Encryption) feature and remove internet exposure of the management interface.
- Hunt for compromise (unexpected files, config changes) on exposed appliances.
- 7.0 is end-of-support and no 7.2 fix was reported as planned — plan migration.

**Affected:** FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9 (sources differ slightly on bounds; 7.0 may also be affected). **Disclosed:** ~2026-10-01; added to CISA KEV 2026-10-01 (federal due date 2026-10-04).

## 2. CVE-2026-102489 & CVE-2026-102490 — Zammad Session Fixation + Local Privilege Escalation

**Principle / root cause:** CVE-2026-102489 is a session fixation flaw that can be abused to take over a session and reach code execution as the `zammad` service user. CVE-2026-102490 is an improper privilege management flaw letting that local user escalate to root. Chained, they allow full host compromise. The pair was used against the Dutch Institute for Vulnerability Disclosure (DIVD).

**Mitigation:**
- Upgrade to Zammad 7.2.0 (recommended; also hardens the affected code). DIVD advises moving to Zammad 7 or taking affected instances offline.
- Preserve application/network logs before upgrading and check for indicators of compromise.
- Note: Zammad GmbH disputes parts of the DIVD findings and, as of 2026-10-05, no formal vendor advisory or confirmed fix for CVE-2026-102490 was found. Re-verify.

**Affected:** CVE-2026-102489: Zammad 6.3.0–6.5.4 (7.0.0–7.1.3 contain the code but are reported not exploitable). CVE-2026-102490: reported from 1.5.0 up to 7.1.0-alpha (sources disagree). **Disclosed:** KEV addition 2026-10-02 (federal due date reported 2026-10-05).

## 3. CVE-2026-88779 — Citrix NetScaler ADC / Gateway SAML Memory Flaw (DoS) **[unverified]**

**Principle / root cause:** A memory-buffer handling flaw in the SAML processing path can crash services and cause denial of service of authentication and remote access. Researchers warn it could be escalated further, as with earlier Citrix bugs. The CVE ID could not be confirmed in independent databases.

**Mitigation:** Review Citrix's latest bulletin and apply fixed NetScaler builds; at minimum run builds containing the fixes listed in item 6 (14.1-73.37+ / 13.1-64.23+) and confirm against the new bulletin. Restrict exposure of SAML-configured virtual servers.

**Affected:** NetScaler ADC and Gateway configured for SAML. **Disclosed:** reported ~2026-10-04 (KEV listing, due 2026-10-07) — unconfirmed.

## 4. CVE-2026-21589 — Atlassian Jira / Confluence / Bitbucket Critical Flaw **[unverified]**

**Principle / root cause:** Reported as an unauthenticated file-disclosure flaw: web-root files can be read if the attacker knows the exact path. Exploitation was observed on honeypots within hours of a detailed technical write-up being published. No independent confirmation of this CVE ID or its fixed versions was found.

**Mitigation:** Review Atlassian's security bulletins and apply the latest Data Center/Server releases; limit internet exposure of these products and monitor access logs for unexpected file requests.

**Affected:** Jira, Confluence, Bitbucket (exact versions unconfirmed). **Disclosed:** ~first week of October 2026; not confirmed in CISA KEV.

## 5. CVE-2026-76504 — Cisco Catalyst SD-WAN Manager API Authentication Bypass

**Principle / root cause:** An unauthenticated authentication bypass in the Manager's API: requests can be accepted as authorized without valid credentials, giving administrative access to the SD-WAN control plane regardless of configuration.

**Mitigation:**
- No workaround; upgrade to a fixed release for your train (20.9, 20.12, 20.15, 20.18, 26.1, 26.2). Releases older than 20.9 must migrate to a fixed release.
- Treat any Manager reachable from untrusted networks in September 2026 as potentially compromised: review logs, rotate credentials/keys after patching.

**Affected:** Cisco Catalyst SD-WAN Manager 26.2, 26.1, 20.18, 20.15, 20.12, 20.9 and earlier. **Disclosed:** Cisco became aware of exploitation in Sept 2026; CISA KEV 2026-09-30 (due 2026-10-03).

## 6. CVE-2026-88771 & CVE-2026-88772 — Citrix NetScaler ADC / Gateway Critical Zero-Days (context)

**Principle / root cause:** CVE-2026-88771 is an input-validation weakness allowing unauthenticated command execution, exploitable in default configuration. CVE-2026-88772 is a memory overflow (code execution / DoS) when DTLS is enabled (default on VPN vServers). Public root-cause analysis has driven broader, mass exploitation.

**Mitigation:**
- Upgrade to 14.1-73.37+ or 13.1-64.23+ (FIPS: 14.1-73.37 FIPS+, 13.1-37.279+). Bulletin CTX697096.
- Disabling DTLS mitigates only CVE-2026-88772.
- Patching does not prove no prior compromise — check appliances for indicators.

**Affected:** NetScaler ADC and Gateway (incl. FIPS/NDcPP), Secure Private Access Hybrid using NetScaler. **Disclosed:** 2026-09-27 (bulletin and CISA KEV).
