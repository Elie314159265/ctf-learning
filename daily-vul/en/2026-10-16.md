## 1. CVE-2026-96951 — Windows Shell Mark of the Web Bypass (Exploited Zero-Day)

**Principle / root cause:** A flaw in Windows Shell file handling (classified CWE-77) lets a specially crafted file avoid being tagged with, or evade enforcement of, the Mark of the Web (MotW) attribute. MotW is what triggers SmartScreen and Protected View warnings for files from untrusted sources, so bypassing it removes a key user-facing safety prompt and makes malicious downloads easier to run. User interaction is required (opening or downloading a file delivered by email, chat, collaboration tools, or a malicious site).

**Mitigation:**
- Install the October 2026 Microsoft security updates (released 2026-10-13) on all Windows endpoints and servers.
- Keep email/web attachment filtering and endpoint protection enabled; reinforce user guidance on untrusted files.

**Affected:** Supported Windows versions (see the Microsoft advisory for the exact list). CVSS 3.1: 8.8. Added to CISA KEV. Reported as the third exploited Windows Shell flaw this year. The October release is very large (about 1,400+ CVEs; counts differ by source) with three zero-days reported in total.

## 2. CVE-2026-104935 — Ivanti Connect Secure Authentication Bypass (Zero-Day)

**Principle / root cause:** A spoofing-based authentication bypass (CWE-290) in the appliance's web layer: the product trusts a client-supplied request header that should be controlled only by the server, so an unauthenticated remote request can be treated as authenticated. Researchers report it was chained with a privilege-escalation flaw to obtain root-level command execution, including on otherwise patched devices; exploitation was observed from about 2026-10-03.

**Mitigation:**
- Upgrade to a fixed release: 22.8R2.5, 25.1.1.2, 25.1.3.0, or 25.1.3.1 (depending on the product branch).
- Ivanti reports no reliable indicators of compromise yet; run the Integrity Checker Tool, review logs, and consider a factory reset/rebuild for suspected compromise. Restrict management exposure.

**Affected:** Ivanti Connect Secure 25.1.1.1 and earlier, 25.1.2.2 and earlier, and 22.8R2.4 and earlier (22.7.x and below reported unaffected; sources phrase the boundary differently). CVSS 8.6. Disclosed 2026-10-13; added to CISA KEV (federal deadline 2026-10-16).

## 3. CVE-2026-76519 — Cisco Secure Email Gateway Path Traversal (Zero-Day)

**Principle / root cause:** A relative path traversal (improper handling of paths) in the Advanced Malware Protection (AMP) feature when processing email attachments. A crafted attachment sent by an unauthenticated remote sender can cause arbitrary file writes outside the intended directory, leading to command execution as root.

**Mitigation:**
- Install the Content Scanner Tools update 25.3.0.5525 or later (applied without a full software upgrade or restart).
- Review Cisco's published indicators of compromise; Cisco has notified Secure Email Cloud customers with signs of possible compromise.

**Affected:** Cisco Secure Email Gateway with File Reputation enabled and assigned to a mail policy, and Content Scanner Tools earlier than 25.3.0.5525. CVSS 9.8. Exploited in the wild; added to CISA KEV 2026-10-14. This is the second exploited SEG zero-day in recent weeks (the earlier CVE-2026-76461, an SQL injection in email parsing, was disclosed 2026-09-14).

## 4. CVE-2026-0322 — Palo Alto Networks PAN-OS Management Interface RCE

**Principle / root cause:** A remote code execution flaw in the PAN-OS management interface (rated 8.6, CVSS v4.0). Exposure of the management plane to untrusted networks is the key risk factor.

**Mitigation:**
- Restrict management-interface access to trusted internal IP addresses only; do not expose it to the internet.
- Apply Palo Alto Networks' fixed releases per the vendor advisory as they become available.

**Affected:** PAN-OS on PA-Series and VM-Series firewalls and Panorama; Cloud NGFW and Prisma Access are reported as not impacted. Added to CISA KEV 2026-10-14. Sources conflict on whether exploitation is confirmed ("very limited" per one report); treat as exploited per KEV.

## 5. CVE-2026-105133 & CVE-2026-105134 — AhsayCBS Authentication Flaw + Command Injection

**Principle / root cause:** CVE-2026-105133 is an improper-authentication weakness in a system-password check function; CVE-2026-105134 is an OS command injection in the Replication Receiver component. Chained, they allow unauthenticated code execution (reported as SYSTEM). Observed post-exploitation includes web shells, cryptominer deployment, and persistence via a fake Windows service; attacks were first seen 2026-10-07 and at least five organizations were targeted.

**Mitigation:**
- Vendor release 10.3.4.0 did not adequately fix either issue; install hotfix 10.3.4.45 (via the Ahsay partner portal) and reboot.
- Restrict access to the management interface; hunt for web shells and unexpected services.

**Affected:** Ahsay AhsayCBS backup server prior to the hotfix. CVSS 5.5 (CVE-2026-105133, VulDB) / 9.3 (CVE-2026-105134). Added to CISA KEV 2026-10-14.

## 6. CVE-2026-108398 — Microsoft .NET Framework Bypass (Publicly Disclosed)

**Principle / root cause:** A bypass vulnerability in .NET Framework fixed in the October 2026 Patch Tuesday; details were public before the patch. Exploitation is not confirmed, but public disclosure raises the likelihood of exploit development.

**Mitigation:** Apply the October 2026 .NET Framework updates.

**Affected:** .NET Framework versions listed in the Microsoft advisory. Disclosed 2026-10-13. (Limited secondary coverage; verify details in the Microsoft advisory.)

## Earlier in the week / for context (older than 7 days but still actionable)

### CVE-2026-21589 — Atlassian Data Center Arbitrary File Access (2026-10-05)
Missing access control allows unauthenticated reading of files when the attacker knows the exact file name and path (no directory listing). CVSS 9.3. Affects all versions of Bitbucket, Confluence, Jira Service Management, Jira Software, Bamboo, Crowd, Crucible, and Fisheye Data Center; Cloud is already patched. Exploitation attempts began within hours of a public technical write-up. Mitigation: apply fixed versions (e.g., Confluence 9.2.26 / 10.2.19, Jira Software 9.12.40 / 10.3.26 / 11.3.12).

### CVE-2026-88779 — Citrix NetScaler ADC/Gateway SAML Memory Overflow (CISA KEV 2026-10-04)
Memory overflow (CWE-119) on appliances configured as a SAML SP or IdP, causing denial of service; attempts to reach code execution (web shell installation) are reported but unconfirmed. CVSS v4.0 8.7. Mitigation: upgrade to 14.1-73.41 or 13.1-64.28 (or later) and apply Citrix's deny lists.

### CVE-2026-102489 / CVE-2026-102490 — Zammad (CISA KEV 2026-10-02)
A session hijacking flaw that can lead to code execution as the application user (6.3.0–6.5.4; 7.x reportedly not exploitable in practice) chained with a local privilege escalation to root. The disclosure is disputed between DIVD and the vendor on affected versions and exploitability. Mitigation: upgrade to the latest Zammad 7.x release per vendor guidance, or take instances offline until fixed.

### CVE-2026-104286 — Fortinet FortiMail Path Traversal (CISA KEV 2026-10-01)
Unauthenticated path traversal enabling arbitrary file write, flagged as actively exploited. CVSS 9.8. Mitigation: apply Fortinet's fixed FortiMail release per the vendor advisory.
