Coverage window: 2026-10-20 to 2026-10-27. No PoC or exploitation details are included (public repository). ## Newest / highest priority (last 24–48 hours)

### 1. PHP "PHP2Shell" — CVE-2026-109618 / CVE-2026-109619 (Critical, actively exploited)
- **Disclosure:** Fixes released 2026-10-21 (details reportedly leaked slightly before the scheduled release). Added to CISA KEV on 2026-10-26 (federal deadline 2026-10-29).
- **Severity:** CVSS v4.0 9.2 (some sources list 9.8).
- **Principle / root cause:** Both flaws stem from the PHP engine aborting out of a request while internal state is only partly updated and then trusting that inconsistent state later. CVE-2026-109618 is memory corruption in out-of-memory handling while parsing multipart request bodies; CVE-2026-109619 is a use-after-free where state from one request survives into the next on the same worker. Together they can lead to unauthenticated remote code execution.
- **Affected:** PHP releases prior to the fixes (reports trace the issue back to PHP 5.4 through 8.5.x). Internet exposure is very large (Censys: ~36.7 million services reporting potentially affected PHP versions).
- **Mitigation:** Upgrade to PHP 8.5.12, 8.4.27, 8.3.36 or 8.2.35, or install a distribution vendor backport for older branches. Updating only a CMS or plugin does not fix the engine. Interim hardening reported: disable session upload progress (`session.upload_progress.enabled=Off`); restrict/limit request body size and monitor for abnormal worker crashes.
- **Note:** One third-party tracker disputes part of the record (CVE record not yet visible in MITRE/NVD at time of checking); vendor and mainstream reporting treat it as real. Treat as unconfirmed detail and verify against php.net.

### 2. Node.js / Google Brotli decoder out-of-bounds write — CVE-2026-111497 (High/Critical)
- **Disclosure:** Node.js security release 2026-10-21 (10 CVEs total, 4 High); broader Brotli ecosystem advisories 2026-10-23/24.
- **Principle / root cause:** Out-of-bounds memory write in Google's Brotli decompression library when decoding crafted untrusted compressed data, potentially enabling remote code execution in servers/clients that decode attacker-supplied content. CVSS v4.0 9.2 (Google); Node.js rates it High.
- **Affected:** Node.js 22.x, 24.x, 26.x before fixes; EOL lines (20.x and earlier) are affected and unpatched. Google Brotli 1.0.3–1.2.0; Python `Brotli`/`brotlicffi`; Perl `IO::Compress::Brotli` (0.004001 to before 0.023). Reports also suggest other products bundling Brotli (including .NET, see below).
- **Mitigation:** Upgrade Node.js to 22.23.4, 24.22.1 or 26.12.1. Node.js binaries bundle Brotli, so updating the OS libbrotli or npm packages does not fix them. Update Brotli to 1.0.10 / 1.1.1 / 1.2.1+, Python `Brotli` 1.2.1 / `brotlicffi` 1.2.1.0, Perl module 0.023+. Migrate off EOL Node.js. Until patched, avoid decoding Brotli content from untrusted sources.

### 3. Microsoft .NET out-of-band security updates — CVE-2026-111497 (Brotli) and CVE-2026-114148
- **Disclosure:** Reported emergency patches on 2026-10-25 for .NET 8, 9, 10 and 11 RC3 (single-source reporting; CVE numbering varies between articles — confirm with Microsoft's advisory).
- **Principle:** The Brotli decompression buffer/bounds flaw (same upstream library issue as above) and a local privilege escalation (CVE-2026-114148) caused by unsafe ownership metadata handling when extracting tar archives.
- **Mitigation:** Install the latest .NET runtime/SDK servicing updates and rebuild/redeploy self-contained applications; avoid extracting untrusted tar archives with elevated privileges.

### 4. Collabora CODE Server for Nextcloud (richdocumentscode) — CVE-2026-110447 (Critical, actively exploited)
- **Disclosure:** Added to CISA KEV ~2026-10-23/24; exploitation reportedly began mid-September, about a month before the formal bulletin.
- **Principle:** OS command injection in the `proxy.php` endpoint of the built-in CODE server app, leading to unauthenticated remote code execution; exploitation requires the built-in CODE server to be in a stopped state (e.g., after restart, upgrade or crash). Attackers reportedly planted web shells on Nextcloud servers.
- **Affected:** `richdocumentscode` versions before 26.4.303. Standalone Collabora Online, Docker, RPM/DEB, and Nextcloud All-in-One deployments are reported unaffected.
- **Mitigation:** Upgrade to 26.4.303 or later, or remove the app (merely disabling it is insufficient). Hunt for unexpected web shells / new files in the Nextcloud web root, review web server logs and rotate credentials if compromise is suspected.

### 5. Arista VeloCloud Orchestrator (on-premises) — CVE-2026-114625 (actively exploited)
- **Disclosure:** Fixed October 2026; added to CISA KEV ~2026-10-24 (per The Hacker News; CISA's own alert not confirmed).
- **Principle:** SQL injection allowing a remote attacker to reach privileged internal functionality.
- **Affected:** On-premises VeloCloud Orchestrator prior to the fixed releases (affected range not confirmed in available sources).
- **Mitigation:** Upgrade to 5.2.3.18, 6.1.3.10 or 6.4.2.12 (per branch); restrict management interface exposure to trusted networks.
