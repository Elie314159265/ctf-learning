## Newest items (last 24–72 hours)

### 1. Android — CVE-2026-58868 (Critical, Remote Code Execution)
- **Disclosure date:** November 2026 Android Security Bulletin (published ~2026-11-02).
- **Principle / root cause:** A critical flaw in the Android runtime component that can lead to remote code execution without user interaction. Detailed root-cause is not published in the sources reviewed.
- **Affected:** Android 14, 15, 16, 16-QPR2 and 17 (AOSP tracking ID A-486464711). The bulletin as a whole lists 216 fixes, 23 of them Critical.
- **Mitigation:** Apply security patch level 2026-11-05 or later. Rollout depends on device makers and carriers; prioritize managed fleets via MDM.
- **Exploitation status:** No in-the-wild exploitation reported so far.

### 2. WordPress — CVE-2026-119977 (reported as added to CISA KEV on 2026-11-03) — UNVERIFIED

## Other notable items this week

### 3. Ivanti Connect Secure — CVE-2026-111357 and CVE-2026-118527 (actively exploited)
- **Disclosure date:** Ivanti patch 2026-10-29; added to CISA KEV 2026-10-30 (federal deadlines: 2026-11-02 and 2026-11-13).
- **Principle / root cause:** Final stages of a multi-vulnerability attack chain against the appliance. CVE-2026-111357 is a local privilege escalation to root caused by improper handling of configuration/cache data in an internal broker service; it is used after an attacker already has an authenticated foothold from earlier chain steps (starting with CVE-2026-104935).
- **Affected:** Ivanti Connect Secure; sources conflict. CISA's alert cites 22.8R2.5 and earlier, 25.1.1.2 and earlier, 25.1.2.2 and earlier.
- **Mitigation:** Upgrade to fixed builds (reported as 25.1.1.3 / 22.8R2.6); run Ivanti's integrity checker; rotate credentials, sessions and keys on exposed appliances; hunt for compromise.
- **Exploitation status:** Actively exploited.
