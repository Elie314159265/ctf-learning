## 1. CVE-2026-85706 — GitLab CE/EE Unauthenticated Arbitrary File Read

**Principle / root cause:** The repository commits API in GitLab performs improper path confinement combined with missing authentication enforcement (path traversal, CWE-22/CWE-306). A crafted request to the commits endpoint can escape the intended repository directory and cause the server to read and return the contents of arbitrary files on the host filesystem — without any login required. Exposed files can include configuration secrets, credentials, and internal tokens, which can then be leveraged for further compromise (e.g., authenticating as a privileged user or pivoting into CI/CD pipelines).

**Mitigation:**
- Upgrade immediately to GitLab 19.1.8, 19.2.6, 19.3.2, or later.
- If immediate patching is not possible, restrict network access to the GitLab instance and monitor access logs for anomalous requests to commit/file-related API paths.
- Rotate any secrets or credentials that may have been stored in accessible files (e.g., `.env`, CI variables, SSH keys) if compromise is suspected.

**Affected:** GitLab CE and EE versions 18.7 through 19.1.7, 19.2.0 through 19.2.5, and 19.3.0 through 19.3.1. Fixed versions released 2026-09-10. In-the-wild scanning/probing was observed within hours of disclosure (from ~06:00 UTC on 2026-09-11); added to CISA KEV on 2026-09-11 with a federal remediation deadline of 2026-09-14.

## 2. CVE-2026-80462 — Progress Chef Automate API Gateway Authentication Bypass

**Principle / root cause:** The Chef Automate API gateway improperly verifies internal trust tokens exchanged between backend microservices (CWE-306, missing authentication for a critical function). A remote, unauthenticated attacker can craft requests that bypass this internal trust check and reach private, backend-only endpoints directly, gaining elevated access to functionality that should never be reachable without authentication.

**Mitigation:**
- Upgrade to Chef Automate 4.13.520 or later.
- Restrict network exposure of the Automate API gateway to trusted internal networks as defense in depth.

**Affected:** Progress Software Chef Automate versions 4.13.516 through 4.13.519. Disclosed 2026-09-11. No active in-the-wild exploitation or public proof-of-concept has been confirmed at time of writing, but the maximum CVSS score (10.0) and ease of exploitation (no privileges, no user interaction) make prompt patching a priority.

## 3. CVE-2026-57967 — Apache ActiveMQ Artemis Session Hijack via CORE Protocol Reattachment

**Principle / root cause:** The Artemis broker fails to properly verify the legitimacy of a CORE protocol `SESSION_REATTACH` request against the current authentication state or session-integrity checks. A remote, unauthenticated attacker can craft a reattachment packet to hijack an existing, already-authenticated session and continue operating with that session's privileges — potentially leading to arbitrary command execution within the messaging environment.

**Mitigation:**
- Upgrade to Artemis 2.57.0 or later.
- Restrict network access to the broker's CORE protocol port to trusted clients only.

**Affected:** Apache Artemis 2.50.0 through 2.56.0, and Apache ActiveMQ Artemis 1.0.0 through 2.44.0. Disclosed around 2026-09-11; no confirmed in-the-wild exploitation reported yet, but the flaw requires no authentication and is straightforward to reach on any exposed broker.

## 4. CVE-2026-67277 & CVE-2026-86060 ("MikroTrick") — MikroTik RouterOS Chained Pre-Auth Compromise

**Principle / root cause:** CVE-2026-67277 allows RouterOS to accept a "related" bandwidth-test (btest) connection before authentication completes; with certain test parameters, an integer underflow while processing uninitialized kernel packet-buffer data can produce malformed, oversized fragmented output that crashes and restarts the RouterOS kernel (denial of service). CVE-2026-86060 is a flaw in SSH login argument handling: usernames beginning with a disallowed character can alter the router's trusted policy mask, enabling privilege escalation reachable via an unauthenticated SSH session. Chained together ("MikroTrick"), these have been used to hijack routers without valid credentials.

**Mitigation:**
- Upgrade to RouterOS 7.25beta3, 7.24.2, 7.23.4, or 6.49.21 (fixed releases from 2026-09-03), depending on your release track.
- Restrict management-plane and SSH access to trusted management networks; disable unused services (e.g., btest) where not required.

**Affected:** MikroTik RouterOS across multiple release branches prior to the fixed versions above. Actively exploited in the wild; added to CISA KEV on 2026-09-10.

## 5. CVE-2026-80229 & CVE-2026-18924 — curl/libcurl Use-After-Free Issues

**Principle / root cause:** CVE-2026-80229 affects libcurl's OpenSSL 3 "provider" integration: when using the multi interface, pooled TLS connections can outlive the easy handle that created them. libcurl attaches a library context to the easy handle without holding a proper ownership reference; if the easy handle is destroyed early, the context is freed while an active connection still holds a dangling pointer to it, causing a heap use-after-free on subsequent I/O. CVE-2026-18924 is a related-but-distinct use-after-free in libcurl's handling of HTTP/2 server-push streams when a parent handle shares connections with other handles, triggered during connection cleanup.

**Mitigation:**
- Upgrade curl/libcurl to 8.22.0 or later (released 2026-09-02, with the HTTP/2 fix following shortly after).
- Rebuild and redeploy any statically linked applications that bundle an affected libcurl version.

**Affected:** libcurl built against OpenSSL 3+ (for CVE-2026-80229); libcurl applications sharing connections across handles while using HTTP/2 server push (for CVE-2026-18924). No known in-the-wild exploitation; both are memory-safety issues that could lead to crashes or, in some configurations, further exploitation.

## 6. Microsoft September 2026 Patch Tuesday — Record 973 CVEs, 2 Exploited Zero-Days

**Principle / root cause:** Microsoft's largest Patch Tuesday to date covers roughly 973 vulnerabilities (113 rated Critical) across Windows, Office, SQL Server, Exchange, SharePoint, and developer tools. Two flaws are confirmed under active exploitation: **CVE-2026-85880**, a heap-based buffer overflow in Windows Advanced Local Procedure Call (ALPC) allowing a local attacker to escalate to SYSTEM privileges, and **CVE-2026-81963**, an elevation-of-privilege flaw in the Windows Update Stack rooted in improper link resolution before file access (CWE-59) combined with weak access control (CWE-284), also enabling SYSTEM-level compromise. Separately, **CVE-2026-69730** is a critical, unauthenticated Windows DNS Server remote code execution vulnerability (CVSS 9.8) reachable over the network with no credentials.

**Mitigation:**
- Apply the September 2026 cumulative updates across all affected Windows, Office, Exchange, SQL Server, and SharePoint deployments as soon as possible, prioritizing the two exploited EoP flaws and the DNS Server RCE.
- Federal Civilian Executive Branch agencies must remediate CVE-2026-81963 and CVE-2026-85880 by 2026-09-22 per CISA KEV requirements.

**Affected:** Broad range of supported Windows client and server versions, Office, Exchange Server, SQL Server, SharePoint Server, and Visual Studio/developer tooling. Released 2026-09-08; the two zero-days are already in CISA KEV.

## 7. CVE-2026-75650 ("StyleSmuggler") — Adobe Commerce / Magento Zero-Day RCE

**Principle / root cause:** The vulnerability abuses Magento's template-processing/style-handling functionality to smuggle and execute malicious PHP code without authentication (CVSS 10.0). Attackers exploited it as a zero-day for several days before a patch existed, using it to plant persistent backdoors — including a Rust-based Linux backdoor and PHP web shells — on compromised storefronts.

**Mitigation:**
- Apply Adobe's hotfix VULN-39341 (released 2026-09-07) or upgrade to a fixed release immediately.
- Because active exploitation preceded the patch, treat any previously unpatched instance as potentially compromised: rotate Commerce encryption keys, admin/API credentials, payment credentials, and database credentials, and scan for planted web shells or backdoors.

**Affected:** Adobe Commerce, Adobe Commerce B2B, and Magento Open Source versions 2.4.4 through 2.4.9. Active exploitation began around 2026-09-04, roughly three days before the patch shipped on 2026-09-07.

## 8. CVE-2026-86218 (+ CVE-2026-86206 / CVE-2026-86207) — N-able N-central Pre-Auth RCE

**Principle / root cause:** CVE-2026-86218 is a static code injection flaw (CWE-96) in N-central, an on-premises remote monitoring and management (RMM) platform: a remote, unauthenticated attacker can inject and execute arbitrary code on the N-central server before any authentication occurs. It can be chained with two authentication-bypass flaws (CVE-2026-86206, CVE-2026-86207) that let an attacker bypass console login and create attacker-controlled administrative accounts. Because N-central servers hold privileged agent credentials and remote-execution rights across every managed customer network, compromise of the server threatens the entire MSP customer base it manages.

**Mitigation:**
- Upgrade to N-central 2026.3 Hotfix 4 (build 2026.3.1.14) or later, released 2026-09-05.
- Audit for unexpected administrative accounts and unusual agent activity across all managed endpoints if the server was exposed prior to patching.

**Affected:** N-able N-central builds prior to 2026.3.1.14. Actively exploited; this is reported as the third N-central zero-day in six weeks. Added to CISA KEV on 2026-09-08.

## 9. Android Security Bulletin — September 2026

**Principle / root cause:** The monthly bulletin fixes multiple critical System-component remote code execution vulnerabilities, including CVE-2026-49882 (a heap buffer overflow in Bluetooth/NFC-adjacent handling code reachable through the dialer application) alongside CVE-2026-28604, CVE-2026-28618, CVE-2026-28639, CVE-2026-28662, CVE-2026-49884, CVE-2026-49919, and CVE-2026-49921. These are memory-safety issues that, in the worst case, allow remote code execution with no additional privileges or user interaction required.

**Mitigation:** Apply the 2026-09-01 or 2026-09-05 security patch level (or later) via your device manufacturer's update mechanism.

**Affected:** Android devices running patch levels prior to 2026-09-01/2026-09-05, primarily Android 14, 15, and 16. Published 2026-09-08; no confirmed in-the-wild exploitation reported by Google at time of writing.

## 10. CVE-2026-85046 — Google Chrome V8 Type Confusion (Continuity Note)

Already patched earlier this cycle but still relevant for any organization that has not yet updated: a type-confusion bug in Chrome's V8 JavaScript/WebAssembly engine allowed a remote attacker to execute arbitrary code inside the sandbox via a crafted HTML page. Fixed in Chrome 152.0.7977.82/.83 (Windows/Mac) and 152.0.7977.82 (Linux). Actively exploited as a zero-day; added to CISA KEV on 2026-09-04 with a federal remediation deadline of 2026-09-18. Verify all managed Chrome/Chromium-based browser fleets are updated past this version.
