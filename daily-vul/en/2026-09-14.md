## 1. CVE-2026-85706 — GitLab CE/EE Unauthenticated Path Traversal (Exploited Within 24 Hours)

**Principle / root cause:** The repository commits API fails to properly confine a user-supplied file path to the intended repository directory and does not enforce authentication on the affected endpoint. A crafted request can therefore traverse outside the intended directory and read arbitrary files from the GitLab server's filesystem without any credentials.

**Mitigation:**
- Upgrade immediately to GitLab 19.1.8, 19.2.6, 19.3.2, or later.
- Treat any exposed instance as potentially compromised: rotate SSH host/deploy keys, database credentials, CI/CD variables, and any secrets that could have been readable via arbitrary file read, since attackers began probing within a day of disclosure.

**Affected:** GitLab Community Edition and Enterprise Edition, versions 18.7 up to (but not including) 19.1.8, 19.2 up to 19.2.6, and 19.3 up to 19.3.2. Patch released 2026-09-10; active exploitation observed from 2026-09-11; added to CISA KEV 2026-09-11.

## 2. CVE-2026-20079 & CVE-2026-20316 — Cisco Secure Firewall Management Center Authentication Bypass to RCE

**Principle / root cause:** During system boot, a startup process on the FMC creates a partial session record in the internal `sfsnort.sessions` database. If no legitimate user authenticates soon after boot, that leftover session can be leveraged by a remote, unauthenticated attacker who reaches the web management interface, effectively bypassing authentication (CWE-288, authentication bypass using an alternate path). Once authenticated as this artifact session, the attacker can invoke a broad set of CGI scripts to execute code and obtain root access on the underlying operating system.

**Mitigation:**
- Apply Cisco's fixed software releases immediately — there is no workaround.
- Restrict management-interface access to trusted networks and monitor for anomalous CGI script invocations shortly after device reboots.

**Affected:** Cisco Secure Firewall Management Center software running the vulnerable web UI, across supported release trains. Cisco PSIRT confirmed active exploitation by state-sponsored and financially motivated actors in August 2026; added to CISA KEV 2026-09-09 with a federal remediation deadline of 2026-09-12.

## 3. CVE-2026-67277 & CVE-2026-86060 — MikroTik RouterOS "MikroTrick" Unauthenticated Full Device Takeover

**Principle / root cause:** CVE-2026-67277 is a missing-authentication flaw in RouterOS's bandwidth-test (`btest`) service that can leak kernel memory and cause a denial of service. CVE-2026-86060 is an argument-injection flaw in the SSH login path: a username beginning with a specific disallowed character is mishandled, letting an unauthenticated SSH connection attempt alter the router's trusted policy mask. Chained together, these let a remote attacker with no credentials fully take over a RouterOS device that exposes SSH.

**Mitigation:**
- Upgrade to RouterOS 6.49.21 (long-term), 7.23.4 (long-term), or 7.24.2 (stable) or later.
- Do not expose the SSH service or `btest` to the public internet; restrict management access via firewall rules.

**Affected:** MikroTik RouterOS versions prior to the fixed releases above, where SSH and/or `btest` are reachable from untrusted networks. Actively exploited; added to CISA KEV 2026-09-10, federal deadline 2026-09-13.

## 4. CVE-2025-25249 — Fortinet FortiOS / FortiSwitchManager Heap-Based Buffer Overflow

**Principle / root cause:** The `cw_acd` daemon on FortiOS/FortiSwitchManager mishandles specially crafted network packets, leading to a heap-based buffer overflow (CWE-122) that a remote, unauthenticated attacker can leverage to execute arbitrary code or commands on the device.

**Mitigation:**
- Upgrade to FortiOS 7.6.4, 7.4.9, 7.2.12, 7.0.18, or later (also patch FortiSwitchManager/FortiSASE per Fortinet's advisory).
- CISA recommends forensic triage of exposed devices rather than treating this as routine patching, given confirmed in-the-wild exploitation.

**Affected:** FortiOS 6.4–7.6.3 ranges and FortiSwitchManager 7.0–7.2.6 prior to fixed builds. Actively exploited; added to CISA KEV 2026-09-09, federal deadline 2026-09-12.

## 5. CVE-2026-84869 — ConnectWise ScreenConnect Unauthorized File Transfer/Execution

**Principle / root cause:** A missing-authorization and improper-privilege-management flaw in the ScreenConnect client allows files to be transferred to and executed on a connected endpoint through an active remote-support session, without the normal authorization or host-confirmation checks — effectively letting an attacker with access to the relay abuse existing sessions to push and run malicious payloads.

**Mitigation:**
- Update to ScreenConnect 26.6.5 or later immediately.
- Review session logs for unexpected file transfers/executions since 2026-08-20 and treat connected endpoints as potentially compromised.

**Affected:** ConnectWise ScreenConnect deployments prior to 26.6.5. Huntress reported exploitation (malicious VBScript payload delivery) in the wild since 2026-08-20; added to CISA KEV, federal deadline 2026-09-14.

## 6. CVE-2026-19490 — Citrix NetScaler ADC/Gateway Authentication Bypass

**Principle / root cause:** An authentication-bypass-using-an-alternate-path flaw (CWE-288) in NetScaler appliances configured as an AAA virtual server or Gateway (SSL VPN, ICA Proxy, CVPN, RDP Proxy) allows a remote, unauthenticated attacker to circumvent the authentication sequence entirely and reach protected resources behind the appliance.

**Mitigation:**
- Upgrade to NetScaler ADC/Gateway 14.1-73.32, 13.1-63.21, or later.
- Given NetScaler's typical DMZ placement, treat exposed unpatched appliances as high priority even without confirmed compromise.

**Affected:** NetScaler ADC and Gateway 14.1 releases before 14.1-73.32 and 13.1 releases before 13.1-63.21. Patched 2026-08-19/20; a public PoC appeared 2026-09-02, and active exploitation was confirmed from multiple source IPs/countries by 2026-09-03.

## 7. CVE-2026-42016 & CVE-2026-42018 — JFrog Artifactory Authorization/Authentication Flaws (Chained with CVE-2026-82329)

**Principle / root cause:** CVE-2026-42016 is an incorrect-authorization bug: token validation checks the token's signature and issuer but not its intended scope, allowing privilege escalation with a token that should have limited rights. CVE-2026-42018 is an improper-authentication bug that can return an internal anonymous-user token to a caller even when anonymous access has been disabled. Attackers have been chaining both together with the previously reported CVE-2026-82329 authentication-bypass flaw to gain full administrative control of self-hosted Artifactory servers.

**Mitigation:**
- Apply JFrog's fixes for all three CVEs; ensure CVE-2026-82329's fix (7.161.20+) is already applied.
- Rotate admin tokens and audit for backdoors, since chained exploitation was observed between 2026-08-15 and 2026-09-08.

**Affected:** Self-hosted JFrog Artifactory prior to the fixed versions. Federal remediation deadline 2026-09-25.

## 8. CVE-2026-85046 & CVE-2026-87491 — Google Chrome/V8 Zero-Day Sandbox-Escape Chain

**Principle / root cause:** CVE-2026-85046 is a type-confusion bug (CWE-843) in the V8 JavaScript engine's compiler: an array holding `PACKED_ELEMENTS` can incorrectly be given a `PACKED_SMI_ELEMENTS` map, which can be turned into arbitrary read/write inside the V8 heap via a crafted web page. CVE-2026-87491 is a related out-of-bounds write in V8/WebAssembly handling that, chained after the first bug, allows escape from Chrome's sandbox entirely.

**Mitigation:** Ensure Chrome auto-updates to 152.0.7977.82/.83 or later (fixes CVE-2026-85046) and 153.0.8010.36/.37 or later (fixes CVE-2026-87491); restart the browser to apply the update.

**Affected:** Chrome (and Chromium-based browsers) prior to the fixed builds. Fixed 2026-09-03 and 2026-09-08 respectively. Two China-linked threat clusters (tracked as UTA0560 and JungleBamboo) independently exploited this chain in spear-phishing campaigns beginning 2026-09-01. Notably, real-world attack chains have paired this browser escape with the Windows kernel elevation bug below (item 9) to reach SYSTEM privileges after escaping the browser sandbox.

## 9. CVE-2026-81963 & CVE-2026-85880 — Microsoft Windows Zero-Days (September 2026 Patch Tuesday)

**Principle / root cause:** CVE-2026-81963 is an improper-link-resolution flaw in the Windows Update Stack that lets a local attacker manipulate file-path resolution to gain elevated privileges. CVE-2026-85880 combines a heap-based buffer overflow with an uninitialized resource in the Windows Advanced Local Procedure Call (ALPC) subsystem; an attacker who already has low-privilege code execution (e.g., inside an AppContainer sandbox, or after a browser sandbox escape as in item 8) can trigger the overflow to elevate to SYSTEM.

**Mitigation:** Install the September 2026 cumulative updates for all affected Windows client and server versions as soon as possible; prioritize systems that also run internet-facing browsers or other sandboxed applications.

**Affected:** CVE-2026-85880 affects Windows 10 (1607, 1809, 21H2, 22H2) and Windows Server 2012/2012 R2/2016/2019/2022; CVE-2026-81963 affects the Windows Update Stack across supported versions. Both patched 2026-09-08 (Patch Tuesday) and both under confirmed active exploitation, added to CISA KEV.

## 11. CVE-2026-82617 — Apache OpenNLP Regular-Expression Denial of Service

**Principle / root cause:** Built-in name-finder patterns used to detect emails and URLs contain ambiguous nested quantifiers. Crafted input (e.g., an email-like string missing a terminating `@`, or a URL with many `&`-separated query tokens) can trigger super-linear regex backtracking or unbounded recursion in Java's regex matcher, consuming excessive CPU or crashing the processing thread with a stack overflow.

**Mitigation:** Upgrade to Apache OpenNLP 2.5.12, or 3.0.0-M6 for the 3.0.0 milestone line.

**Affected:** Apache OpenNLP 2.0.0 through 2.5.11, and 3.0.0-M1 through 3.0.0-M5. Disclosed around 2026-09-12; no known in-the-wild exploitation, but any service that runs OpenNLP name-finding on untrusted text is at risk of denial of service.

## 12. CVE-2026-87988 — MistralAI Mistral Vibe Arbitrary File Access

**Principle / root cause:** Mistral Vibe (an AI coding-assistant tool) classifies certain commands as "unconditionally allowed" and does not validate the file paths those commands operate on. This missing path validation lets a workspace-restricted command escape the intended project sandbox and access files outside the active workspace without user approval (CWE-732, incorrect permission assignment).

**Mitigation:** Update Mistral Vibe past version 2.15.0 once a fix is available/applied, and review any automated or unattended use of the tool against untrusted repositories or prompts in the meantime.

**Affected:** Mistral Vibe versions up to and including 2.15.0. Disclosed 2026-09-11; no known in-the-wild exploitation, but notable as another example of AI-assistant tooling with insufficient sandboxing (following the LiteLLM MCP bypass covered previously).

## 13. WordPress Plugin Critical Vulnerabilities (Multiple, 2026-09-12/13)

- **CVE-2026-14560 (CVSS 10) — Teddy Bear Customize Addon ≤1.0.5:** The plugin's file-upload handler trusts a client-supplied content type and preserves the original filename without validation, letting unauthenticated attackers upload arbitrary PHP files and achieve full remote code execution. Fix: update to 1.0.6+, or remove the plugin and block PHP execution in the uploads directory as a stopgap.
- **CVE-2026-82845 (CVSS 9.9) — Masteriyo LMS:** A critical flaw in the learning-management-system plugin; check the vendor advisory for the exact mechanism and update to the patched release as soon as it is confirmed.
- **CVE-2026-81402 (CVSS 9.8) — DS Ad Rotator:** A critical flaw in the ad-rotation plugin; update to the patched release once available.

**Mitigation (general):** WordPress sites should update all three plugins immediately, or deactivate them if patches are not yet installed, given the critical severity and the pattern of rapid weaponization seen with other high-install-count plugins this year.

**Affected:** Active installs of the respective plugins prior to their fixed versions. Disclosed 2026-09-12 (Teddy Bear Customize Addon) and 2026-09-13 (Masteriyo LMS, DS Ad Rotator); no confirmed in-the-wild exploitation yet, but WordPress plugin flaws are routinely mass-scanned within days of disclosure.
