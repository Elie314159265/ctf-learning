## 1. CVE-2026-91144 — ZFile Share-Link Path Traversal / Authorization Bypass

**Principle / root cause:** ZFile's file-download endpoint for share links does not validate a requested file path against the specific set of entries that a share link was actually scoped to. Because the authorization check only confirms that the share link is valid — not that the requested path is one of the paths it was granted — an attacker who already holds a legitimate (even narrowly-scoped) share link can supply a different path as a query parameter and retrieve arbitrary files stored anywhere under the share's base directory (CWE-639, Authorization Bypass Through User-Controlled Key).

**Mitigation:**
- Upgrade ZFile beyond version 5.0.5 once a fixed release is available; monitor the project's advisories.
- In the interim, treat all active share links as capable of exposing the entire base directory they are rooted in, not just the intended sub-path; avoid sharing directories that also contain sensitive files.

**Affected:** ZFile through 5.0.5 (self-hosted file-listing/sharing web application). Disclosed 2026-09-14. No confirmed in-the-wild exploitation at time of writing, but it is the most recently disclosed item in this window.

## 2. CVE-2026-81963 & CVE-2026-85880 — Windows Privilege-Escalation Zero-Days (Patch Tuesday)

**Principle / root cause:** CVE-2026-81963 is an improper link-resolution ("link following") flaw in the Windows Update Stack: a process running with elevated rights follows a filesystem link that a lower-privileged local user can redirect, letting that user cause privileged file operations on a location of their choosing. CVE-2026-85880 is a heap-based buffer overflow in Windows Advanced Local Procedure Call (ALPC), where a malformed inter-process message causes memory corruption inside a component running with elevated privileges. In both cases, a local attacker who already has a low-privileged foothold can escalate to SYSTEM.

**Mitigation:**
- Apply Microsoft's September 2026 cumulative updates immediately; both were confirmed exploited *before* the patch shipped.
- Prioritize internet-facing and multi-user Windows hosts; CISA's federal remediation deadline is 2026-09-22.

**Affected:** CVE-2026-81963 affects current Windows 11 releases and Windows Server 2025; CVE-2026-85880 reaches older Windows 10 and Windows Server branches. Disclosed/patched 2026-09-08; added to CISA KEV the same day.

## 3. CVE-2026-69676 — Windows Kerberos Authentication Bypass by Capture-Replay

**Principle / root cause:** A flaw in Windows' handling of Kerberos authentication exchanges (CWE-294, Authentication Bypass by Capture-Replay) allows an attacker who can capture a legitimate Kerberos ticket exchange on the network to replay a modified version of it. The server-side validation accepts the replayed/modified exchange as authentic, allowing code to run in a context the attacker was not actually authorized for.

**Mitigation:**
- Apply the September 2026 cumulative update.
- As defense in depth, enforce SMB/LDAP signing and channel binding, and segment networks to limit an attacker's ability to intercept authentication traffic.

**Affected:** Windows 10 (1607, 1809, 21H2, 22H2), Windows 11 (23H2, 24H2, 25H2, 26H1), and Windows Server (2012 through 2025). Patched 2026-09-08; Microsoft rates future exploitation "More Likely" but it is not yet confirmed exploited in the wild.

## 4. CVE-2026-20079 & CVE-2026-20316 — Cisco Secure Firewall Management Center Auth Bypass to Root RCE

**Principle / root cause:** An improperly-created system process at device boot time leaves a partial administrative session in an internal database (`sfsnort.sessions`). If no legitimate user authenticates after boot, that partial session persists and can be upgraded by a remote, unauthenticated attacker into usable administrative permissions via crafted HTTP requests to the web interface — ultimately allowing script/command execution as root. Because FMC centrally manages fleets of Cisco firewalls, compromising it can compromise every device it administers.

**Mitigation:**
- Apply the fixes Cisco shipped on 2026-07-29 immediately if not already done.
- Restrict management-interface exposure to trusted networks; review for signs of unauthorized administrative sessions created since boot.

**Affected:** Cisco Secure Firewall Management Center software, versions prior to the July 2026 fix. Cisco confirmed active exploitation in August 2026, attributing distinct intrusions to a Sandworm-linked APT and a Qilin ransomware affiliate; added to CISA KEV on 2026-09-09.

## 5. CVE-2026-19490 — Citrix NetScaler ADC/Gateway Authentication Bypass

**Principle / root cause:** NetScaler appliances configured with an AAA virtual server or Gateway service (SSL VPN, ICA Proxy, CVPN, RDP Proxy) contain an authentication-bypass flaw (CWE-288, Authentication Bypass Using an Alternate Path or Channel) that lets a remote, unauthenticated attacker reach functionality normally gated behind a valid login, effectively walking around the intended authentication check via an alternate request path.

**Mitigation:**
- Apply Citrix's fixed builds referenced in bulletin CTX696939 immediately.
- Assume compromise if the appliance was internet-facing and unpatched between disclosure (2026-08-19) and now — CISA requires forensic triage in addition to patching, since patching alone may not remove an existing foothold.

**Affected:** Citrix NetScaler ADC and NetScaler Gateway. Disclosed 2026-08-19; a public PoC appeared 2026-09-02, with active exploitation confirmed within 24 hours (2026-09-03); federal patch deadline was 2026-09-12.

## 6. CVE-2025-25249 — Fortinet FortiOS/FortiSwitchManager Buffer Overflow (PivotC2 RAT Campaign)

**Principle / root cause:** A heap-based buffer overflow in the `cw_acd` daemon of FortiOS and FortiSwitchManager allows a remote, unauthenticated attacker to trigger memory corruption via specially crafted requests, resulting in arbitrary code/command execution on the appliance.

**Mitigation:**
- Apply Fortinet's fix for FortiOS/FortiSwitchManager without delay.
- Hunt for the PivotC2 implant: attackers have been observed abusing the device's own CAPWAP tunneling to route command-and-control traffic through the compromised firewall so it appears to originate from a trusted internal source.

**Affected:** FortiOS and FortiSwitchManager deployments running the vulnerable `cw_acd` daemon. Exploitation observed since at least July 2026 against over 30,000 scanned IPs, with 178 confirmed device infections and at least two confirmed full network intrusions with data exfiltration; added to CISA KEV on 2026-09-09 with a three-day federal remediation window.

## 7. CVE-2026-67277 & CVE-2026-86060 — MikroTik RouterOS "MikroTrick" Chain

**Principle / root cause:** CVE-2026-86060 is a flaw in RouterOS's SSH login helper: usernames beginning with a specific prohibited character are mishandled, letting an unauthenticated SSH client alter the trusted policy mask normally reserved for authenticated users. CVE-2026-67277 is a separate defect in RouterOS's bandwidth-test ("btest") handling: the router accepts a "related" connection before the primary session has finished authenticating, and an inverted, unchecked packet-size interval causes an integer underflow that can crash (or, combined with the SSH flaw, be leveraged against) the device. Chained together, an attacker with network access to the SSH service can gain full unauthenticated control of the router.

**Mitigation:**
- Upgrade to RouterOS 6.49.21 (Long-term), 7.23.4 (Long-term), or 7.24.2 (Stable) or later.
- Do not expose RouterOS SSH management to the public internet; restrict to a management VLAN or VPN.

**Affected:** MikroTik RouterOS devices with SSH reachable from the internet, prior to the fixed versions above. Actively exploited to hijack routers; added to CISA KEV on 2026-09-10.

## 8. CVE-2026-86218 — N-able N-central Pre-Authentication RCE

**Principle / root cause:** A public-facing endpoint in N-central accepts attacker-supplied input that is used to inject and execute arbitrary code without any authentication (consistent with CWE-96, Static Code Injection). No credentials, privileges, or user interaction are required. Researchers also note it can be chained with separate authentication-bypass issues (CVE-2026-86206/86207) that let an attacker create attacker-controlled administrative accounts after bypassing console login.

**Mitigation:**
- Upgrade on-premises N-central to 2026.3.1.14 (Hotfix 4) or later immediately.
- Audit for unexpected administrative accounts created around or before the patch date, since exploitation was observed prior to public disclosure.

**Affected:** N-able N-central on-premises RMM servers prior to 2026.3.1.14. This was the platform's third zero-day in six weeks. Patched 2026-09-05; added to CISA KEV 2026-09-08.

## 9. CVE-2026-75650 ("StyleSmuggler") — Adobe Commerce / Magento Template-Engine RCE

**Principle / root cause:** Adobe Commerce and Magento Open Source insufficiently neutralize special elements when user-controllable input reaches the platform's template-processing engine (CWE-1336-class template injection). By smuggling crafted styling/template content into a code path that the engine later evaluates, an unauthenticated attacker can get arbitrary PHP code executed on the storefront server.

**Mitigation:**
- Apply Adobe's Hotfix VULN-39341 (APSB26-146) immediately — patching alone does not remove any backdoor already planted.
- Because active exploitation began three days before the patch shipped, audit affected stores for a Rust-based Linux backdoor and/or a PHP web shell, and rotate credentials/API keys if compromise indicators are found.

**Affected:** Adobe Commerce, Adobe Commerce B2B, and Magento Open Source versions 2.4.4 through 2.4.9. Exploitation ("StyleSmuggler," per Sansec) began 2026-09-04; Adobe's hotfix shipped 2026-09-07.

## 10. Microsoft September 2026 Patch Tuesday (Bulk Update)

**Principle / root cause:** Microsoft's monthly cumulative update addressed roughly 973 CVEs across Windows and related products — the largest Patch Tuesday on record — spanning memory-safety bugs, authentication-bypass issues, and elevation-of-privilege flaws. Beyond the zero-days and Kerberos issue detailed above (items 2–3), notable RCE fixes include Windows Print Spooler (CVE-2026-85877), Windows Message Queuing (CVE-2026-83997), and the Remote Desktop Client (CVE-2026-83998).

**Mitigation:** Apply the full September 2026 cumulative update rather than cherry-picking individual CVEs, given the scale of this release.

**Affected:** Current and legacy supported Windows client and Server versions, per Microsoft's per-CVE applicability tables. Released 2026-09-08; 113 CVEs rated Critical; 2 confirmed exploited prior to release (covered above).
