## 1. CVE-2026-81963 & CVE-2026-85880 — Microsoft Windows Zero-Days (September 2026 Patch Tuesday)

**Principle / root cause:** Microsoft's September 2026 Patch Tuesday (966–974 CVEs, one of the largest single releases on record) included two elevation-of-privilege flaws that were already being exploited before patches shipped. CVE-2026-85880 is a heap-based buffer overflow in the Windows Advanced Local Procedure Call (ALPC) subsystem; an attacker who can run low-privileged code (including from inside an AppContainer sandbox) can corrupt heap memory in the ALPC service and escalate to SYSTEM without any user interaction. CVE-2026-81963 is an "improper link resolution before file access" (link-following, CWE-59/61 family) flaw in the Windows Update Stack: a local attacker plants a symlink/junction so that a file operation the Update Stack performs with elevated rights is redirected to a location of the attacker's choosing, again yielding SYSTEM-level access.

**Mitigation:**
- Apply the September 2026 cumulative updates immediately; both flaws were exploited pre-patch, so treat this as an emergency deployment, especially on endpoints exposed to untrusted local code (shared workstations, sandboxed/AppContainer-hosting hosts, RDS/VDI).
- Prioritize hosts where low-privileged code execution is already possible (browsers, sandboxed apps) since both bugs are local EoP primitives typically chained after an initial foothold.

**Affected:** Windows Update Stack (CVE-2026-81963) and the ALPC component (CVE-2026-85880) across current, supported Windows client and server releases. Disclosed and patched 2026-09-08; both added to CISA KEV the same day.

## 2. CVE-2026-75650 — Adobe Commerce / Magento "StyleSmuggler" Zero-Day RCE

**Principle / root cause:** Rated the maximum CVSS 10.0, this is an improper-neutralization flaw (CWE-1336, "special elements in a template engine") in Magento's server-side template-rendering functionality. Attacker-controlled input that is meant to be treated as inert style/template data is instead parsed and executed by the template engine, letting an unauthenticated remote attacker run arbitrary PHP code in the context of the web application — no login and no user interaction required. Researchers named the technique "StyleSmuggler" because the malicious payload is smuggled in through a styling/template field that the engine unexpectedly evaluates.

**Mitigation:**
- Apply Adobe's emergency hotfix from Security Bulletin APSB26-146 immediately; this is under active exploitation.
- Since attacks began several days before the patch existed, treat any affected, internet-facing store as potentially already compromised: check for unexpected cron jobs, unfamiliar PHP files/web shells in writable directories, and unrecognized outbound connections consistent with a backdoor.
- Rotate admin credentials and API keys after patching if compromise indicators are found.

**Affected:** Adobe Commerce, Adobe Commerce B2B, and Magento Open Source, versions up to and including 2.4.9-2026-aug, 2.4.8-2026-aug, 2.4.7-2026-aug, and 2.4.6-2026-aug. Exploitation confirmed from 2026-09-04; Adobe's hotfix shipped 2026-09-07; added to CISA KEV 2026-09-08. Attackers have used the flaw to deploy both a Rust-based Linux backdoor and a PHP web shell.

## 3. CVE-2026-86218 — N-able N-central Pre-Auth Static Code Injection / RCE

**Principle / root cause:** CVSS 10.0, classified as CWE-96 ("static code injection"). N-central's server-side code fails to properly neutralize attacker-supplied directives before they are saved into statically evaluated code paths, so an unauthenticated network client can inject code that N-central later executes with the privileges of the N-central service itself. Because remote monitoring-and-management (RMM) platforms like N-central have privileged agents deployed across many managed customer networks, compromise of the central server can cascade into every endpoint it manages.

**Mitigation:**
- Upgrade to N-central 2026.3.1.14 (shipped as "2026.3 Hotfix 4") or later immediately.
- This is the third distinct N-central zero-day disclosed in six weeks; if you cannot patch immediately, restrict network access to the N-central management interface to trusted/VPN-only sources and review agent/server logs for signs of prior exploitation from the earlier waves.

**Affected:** All N-able N-central builds prior to 2026.3.1.14. Hotfix released 2026-09-06 (UTC); added to CISA KEV 2026-09-08. Huntress and other responders report exploitation attempts across all three vulnerability waves in this product this year.

## 4. SAP September 2026 Security Patch Day — Multiple Critical Flaws

**Principle / root cause:** SAP's monthly patch day shipped 19 new security notes plus one update. The most severe, **CVE-2026-44756** (CVSS 10.0), is a memory-corruption vulnerability in SAP Extended Passport Processing, affecting multiple SAP kernel/Web Dispatcher versions — successful exploitation can corrupt process memory in a way that leads to arbitrary code execution. **CVE-2026-58240** (CVSS 9.8) is a missing-authentication-check flaw in the SAP NetWeaver Message Server, letting an attacker without any valid credentials interact with services that should require authentication. **CVE-2026-76969** (CVSS 9.4) is a credential-disclosure bug in the `sap/cds-mtxs` library used by multitenant applications built on the SAP Cloud Application Programming Model — a flaw in tenant-isolation logic can expose one tenant's credentials/secrets to another.

**Mitigation:**
- Apply the corresponding SAP Notes: 3747649 (CVE-2026-44756), 3759472 (CVE-2026-58240), and the CAP `cds-mtxs` update covering CVE-2026-76969, prioritizing internet- or WAN-reachable NetWeaver Message Servers and Web Dispatchers.
- For CVE-2026-76969, upgrade `sap/cds-mtxs` past the affected 1.18.3 / 2.7.6 / 3.9.6 / 4.0.2 lines in every multitenant application that bundles it, not just central SAP infrastructure.

**Affected:** SAP kernel/Web Dispatcher (KERNEL 7.22, 7.53, 7.54, 7.77, 7.89, 7.93, 8.04, 9.16–9.20) for CVE-2026-44756; NetWeaver Message Server (KERNEL 9.16, 9.18, 9.19, 9.20) for CVE-2026-58240; `sap/cds-mtxs` up to 1.18.3/2.7.6/3.9.6/4.0.2 for CVE-2026-76969. Patched 2026-09-08; no confirmed in-the-wild exploitation yet, but patch quickly given the severity and SAP's history of rapid reverse-engineering of patch diffs by attackers.

## 5. CVE-2026-67276 & CVE-2026-86060 — MikroTik RouterOS "MikroTrick" SSH Bypass Chain

**Principle / root cause:** Two chained flaws let a remote attacker fully take over internet-facing RouterOS devices via SSH without valid credentials. CVE-2026-67276 (CVSS 9.2) is caused by RouterOS validating only part of an RSA public key during SSH public-key authentication instead of the complete key, allowing a specially crafted alternative key to be accepted as if it belonged to a legitimate, existing user. Once in this pre-authenticated state, CVE-2026-86060 (CVSS 9.2) lets the attacker escalate to full administrative control by supplying a crafted username that RouterOS's SSH login helper misinterprets as a command-line argument rather than as user identification — a classic argument-injection pattern. CERT Polska named the two-stage chain "MikroTrick."

**Mitigation:**
- Update to the RouterOS builds MikroTik released on 2026-09-03 as soon as possible.
- Until patched, disable SSH access from the WAN/internet on RouterOS devices, or restrict it to a management VPN.
- Check for indicators of prior compromise: an unexpected SSH user (reports describe a suspicious account literally named "-2") is a known artifact from active campaigns exploiting this chain.

**Affected:** MikroTik RouterOS devices with SSH exposed to public networks, prior to the 2026-09-03 patched builds. Exploitation began 2026-09-02, a day before patches were available; CERT Polska's advisory was published 2026-09-05.

## 6. CVE-2026-85046 — Google Chrome/Chromium V8 Type Confusion Zero-Day

**Principle / root cause:** A type-confusion bug (CVSS 8.8) in V8, the JavaScript/WebAssembly engine used by Chrome and other Chromium-based browsers. Certain compiler tiers within V8 can incorrectly treat an array declared with generic ("packed") elements as if it held only small integers, a mismatch between the engine's internal type assumptions and the object's real layout. A crafted web page can trigger this mismatch to obtain out-of-bounds read/write primitives in the JavaScript heap, which can be escalated to arbitrary code execution inside the browser's rendering sandbox.

**Mitigation:**
- Update Chrome (and any Chromium-based browser: Edge, Brave, Opera, etc.) to 152.0.7977.82 or later; verify via the browser's "About" page that the update has actually applied and the browser has restarted.
- Enterprises should confirm managed-update policies pushed this version promptly given confirmed in-the-wild exploitation.

**Affected:** Chrome/Chromium prior to 152.0.7977.82. Reported by an external researcher on 2026-08-04; patched 2026-09-03/04; added to CISA KEV 2026-09-04.

## 7. CVE-2026-32475 — Elementor Pro (WordPress) Arbitrary File Upload — Mass Exploitation Continuing

**Principle / root cause:** In Elementor Pro's Forms module, the file-upload feature validates file extensions and moves uploaded files to their final destination in two separate code loops that handle "empty" file entries inconsistently. By submitting two file parts for the same form field, an unauthenticated attacker can cause the extension check to pass on one part while a PHP file is written to a publicly accessible directory via the other — bypassing the extension blocklist entirely and resulting in a web shell.

**Mitigation:**
- Update to Elementor Pro 4.2.2 or later immediately if not already patched (fix has been available since 2026-08-19).
- Given mass scanning/exploitation (Wordfence reported blocking 190,000+ attempts as of 2026-09-02), scan affected sites for unexpected PHP files in uploads directories even after patching.

**Affected:** Elementor Pro up to and including 4.2.1, estimated to affect roughly 6 million WordPress sites. Public disclosure began 2026-08-19; mass exploitation reported ongoing through this reporting window.
