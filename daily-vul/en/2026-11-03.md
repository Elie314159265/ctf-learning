## 1. Fortinet coordinated security updates with deferred disclosure (disclosed 2026-10-22; details due 2026-11-10)

**Principle / root cause:** Not public. Fortinet released updates it called urgent but withheld CVE IDs, CVSS scores and technical details until 2026-11-10. Experts warn that attackers can compare patched and unpatched builds ("patch diffing") to rediscover the flaws, so exploitation may precede the official disclosure.

**Mitigation:**
- Do not wait for 2026-11-10: apply the latest FortiOS, FortiManager and FortiAnalyzer releases (and the recent FortiMail and FortiAuthenticator releases) now.
- Restrict management interfaces to trusted networks and monitor for anomalous admin activity.

**Affected:** FortiOS, FortiManager, FortiAnalyzer; earlier related updates for FortiMail and FortiAuthenticator. Specific versions are not yet published. One source mentioned five product lines, but I could only confirm these products.

## 2. CVE-2026-101767 — Oracle E-Business Suite SQL Injection

**Principle / root cause:** SQL injection (improper neutralization of input in a database query) in an E-Business Suite component, which can let a remote party manipulate backend queries.

**Mitigation:** Apply the October 2026 Oracle Critical Patch Update (which fixed about 1,209 CVEs, six rated CVSS 10.0). Restrict internet exposure of EBS and monitor for unusual query patterns.

**Affected:** Oracle E-Business Suite (exact versions: see Oracle CPU advisory). Honeypots recorded probing from 2026-10-27, about a week after the fix; Oracle reported no exploitation.

## 3. CVE-2026-109619 — Reported actively exploited (product not identified)

**Details:** A roundup lists this CVE as actively exploited and in CISA KEV since 2026-10-26. The source gave no product, root cause or fix. **Action:** check the CISA KEV catalog entry for the affected product and remediation deadline.

## 4. CVE-2026-28336 — SolarWinds Dameware command injection (*unverified*)

**Principle / root cause:** One aggregator lists an OS command-injection flaw (CVSS 9.9) with disclosure on 2026-11-03 and no known exploitation. A follow-up search found no record of this ID from SolarWinds or other sources, so it may be incomplete or inaccurate.

**Mitigation:** Watch the SolarWinds Trust Center advisories; apply any Dameware update when published and limit exposure of Dameware services.

## Context items from earlier (outside the 7-day window)

- **CVE-2026-104286 (FortiMail, CVSS 9.8)** — path traversal combined with NULL-byte mishandling lets an unauthenticated remote party write files via crafted web requests, potentially leading to code execution. Advisory FG-IR-26-175 (2026-10-01); in CISA KEV. Reported affected: 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8, 7.2.0–7.2.9.
