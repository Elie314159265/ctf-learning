# Daily Vulnerability Summary — 2026-10-13

Coverage: disclosures from 2026-10-06 to 2026-10-13, with newest items first. Sources are secondary (news/aggregators); vendor advisories could not be fetched directly, and some sources conflict. **Verify fixed versions against the vendor advisory before acting.** No PoC or exploitation details are included.

## Newest (last 24–48 hours)

### Microsoft October 2026 Patch Tuesday (disclosed 2026-10-13)
- **Details:** Reports conflict on scale (one source: ~1,411 flaws with 3 zero-days; another: ~1,417 with 76 critical; a vendor page lists only an Exchange Server elevation-of-privilege, CVE-2026-96940, CVSS 8.8). One reported exploited flaw is CVE-2026-96951, a Windows Shell Mark-of-the-Web (MotW) security feature bypass. **This CVE could not be independently confirmed.**
- **Principle / root cause:** Security-feature bypass class: the shell fails to preserve or honor the "downloaded from internet" marker, so protective prompts (SmartScreen/Protected View) are skipped when a user opens a crafted file.
- **Affected:** Supported Windows client/server releases; Exchange Server (CVE-2026-96940).
- **Mitigation:** Apply the October 2026 cumulative updates and Exchange security updates; check MSRC Security Update Guide for the authoritative list; user training on opening untrusted files.

## Actively exploited / recent items

### SonicWall SMA 1000 — CVE-2026-102255 (CVSS 10.0), disclosed ~2026-10-07/08
- **Principle / root cause:** Pre-authentication server-side request forgery (SSRF) in the WorkPlace interface, letting an unauthenticated remote party make the appliance issue internal requests, which can expose internal services.
- **Affected:** SMA 6210, 7210, 8200v running 12.4.3-03526 and earlier, or 12.5.0-02952 and earlier. SMA 100 series and firewall SSL-VPN are not affected.
- **Mitigation:** Upgrade to 12.4.3-03670 / 12.5.0-03082 or later (advisory SNWLID-2026-0017; one regional CERT cites different hotfix builds — confirm). No workaround listed. Same advisory fixes CVE-2026-102256 (authenticated OS command injection, 7.8), CVE-2026-102257 (Zip Slip, 7.2), CVE-2026-102258 (stored XSS, 5.5).
- **Status:** Exploitation attempts reported by researchers (Oct 9); vendor stated no confirmed exploitation at the time.

### Citrix NetScaler ADC / Gateway — CVE-2026-88779 (CVSS 4.0: 8.7), disclosed 2026-10-04 (CISA KEV 2026-10-04)
- **Principle / root cause:** Memory overflow in SAML handling; repeated triggering can crash the appliance (denial of service). Researchers were still assessing whether code execution is possible.
- **Affected:** Appliances configured as SAML service provider or identity provider; NetScaler 14.1 before 14.1-73.41 and 13.1 before 13.1-64.28 (FIPS/NDcPP 13.1: 13.1-37.282). Sources disagree on build numbers.
- **Mitigation:** Upgrade to fixed builds (re-upgrade even if recently patched for CVE-2026-88771/88772, exploited zero-days added to KEV 2026-09-27). Federal deadline was 2026-10-07.

### Fortinet FortiMail — CVE-2026-104286 (CVSS 9.8), disclosed 2026-10-01 (CISA KEV 2026-10-01)
- **Principle / root cause:** Path traversal with NULL-byte handling flaw in the Identity-Based Encryption (IBE) service allows unauthenticated arbitrary file write via crafted web requests.
- **Affected:** FortiMail 8.0.0–8.0.1, 7.6.0–7.6.6, 7.4.0–7.4.8 (some sources also 7.2.x).
- **Mitigation:** Upgrade to 7.4.9 / 7.6.7 / 8.0.2 when available (sources conflict on whether released); meanwhile disable IBE or restrict public exposure, and hunt for compromise. Advisory FG-IR-26-175.

### Zammad — CVE-2026-102489, CVE-2026-102490, CISA KEV 2026-10-02
- **Principle:** Session fixation (102489) and improper privilege management enabling local privilege escalation to root (102490).
- **Affected / mitigation:** Zammad help-desk deployments; upgrade to the latest fixed release per Zammad advisory (versions not confirmed); rotate sessions after upgrade.

### Bricksforge WordPress plugin — CVE-2026-85097 (CVSS 10.0)
- **Principle:** Unauthenticated arbitrary file upload leading to server-side code execution. Exploitation attempts observed from 2026-10-07 (Patchstack).
- **Mitigation:** Update to the fixed plugin release or remove the plugin; review webroot for unexpected files. Affected version range not confirmed.
