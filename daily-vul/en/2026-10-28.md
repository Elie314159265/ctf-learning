## Top priority (last 24–72 hours)

### 1. PHP — CVE-2026-109618 / CVE-2026-109619 (unauthenticated RCE, actively exploited)
- **Disclosure:** Security release 2026-10-21; added to CISA KEV 2026-10-26 (evidence of active exploitation).
- **Severity:** CVSS v4.0 9.2 (some sources report 9.8).
- **Principle / root cause (conceptual):**
  - CVE-2026-109618: out-of-memory handling can abort request processing while internal request data is only partially initialized, and request cleanup then trusts that invalid data (memory-safety flaw).
  - CVE-2026-109619: PHP's fatal-error path (non-local jump) is not handled safely in some contexts, leaving global state pointing at memory freed at request end; later requests can use the stale memory (use-after-free class).
  - Together these can lead to remote code execution without authentication.
- **Affected:** PHP from 5.x (reported 5.4) through 8.5.11, including Apache mod_php; PHP-FPM is also affected under different prerequisites. Branches 8.1 and older receive no official upstream fix.
- **Mitigation:**
  - Upgrade to 8.5.12, 8.4.27, 8.3.36 or 8.2.35 (or later).
  - For 8.1 and older, apply the OS/distribution vendor backport or migrate to a supported branch.
  - Check container base images and hosting platforms that bundle PHP; restart PHP workers/Apache after patching.
  - Prioritise internet-facing PHP applications; review logs for abnormal worker crashes or out-of-memory events.

### 2. Arista VeloCloud Orchestrator (VCO) — CVE-2026-114625 (SQL injection → privilege escalation, actively exploited)
- **Disclosure:** 2026-10-22.
- **Severity:** CVSS 9.9 (v3.1) / 9.4 (v4.0), per secondary reports.
- **Principle / root cause:** Insufficient input sanitisation in a database query path lets a low-privileged authenticated user (reportedly as low as an "Enterprise Read Only" role) manipulate queries and escalate privileges. No user interaction required.
- **Affected:** On-premises VeloCloud Orchestrator. Exact fixed-version matrix per release train not confirmed from sources; see Arista Security Advisory 0199.
- **Mitigation:** Apply Arista's fixed VCO release for your train; restrict management-plane access to trusted networks; block attacker IPs listed in the Arista advisory; audit accounts and roles and review logs for unusual privilege changes.

### Related: Arista VCO — CVE-2026-93952 (CVSS 10.0, exploited, in CISA KEV; disclosed 2026-09-22)
- Unauthenticated access to privileged internal functionality; only orchestrators configured for certificate-based Edge authentication are exposed. As of the September reporting, fixes existed for 5.2 and 6.4 trains but not yet 6.1 and 7.0 — check current status.

## Other notable items (context, slightly older than 7 days)

### 3. Cisco Secure Email Gateway — CVE-2026-76519 (critical, actively exploited)
- **Disclosure:** Exploitation acknowledged October 2026; added to CISA KEV 2026-10-14.
- **Severity:** CVSS 9.8.
- **Principle:** Processing of a crafted email attachment by the file-reputation / content-scanning component can result in arbitrary file writes and potentially root-level command execution.
- **Affected:** Physical and virtual Secure Email Gateway appliances where File Reputation is enabled and assigned to a mail policy and Content Scanner Tools is earlier than 25.3.0.5525. Cloud-hosted customers were patched by Cisco.
- **Mitigation:** Update Content Scanner Tools to 25.3.0.5525 or later (no restart) and/or upgrade AsyncOS to a fixed release (reported 15.5.5-014 / 16.5.0-780; verify against advisory cisco-sa-esa-afw-zqYJkjxp). No workaround. For suspected compromise, rebuild on a fresh VM with a fixed release rather than upgrading in place (preserves evidence) and do not import the old configuration; restore all members of an affected cluster.

### 4. Ivanti Connect Secure — CVE-2026-104935 (auth bypass → command execution, exploited as zero-day)
- **Disclosure:** 2026-10-13; added to KEV same day; exploitation reportedly from ~2026-10-03.
- **Severity:** CVSS 8.6.
- **Affected:** Connect Secure 25.1.2.2 and earlier; 22.8R2.4 and earlier.
- **Mitigation:** Apply Ivanti's patch, run the Integrity Checker, hunt for compromise. Volexity reports a related unpatched privilege-escalation flaw used in chains; follow Ivanti updates.

### 5. Microsoft Windows Shell — CVE-2026-96951 (security feature bypass, exploited)
- **Disclosure:** October 2026 Patch Tuesday (2026-10-13). CVSS 8.8.
- **Principle:** Windows Shell fails to enforce a security protection when handling certain user-opened content, allowing the warning/trust mechanism to be bypassed.
- **Mitigation:** Install the October 2026 cumulative updates on all supported Windows versions; user-awareness on opening untrusted files. Patch Tuesday also addressed a very large number of other CVEs (reports cite ~1,400).

## General recommendations
- Patch internet-facing edge devices (email gateways, VPNs, SD-WAN, ADCs) first; these dominate current exploitation.
- Track CISA KEV additions and apply remediation within their due dates.
- Assume compromise on unpatched exposed devices during the exploitation window; hunt and rotate credentials where warranted.
