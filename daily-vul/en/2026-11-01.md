## Newest / highest priority (last 24–72 hours)

### 1. GitLab CE/EE — CVE-2026-97229 (CVSS 10.0, actively exploited)
- **Disclosure / status:** Fixed by GitLab around 2026-10-12; added to CISA KEV on 2026-10-29 (federal remediation due 2026-11-01), i.e. now confirmed exploited in the wild.
- **Root cause:** Integer overflow/wraparound (CWE-190) in the CI/CD regular-expression compiler component, which can lead to memory corruption and remote code execution.
- **Affected:** GitLab CE/EE 19.2 before 19.2.8, 19.3 before 19.3.5 (some sources say 19.3.4 — confirm), 19.4 before 19.4.2. GitLab.com and Dedicated are already patched.
- **Mitigation:** Upgrade self-managed instances to 19.2.8 / 19.3.5 / 19.4.2 or later immediately; review instance logs and CI configuration changes for anomalies; restrict external exposure until patched.
