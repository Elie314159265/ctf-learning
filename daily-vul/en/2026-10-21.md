## Most Recent (last 24–48 hours)

### 1. PAN-OS CVE-2026-0257 — ransomware exploitation reported (Palo Alto Networks)
- **Disclosure date:** Originally published earlier in 2026 (CISA KEV mitigation deadline 2026-06-01); Unit 42 threat brief updated 2026-10-20 reporting ransomware affiliates (e.g. Qilin, Inc) attempting exploitation.
- **Principle / root cause:** Authentication bypass in the GlobalProtect portal/gateway. Exploitable only when authentication override cookies are enabled together with a particular certificate configuration, which can allow an unauthorized party to establish a VPN session.
- **Affected:** PAN-OS firewalls (PA-Series / VM-Series) with GlobalProtect portal or gateway configured; Panorama and Cloud NGFW not affected. Branches 10.2, 11.1, 11.2, 12.1 (see vendor advisory for exact fixed releases).
- **Mitigation:** Upgrade to the fixed release for your branch; if not possible, disable authentication override cookies or use a dedicated, securely stored certificate for them. Review VPN logs for unusual source IPs and post-login activity.

## Other Notable Items This Week

### 3. Cisco Secure Email Gateway CVE-2026-76519 (CVSS 9.8) — actively exploited
- **Disclosure date:** 2026-10-13/14 (added to CISA KEV 2026-10-14).
- **Root cause:** Relative path traversal allowing unauthenticated file writes on the appliance.
- **Affected:** Physical and virtual Cisco Secure Email Gateway running AsyncOS, only when File Reputation is enabled and assigned to a mail policy and Content Scanner Tools is older than 25.3.0.5525.
- **Mitigation:** Update Content Scanner Tools to 25.3.0.5525 or later (no workaround). If the log shows "Suspected compromise indicator was found", contact Cisco TAC before upgrading, since upgrading destroys evidence. Advisory: cisco-sa-esa-afw-zqYJkjxp.

### 4. Microsoft Windows Shell CVE-2026-96951 (CVSS 8.8) — zero-day, Patch Tuesday 2026-10-13
- **Root cause / type:** Details not confirmed in sources reviewed (reported as actively exploited zero-day in Windows Shell).
- **Affected:** Supported Windows versions (see Microsoft Security Update Guide).
- **Mitigation:** Apply the October 2026 cumulative updates; CISA KEV federal deadline was 2026-10-16. Reported Patch Tuesday CVE totals vary widely between sources.

### 5. Ivanti Connect Secure CVE-2026-104935 — authentication bypass
- **Disclosure date:** Added to CISA KEV 2026-10-13.
- **Root cause:** Improper authentication allowing access without valid credentials.
- **Affected / fixed versions:** Not confirmed in sources reviewed; see Ivanti advisory.
- **Mitigation:** Apply Ivanti's latest Connect Secure patch, run the integrity checker tool, review access logs.

### 6. Palo Alto Networks PAN-OS CVE-2026-0322 — code injection (management interface)
- **Disclosure date:** Added to CISA KEV 2026-10-14.
- **Root cause:** Code injection letting an authenticated management-interface user execute code as root.
- **Affected:** PA-Series, VM-Series, Panorama (fixes reported across 10.2–12.2); Cloud NGFW and Prisma Access not affected.
- **Mitigation:** Upgrade to the fixed release; restrict management interface access to trusted internal networks.

### 7. Ahsay AhsayCBS CVE-2026-105133 (improper authentication) and CVE-2026-105134 (command injection)
- **Disclosure date:** Added to CISA KEV 2026-10-14 (federal deadline 2026-10-17).
- **Root cause:** Authentication weakness combined with command injection in the backup server management service.
- **Affected / fixed versions:** See Ahsay advisory.
- **Mitigation:** Upgrade to the latest AhsayCBS; do not expose the management console to the internet.
